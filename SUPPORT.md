### Bug Reports

When reporting bugs, please include:

1. AI Native Gateway version (`/version` endpoint or binary `--version`)
2. Deployment mode (Docker, binary, Kubernetes)
3. Operating system and architecture
4. PostgreSQL and Redis versions
5. Steps to reproduce
6. Expected vs actual behavior
7. Relevant logs (with sensitive information redacted)

### Feature Requests

We welcome feature suggestions! Please:

1. Search existing issues to avoid duplicates
2. Describe the use case and expected behavior
3. Explain why this would benefit the community
4. Consider contributing a pull request

### Security Vulnerabilities

**DO NOT** report security vulnerabilities through public GitHub issues.

Please see our [Security Policy](SECURITY.md) for responsible disclosure.
