# Page des options de filtrage des tours

Maintenance des options du filtre de la liste des tours (valeurs déroulantes pour les projets/clients, etc.).

## Règles de référence

Options = valeurs réellement observées + valeurs saisies manuellement, fusionnées et dédupliquées.

## Comment vérifier les écarts lorsque les chiffres ne concordent pas

- 1. Impossible de filtrer sur un projet donné : son nom apparaît automatiquement s’il n’est pas enregistré et que du nouveau trafic est généré ; il peut aussi être ajouté manuellement.
- Incohérence entre les options et la liste : actualisez le cache des options, puis réessayez.
