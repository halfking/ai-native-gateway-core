# 模型可信度頁資料說明

這一頁檢測「上游是否拿低配模型冒充高配」——俗稱摻水/降智。用四把尺交叉驗證，測不出結論時如實標「證據不足」，不當作沒問題。

## 四種結論

| 結論 | 含義 |
| --- | --- |
| 已驗證 | 多項證據一致，模型貨真價實 |
| 存疑 | 有可疑訊號但不足以定論，建議複查 |
| 滲水 | 有較強證據表明實際交付低於宣稱配置 |
| 證據不足 | 證據太少無法判定（**不等於沒問題**） |

## 四把尺（判定依據）

上游自報身份、同款模型能力對比、請求籤名是否漂移、外部基線校準。

## 口徑說明

- 「已判定節點」按「模型 × 供應商」組合計；同模型不同供應商各自判定。
- 結論以**最近一次檢測**為準；「全量檢測」會重新跑一遍並覆蓋舊結論。

## 數字對不上時怎麼自查

1. 「存疑」多但業務沒異常：存疑不是定罪，是提醒複查；結合完整性監控頁的指紋漂移一起看。
2. 剛測完就變「證據不足」：該組合近期流量太少，取樣不足；有真實流量後再測。
3. 與供應商後臺能力不符：四把尺裡的「能力對比」依賴本平臺實測流量，冷門模型證據天然少。
