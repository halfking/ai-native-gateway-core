# Página de detalles del análisis de clientes

Perfil de uso de un cliente conectado (IDE/CLI/aplicación).

## Criterios de cálculo

Los clientes se agrupan por identificador de integración; las distintas versiones del mismo cliente se consolidan en las estadísticas.

## Cómo comprobar las discrepancias cuando las cifras no coinciden

- 1.El consumo del cliente no coincide con el consumo del usuario: un usuario puede utilizar varios clientes y un cliente puede ser compartido por varios usuarios, por lo que ambas perspectivas no coinciden al cruzarlas.
- Cliente desconocido: las conexiones sin un identificador estándar se agrupan bajo «Desconocido» y no afectan a la medición del consumo.
