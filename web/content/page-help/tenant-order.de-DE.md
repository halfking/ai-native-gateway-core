# Bestelldetailseite

Alle Informationen zu einer Bestellung: Was gekauft wurde, wie viel bezahlt wurde und wie der Status lautet.

## Definitionen und Berechnungsgrundlagen

Statusübergang einer Bestellung = Zahlung ausstehend → bezahlt → abgeschlossen; Erstattungen erfolgen über den ursprünglichen Zahlungsweg.

## So prüfen Sie selbst, wenn Zahlen nicht übereinstimmen

- 1.Bezahlte Bestellung nicht aktualisiert: Die Rückmeldung ist verzögert. Aktualisieren Sie die Seite oder warten Sie kurz; gleichen Sie die Bestellung anhand der Zahlungsbelegnummer ab.
- Bestellbetrag weicht vom Paketpreis ab: Der Betrag enthält die damals gültigen Preisnachlässe; in den Details werden sie separat ausgewiesen.
