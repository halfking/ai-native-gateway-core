# My Usage Page

A self-service usage page for the tenant: request volume, Token usage, and spending trends for this tenant.

## Calculation Methodology

The calculations match those on the platform dashboard, but include only this tenant; days are divided by UTC.

## How to Reconcile Discrepancies

- 1.Different from the invoice: Invoices are issued monthly and include approved adjustments; this page provides a real-time transaction view.
- Two spending figures are shown separately: internal cost and credits. They are not combined.
