# 对话页数据说明

这一页是内置的「试聊窗口」：直接与网关接入的模型对话，也是验证密钥是否可用的最短路径。

## 前提条件

需要一把**属于你且已启用**的 API 密钥。没有密钥时页面会引导先去申请；密钥被停用/过期时对话会失败并提示原因。

## 模型选择

- 选「auto」由网关自动挑合适模型（按路由策略）。
- 手动指定模型时按你的选择走；该模型不可用时本轮对话失败，不影响下一轮。
- **参数变更在下一轮生效**：改温度、换模型都从下一条消息开始用新值，历史消息不变。

## 与统计的对应

- 这里每一轮对话都是真实调用，**会计入用量与费用**——测试也会花钱。
- 对话记录与「请求记录」页一一对应：每轮可在请求记录里查到明细。

## 数字对不上时怎么自查

1. 同一段对话两轮费用差很多：auto 模式每轮独立选模型，可能换了更贵/更便宜的模型。
2. 回答被截断：先看「最大输出长度」设置，再看所选模型的容量上限。
3. 对话失败但密钥页显示正常：确认密钥的额度没耗尽、模型在你密钥的可用范围内。
