# 請求詳情頁資料說明

這一頁展示**一筆請求的完整檔案**：從進閘道器到出答案的全過程與每一項數字。

## 三個區塊

- **基本資訊**：時間、金鑰、模型、狀態、總耗時。
- **過程明細**：各環節（鑑權、選路、上游呼叫、脫敏回填、計量）的耗時與結果。
- **內容與用量**：實際傳送/收到的內容摘要、輸入/輸出文字量、這筆的費用。

## 關鍵口徑

- **總耗時**＝從收到請求到返回完整答案；它包含閘道器處理時間與上游生成時間兩部分，明細裡分開列出。
- **費用**按請求發生時的價格表計算；之後調價不改變歷史請求的這筆費用。
- 內容摘要可能被截斷顯示（保護效能）；完整內容看「檢視全文」。

## 數字對不上時怎麼自查

1. 這筆的費用與模型目錄價「對不上」：先確認請求時間與調價時間——價格按**請求時刻**凍結。
2. 輸入文字量比你自己統計的多：系統計數包含訊息包裝（系統提示、歷史輪次），不只看你打的那句話。
3. 狀態「成功」但使用者說沒收到：閘道器視角的成功是「上游完整返回」；之後客戶端網路斷了屬於鏈路後段問題，看請求的動作時間線確認回包環節。
4. 重試痕跡：一次請求可能內部試了多個候選，最終狀態只記最後一次；過程明細能看到完整嘗試鏈。
