# セッション詳細ページのデータ説明

このページには、**1つの完全な会話**の全体像が表示されます。会話の内容、何往復あるか、各往復の質問と回答内容を確認でき、管理担当者が1回のサービスについて全体像と経緯を完全に把握できます。

## このページで確認できること

- **セッションサマリーバー**：会話のテーマの要約、参加者、往復回数、進行中かどうか。
- **往復タイムライン**：順番に並ぶ各往復の質問と回答。往復ごとに展開すると、全内容を確認できます。
- **往復の要点**：重要な往復から抽出した要約。重要な箇所を素早く特定できます。

## 集計基準

- **1回のセッション**とは、連続した同じ会話を指します。ページ上のすべての数字は**この1回のセッション**のみを対象としており、複数のセッションをまとめて集計することはありません。
- **往復回数**は、質問とその回答の組を1往復として数えます。ユーザーが新しく質問するたびに1往復として記録し、回答が長くてもその往復に含まれます。
- **要約**は、システムが会話全体から自動的に抽出して生成します。セッションが進行中の場合、要約が最新の数往復に追いつかないことがあります。「生成時刻」を基準にしてください。
- **時刻表示**は、サーバーに記録された時刻です。別のタイムゾーンから閲覧する場合も、システム標準時刻（UTCでの日付切り替え）を基準としてください。ローカルタイムゾーンへの変換は行いません。

## 数字が一致しない場合の確認方法

- **往復回数が一覧ページと一致しない場合**：一覧ページでは絞り込み条件が適用されている場合があります。すべての絞り込み条件をクリアしてから照合してください。
- **要約が最新の会話内容と一致しない場合**：進行中のセッションでは要約の生成に時間がかかります。数分待って再読み込みしてください。「生成時刻」が最後の往復より前時刻になっていても異常ではありません。
- **特定の往復を開けない場合**：その往復は、保存保持期間を過ぎて削除されている可能性があります。一覧には表示されていても本文は残っていないことがあり、これは所定の保持方針によるものです。
- **比較する両側に同名のセッションが1件ずつある場合**：同一のセッションかどうかはセッション番号を基準に判断してください。タイトルが似ているだけでは、同じ会話であるとは限りません。
