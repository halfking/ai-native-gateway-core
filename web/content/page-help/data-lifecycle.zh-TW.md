# 資料生命週期頁資料說明

這一頁管理資料的「存放、搬家與清理」：資料庫裡哪些資料佔空間、何時歸檔、怎麼回收。

## 頁籤一覽

- **儲存總覽**：各表佔多大空間、漲得多快。
- **Hot 表遷移 & 分割槽清理**：把高頻寫入的大表按月分格存放，老月份整體歸檔。
- **降級恢復與清理**：聚合資料損壞時從明細重建。
- **儲存配置**：資料庫連線與儲存位置設定。
- **日誌管理**：執行日誌的保留與清理。
- **會話附件 / 大欄位 / 檔案系統**：檔案類資料的佔用與維護。

## 關鍵口徑

- **保留期**＝資料在庫內保留多久；到期的資料進入「可清理」，清理前可預覽影響行數。
- 「可清理」不等於「已刪除」：清理要預覽並手動執行；預覽數字與實際執行之間若有新資料寫入，實際行數會略有出入。
- 表空間佔用先漲後落：整理類操作（回收空間）執行期間磁碟會先翻倍（舊檔案+新檔案並存），結束後才釋放。

## 安全機制

- 所有清理動作都要求先「預覽」再「執行」，兩步分開。
- 歸檔是把資料挪到慢儲存，不是刪除；要恢復資料仍可找回。

## 數字對不上時怎麼自查

1. 佔用數字取自資料庫統計器，與作業系統看到的檔案大小有固定差異（資料庫有內部冗餘空間），量級一致即可。
2. 「可清理」行數隨時間增加是正常現象（資料老化），不是異常增長。
3. 重建/遷移進行中看到的行數波動是中間狀態，以任務完成後的終態為準。
4. 先確認頁籤：同一張表在不同頁籤的口徑不同（總覽看佔用、分割槽頁看行數分佈）。
