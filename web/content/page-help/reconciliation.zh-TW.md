# 對賬報表頁資料說明

這一頁彙總前一天由閘道記錄的用量，可按供應商/租戶/人員/模型等視角核對。它用於核對閘道記錄，不代表供應商帳單或應付金額。

## 歷史請求統計

歷史請求統計讀取非同步更新的請求投影。展開「按天」後，開啟「按日明細」，選擇日期與維度即可翻頁查看。區間篩選適用於明細與匯出。「匯出區間完整明細」包含所選區間與維度的所有資料列。

## 快照怎麼生成

- 每日聚合任務在凌晨生成**前一日**的快照；當天資料要等次日凌晨才有快照，頁面會提示「今日快照次日凌晨生成」。
- 某天沒有快照（如系統當時停機）會用「未聚合」標註；「重跑結束日」可手動補算。已產生的快照也可重新計算，並非永久定稿。

## 兩個金額口徑（不合並）

- **供應商視角金額**：按閘道記錄的終態用量彙總，包含未分配至供應商及非業務流量。金額是閘道記錄的估算值，不是供應商回傳的實際金額，也不代表已確認應付或已支付金額。
- **內部積分 / 內部金額**：只彙總業務流量；積分依快照保存的價格係數換算為金額。這是平臺內部計費口徑，不等同於已開票或已收款金額。
- 只有流量範圍與幣別都相符時，兩種口徑才適合比較；差額不能直接視為毛利。頁面分開列示，不做跨單位合計。

## Token 的四個分項

本頁目前的總 Token 為輸入、輸出、快取讀取與寫入四項之和。快取可能與輸入重疊。按跨報表標準核對時，總 Token 取正規化輸入加輸出，快取讀寫另列。

## 數字對不上時怎麼自查

1. 快照是依當時資料重新計算的彙總：與即時看板數字不同屬正常——即時看板可能包含當天資料；快照可透過重跑更新。
2. 「未聚合」的日期沒有數字：用重跑補算後再對。
3. 按供應商視角與供應商帳單核對時，除時區外也要考慮口徑差異：本頁統計閘道記錄的終態用量，包含未分配及非業務流量；金額是估算，不是供應商帳單金額。供應商帳單也可能按當地時區切日。
4. 失敗請求若有終態用量或費用記錄，也會計入閘道彙總；這不表示供應商已確認收費。
