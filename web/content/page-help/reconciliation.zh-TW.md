# 對賬報表頁資料說明

這一頁是「賬本核對器」：每天凌晨把前一天的流水匯成一頁賬，可按供應商/租戶/人員/模型多個視角核對。

## 快照怎麼生成

- 每日聚合任務在凌晨生成**前一日**的快照；當天資料要等次日凌晨才有快照，頁面會提示「今日快照次日凌晨生成」。
- 某天沒有快照（如系統當時停機）會用「未聚合」標註；「重跑結束日」可手動補算。

## 兩個金額口徑（不合並）

- **供應商成本（美元）**：平臺支付給上游的錢。
- **內部積分 / 內部金額**：平臺向租戶的計費口徑。
- 兩者的差就是平臺的毛利；頁面分開列示，不做跨單位合計。

## Token 的四個分項

入（發給模型的文字量）、出（模型答出的文字量）、快取讀（複用上次的輸入，不重複計費或按折扣計）、快取寫（首次存入快取的輸入）。四個分項相加＝總 Token。

## 數字對不上時怎麼自查

1. 快照是「終賬」：與實時看板數字不同屬正常——快照在次日凌晨凍結，之後不再變化；實時看板包含當天。
2. 「未聚合」的日期沒有數字：用重跑補算後再對。
3. 按供應商視角與供應商後臺賬單核對時，注意時區：本系統按 UTC 切日，供應商賬單可能按本地時區，跨零點的流量歸屬日會不同。
4. 失敗請求也產生少量費用（如上游已計費的半截回答），失敗率高的日子成本與請求數比例會偏高。
