# 会話ユーザーリストページのデータ説明

このページでは「人」単位で使用量を把握します。ユーザーごとに1行表示し、会話数、Token数、費用、よく使うモデルをまとめて示します。

## 各行の項目

ユーザー（表示名/アカウント）、会話数、Token数、費用、成功率、よく使うモデルのTopリスト（行を展開すると確認できます）。

## 会話分析の概要との関係

- 概要ページは全体の集計です。本ページは同じデータソースを**ユーザー単位**で分割したもので、対象期間が同じなら数値を照合できます。
- ランキングページは本ページを並び替えた表示（Top N）です。本ページは全ユーザー一覧であり、検索できます。

## 集計基準

- 「費用」列には2種類の課金基準が並べて表示され、互いに換算されません。
- 会話は「開始者」に帰属します。同じ会話に複数の参加者がいても、その使用量は開始者のアカウントに記録されます。

## 数字が合わない場合の確認方法

1. ユーザー数がシステムユーザー数より多い場合：本ページでは「会話を行ったことがある」ID（システム/サービスアカウントを含む）を集計しています。人員名簿はユーザーリストページで確認してください。
2. 展開した行のモデル別使用量の合計 ≠ 行全体のToken数：展開リストにはTopモデルのみが表示され、使用量の少ないモデルは「その他」に集計されます。
3. 同じ人に2行ある場合：アカウントと表示名の変更により、履歴上は別のユーザーとして扱われます。使用量はアカウント単位で帰属するため、照合時はアカウント列を使用してください。
