# AUTO 路由運營頁資料說明

這一頁是「自動調參」的閉環工作臺：標註 → 統計 → 檔案建議 → 調參審批。系統據此越來越會挑模型，但**每一次生效都要過門禁並經人工批准**。

## 四個頁籤構成一條流水線

- **標註工作臺**：人工給歷史請求標註「效果好壞」，是後續一切統計的原料。
- **標註統計**：標註量的彙總（今日待標註、累計標註、參與人數）。
- **任務畫像**：按任務型別看模型表現，產出「某類任務更適合某模型」的檔案建議。
- **調參審批**：系統提出的引數調整建議在此等待人工批准或駁回。

## 口徑說明

- 「今日待標註」按自然日（UTC）計算；昨天沒標完的會累計到「累計標註」的待辦裡。
- 調參提案有置信度門檻：系統只對有把握的建議發起審批，低置信度的自動擱置，不會打擾審批人。
- 每次調參生效前都有「舊值快照」：批准後若發現效果不對，可以一鍵回退到調整前。

## 數字對不上時怎麼自查

1. 標註數與請求數對不上是正常的：不是每筆請求都需要標註，系統只挑有代表性的抽樣。
2. 提案被駁回不會重複出現同一建議：同族建議會參考歷史審批結論。
3. 調參生效後指標沒變化：引數生效有延遲（熱載入間隔），且效果要在新流量上才體現。
4. 深鏈頁籤不對：本頁四個舊頁面已合併為一頁四頁籤，舊連結會自動跳轉。
