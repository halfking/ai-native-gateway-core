# 密钥列表页数据说明

这一页管理调用网关的「钥匙」：每把密钥代表一个可以发起模型调用的身份。

## 每行字段

- 名称与前缀：密钥的人读标识；完整密钥只在签发那一刻显示一次。
- 状态：见下方四种状态。
- 用量与额度：已消耗量相对配额的比例。

## 四种状态怎么判定

| 状态 | 条件 |
| --- | --- |
| 待激活 | 密钥已签发但尚未完成首次验证 |
| 启用中 | 状态正常 + 未过期 + 未被停用，三者同时满足 |
| 已过期 | 设定了到期时间且已过点 |
| 已吊销 | 被手动停用 |

注意：「启用中」要求三个条件同时成立——只要过期或被停用，即使后台状态字段还是「正常」，页面也会显示「已过期」或「已吊销」。

## 用量统计口径

- 用量数字统计的是**已完成的调用**；进行中的请求不计入。
- 用量数据有短暂延迟：刚发起的调用可能要等片刻才反映到用量里。

## 数字对不上时怎么自查

1. 状态筛选标签页选的是哪一类：页面顶部按状态分页签，切换后列表内容不同。
2. 过期判断以服务器时间为准，本机时钟偏差不影响判定。
3. 系统内置密钥（平台自身使用）会固定出现在列表里，不计入普通统计。
4. 配额与用量来自两个数据源，更新节奏不同：用量准实时、配额改动即时生效；对不上时先刷新页面。
