# Promptインジェクション対策ページのデータ説明

このページでは「越権指示対策」を設定します。ユーザーの入力に混入した「ルール無視／システムへのなりすまし」ような攻撃内容を検出します。

## 3つのタブ

- **ポリシー**：マスタースイッチと実行モード。
- **LLM エンジン**：モデルで二次判定を行うエンジンの設定。
- **検出ルール**：具体的な攻撃特徴のルール一覧。

## 2つの実行モード（重要な違い）

- **監視モード（記録のみ）**：検出結果のみ記録し、リクエストを**一切遮断しない**——まず誤報率を確認し、遮断基準を厳格にするかどうかを決めるために使用します。
- **強制モード**：「重大度マトリクス」に従って処理を実行（許可／手動承認／直接遮断）。承認タイムアウトを 0 に設定すると、無期限に待機します。

## 集計基準

- ルールヒット数は「検出」として数えます。監視モードでのヒットでは**遮断が発生せず**、統計上も強制モードとは別に集計します。
- 重大度マトリクスは「同じヒットを各モードでどう処理するか」を決定します。マトリクスを変更する場合は、両方の列を併せて確認してください。

## 数値が合わない場合のセルフチェック

1. ヒットしたのにリクエストが遮断されていない場合：多くは監視モードです（設計上の動作です）。強制モードに切り替える前に、そのルールの誤報を再確認してください。
2. 誤報が多い場合：ルールごとにヒットしたサンプルを確認します。正常な業務文に「上記の指示を無視」などの表現が含まれることが、誤報の一般的な原因です。マスタースイッチを切るのではなく、該当するルールを調整してください。
3. 強制モードですべてが承認に回される場合：重大度マトリクスで高レベルのすべてが「承認」に設定されています。承認者が対応できない場合、「すべて停止」となります。マトリクスまたは承認タイムアウトを調整してください。
