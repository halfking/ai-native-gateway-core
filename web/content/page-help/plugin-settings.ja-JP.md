# プラグイン設定ページのデータ説明

このページでは、プラットフォームの各「プラグインスロット」で、どの実装を使用するかを設定します（例：ログイン認証には組み込みコンポーネントを使用するか、外部IDサービスを使用するか）。

## 使用方法

- 各プラグインスロットは1枚のカードで表示されます：現在の有効な実装と、選択可能なオプションのドロップダウン。
- **保存後はサービスを再起動 才で反映されます**：このページに保存される設定は構成情報であり、実際の切り替えは次回起動時に行われます——保存が成功しただけでは切り替えられたことを意味しません。

## 設定の参照元

- ページ上部には「設定の参照元」が表示されます：現在の値がデータベースからのものか、環境変数からのものかを説明します。
- 環境変数からの項目は、ページで変更しても環境変数で上書きされます——永続的に切り替えるには、デプロイ環境を変更する必要があります。

## 数値が一致しない場合の確認方法

1. 切り替えた後にログイン動作が変わらない場合：まず、新しい設定でサービスが再起動されているか確認してください。
2. ページに表示された状態が実際と異なる場合：「設定の参照元」を基準にしてください——環境変数の優先順位は、ページに保存された値より高くなります。
3. あるプラグインスロットに選択可能なオプションがない場合：その位置の候補となる実装がまだデプロイされていないため、対応するコンポーネントを先にインストールしてください。
