# 輪次列表頁資料說明

這一頁把模型呼叫按「會話 → 輪次」組織起來：一個會話是一段連續對話，一輪是一問一答。

## 層級關係

- 專案 / 使用者 / 客戶端 / 金鑰是四種歸組視角，同一批會話可以從不同角度去看。
- 展開一個會話，能看到它的每一輪：提問內容摘要、回答摘要、耗時、狀態。

## 「輪次」怎麼算

- 使用者發一次問、模型答一次，計一輪。
- 同一會話裡輪次按時間先後排序。
- 一輪可能包含多次內部模型呼叫（重試、工具呼叫），這些算在這輪之內，不單獨計輪。

## 總結與狀態

- 會話摘要由系統自動生成；「立即總結」是手動觸發重新生成，生成中會顯示進行狀態。
- 錄製不可用時，新會話可能暫時沒有輪次明細，這是採集層面的臨時狀態，不是資料丟失。

## 數字對不上時怎麼自查

1. 這一頁按「會話」聚合、請求記錄頁按「單次呼叫」展開：一筆請求在會話視角可能只是某輪的一部分，兩頁條數天然不等。
2. 篩選維度（專案/使用者/客戶端/金鑰）選得越多，會話越少：清空篩選再對總數。
3. 輪次載入有上限（一次展開取最近 100 輪）：超長會話請縮小時間範圍或翻頁檢視。
