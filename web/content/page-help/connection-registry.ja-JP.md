# 接続登録簿ページ

各上流認証情報の「接続識別情報」を登録します：ノード、復旧タイムライン、状態変更履歴。

## 定義

1つの認証情報につき1行とします。復旧タイムラインには、その認証情報が障害から復旧するまでの各ステップを記録します。

## 数値が一致しない場合のセルフチェック

- 1.認証情報が認証情報監視ページでは正常だが、ここでは異常な場合：両ページの視点が異なります（監視ページはリアルタイムの健全性を、登録簿は履歴アーカイブを確認します）。タイムラインを基準に遡って確認します。
- 復旧タイムラインに欠落がある場合：収集サービスの再起動の隙間では記録を補填しないため、欠落は既知のパターンです。
