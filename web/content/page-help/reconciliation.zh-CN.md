# 对账报表页数据说明

这一页汇总前一天网关记录的用量，可按供应商/租户/人员/模型等视角核对。它用于核对网关记录，不代表供应商账单或应付金额。

## 历史请求统计

历史请求统计读取异步请求投影。展开「按天」，打开「按天明细」，选择一日和一个维度后翻页查看。区间筛选会同时应用于明细和导出。「导出区间完整明细」会包含所选区间及维度的所有行。

浏览器的下载列表会显示导出进度。数据超过 Excel 单张工作表的行数上限时，工作簿会在带编号的续表中保留剩余行。

## 快照怎么生成

- 每日聚合任务在凌晨生成**前一日**的快照；当天数据要等次日凌晨才有快照，页面会提示「今日快照次日凌晨生成」。
- 某天没有快照（如系统当时停机）会用「未聚合」标注；「重跑结束日」可手动补算。已生成的快照也可重算，并非永久定稿。

## 两个金额口径（不合并）

- **供应商视角金额**：按网关记录的终态用量汇总，包含未分配到供应商以及非业务流量。金额是网关记录的估算值，不是供应商返回的实际金额，也不代表已确认应付或已支付金额。
- **内部积分 / 内部金额**：仅汇总业务流量；积分按快照保存的价格系数换算为金额。它是平台内部计费口径，不等同于已开票或已收款金额。
- 两种口径只有在流量范围与币种都匹配时才适合比较；差额不能直接视为毛利。页面分开列示，不做跨单位合计。

## Token 的四个分项

本页当前的总 Token 为输入、输出、缓存读和缓存写四项之和。缓存分项可能与输入重叠。按跨报表标准核对时，总 Token 取归一化输入＋输出，缓存读写单列。

## 数字对不上时怎么自查

1. 快照是按当时数据重算出的汇总：与实时看板数字不同属正常——实时看板可能包含当天数据；快照可通过重跑更新。
2. 「未聚合」的日期没有数字：用重跑补算后再对。
3. 按供应商视角与供应商账单核对时，除时区外还要考虑口径差异：本页统计网关记录的终态用量，包含未分配和非业务流量；金额是估算，不是供应商账单金额。供应商账单也可能按本地时区切日。
4. 失败请求若有终态用量或费用记录，也会计入网关汇总；这不表示供应商已确认收费。
