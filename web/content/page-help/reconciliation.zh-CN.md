# 对账报表页数据说明

这一页是「账本核对器」：每天凌晨把前一天的流水汇成一页账，可按供应商/租户/人员/模型多个视角核对。

## 快照怎么生成

- 每日聚合任务在凌晨生成**前一日**的快照；当天数据要等次日凌晨才有快照，页面会提示「今日快照次日凌晨生成」。
- 某天没有快照（如系统当时停机）会用「未聚合」标注；「重跑结束日」可手动补算。

## 两个金额口径（不合并）

- **供应商成本（美元）**：平台支付给上游的钱。
- **内部积分 / 内部金额**：平台向租户的计费口径。
- 两者的差就是平台的毛利；页面分开列示，不做跨单位合计。

## Token 的四个分项

入（发给模型的文字量）、出（模型答出的文字量）、缓存读（复用上次的输入，不重复计费或按折扣计）、缓存写（首次存入缓存的输入）。四个分项相加＝总 Token。

## 数字对不上时怎么自查

1. 快照是「终账」：与实时看板数字不同属正常——快照在次日凌晨冻结，之后不再变化；实时看板包含当天。
2. 「未聚合」的日期没有数字：用重跑补算后再对。
3. 按供应商视角与供应商后台账单核对时，注意时区：本系统按 UTC 切日，供应商账单可能按本地时区，跨零点的流量归属日会不同。
4. 失败请求也产生少量费用（如上游已计费的半截回答），失败率高的日子成本与请求数比例会偏高。
