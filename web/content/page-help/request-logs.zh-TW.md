# 請求記錄頁資料說明

這一頁是所有模型呼叫的「流水賬」：每一筆請求一行，可以按條件篩選後逐筆檢視。

## 每一行代表什麼

一行 = 一次模型呼叫。包含：呼叫時間、使用的金鑰與模型、狀態（成功/失敗）、耗時、輸入/輸出文字量、這筆的費用。

## 時間視窗的規則

- 可選快捷範圍（最近 1 小時到本月）或自定義起止時間。
- **非預設租戶最多看最近 3 天**：如果選了更寬的範圍，系統自動收窄到 3 天，頁面上會體現為時間選擇器被回撥。
- 預設租戶可用全部範圍，包括近 7 天/本週/本月/今年。

## 常用篩選之間是「並且」關係

同時設定多個篩選條件（時間 + 金鑰 + 模型 + 狀態 + 供應商）時，結果必須同時滿足所有條件，條件越多結果越少。

## 狀態口徑

- 「成功」＝模型正常返回了完整答案。
- 失敗類狀態會細分原因（上游出錯、內容被攔截、超時等）；同一筆請求只歸入一類。

## 數字對不上時怎麼自查

1. 時間窗不一致是最常見原因：這一頁與統計頁的視窗要選同一檔。
2. 設了篩選後看到的是「子集」：清空全部篩選再對總數。
3. 租戶身份影響可見範圍：非預設租戶只能看到自己租戶的請求，且最多 3 天。
4. 這一頁是明細（可逐筆核對），統計頁是彙總（已去重聚合）：抽查時以這一頁為準，對總數時以統計頁為準。
