# Page de détails de l’approbation

Dossier complet d’une approbation individuelle : motif de déclenchement, demande associée, statut actuel et actions possibles.

## Explication des règles

Transition de statut=en attente d’approbation→approuvée/rejetée ; les actions sont journalisées et traçables.

## Comment vérifier en cas d’écart entre les chiffres

- 1.Après approbation, l’effet opérationnel n’est pas visible : l’application peut présenter un délai de quelques secondes ; si plus d’une minute s’écoule, vérifier sur la page de la fonctionnalité correspondante.
- Le contenu de la demande n’apparaît pas dans les détails : le résumé du contenu est masqué selon les droits d’accès ; le contenu complet nécessite des droits plus élevés.
