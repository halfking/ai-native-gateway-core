# 簡易モード概要ページのデータ説明

このページは「ひと目でわかる」版のワークスペースです。全体の状況 + 利用コスト + クイック操作をまとめ、常時監視しない利用者向けに設計されています。

## ページは3つのブロックに分かれています

- **統計カード**：今日のリクエスト数、成功率、コストなどの中核的な数値。
- **システムステータス**：主要なコンポーネントが正常かどうかを、色とテキストで直接示します。
- **直近 7 日間の推移**：日別の棒グラフでリクエスト数の変化を表示します。

## 集計基準

- 統計カードは**本日基準**です（本日 0 時から現在まで、UTC の日付切り替え基準）。
- トレンドグラフとエキスパートダッシュボードは**同一データソース**です。2つのモードで表示される数値に矛盾はありません。
- トレンドグラフには「データのある日」のみ描画されます。新規デプロイ後の第 1 日は棒が 1 本だけになるのが正常であり、根拠のないゼロは描画されません。

## 数字が一致しない場合の確認方法

1. 「今日リクエスト」は UTC の日付切り替えの 0 時に更新されます：北京時間の午前 8 時より前では、グラフの「今日」はまだ前日の最後の枠を示します。
2. 成功率の分母は、すべてのリクエスト（ブロックされたものを含む）です。「成功件数 ÷ 想定していた総数」と一致しない場合は、まずブロックされたリクエストの有無を確認してください。
3. コストは1種類の基準でのみ表示されます。内部コスト（米ドル）と外部クレジットは統合して表示されないため、それぞれ確認してください。
4. システムステータス項目が「正常」と表示されていても、特定のページを開けない場合があります。ステータスチェックで確認するのはコンポーネントの稼働状況であり、それぞれの機能が利用できるかどうかではありません。個別の問題は該当ページの説明を確認してください。
