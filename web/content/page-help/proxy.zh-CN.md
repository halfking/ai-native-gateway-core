# 代理管理页数据说明

这一页管理网关访问上游时走的「代理出口」：订阅来源、节点池、当前用哪个出口。

## 三个页签

- **状态概览**：总览卡（订阅数、节点总数、可拨号/健康数）+ 当前选中出口 + 自动切流状态。
- **订阅管理**：代理订阅源（导入一批节点的链接），可设「地区黑名单」过滤出口。
- **节点管理**：逐个节点的手工登记与维护。

## 关键口径

- **可拨号**＝节点当前能建立连接；**健康**＝连续探测正常的节点。可拨号但反复失败的节点不算健康。
- **自动切流**：当前出口连续失败达到阈值时自动换下一个节点；「连续失败次数」实时累加，成功后清零。
- 「最近主动探测」是系统自己发起的连通性检查时间，不是业务请求时间。

## 数字对不上时怎么自查

1. 节点总数 ≠ 可拨号数：正常现象——总数是登记量，可拨号是当下连通量。
2. 切流后业务仍失败：切流有探测周期，几秒内完成；持续失败看「连续失败次数」是否还在涨。
3. 订阅更新后节点数没变：订阅源内容可能相同；对比更新前后节点的指纹而不是数量。
4. 黑名单地区不生效：地区代码要按节点上报的地区值精确匹配（大小写敏感），配错写法不会报错但不会过滤。
