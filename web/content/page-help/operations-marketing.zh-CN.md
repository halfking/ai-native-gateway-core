# 营销管理页数据说明

这一页管理四类营销工具：套餐、加油包、优惠码、活动。

## 四个页签

- **套餐**：月包的定义（含多少订阅额度、什么价）。
- **加油包**：一次性购买的额外额度包。
- **优惠码**：客户兑换后获得折扣或积分的码。
- **活动**：限时的折扣/赠送策略（草稿 → 生效 → 结束）。

## 生效规则

- **折扣型活动**：租户领取后，下一张订单自动按比例折减；用完即止。
- **赠送型活动**：领取即发放积分，立刻到账。
- 活动「草稿」不影响任何订单；「生效」后对领取过的租户生效；「结束」后不可再领取，已领取的权益按各自规则继续用完。

## 数字对不上时怎么自查

1. 优惠码「已领取 N 次」但订单没打折：折扣只作用于领取后的**下一张**订单；更早订单不受影响。
2. 赠送积分没到账：确认活动状态是「生效」而非「草稿」，且该租户在领取名单里。
3. 套餐价格与卖价页不一致：套餐是「打包价」，与按 Token 计费的标价是两套体系；套餐用户按套餐扣额度，不逐 Token 扣钱。
