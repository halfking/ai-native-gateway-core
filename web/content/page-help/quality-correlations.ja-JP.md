# 品質関連分析ページのデータ説明

このページでは「回答品質に影響する要因」を確認できます。リクエスト特性（プロンプト長、画像の有無、コードの有無、ツール呼び出し回数）と回答品質スコアとの統計的な関連を测算します。

## コアセクション

- **品質予測因子**（相関係数テーブル）：各特性と品質的相关の強さ（|r| が大きいほど予測力が高くなります）。
- **バケット比較**：リクエスト的特性値ごとにグループ化（例：プロンプト長を5段階に分割）し、各グループの平均品質、成功率、レイテンシを確認できます。

## 集計基準

- 品質スコアは、回答に対するシステムによる自動評価（複数次元を統合したもの）であり、ユーザーによる評価ではありません。
- 相関係数（Pearson r）の範囲は -1 ~ +1：正の値＝特性が大きいほど品質が高い、負の値＝特性が大きいほど品質が低い、0に近い＝関連がない。
- バケットには品質スコアのあるリクエストのみを集計します。評価対象外のリクエストは分母に含めません。

## 数字が合わない場合の確認方法

1. 関連は強いものの業務的な意味が合わない場合：関連には共通の原因がある可能性があります（例：「画像付きリクエストがすべて特定のサプライヤーだった」など）。バケット別の明細と併せて確認してください。
2. バケットの合計リクエスト数 < ページ全体の総リクエスト数：未評価のリクエストはバケットに含まれないため、差額が「未評価」の部分です。
3. 同じ特性について2回確認した r の値が異なる場合：集計期間が異なるためです。r は期間の影響を受けやすいため、比較時は同じ期間に固定してください。
