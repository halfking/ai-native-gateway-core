# 外掛配置頁資料說明

這一頁選擇平臺各「外掛位」用哪個實現（例如登入認證用內建元件還是外部身份服務）。

## 使用方式

- 每個外掛位一張卡片：當前生效的實現 + 可選項下拉。
- **儲存後需重啟服務才生效**：頁面儲存的是配置，切換髮生在下次啟動時——儲存成功不代表已切換。

## 配置來源

- 頁面頂部顯示「配置來源」：說明當前值來自資料庫還是環境變數。
- 來自環境變數的項在頁面上改了也會被環境覆蓋——要永久切換需改部署環境。

## 數字對不上時怎麼自查

1. 切換後登入行為沒變：先確認服務已按新配置重啟過。
2. 頁面顯示的狀態與實際不符：以「配置來源」為準——環境變數優先順序高於頁面儲存值。
3. 某外掛位沒有可選項：該位置的候選實現未部署，先完成對應元件安裝。
