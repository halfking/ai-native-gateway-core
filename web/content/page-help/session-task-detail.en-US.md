# Task Analysis Details Page

A usage and quality profile for a category of tasks (grouped by task type).

## Metric Definitions

Task types are automatically categorized by the agent; incorrectly categorized samples can be manually corrected.

## How to Self-Check When Numbers Don't Match

- 1. Task total ≠ total sessions: Uncategorized sessions are included under “Other”; classification coverage improves as more samples are annotated.
- Quality scores differ from those on the Quality Correlation page: This page aggregates by task type, while that page groups data into feature buckets.
