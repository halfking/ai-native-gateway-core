# Page de conformité des réponses

Vérifiez que les réponses du modèle ne franchissent pas les limites de conformité (contenu sensible, exigences de format).

## Explication des critères

Chaque contrôle est classé « conforme/violation » selon la règle ; les enregistrements de violations incluent l’extrait déclencheur (affiché expurgé).

## Comment s’auto-évaluer lorsque les chiffres ne concordent pas

- 1. Le nombre de violations et le nombre de blocages diffèrent : une violation est « consignée » ; le blocage dépend de la stratégie, et le mode observation consigne sans bloquer.
- Plusieurs violations pour un même segment de contenu : chaque règle est déclenchée indépendamment ; examinez les résultats séparément selon la règle.
