# 錯誤智慧分析頁資料說明

這一頁用 AI 幫你分析「請求為什麼失敗」：把錯誤佇列裡的失敗逐個（或批次）交給智慧體分析，產出原因判斷與修正建議。

## 兩個頁籤

- **錯誤佇列**：待分析的失敗記錄清單（每行一筆失敗請求）。
- **分析結果**：AI 分析產出的結論清單（原因分類、依據、建議）。

## 頂部六張卡的口徑

- 總數 / 待分析 / 已分析 / 失敗：來自**錯誤佇列**的統計（佇列域）。
- 誤報率 / 平均耗時：來自**分析結果**的統計（結果域）。
- 三張卡與另外三張卡的統計範圍不同，加總沒有意義——頁面按域分組展示。

## 修正建議的落地方式

- AI 給出的建議（改規則/調級別/改匹配式）需要**人工批准**才生效；批准時有置信度門檻，低置信建議會被攔下要求複核。
- 每次落地都留「舊值快照」，可一鍵回退。

## 數字對不上時怎麼自查

1. 佇列條數與請求記錄頁失敗數不同：佇列只收**納入分析範圍**的失敗型別；被前置攔截（如鑑權失敗）的請求不進佇列。
2. 「已分析」但結果頁找不到：分析產出有短暫落庫延遲；重新整理後再看。
3. 同一錯誤反覆出現：同一模式的錯誤會合並分析；佇列裡顯示的是代表樣本。
