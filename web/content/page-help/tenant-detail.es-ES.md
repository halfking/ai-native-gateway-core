# Página de detalles del tenant

Ficha de administración de un tenant individual: panorama completo de miembros, claves, cuotas y consumo.

## Criterios de cálculo

La cuota = suscripción + monedero; ambos fondos se muestran por separado; el consumo se calcula de forma aislada para cada tenant.

## Cómo comprobar las discrepancias en los números

- 1.El consumo en los detalles ≠ el panel general: el panel general incluye el consumo interno del tenant predeterminado; para la cuenta del tenant, los detalles son la fuente de referencia.
- La lista de miembros es distinta de la página de usuarios: aquí solo se enumeran los miembros de este tenant, mientras que la página de usuarios muestra a todos los usuarios.
