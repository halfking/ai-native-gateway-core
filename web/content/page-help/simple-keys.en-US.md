# Simple Key Issuance Page

A minimal page for issuing keys in two steps: enter a name → issue the key.

## Definitions

Issued keys are ready to use; go to the Full Key page for advanced configuration (quota/expiration/model restrictions).

## How to Self-Check When Numbers Do Not Match

- 1.Cannot find the key you just issued: the full list is on the Key List page; this page only handles key issuance.
- To add a quota limit after issuance, find the key on the Key List page and edit it.
