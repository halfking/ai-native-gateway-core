# Page de détail du tenant

Profil de gestion d’un tenant : membres, clés, quotas et vue d’ensemble de l’utilisation.

## Explication des règles de calcul

Quota = abonnement + portefeuille : les deux pools sont affichés séparément ; l’utilisation est calculée de façon isolée par tenant.

## Comment vérifier les écarts lorsque les chiffres ne concordent pas

- 1.Utilisation détaillée ≠ tableau de bord global : le tableau de bord global inclut la consommation interne du tenant par défaut ; pour le compte du tenant, les données détaillées font foi.
- La liste des membres diffère de la page des utilisateurs : ici, seuls les membres de ce tenant sont répertoriés, tandis que la page des utilisateurs recense tous les utilisateurs.
