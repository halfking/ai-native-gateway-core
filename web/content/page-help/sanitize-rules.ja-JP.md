# マスキング規則ページのデータ説明

このページでは、「機密情報ブロッカー」のルールライブラリを管理します。モデルに送信される内容のうち、どのパターンを置換／マスクするか（電話番号、身分証明書番号、キー文字列など）を設定します。

## 2つのタブ

- **ルール**：ルール一覧（各ルールで、1つの機密パターンの検出方法と置換方法を定義します）。
- **検知とレビュー**：実際のブロック記録（どのリクエストのどの位置でどのルールが検知され、何に置換されたか）。

## ルールが有効になるロジック

- 各ルールは「実行モード」ごとに個別にオン／オフできます。全体の「有効」がマスタースイッチであり、これがオフになるとすべてのルールは無効になります。
- ルール変更は**即時反映**され、以降のリクエストに適用されます。送信済みの過去のリクエストには遡って適用されません。

## 検知記録の集計基準

- 1件のリクエストが複数のルールに一致することがあり、各一致につき1件ずつ記録されます。
- 「レビュー」は人手による確認工程です。置換が妥当か、誤検知かを確認し、ルールを継続的に調整するために使用しますが、完了済みのリクエストには影響しません。

## 数字が合わない場合のセルフチェック

1. 機密情報が明明あるのにブロックされなかった場合：まず全体の「有効」と、対象モードのルールスイッチを確認します。次に、ルールのパターンと実際の内容が一致するか確認してください（一部のルールは特定の形式のみを認識します）。
2. 検知数が想定より多い場合：1つの内容内の複数の箇所がそれぞれ個別にカウントされます。件数を確認するときは、「リクエスト」単位で重複を除いた件数を確認してください。
3. 誤検知が多い場合：「検知とレビュー」でルールごとに集計し、誤検知がどのルールに集中しているかを確認します。全体スイッチをオフにするのではなく、そのルールの一致条件を調整してください。
