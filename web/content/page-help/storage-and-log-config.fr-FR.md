# Page de configuration du stockage et des journaux

Trois résumés en lecture seule : configuration actuelle du système de stockage, de la maintenance du système de fichiers et de la gestion des journaux.

## Explication des règles

Affichage en lecture seule = cette page ne modifie pas la configuration ; les entrées de modification se trouvent sur les sous-pages correspondantes.

## Comment vérifier les écarts entre les chiffres

- 1. La valeur affichée est différente de la variable d’environnement : la variable d’environnement est prioritaire sur la configuration de la bibliothèque ; la source indiquée sur la page fait foi.
- Après une modification, cette page n’a pas changé : elle est mise en cache ; actualisez-la une fois.
