# Detailseite der Client-Analyse

Ein Nutzungsprofil für einen angebundenen Client (IDE/CLI/Anwendung).

## Berechnungsgrundlage

Clients werden nach Integrationskennung gruppiert; bei mehreren Versionen desselben Clients werden die Daten zusammengefasst.

## So prüfen Sie Abweichungen, wenn Zahlen nicht übereinstimmen

- 1.Die clientbezogene und die nutzerbezogene Nutzung stimmen nicht überein: Ein Nutzer kann mehrere Clients nutzen, und ein Client kann von mehreren Nutzern gemeinsam genutzt werden. Die beiden Perspektiven sind daher nicht deckungsgleich.
- Unbekannter Client: Anbindungen ohne Standardkennung werden einheitlich unter „Unbekannt“ erfasst; die Verbrauchsmessung ist dadurch nicht beeinträchtigt.
