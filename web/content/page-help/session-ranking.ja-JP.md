# 会話ランキングページのデータ説明

このページでは、会話分析を3つのランキングに分けています：**誰が利用しているか**（人）、**誰が業務を実行しているか**（エージェント）、**最も多く利用されているもの**（モデル）。

## ランキング表の列

- 会話数 / リクエスト数 / Token 数：それぞれ独立して集計します（会話は重複を除外、リクエストは1件ずつ、Token は累積）。
- コスト：社内コストと外部クレジットの**合計**。高低の相対比較にのみ使用し、金額として解釈しないでください（2種類の単位があります）。
- 成功率 / キャッシュヒット率 / 平均時間：対象の効率指標です。

## 並び替えと時間範囲

- ページ上部で時間範囲を選択します。ランキングは選択した指標に基づいて並び、列ヘッダーをクリックすると並べ替え項目を変更できます。
- 「順位の変化」＝同じ長さの前段时间枠と比べたときの順位の移動。新しく掲載された場合は「新」と表示されます。

## 数字が一致しない場合の確認方法

1. 同じ人物の会話数が2つの画面で異なる場合：ランキングページは選択した時間枠で集計しますが、詳細ページは別の時間枠が既定になっている場合があるため、まず時間範囲を揃えてください。
2. 「コスト」列が請求内容と異なる場合：この列は2種類の集計基準による合計で、比較専用です。照合には必ず照合レポートページを使用してください。
3. 匿名名や表示名が一致しない場合：設定済みの表示名を優先して表示し、ない場合はシステムアカウント名を表示します。名前を変更しても過去データは同じアイデンティティとして集計されるため、2人の人物に分かれることはありません。
4. ランキングの合計 ≠ 概要ページの総数：ランキングには Top のみが表示されます。流量の少ないロングテール対象はランキングに含まれませんが、概要ページにはすべて含まれます。
