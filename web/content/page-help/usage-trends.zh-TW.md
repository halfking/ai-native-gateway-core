# 用量趨勢頁資料說明

這一頁用大圖回答「用量隨時間怎麼變」：可按模型/金鑰/租戶多維拆分，看漲跌、找異常。

## 圖表口徑

- 時間粒度可選「按小時/按天」；按天時以世界標準時（UTC）切零點。
- 平線（零線）有兩種含義要區分：**真零**（確實沒用量）與**沒算出來**（資料來源未就緒）。頁面在資料來源未就緒時明確提示，此時平線不是零。
- 多選模型時曲線是**分別展示**而非疊加；要算合計請用逐日數值相加。

## 篩選之間是「並且」關係

選了時間 + 模型 + 金鑰後再篩選，結果同時滿足全部條件。

## 數字對不上時怎麼自查

1. 與看板數字差一筆：趨勢頁從聚合檢視取數，最近幾分鐘的請求尚未入聚合，以看板實時數為準。
2. 曲線在零點附近「缺一格」：跨 UTC 零點的按天聚合，北京時間的白天對應 UTC 的前一日下午，視窗起點不同屬口徑差異。
3. 拆分維度後總和不等於總曲線：部分請求的維度值缺失（如上游沒返回模型名），它們只進總數不進拆分——頁面會標註未歸類部分的量。
