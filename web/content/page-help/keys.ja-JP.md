# キーリストのデータ説明

このページでは、ゲートウェイの呼び出しに使用する「キー」を管理します。各キーは、モデル呼び出しを実行できるアクセス主体を表します。

## 各行の項目

- 名称とプレフィックス：キーの判別しやすい識別子です。完全なキーは、発行された瞬間にのみ1回表示されます。
- 状態：下記の4つの状態を参照してください。
- 使用量とクォータ：消費量をクォータに対する比率で示します。

## 4つの状態の判定方法

| 状態 | 条件 |
| --- | --- |
| 未有効化 | キーは発行済みですが、初回検証が完了していません |
| 有効 | 状態が正常で、期限切れではなく、無効化もされていない3つの条件をすべて満たしています |
| 期限切れ | 有効期限が設定され、その期限を過ぎています |
| 取り消し済み | 手動で無効化されています |

注意：「有効」にするには3つの条件をすべて満たす必要があります。期限が切れている場合や無効化されている場合は、バックエンドの状態項目が「正常」のままでも、ページには「期限切れ」または「取り消し済み」と表示されます。

## 使用量の集計基準

- 使用量の数値は**完了した呼び出し**をカウントしています。進行中のリクエストは含めません。
- 使用量データには短い遅延があります。直ちに開始した呼び出しは、少し待ってから使用量に反映される場合があります。

## 数値が一致しない場合の確認方法

1. 状態フィルターのタブで選択している種類を確認してください。ページ上部には状態別のタブがあり、タブを切り替えると一覧の内容が変わります。
2. 期限切れの判定はサーバー時刻を基準とするため、ローカル端末の時刻にずれがあっても判定には影響されません。
3. システム内蔵のキー（プラットフォーム自体の使用用）は常に一覧に表示され、一般の統計には含まれません。
4. クォータと使用量は別々のデータソースから取得されるため、更新タイミングも異なります。使用量はほぼリアルタイムで更新され、クォータの変更は即時に反映されます。数値が一致しない場合は、まずページを更新してください。
