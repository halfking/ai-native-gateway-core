# Data Notes for the Integration Examples Page

This page is the “How to Integrate” tutorial for developers, covering integration steps, code examples, and configuration for common clients.

## Contents

- **Integration Checklist**: The complete steps from requesting a key to making your first successful call.
- **Code Examples**: Sample calls for the OpenAI-compatible API (ready to copy).
- **Automatic Configuration**: One-click configuration instructions for common clients (IDEs and CLI tools).

## Relationship to the Data Page

This page contains **instructional content only** and no dynamic statistics; the address/key generated by “Automatic Configuration” comes from the identity you are currently signed in with, but the page itself does not count toward your usage.

## Common Questions

1. You follow the example but still get a 401: the key is not enabled, or extra spaces were included when it was copied; check its status in the key list first.
2. A call using the model name in the example fails: the example uses a generic name, so replace it with one that is actually available in the catalog.
3. Writing the one-click configuration fails: the tool version is too old to support that configuration file format, so copy and paste the configuration manually instead.
