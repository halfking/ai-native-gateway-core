# 對話頁資料說明

這一頁是內建的「試聊視窗」：直接與閘道器接入的模型對話，也是驗證金鑰是否可用的最短路徑。

## 前提條件

需要一把**屬於你且已啟用**的 API 金鑰。沒有金鑰時頁面會引導先去申請；金鑰被停用/過期時對話會失敗並提示原因。

## 模型選擇

- 選「auto」由閘道器自動挑合適模型（按路由策略）。
- 手動指定模型時按你的選擇走；該模型不可用時本輪對話失敗，不影響下一輪。
- **引數變更在下一輪生效**：改溫度、換模型都從下一條訊息開始用新值，歷史訊息不變。

## 與統計的對應

- 這裡每一輪對話都是真實呼叫，**會計入用量與費用**——測試也會花錢。
- 對話記錄與「請求記錄」頁一一對應：每輪可在請求記錄裡查到明細。

## 數字對不上時怎麼自查

1. 同一段對話兩輪費用差很多：auto 模式每輪獨立選模型，可能換了更貴/更便宜的模型。
2. 回答被截斷：先看「最大輸出長度」設定，再看所選模型的容量上限。
3. 對話失敗但金鑰頁顯示正常：確認金鑰的額度沒耗盡、模型在你金鑰的可用範圍內。
