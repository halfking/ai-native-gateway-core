# 會話排行頁資料說明

這一頁把會話分析拆成三個排行榜：**誰在用**（人員）、**誰在幹活**（智慧體）、**什麼被用得最多**（模型）。

## 排行表的列

- 會話數 / 請求數 / Token 數：各自獨立計數（會話去重、請求逐筆、Token 累加）。
- 花費：內部成本與外部積分的**合計**，只用於相對比較高低，不能當金額讀（兩種單位）。
- 成功率 / 快取命中率 / 平均時長：該物件的效率指標。

## 排序與時間窗

- 頁面頂部選時間範圍；排行按所選指標排序，點列頭可換排序鍵。
- 「排名變化」＝與上一個等長時間窗相比的名次移動；新上榜顯示「新」。

## 數字對不上時怎麼自查

1. 同一個人兩處會話數不同：排行頁按所選視窗聚合；詳情頁可能預設另一個視窗，先對齊時間。
2. 「花費」列與賬單不符：該列是兩口徑合計僅供比較；對賬務必用對賬報表頁。
3. 匿名/顯示名不一致：優先顯示設定的顯示名，無則顯示系統賬號名；改名後歷史資料按同一身份聚合，不會分裂成兩人。
4. 榜單合計 ≠ 總覽頁總數：榜單展示 Top 名單；小流量長尾物件不入榜，總覽頁含全部。
