# 会話ページのデータについて

このページは組み込みの「テストチャットウィンドウ」です。ゲートウェイに接続されたモデルと直接チャットでき、キーが利用可能かを確認する最も短い手順です。

## 前提条件

**あなたが所有し、有効化されている** API キーが必要です。キーがない場合は、先に申請するようページが案内します。キーが無効化されているか期限切れの場合、チャットは失敗し、理由が表示されます。

## モデルの選択

- 「auto」を選ぶと、ゲートウェイがルーティングポリシーに従って適切なモデルを自動的に選択します。
- 手動でモデルを指定すると、その選択が使用されます。指定したモデルが利用できない場合、そのターンのチャットは失敗しますが、次のターンには影響しません。
- **パラメータの変更は次のターンから反映されます**：温度やモデルを変更した場合、次のメッセージから新しい値が使用され、過去のメッセージは変更されません。

## 統計との対応

- このページでの各ターンは実際の呼び出しであり、**使用量と費用に計上されます**——テストにも費用がかかります。
- 会話履歴は「リクエスト記録」ページと1対1に対応しており、各ターンの詳細をリクエスト記録で確認できます。

## 数字が一致しない場合のセルフチェック

1. 同じ会話の2ターン間で費用が大きく異なる場合：auto モードでは各ターンで独立してモデルを選択するため、より高価または安いモデルに変わっている可能性があります。
2. 回答が途中で切れている場合：まず「最大出力長」の設定を確認し、次に選択したモデルの容量上限を確認してください。
3. チャットに失敗したのに、キーページでは正常と表示されている場合：キーの利用枠を使い切っていないか、モデルがキーで利用可能な範囲にあるかを確認してください。
