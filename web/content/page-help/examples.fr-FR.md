# Explication des données de la page d’exemple d’intégration

Cette page est la page pédagogique « Comment s’intégrer » : elle présente aux développeurs les étapes d’intégration, des exemples de code et les configurations courantes des clients.

## Composition du contenu

- **Liste des étapes d’intégration** : toutes les étapes, de la demande de clé à la réussite du premier appel.
- **Exemples de code** : exemples d’appels à l’API compatible OpenAI (pouvant être copiés).
- **Configuration automatique** : instructions de configuration en un clic des clients courants (IDE, outils CLI).

## Relation avec la page de données

Cette page est **purement pédagogique** et ne contient aucune statistique dynamique ; l’adresse/la clé générée par la « Configuration automatique » provient de l’identité avec laquelle vous êtes actuellement connecté, mais la page elle-même ne consomme aucun quota.

## Questions fréquentes

1. L’appel按照 l’exemple renvoie encore 401 : la clé n’est pas activée ou des espaces ont été copiés avec elle ; vérifiez d’abord son statut dans la liste des clés.
2. Le nom du modèle dans l’exemple échoue : il s’agit d’une formulation générique ; remplacez-le par un modèle réellement disponible dans le catalogue.
3. L’écriture de la configuration en un clic échoue : la version de l’outil est trop ancienne pour prendre en charge ce format de fichier de configuration ; copiez-collez plutôt la configuration manuellement.
