# Help Manual Page Data Notes

This page is the platform-wide **complete documentation manual**: in-depth guides for installation and deployment, day-to-day operations, and troubleshooting.

## Differences from the “?” in the Upper-Right Corner

- The “?” in the upper-right corner: a quick reference to the **current page**’s data definitions (which numbers this page covers and how they are calculated).
- This page: a **cross-page** complete manual (how to install, configure, and troubleshoot).

The two complement each other: use the “?” to look up what a number means; use this page to find out how to do something.

## Usage Tips

- The search box at the top supports full-text search; the table of contents lets you jump to sections.
- There is a copy button in the upper-right corner of code blocks, making it easy to copy commands.

## Content Freshness

The manual is updated with each release; if you find that the manual does not match the page’s actual behavior, follow the page’s actual behavior and notify the administrator so the manual can be updated.
