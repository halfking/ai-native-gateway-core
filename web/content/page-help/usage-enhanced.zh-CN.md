# 用量增强分析页数据说明

汇总、成本归因、缓存经济和热门 API Key 使用 `request_metrics`，共用所选日期范围。环比卡比较本月和上月两个自然月。

## 核心卡片

- **总成本（美元）**取时间窗内记录为 USD 的请求成本，内部积分单列。
- **总请求**按租户和请求标识计数，采用请求最新事实版本。
- **环比变化**比较当前自然月与上一个自然月。

## 口径说明

- 缓存命中率按可确认计量口径的输入 Token 计算。缓存或压缩节省额需要合同费率或账单明细。
- 环比按自然月汇总已投影的 USD 成本。本月仍在累计，上月成本为零时没有有效的百分比基准。

## 数字对不上时怎么自查

1. 将选定日期范围与看板的时间窗和流量范围对齐。环比卡始终使用两个自然月。
2. 对拍成本时纳入未归类分组和「其他」。热门 API Key 仅展示排行中的密钥。
3. 核对请求投影的刷新进度。显示降级时，该数据源暂不可用。
