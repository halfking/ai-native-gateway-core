# 用量增强分析页数据说明

这一页并列展示五个接口返回的用量指标：汇总、成本趋势、月度对比、缓存经济和热门 API Key。它们不是同一张表或同一时间窗口的重复统计。

## 核心卡片

- **总成本（美元）**：时间窗内支付给上游的费用合计。
- **总请求**：同窗请求笔数。
- **环比变化**：当前窗口与上一个等长窗口的对比百分比。
- 明细拆解：按模型/密钥/日等维度列出贡献占比。

## 口径说明

- 页面组合五个独立接口。汇总与热门 API Key 按天数查询；成本趋势与缓存经济按所选日期范围查询；环比卡比较当前自然月与上一个自然月。各项数据源和窗口不同，不能假定与看板或彼此逐项相等。
- 环比接口按自然月汇总上游美元成本，并计算（当月成本－上月成本）÷上月成本。接口不校验两个月是否完整；上月成本为零时变化率为 0，不能据此认定两月数据完整或用量没有变化。

## 数字对不上时怎么自查

1. 比较环比卡与日期范围内的其他指标时，先注意环比卡固定比较当前月和上月；它不跟随页面选择的起止日期。
2. 成本趋势按维度取数；缺失维度会归为「unknown」，长尾分组可能合并为「其他」。它与汇总卡的请求范围、来源或窗口不完全一致时，合计可能不同。
3. 汇总及热门 API Key 使用天数窗口，成本趋势与缓存经济使用所选日期范围；窗口边界、数据刷新和当前日仍在变化都可能造成差异。部分接口若显示降级提示，其零值或空结果不是实际零用量。
