# Anfrageregister-Seite

Das vollständige Anfrageregister (eine tiefer gehende Archivsicht als auf der Seite mit Anfrageaufzeichnungen, einschließlich noch nicht abgeschlossener Anfragen).

## Begriffsdefinition

Ein Registereintrag wird erfasst, sobald die Anfrage das Gateway erreicht (auch wenn sie später fehlschlägt oder unterbrochen wird); die Seite mit Anfrageaufzeichnungen legt den Schwerpunkt auf gut lesbare Details.

## So prüfen Sie Abweichungen bei den Zahlen selbst

- 1. Die Anzahl der Einträge im Anfrageregister ist größer als auf der Seite mit Anfrageaufzeichnungen: Das Register enthält „nicht abgeschlossene“ Anfragen, während die Aufzeichnungsseite nur gut lesbare Details anzeigt.
- Zwei Registereinträge für dieselbe Anfrage: Die Hauptanfrage und ein interner Wiederholungsversuch werden jeweils separat erfasst und anhand der Hauptanfrage-ID zusammengefasst.
