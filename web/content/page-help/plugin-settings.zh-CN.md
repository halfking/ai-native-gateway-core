# 插件配置页数据说明

这一页选择平台各「插件位」用哪个实现（例如登录认证用内置组件还是外部身份服务）。

## 使用方式

- 每个插件位一张卡片：当前生效的实现 + 可选项下拉。
- **保存后需重启服务才生效**：页面保存的是配置，切换发生在下次启动时——保存成功不代表已切换。

## 配置来源

- 页面顶部显示「配置来源」：说明当前值来自数据库还是环境变量。
- 来自环境变量的项在页面上改了也会被环境覆盖——要永久切换需改部署环境。

## 数字对不上时怎么自查

1. 切换后登录行为没变：先确认服务已按新配置重启过。
2. 页面显示的状态与实际不符：以「配置来源」为准——环境变量优先级高于页面保存值。
3. 某插件位没有可选项：该位置的候选实现未部署，先完成对应组件安装。
