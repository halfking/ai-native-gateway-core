# 運維總覽頁資料說明

這一頁是多部署點的「全域性指揮板」：中心服務、各區域、部署節點、資料面健康一屏看完。

## 四個區塊

- **中心例項**：中心服務的執行狀態與版本。
- **區域分佈**：按地域看部署點的分佈與狀態。
- **部署節點**：最近部署記錄（時間、版本、結果）。
- **資料面**：核心資料表的規模與健康。

## 狀態口徑

- 節點狀態由該節點定期上報；「離線」＝超過上報週期沒有訊息，可能是節點停了，也可能是網路斷了。
- 版本號以節點自己上報為準；同一區域出現多個版本屬滾動升級的中間狀態。

## 時效說明

- 本頁資料按固定週期輪詢重新整理（不是秒級實時）；剛完成的部署要等下一輪重新整理才出現。
- 「最近 N 條」的 N 是頁面擷取上限，不是全部歷史；完整歷史到部署管理裡查。

## 數字對不上時怎麼自查

1. 先確認查詢時刻：本頁與節點本機看到的狀態之間有輪詢間隔。
2. 區域合計與節點逐條相加不等：部分節點未上報時按「未知」處理，不計入區域合計。
3. 版本不一致不一定是故障：滾動升級期間新舊版本並存是預期行為，升級完成後應收斂為一個版本。
