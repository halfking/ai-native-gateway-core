# 詳細な使用量分析ページのデータ説明

このページでは、5つのインターフェースから取得した使用量データを、総合ビューにまとめています。総費用、総リクエスト数、前期間比の変化、内訳を1画面で確認できます。

## コアカード

- **総コスト（ドル）**：選択した時間範囲内に上流プロバイダーへ支払った費用の合計。
- **総リクエスト数**：同じ期間内のリクエスト件数。
- **前期間比の変化**：現在の期間と、同じ長さの直前の期間を比較した変化率。
- 内訳：モデル/キー/日などの次元別に、寄与度の割合を一覧表示します。

## 集計基準

- 本ページのデータは、ダッシュボードと同じデータソースの集計インターフェースから取得しています。数値はダッシュボードと一致するはずです。異なる場合は、まず対象期間をそろえてください。
- 「前期間比」は、両方の期間に完全なデータがある場合のみ表示されます。1日分欠けている場合は「データが不完全」と表示され、その場合の割合は参考値です。

## 数字が一致しない場合のセルフチェック

1. 前期間比の変化が直觉に反する場合（使用量は変わらないのに大きな変化と表示される）：前期間のデータが不完全だと基準値が歪むため、まず前期間のデータの完全性を確認してください。
2. 内訳の合計 ≠ 総カード：次元値が欠けているリクエストは合計にのみ算入されます（ページには「未分類量」と表示されます）。
3. 時間範囲に今日が含まれる場合：今日の数値はリアルタイムで増加しているため、前期間比も継続的に変動します。業務終了後に確認すると、より正確です。
