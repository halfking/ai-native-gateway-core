# 詳細な使用量分析ページのデータ説明

このページでは、5つのAPIの結果（概要、コスト傾向、月次比較、キャッシュ経済性、上位APIキー）を並べて表示します。同じテーブルまたは同じ期間の重複集計ではありません。

## コアカード

- **総コスト（ドル）**：選択した時間範囲内に上流プロバイダーへ支払った費用の合計。
- **総リクエスト数**：同じ期間内のリクエスト件数。
- **前期間比の変化**：現在の期間と、同じ長さの直前の期間を比較した変化率。
- 内訳：モデル/キー/日などの次元別に、寄与度の割合を一覧表示します。

## 集計基準

- 5つの独立したエンドポイントを組み合わせています。概要と上位APIキーは日数指定の期間、コスト傾向とキャッシュ経済性は選択した日付範囲を使い、比較カードは当月と前月の暦月を比較します。データソースと期間が異なるため、ダッシュボードや各項目の数値が一致するとは限りません。
- 比較APIは暦月ごとの上流コスト（USD）を合計し、（当月コスト－前月コスト）÷前月コストを計算します。月全体のデータがそろっているかは検証しません。前月コストが0の場合、変化率は0になりますが、両月のデータが完全であることや利用量に変化がないことを意味しません。

## 数字が一致しない場合のセルフチェック

1. 比較カードと選択した日付範囲の指標を比べる場合、カードは常に当月と前月を比較し、選択した開始日・終了日には連動しない点に注意してください。
2. コスト傾向はディメンション別に集計します。値が欠けている項目は「unknown」にまとめられ、少額の長尾グループは「その他」に統合されることがあります。データソースや期間が完全には一致しない場合、合計も異なることがあります。
3. 概要と上位APIキーは日数指定の期間を使い、コスト傾向とキャッシュ経済性は選択した日付範囲を使います。期間境界、更新タイミング、集計中の当日分が差の原因になります。データ劣化の通知がある場合、0や空の結果は実測ゼロではありません。
