# 请求记录页数据说明

这一页是所有模型调用的「流水账」：每一笔请求一行，可以按条件筛选后逐笔查看。

## 每一行代表什么

一行 = 一次模型调用。包含：调用时间、使用的密钥与模型、状态（成功/失败）、耗时、输入/输出文字量、这笔的费用。

## 时间窗口的规则

- 可选快捷范围（最近 1 小时到本月）或自定义起止时间。
- **非默认租户最多看最近 3 天**：如果选了更宽的范围，系统自动收窄到 3 天，页面上会体现为时间选择器被回拨。
- 默认租户可用全部范围，包括近 7 天/本周/本月/今年。

## 常用筛选之间是「并且」关系

同时设置多个筛选条件（时间 + 密钥 + 模型 + 状态 + 供应商）时，结果必须同时满足所有条件，条件越多结果越少。

## 状态口径

- 「成功」＝模型正常返回了完整答案。
- 失败类状态会细分原因（上游出错、内容被拦截、超时等）；同一笔请求只归入一类。

## 数字对不上时怎么自查

1. 时间窗不一致是最常见原因：这一页与统计页的窗口要选同一档。
2. 设了筛选后看到的是「子集」：清空全部筛选再对总数。
3. 租户身份影响可见范围：非默认租户只能看到自己租户的请求，且最多 3 天。
4. 这一页是明细（可逐笔核对），统计页是汇总（已去重聚合）：抽查时以这一页为准，对总数时以统计页为准。
