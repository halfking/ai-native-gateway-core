# 対帳レポートページのデータ説明

このページでは、前日のゲートウェイ記録上の使用量を、サプライヤー、テナント、担当者、モデルなどの視点で集計します。ゲートウェイ記録の照合に使うものであり、サプライヤーの請求書や確定した支払額を示すものではありません。

## リクエスト履歴の統計

リクエスト履歴の統計には非同期で更新されるリクエスト投影を使用します。日別明細を開き、日付と集計軸を選ぶと、ページを切り替えて確認できます。期間フィルターは詳細表示とエクスポートの両方に適用されます。期間全体のエクスポートには選択した期間と集計軸の全行が含まれます。

ダウンロードの進行状況はブラウザーのダウンロード一覧で確認できます。Excel のワークシートの行数上限を超える場合は、残りの行が連番の付いたシートに保存されます。

## スナップショットの生成方法

- 日次集計ジョブが深夜に**前一日**のスナップショットを生成します。当日分のデータは翌日の深夜までスナップショットがないため、ページには「本日のスナップショットは翌日の深夜に生成されます」と表示されます。
- スナップショットがない日（システムが当時停止していた場合など）は「未集計」と表示されます。「再集計終了日」を指定すると、手動で再計算できます。生成済みのスナップショットも再計算でき、永久に確定したものではありません。

## 2つの金額基準（合算しない）

- **サプライヤー視点の金額**：ゲートウェイが記録した終端状態の使用量の合計です。サプライヤー未割当ての使用量と非業務トラフィックも含みます。金額はゲートウェイ記録に基づく推定値であり、サプライヤーから返された実額でも、確定した支払額・支払済み額でもありません。
- **内部ポイント / 内部金額**：業務トラフィックのみを集計し、スナップショットに保存された価格係数でポイントを金額に換算します。プラットフォーム内部の課金基準であり、請求書の発行や入金を示すものではありません。
- トラフィック範囲と通貨が一致する場合に限り、両者を比較してください。差額をそのまま粗利とはみなせません。金額は別々に表示され、異なる単位の合計は算出されません。

## Token の4つの内訳

このレポートでは現在、入力、出力、キャッシュ読み取り、書き込みの4項目を合計しています。キャッシュ分は入力と重複する場合があります。レポート間の照合では、正規化した入力と出力を合計し、キャッシュの内訳は別に示します。

## 数字が合わない場合の確認方法

1. スナップショットは、その時点で利用可能なデータから計算した集計です。リアルタイムダッシュボードと数値が異なるのは正常です。ダッシュボードには当日分が含まれることがあり、再集計でスナップショットを更新できます。
2. 「未集計」の日付には数値がありません。再集計で再計算してから、もう一度照合してください。
3. サプライヤー視点と請求書を比較する際は、タイムゾーンだけでなく集計範囲にも注意してください。このページは未割当ておよび非業務トラフィックを含む、ゲートウェイ記録上の終端状態の使用量を合計した推定値です。サプライヤーの請求額ではありません。請求書では UTC と異なる現地時間で日付を区切ることもあります。
4. 終端状態の使用量または費用が記録された失敗リクエストは、ゲートウェイ集計に含まれます。これだけでサプライヤーが請求を確定したことにはなりません。
