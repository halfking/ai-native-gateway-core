# Work Types Page

Manage the task classification system: define task types and identify keywords.

## Definition

Identification chain = Request → Intent → Work Type; keywords determine classification accuracy.

## How to Self-Check When Numbers Do Not Match

- 1.Inaccurate classification: Add identification keywords for that type, or correct the sample in the annotation workspace.
- Type distribution differs from the Statistics page: Statistics reflects final classifications, while the distribution on this page includes intermediate states that have not been finalized.
