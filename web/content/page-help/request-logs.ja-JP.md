# リクエスト記録ページのデータ説明

このページは、すべてのモデル呼び出しの「台帳」です。各リクエストが1行に 표시され、条件で絞り込んだ後、1件ずつ確認できます。

## 各行が表す内容

1行 = 1回のモデル呼び出しです。含まれる項目：呼び出し時刻、使用したキーとモデル、ステータス（成功/失敗）、所要時間、入力/出力文字数、このリクエストの費用。

## 時間範囲のルール

- 期間選択のプリセット（過去1時間～今月）または任意の開始・終了時刻を選べます。
- **デフォルト以外のテナントでは最大3日間のみ閲覧可能**：より広い範囲を選択した場合、自動的に3日間に絞り込まれ、ページ上でも時間セレクターの起点が3日前まで引き戻されます。
- デフォルトのテナントは、过去7日間／今週／今月／今年など、すべての範囲を利用できます。

## 複数の絞り込み条件は「かつ」の関係

複数の絞り込み条件（時間 + キー + モデル + ステータス + プロバイダー）を同時に設定した場合、表示結果はすべての条件を満たす必要があります。条件が多いほど結果は少なくなります。

## ステータスの判定基準

- 「成功」＝モデルが完全な回答を正常に返した状態。
- 失敗系のステータスは原因ごとに分類されます（上流側のエラー、コンテンツがブロックされた、タイムアウトなど）。同じリクエストは1つのカテゴリにのみ分類されます。

## 数字が一致しない場合の確認方法

1. 最も多い原因は時間範囲の不一致です。このページと統計ページの時間範囲を同じ設定にしてください。
2. 絞り込み後に表示されるのは「サブセット」です。すべての絞り込み条件を解除してから、合計件数と比較してください。
3. テナントによって閲覧可能な範囲が変わります。デフォルト以外のテナントは、自テナントのリクエストのみを最大3日間確認できます。
4. このページは明細（1件ずつ確認可能）、統計ページは集計（重複排除後に集計）です。サンプリング確認ではこのページを、合計件数の確認では統計ページを基準にしてください。
