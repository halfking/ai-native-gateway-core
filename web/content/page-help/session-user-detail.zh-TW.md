# 會話使用者詳情頁資料說明

這一頁看**一個人**的完整使用畫像：他的會話、專案、任務、常用模型與花費趨勢。

## 內容構成

- **概要卡**：會話數、Token、花費、成功率、快取命中率、平均時長。
- **趨勢區**：該使用者所選視窗內的會話/花費逐日曲線。
- **明細表**：按專案 / 任務 / 智慧體 / 模型拆分的用量行。

## 口徑說明

- 所有數字只統計**該使用者發起**的會話；協作參與（別人的會話裡他出現）不計入。
- 「花費」兩口徑並存展示；「排名」卡顯示該使用者在全體排行中的位置與較上期的變化。

## 數字對不上時怎麼自查

1. 詳情合計 ≠ 列表頁該行數字：先對齊兩頁的時間範圍（詳情頁頂部有自己的範圍選擇）。
2. 專案/任務明細合計 ≠ 概要總量：未歸類到專案/任務的會話只進總量；明細表底部有「未歸類」行時以它解釋差額。
3. 「排名變化」方向反了：變化以**排名序位**計（升=名次變好），不是數值增減。
