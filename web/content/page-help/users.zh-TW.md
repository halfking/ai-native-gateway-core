# 使用者列表頁資料說明

這一頁管理能登入使用本平臺的人員賬號。

## 每行欄位

賬號名、角色、狀態（啟用/停用）、所屬租戶、最近活躍時間。

## 角色與可見範圍

- 角色決定這個人登入後能看哪些頁面：管理員看全部，租戶管理員只看自己租戶。
- 「停用」的賬號無法登入，但歷史用量與請求記錄仍保留並可查。

## 「最近活躍」口徑

- 取這個人**最後一次登入或最後一次呼叫**中較新的時間。
- 顯示「很久以前」不代表賬號異常：可能只是這段時間沒用。

## 數字對不上時怎麼自查

1. 使用者數與租戶裡配置的席位數不等：席位是授權概念，列表是實際賬號；多餘賬號可能來自試用或歷史遺留。
2. 兩個同名賬號：賬號以唯一 ID 區分，重名不影響計費與統計；改名不會合並歷史資料。
3. 剛停用仍顯示活躍：狀態即時生效，但「最近活躍」停在停用前的時刻，屬正常。
