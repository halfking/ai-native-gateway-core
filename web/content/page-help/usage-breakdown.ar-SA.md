# ملاحظات بيانات الاستخدام حسب البُعد

ترتّب قائمة العمليات الأبعاد باستخدام بيانات لوحة المعلومات. تعرض صفحة التفاصيل الإجماليات والاتجاهات والتفصيل بحسب النموذج أو المورّد أو العميل أو المستأجر المحدد والمدة المختارة.

تعتمد الإجماليات على سجلات الطلبات أولًا وعلى تجميع الدقيقة عند الحاجة. تستخدم الاتجاهات والتفاصيل بيانات مجمّعة بالدقيقة. وحّد النطاق ووقت التحديث قبل مقارنة التكاليف والطلبات والرموز.
