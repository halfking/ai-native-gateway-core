# Paket- und Aufladeseite

Mandanten können selbst kaufen: Stufen von Monatspaketen und Aufladen von Nachladepaketen.

## Bedeutungen

Monatspaket = monatlich zurückgesetztes Abonnementkontingent; Nachladepaket = einmaliges Kontingent, das bis zur vollständigen Nutzung gilt.

## Selbstprüfung bei abweichenden Zahlen

- 1.Kauf abgeschlossen, aber noch nicht gutgeschrieben: Die Zahlungsbestätigung kann sich um einige Minuten verzögern; bei einer Verzögerung anhand der Bestellnummer prüfen.
- Reihenfolge der Verrechnung von Monatspaket und Nachladepaket: zuerst das im Paket enthaltene Abonnementkontingent, danach das Nachladepaket, zuletzt das Wallet-Guthaben.
