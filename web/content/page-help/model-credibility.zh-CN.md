# 模型可信度页数据说明

这一页检测「上游是否拿低配模型冒充高配」——俗称掺水/降智。用四把尺交叉验证，测不出结论时如实标「证据不足」，不当作没问题。

## 四种结论

| 结论 | 含义 |
| --- | --- |
| 已验证 | 多项证据一致，模型货真价实 |
| 存疑 | 有可疑信号但不足以定论，建议复查 |
| 渗水 | 有较强证据表明实际交付低于宣称配置 |
| 证据不足 | 证据太少无法判定（**不等于没问题**） |

## 四把尺（判定依据）

上游自报身份、同款模型能力对比、请求签名是否漂移、外部基线校准。

## 口径说明

- 「已判定节点」按「模型 × 供应商」组合计；同模型不同供应商各自判定。
- 结论以**最近一次检测**为准；「全量检测」会重新跑一遍并覆盖旧结论。

## 数字对不上时怎么自查

1. 「存疑」多但业务没异常：存疑不是定罪，是提醒复查；结合完整性监控页的指纹漂移一起看。
2. 刚测完就变「证据不足」：该组合近期流量太少，采样不足；有真实流量后再测。
3. 与供应商后台能力不符：四把尺里的「能力对比」依赖本平台实测流量，冷门模型证据天然少。
