# Explicación de los datos de las páginas del manual de ayuda

Esta página es el **manual completo de documentación de la plataforma**: instrucciones detalladas sobre instalación y despliegue, mantenimiento diario y resolución de problemas.

## Diferencia con el «?» de la esquina superior derecha de la página

- El «?» de la esquina superior derecha: consulta rápida de los datos de la **página actual** (qué cifras muestra y cómo se calculan).
- Esta página: **manual completo para todas las páginas** (cómo instalar, configurar y resolver problemas).

Ambos son complementarios: consulta el «?» para saber qué significa una cifra; consulta esta página para saber cómo realizar una tarea.

## Consejos de uso

- El cuadro de búsqueda de la parte superior permite buscar en todo el texto; el árbol del directorio permite saltar a una sección.
- Los bloques de código tienen un botón de copia en la esquina superior derecha para copiar los comandos fácilmente.

## Vigencia del contenido

El manual se actualiza con cada versión. Si observas que el manual y el comportamiento de la página no coinciden, prevalece el comportamiento real de la página y debes informar al administrador para que actualice el manual.
