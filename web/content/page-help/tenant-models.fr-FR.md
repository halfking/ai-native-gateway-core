# Page des modèles standard

Catalogue des modèles du point de vue du tenant : modèles et prix mis à disposition pour ce tenant.

## Définition des prix

Le prix indiqué correspond au prix en crédits par million de Token ; il comprend quatre éléments : entrée, sortie, lecture du cache et écriture dans le cache.

## Comment vérifier les écarts entre les chiffres

- 1. Un modèle n’est pas visible : l’administrateur ne l’a pas mis à disposition pour ce tenant ; demandez à l’administrateur de l’activer.
- Le prix diffère de celui affiché dans l’administration : l’administration affiche le coût en dollars, tandis que le côté tenant affiche le prix de vente en crédits. Il s’agit de deux systèmes distincts.
