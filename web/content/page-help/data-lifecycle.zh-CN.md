# 数据生命周期页数据说明

这一页管理数据的「存放、搬家与清理」：数据库里哪些数据占空间、何时归档、怎么回收。

## 页签一览

- **存储总览**：各表占多大空间、涨得多快。
- **Hot 表迁移 & 分区清理**：把高频写入的大表按月分格存放，老月份整体归档。
- **降级恢复与清理**：聚合数据损坏时从明细重建。
- **存储配置**：数据库连接与存储位置设置。
- **日志管理**：运行日志的保留与清理。
- **会话附件 / 大字段 / 文件系统**：文件类数据的占用与维护。

## 关键口径

- **保留期**＝数据在库内保留多久；到期的数据进入「可清理」，清理前可预览影响行数。
- 「可清理」不等于「已删除」：清理要预览并手动执行；预览数字与实际执行之间若有新数据写入，实际行数会略有出入。
- 表空间占用先涨后落：整理类操作（回收空间）运行期间磁盘会先翻倍（旧文件+新文件并存），结束后才释放。

## 安全机制

- 所有清理动作都要求先「预览」再「执行」，两步分开。
- 归档是把数据挪到慢存储，不是删除；要恢复数据仍可找回。

## 数字对不上时怎么自查

1. 占用数字取自数据库统计器，与操作系统看到的文件大小有固定差异（数据库有内部冗余空间），量级一致即可。
2. 「可清理」行数随时间增加是正常现象（数据老化），不是异常增长。
3. 重建/迁移进行中看到的行数波动是中间状态，以任务完成后的终态为准。
4. 先确认页签：同一张表在不同页签的口径不同（总览看占用、分区页看行数分布）。
