# 模型完整性监控页数据说明

这一页盯着「上游交付的答案是否完整、是否被偷换」：替换、截断、空回复、重复、指纹漂移都算完整性异常。

## 两个页签

- **完整性事件**：每条异常一条记录（类型、严重度、涉事模型/供应商、是否已解决）。
- **指纹漂移**：同一模型的「行为指纹」随时间的变化——漂移大说明上游悄悄换了实现。

## 口径说明

- 事件总数 / 未解决 / 严重事件按所选统计窗口计；窗口可改。
- 「严重」＝影响答案正确性或安全的异常（如模型替换）；「截断/空响应」通常为中等。
- 指纹漂移是**相对基线**的比较：基线更新后历史漂移结论会重算。

## 数字对不上时怎么自查

1. 事件数与格式异常页不同：两页关注的异常类型不同（本页管「答案完整性」，那边管「响应格式」），有交叉但不重合。
2. 「未解决」降不下去：需要人工确认处理；与格式异常页一样，自动恢复不自动销案。
3. 指纹突然全部漂移：先查是不是刚更新过基线或切换了统计窗口，再怀疑上游集体改版。
