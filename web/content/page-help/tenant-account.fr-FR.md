# Page Mon compte

Espace de gestion de compte en libre-service pour les tenants : solde, forfait et historique des rechargements.

## Définitions des données

Le solde correspond au portefeuille espèces ; les quotas d’abonnement sont affichés séparément et ne sont pas additionnés.

## Comment vérifier les écarts entre les chiffres

- 1.Après un rechargement, le solde n’a pas changé : le traitement du paiement peut présenter un délai de quelques minutes ; si le crédit n’est toujours pas appeared après le délai prévu, vérifiez-le à l’aide du numéro de référence du paiement.
- Le solde ne correspond pas à la consommation : vérifiez d’abord l’horodatage des données ; les déductions de consommation sont appliquées en temps réel.
