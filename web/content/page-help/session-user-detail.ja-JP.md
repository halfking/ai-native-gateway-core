# セッション利用者詳細ページのデータ説明

このページには、**個人**の完全な利用状況（セッション、プロジェクト、タスク、よく使うモデル、費用の推移）が表示されます。

## 構成内容

- **概要カード**：セッション数、Token、費用、成功率、キャッシュヒット率、平均所要時間。
- **トレンドエリア**：選択した期間内のセッション数／費用の日別推移グラフ。
- **明細表**：プロジェクト / タスク / エージェント / モデルごとに分けた利用量。

## 集計基準

- すべての数値は、**その利用者が開始した**セッションのみを対象とします。共同作業への参加（他人のセッションにこの利用者が現れた場合）は集計されません。
- 「費用」は2つの集計基準を併記しています。「ランキング」カードには、その利用者の全体ランキングでの位置と、前期間からの変化が表示されます。

## 数字が一致しない場合の確認方法

1. 詳細ページの合計 ≠ 一覧ページの該当行の数値：まず両ページの期間範囲を揃えます（詳細ページ上部に独自の期間選択があります）。
2. プロジェクト／タスク明細の合計 ≠ 概要の合計：プロジェクト／タスクに分類されていないセッションは、合計にのみ含まれます。明細表の下部に「未分類」行がある場合は、その行で差額を説明します。
3. 「ランキング変化」の方向が逆の場合：変化は**ランキング順位**を基準に計算します（上昇＝順位が改善）。数値の増減ではありません。
