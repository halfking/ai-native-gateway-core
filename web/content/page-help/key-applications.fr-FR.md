# Page de demande de clé

Centralisez les demandes de clés : demandeur, permissions demandées et décision d’approbation.

## Règles d’application

Chaque demande fait l’objet d’un dossier distinct ; une fois approuvée, une clé est générée automatiquement et le demandeur est averti.

## Comment vérifier en cas d’écart sur les chiffres

- 1. Demande approuvée, mais aucune clé reçue : la clé ne s’affiche qu’une seule fois et doit être réinitialisée après expiration ; la notification a peut-être été placée dans les courriers indésirables.
- Plusieurs demandes de la même personne : chaque demande crée un dossier distinct ; les anciennes ne sont pas fusionnées automatiquement.
