# Page simple de délivrance des clés

Page minimaliste de délivrance de clés en deux étapes : saisir un nom → délivrer la clé.

## Définitions

La clé est utilisable dès sa délivrance ; les paramètres avancés (quota/expiration/restrictions de modèle) se configurent sur la page de gestion complète des clés.

## Comment vérifier les écarts de chiffres

- 1. Vous ne trouvez pas la clé que vous venez de délivrer : la liste complète se trouve sur la page de liste des clés ; cette page gère uniquement la délivrance.
- Pour ajouter une limite de quota après la délivrance : accédez à la page de liste des clés, recherchez la clé et modifiez-la.
