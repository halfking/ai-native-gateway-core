# 利用量トレンドページのデータ説明

このページでは、大きなグラフで「利用量が時間とともにどう変化するか」を確認できます。モデル/キー/テナントごとに多次元で分解し、増減の確認や異常の発見ができます。

## グラフの集計基準

- 時間粒度は「時間別/日別」から選択できます。日別の場合は、世界標準時（UTC）の午前0時で区切ります。
- 横ばいの線（ゼロライン）には、区別すべき2つの意味があります：**実際のゼロ**（利用量がまったくない場合）と**算出されていない**（データソースが未準備の場合）です。データソースが未準備の場合はページに明示され、その場合、横ばいの線がゼロを示すわけではありません。
- モデルを複数選択した場合、曲線は**個別に表示**され、積み上げ表示にはなりません。合計を算出するには、日別の数値を合算してください。

## フィルター同士は「かつ」の関係

時間 + モデル + キーを選択してから追加で絞り込んでも、結果はすべての条件を同時に満たします。

## 数字が一致しない場合のセルフチェック

1. ダッシュボードの数値と1件分ずれる場合：トレンドページは集計ビューからデータを取得するため、直近数分間のリクエストはまだ集計に含まれていません。ダッシュボードのリアルタイム値を基準にしてください。
2. 曲線が0時付近で「1枠だけ欠ける」場合：UTCの0時をまたぐ日次集計では、北京時間の昼間はUTCの前日の午後に該当するため、集計ウィンドウの起点が異なることに起因する集計基準の差です。
3. ディメンション別に分解した合計値が総合曲線と一致しない場合：一部のリクエストにはディメンション値がありません（例：アップストリームがモデル名を返していない場合）。これらは合計にのみ含まれ、内訳には含まれません――ページには未分類部分の量が示されます。
