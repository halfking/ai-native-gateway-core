# 会話分析概要ページのデータ説明

このページは「利用者がどのように利用しているか」を示します：会話数、平均的な長さ、どのタスクが利用されているか、トレンド。

## 主要指標カード

| カード | 意味 | 算出方法 |
| --- | --- | --- |
| 会話総数 | 対象期間内の会話数 | 重複排除でカウント：1つの会話は、含まれる往復回数にかかわらず1回として数えます |
| 平均 Token 数 | 1会話あたりに消費される平均テキスト量 | 全会話の Token 合計 ÷ 会話総数 |
| 平均会話時間 | 1会話あたりの平均継続時間 | 各会話の最初と最後の時刻の差を平均化 |
| 平均往復回数 | 1会話あたりの平均問答回数 | 全往復回数 ÷ 会話総数 |
| 内部コスト（米ドル） | プラットフォームが上流プロバイダーに支払う米ドル建てのコスト | 上流の料金設定に基づいて1件ずつ累積 |
| 外部コスト（クレジット） | テナントに請求するクレジット | プラットフォームの料金設定に基づいて1件ずつ累積 |

**内部コストと外部コストは合算しません**：米ドルとクレジットは単位が異なるため、合算してもビジネス上の意味はありません。ページ上部のトレンドチャートも、両方の単位を別々に表示します。

## トレンドとランキング

- トレンドチャートは日単位に集約（世界標準時 UTC で日付を切り替え）、会話数またはコストの日次変化を表示します。
- 「前期間比」＝現在のウィンドウと、同じ長さの直前のウィンドウを比較したパーセント変化。
- ランキングページ（ユーザー/エージェント/モデル）は選択した指標順に並びます。「コスト」列は両方のコスト口径の合計であり、**相対的な高低の比較専用であり、金額として解釈することはできません**。

## データの鮮度

このページが参照するのは、システムが定期的に集計する「集計スナップショット」で、個別のリクエスト明細ではありません。スナップショットには更新許容時間（約90分）が設定されています。期限を過ぎると、ページに「集計データを更新中」というバナーが表示され、古い数値は返されません。これは保護機能であり、障害ではありません。

## 数字が一致しない場合の確認方法

1. 時間範囲：本ページとリクエスト記録ページのウィンドウが異なるため、数字は一致しません。まず対象期間をそろえてください。
2. スナップショットの遅延：最近のリクエストは、まだ集計スナップショットに含まれていない場合があります。更新後に再確認してください。
3. 集計単位の違い：本ページは「会話」単位で集約しますが、リクエスト記録ページは「1回の呼び出し」単位で展開するため、件数が異なるのは当然です。
4. 重複排除ルール：会話数は会話単位で重複を除いて数えます。同じ会話内の複数の往復は重複して数えません。往復回数は、往復ごとに数えます。
