# Page des coûts d’utilisation

Analyse de l’utilisation sous l’angle des coûts : qui dépense le plus et pour quoi.

## Méthodologie de calcul

Coût = coût amont en dollars ; lors de la ventilation par dimension, les éléments non classés sont isolés.

## Comment vérifier les écarts lorsque les chiffres ne concordent pas

- 1. Divergence avec le rapport de réconciliation : le rapprochement est figé dans un instantané quotidien ; cette page agrège les données en temps réel, y compris les données du jour qui ne sont pas encore facturées.
- Le total de la ventilation ≠ le volume total : les quantités sans dimension sont classées dans « Non classés ».
