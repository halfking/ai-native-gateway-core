# Page du registre des requêtes

Registre de toutes les requêtes (vue d’archive plus fondamentale que celle de la page des enregistrements de requêtes, incluant les requêtes inachevées).

## Explication des règles de comptage

Enregistrement = une entrée est créée dès que la requête entre dans la passerelle (y compris si elle échoue ou est interrompue ultérieurement) ; la page des enregistrements de requêtes privilégie les détails lisibles.

## Comment vérifier les écarts lorsque les chiffres ne concordent pas

- 1. Nombre d’entrées dans le registre > nombre d’entrées sur la page des enregistrements de requêtes : le registre inclut les requêtes « non terminées », tandis que la page des enregistrements n’affiche que les détails lisibles.
- Une même requête génère deux entrées : la requête principale et la tentative interne sont chacune enregistrées une fois, puis regroupées selon l’ID de la requête principale.
