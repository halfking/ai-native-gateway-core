# リクエスト詳細ページのデータ説明

このページには**1件のリクエストに関する完全な記録**が表示されます。ゲートウェイでの受付から回答の返却までの全プロセスと、各項目の数値です。

## 3つのセクション

- **基本情報**：時刻、キー、モデル、ステータス、合計処理時間。
- **処理詳細**：各処理（認証、経路選択、上流サービス呼び出し、脱敏値の反映、使用量計測）の処理時間と結果。
- **内容と使用量**：実際に送信・受信した内容の概要、入力・出力文字数、このリクエストの費用。

## 重要な定義

- **合計処理時間**＝リクエストの受信から完全な回答を返すまで。ゲートウェイの処理時間と上流サービスの生成時間の2つの部分を含み、詳細では分けて記載します。
- **費用**はリクエスト発生時の価格表に基づいて計算されます。その後の価格変更によって、過去のリクエストの費用は変わりません。
- 内容の概要は、パフォーマンス保護のため省略表示される場合があります。全内容は「全文表示」で確認できます。

## 数値が一致しない場合の確認方法

1. このリクエストの費用とモデルカタログの掲載価格が一致しない場合：まずリクエスト時刻と価格改定時刻を確認してください。価格は**リクエスト時刻**に確定します。
2. 入力文字数が自分で数えた値より多い場合：システム上の文字数には、メッセージの包装部分（システムプロンプト、過去の会話履歴）が含まれ、入力された文だけを数えているわけではありません。
3. ステータスは「成功」なのにユーザーから受信していないと報告された場合：ゲートウェイから見た成功は「上流サービスから完全な応答が返された」ことを意味します。その後にクライアントのネットワークが切断された場合は、リンク後段側の問題です。リクエストの処理タイムラインで、応答返却の工程を確認してください。
4. 再試行の記録：1件のリクエストで内部的に複数の候補を試行することがあり、最終ステータスには最後の試行だけが記録されます。処理詳細では、試行の完全なチェーンを確認できます。
