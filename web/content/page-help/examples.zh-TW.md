# 接入示例頁資料說明

這一頁是「怎麼接」的教學頁：給開發者看的接入步驟、程式碼示例與常見客戶端配置。

## 內容構成

- **接入清單**：從申請金鑰到第一次呼叫成功的完整步驟。
- **程式碼示例**：OpenAI 相容介面的呼叫樣例（可複製）。
- **自動配置**：常見客戶端（IDE、CLI 工具）的一鍵配置說明。

## 與資料頁的關係

本頁是**純教學內容**，不含任何動態統計；「自動配置」生成的地址/金鑰來自你當前登入的身份，但頁面本身不消耗用量。

## 常見疑問

1. 照著示例調還是 401：金鑰沒啟用或複製時帶了空格；先到金鑰列表確認狀態。
2. 示例裡的模型名呼叫失敗：示例是通用寫法，模型名要換成目錄裡實際可用的。
3. 一鍵配置寫入失敗：工具版本過舊不支援該配置檔案格式，改用手動複製貼上。
