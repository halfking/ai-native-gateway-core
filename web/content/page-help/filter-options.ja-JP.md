# 絞り込みオプションページ

各一覧ページのフィルターにある選択可能な項目（モデル、キー、テナントなどのドロップダウン内容）を管理します。

## 項目の基準

選択肢のソース = 実際に発生した値 + 手動で管理するホワイトリスト。両方を結合し、重複を除きます。

## 数値が一致しない場合のセルフチェック

- 1.一覧ページで特定の値を絞り込めません。まずここに来て、選択肢が登録されているか確認してください。動的な値はデータに合わせて自動的に表示されます。
- 削除した選択肢が再表示されます。その値を生成する実際のトラフィックがあるためです。削除の影響を受けるのは手動管理部分だけです。
