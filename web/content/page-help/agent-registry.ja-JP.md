# エージェント登録ページ

バックエンドで登録された自動化エージェント（スクリプト／ボット）の一覧で、健康状態と所属を含みます。

## 判定基準

健康＝最近、ハートビートと呼び出し成功があります。オフライン＝ハートビート周期を超えてメッセージがありません。

## 数字が合わない場合の確認方法

- 1.エージェント数はユーザー数とは無関係です。エージェントはサービスアカウントであり、ユーザー席を消費しません。
- 同じエージェントに2件の記録がある場合：インスタンスを再構築するとIDが変わるため、過去の使用量はIDごとに归属于されます。
- 健康でも呼び出しに失敗する場合：健康状態はハートビートとログイン状態のみを確認し、具体的な失敗内容はリクエスト記録で確認します。
