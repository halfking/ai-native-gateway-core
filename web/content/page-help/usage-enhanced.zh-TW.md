# 用量增強分析頁資料說明

這一頁把分散在五個介面的用量資料拼成一張綜合檢視：總費用、總請求、環比變化、明細拆解一屏看完。

## 核心卡片

- **總成本（美元）**：時間窗內支付給上游的費用合計。
- **總請求**：同窗請求筆數。
- **環比變化**：當前視窗與上一個等長視窗的對比百分比。
- 明細拆解：按模型/金鑰/日等維度列出貢獻佔比。

## 口徑說明

- 本頁資料來自與看板同源的聚合介面，數字應與看板一致；不一致時先對齊時間窗。
- 「環比」的兩窗都要有完整資料才顯示；資料缺一天時頁面標註「資料不完整」，此時百分比僅供參考。

## 數字對不上時怎麼自查

1. 環比百分比反直覺（用量沒變卻顯示大變化）：上一視窗資料不完整會讓基線失真，先核對上一窗的完整度。
2. 明細拆解合計 ≠ 總卡片：維度值缺失的請求只進總數（頁面標註未歸類量）。
3. 時間窗含今天：今天的數字還在實時增長，環比會持續變動，收盤後再看更準。
