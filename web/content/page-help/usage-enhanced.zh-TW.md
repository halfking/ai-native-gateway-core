# 用量增強分析頁資料說明

這一頁並列顯示五個介面回傳的用量指標：彙總、成本趨勢、月度比較、快取經濟和熱門 API Key。它們不是同一張表或同一時間視窗的重複統計。

## 核心卡片

- **總成本（美元）**：時間窗內支付給上游的費用合計。
- **總請求**：同窗請求筆數。
- **環比變化**：當前視窗與上一個等長視窗的對比百分比。
- 明細拆解：按模型/金鑰/日等維度列出貢獻佔比。

## 口徑說明

- 頁面組合五個獨立介面。彙總與熱門 API Key 按天數查詢；成本趨勢與快取經濟按所選日期範圍查詢；環比卡比較當前自然月與上個自然月。各項資料來源和視窗不同，不能假設與看板或彼此逐項相等。
- 環比介面按自然月彙總上游美元成本，並計算（當月成本－上月成本）÷上月成本。介面不檢查兩個月份是否完整；上月成本為零時變化率為 0，不能據此認定兩月資料完整或用量沒有變化。

## 數字對不上時怎麼自查

1. 比較環比卡與日期範圍內的其他指標時，先注意環比卡固定比較當月和上月；它不會跟著頁面選擇的起訖日期變動。
2. 成本趨勢按維度取數；缺少維度的資料會歸為「unknown」，長尾分組可能合併為「其他」。來源或視窗不完全一致時，合計可能不同。
3. 彙總與熱門 API Key 使用天數視窗，成本趨勢與快取經濟使用所選日期範圍；視窗邊界、資料更新和當日仍在變動都可能造成差異。若介面顯示降級提示，其零值或空結果不代表實際用量為零。
