# Mi página de cuenta

Centro de cuentas autogestionado por el cliente: saldo, plan e historial de recargas.

## Criterios de cálculo

Saldo = monedero de efectivo; las cuotas de suscripción se muestran por separado y no se combinan.

## Cómo comprobarlo cuando los números no coinciden

- 1.El saldo no cambia después de una recarga: la confirmación del pago puede tardar unos minutos; si no se acredita después de un tiempo de espera, compruébelo con el número de pedido de pago.
- El saldo y el consumo no coinciden: confirme primero el momento de referencia; el consumo se descuenta en tiempo real.
