# リクエスト登録台帳ページ

全リクエストの登録台帳（リクエスト記録ページよりも下層のアーカイブ视角で、未完了のリクエストも含む）。

## 集計基準

登録＝ゲートウェイへ 들어온時点で1件記録（後続の失敗・中断を含む）。リクエスト記録ページは、読みやすい詳細情報を中心としている。

## 数字が合わない場合のセルフチェック

- 1.登録台帳の件数 > リクエスト記録ページの件数：登録台帳には「未完了」のリクエストが含まれ、記録ページには読みやすい詳細情報のみが表示される。
- 同じリクエストが登録台帳に2件ある場合：メインリクエストと内部リトライをそれぞれ1件記録し、メインリクエストIDごとに集計する。
