# 自更新頁資料說明

這一頁管理閘道器自身的版本升級：查最新版 → 提醒 → 管理員確認後安裝。

## 三個狀態

- **未配置版本源**：本節點沒填「去哪裡查新版本」，自動檢查未啟用。
- **版本狀態未知**：查過但沒拿到結論（網路或源不可達）。
- **正常**：已知當前版本與最新版本，可比對。

## 升級流程

1. 「立即檢查更新」向配置的版本源查詢最新版本號。
2. 有新版時生成提醒；**不會自動安裝**。
3. 管理員確認安裝後進入升級流程，完成後服務自動用新版本重啟。

## 口徑說明

- 「當前版本」是**本節點正在執行**的版本；多節點部署時各節點可能版本不同，本頁只看本節點。
- 升級過程服務會短暫重啟：期間請求由其他節點承接（多節點時）或短暫中斷（單節點時）。

## 數字對不上時怎麼自查

1. 剛升級完仍顯示舊版本：頁面快取的版本資訊要重新整理一次才更新。
2. 「最新版本」與官方釋出頁不一致：本頁讀的是**配置的版本源**，與官方源不同步時以配置源為準，先核對版本源地址。
3. 檢查更新一直「未知」：版本源地址不可達，用部署機直接測試該地址連通性。
