# 会话排行页数据说明

这一页把会话分析拆成三个排行榜：**谁在用**（人员）、**谁在干活**（智能体）、**什么被用得最多**（模型）。

## 排行表的列

- 会话数 / 请求数 / Token 数：各自独立计数（会话去重、请求逐笔、Token 累加）。
- 花费：内部成本与外部积分的**合计**，只用于相对比较高低，不能当金额读（两种单位）。
- 成功率 / 缓存命中率 / 平均时长：该对象的效率指标。

## 排序与时间窗

- 页面顶部选时间范围；排行按所选指标排序，点列头可换排序键。
- 「排名变化」＝与上一个等长时间窗相比的名次移动；新上榜显示「新」。

## 数字对不上时怎么自查

1. 同一个人两处会话数不同：排行页按所选窗口聚合；详情页可能默认另一个窗口，先对齐时间。
2. 「花费」列与账单不符：该列是两口径合计仅供比较；对账务必用对账报表页。
3. 匿名/显示名不一致：优先显示设置的显示名，无则显示系统账号名；改名后历史数据按同一身份聚合，不会分裂成两人。
4. 榜单合计 ≠ 总览页总数：榜单展示 Top 名单；小流量长尾对象不入榜，总览页含全部。
