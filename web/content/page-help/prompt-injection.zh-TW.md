# 提示注入防護頁資料說明

這一頁配置「越權指令防護」：識別使用者輸入裡夾帶的「無視規則/扮演系統」類攻擊內容。

## 三個頁籤

- **策略**：總開關與執行模式。
- **LLM 引擎**：用模型做二次判定的引擎配置。
- **檢測規則**：具體的攻擊特徵規則清單。

## 兩種執行模式（關鍵區別）

- **觀察模式（僅記錄）**：只把檢測結果記下來，**不攔截**任何請求——用於先看誤報率再決定收緊。
- **強制模式**：按「嚴重度矩陣」執行動作（放行/需人工審批/直接攔截）；審批超時設 0 表示無限等待。

## 口徑說明

- 規則命中數按「檢測到」計；觀察模式下的命中**不產生**攔截，統計裡與強制模式分開。
- 嚴重度矩陣決定「同一命中在不同模式下分別怎麼處理」——改矩陣要兩列一起核對。

## 數字對不上時怎麼自查

1. 看到命中但請求沒被攔：多半在觀察模式（設計如此）；切強制模式前先複核該規則的誤報。
2. 誤報高：按規則逐條看命中樣本；常見誤報是正常業務裡含「忽略以上指令」等措辭，調整該規則而非關總閘。
3. 強制模式下全被送去審批：嚴重度矩陣把高階別都配成了「審批」，審批人沒空時表現為「全卡住」；調整矩陣或審批超時。
