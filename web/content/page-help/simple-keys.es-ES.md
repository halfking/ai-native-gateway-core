# Página sencilla de emisión de claves

Página minimalista para emitir una clave en dos pasos: introduce un nombre → emite la clave.

## Criterios

La clave se puede usar en cuanto se emite; para la configuración avanzada (cuota/caducidad/restricciones de modelos), ve a la página completa de claves.

## Cómo comprobarlo cuando los números no cuadren

- 1. No encuentras la clave recién emitida: la lista completa está en la página de lista de claves; esta página solo gestiona la emisión.
- Si después de emitir una clave quieres añadir un límite de cuota: busca la clave en la página de lista de claves y edítala.
