# 運用概要ページのデータ説明

このページは、複数のデプロイメント拠点向けの「グローバルダッシュボード」です。中央サービス、各リージョン、デプロイノード、データプレーンのヘルスを一度に確認できます。

## 4つのセクション

- **中央インスタンス**：中央サービスの稼働状況とバージョン。
- **リージョン分布**：地域ごとのデプロイメント拠点の分布と状況。
- **デプロイノード**：最近のデプロイ履歴（時刻、バージョン、結果）。
- **データプレーン**：主要データテーブルの規模とヘルス状態。

## ステータスの判定基準

- ノードのステータスは、そのノードから定期的に報告されます。「オフライン」＝報告サイクルを超えてメッセージがない状態で、ノードが停止したか、ネットワークが切断された可能性があります。
- バージョンはノード自身からの報告を基準とします。同じリージョンに複数のバージョンが存在するのは、ローリングアップグレード中の中間状態です。

## 更新頻度について

- このページのデータは固定サイクルでポーリングして更新されます（秒単位のリアルタイムではありません）。直前に完了したデプロイは、次の更新サイクルで表示されます。
- 「最近 N 件」の N はページに表示する上限件数を意味し、全履歴ではありません。全履歴はデプロイ管理で確認できます。

## 数字が一致しない場合のセルフチェック

1. まず、参照時刻を確認してください。このページのステータスとノード上で確認するステータスの間には、ポーリング間隔があります。
2. リージョンの合計と各ノードの値を合計した結果が一致しない場合：一部のノードが未報告の場合は「不明」として扱い、リージョンの合計には含めません。
3. バージョンの不一致は必ずしも異常ではありません。ローリングアップグレード中は新旧バージョンが併存するのが想定どおりで、アップグレード完了後は1つのバージョンに収束するはずです。
