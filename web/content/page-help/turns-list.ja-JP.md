# ターン一覧ページのデータ説明

このページでは、モデル呼び出しを「セッション → ターン」の単位で整理しています。セッションは連続した会話、ターンは一問一答を指します。

## 階層関係

- プロジェクト / ユーザー / クライアント / キーは、4つの集計・分類の観点です。同じセッションの集合を、それぞれの視点から確認できます。
- セッションを展開すると、各ターンの質問内容の要約、回答の要約、所要時間、ステータスが表示されます。

## 「ターン」の数え方

- ユーザーが1回質問し、モデルが1回回答するまでを1ターンとします。
- 同じセッション内のターンは、時系列順に並べられます。
- 1ターンには複数の内部モデル呼び出し（再試行、ツール呼び出しなど）が含まれる場合があります。これらは 해당ターンに含め、個別のターン数としては数えません。

## 要約とステータス

- セッションの要約はシステムが自動生成します。「今すぐ要約」は手動で再生成を起動する操作であり、生成中は進行状況が表示されます。
- 録画が利用できない場合、新しいセッションには一時的にターンの詳細が表示されないことがあります。これは収集処理上の一時的な状態であり、データが失われたことを示すものではありません。

## 数が一致しない場合の確認方法

1. このページは「セッション」単位に集計し、リクエスト記録ページは「単一の呼び出し」単位に展開します。1件のリクエストがセッションの視点ではCertainターンの一部にすぎない場合があるため、両ページの件数が一致しないのは当然です。
2. 絞り込み条件（プロジェクト/ユーザー/クライアント/キー）を多く設定ほど、セッション数は少なくなります。絞り込み条件をクリアしてから総数を確認してください。
3. ターンの読み込みには上限があります（1回の展開で直近100ターンまで読み込みます）。長期のセッションの場合は、期間を絞り込むか、ページを移動して確認してください。
