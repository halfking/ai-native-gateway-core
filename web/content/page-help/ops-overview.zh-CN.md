# 运维总览页数据说明

这一页是多部署点的「全局指挥板」：中心服务、各区域、部署节点、数据面健康一屏看完。

## 四个区块

- **中心实例**：中心服务的运行状态与版本。
- **区域分布**：按地域看部署点的分布与状态。
- **部署节点**：最近部署记录（时间、版本、结果）。
- **数据面**：核心数据表的规模与健康。

## 状态口径

- 节点状态由该节点定期上报；「离线」＝超过上报周期没有消息，可能是节点停了，也可能是网络断了。
- 版本号以节点自己上报为准；同一区域出现多个版本属滚动升级的中间状态。

## 时效说明

- 本页数据按固定周期轮询刷新（不是秒级实时）；刚完成的部署要等下一轮刷新才出现。
- 「最近 N 条」的 N 是页面截取上限，不是全部历史；完整历史到部署管理里查。

## 数字对不上时怎么自查

1. 先确认查询时刻：本页与节点本机看到的状态之间有轮询间隔。
2. 区域合计与节点逐条相加不等：部分节点未上报时按「未知」处理，不计入区域合计。
3. 版本不一致不一定是故障：滚动升级期间新旧版本并存是预期行为，升级完成后应收敛为一个版本。
