# 金鑰列表頁資料說明

這一頁管理呼叫閘道器的「鑰匙」：每把金鑰代表一個可以發起模型呼叫的身份。

## 每行欄位

- 名稱與字首：金鑰的人讀標識；完整金鑰只在簽發那一刻顯示一次。
- 狀態：見下方四種狀態。
- 用量與額度：已消耗量相對配額的比例。

## 四種狀態怎麼判定

| 狀態 | 條件 |
| --- | --- |
| 待啟用 | 金鑰已簽發但尚未完成首次驗證 |
| 啟用中 | 狀態正常 + 未過期 + 未被停用，三者同時滿足 |
| 已過期 | 設定了到期時間且已過點 |
| 已吊銷 | 被手動停用 |

注意：「啟用中」要求三個條件同時成立——只要過期或被停用，即使後臺狀態欄位還是「正常」，頁面也會顯示「已過期」或「已吊銷」。

## 用量統計口徑

- 用量數字統計的是**已完成的呼叫**；進行中的請求不計入。
- 用量資料有短暫延遲：剛發起的呼叫可能要等片刻才反映到用量裡。

## 數字對不上時怎麼自查

1. 狀態篩選標籤頁選的是哪一類：頁面頂部按狀態分頁籤，切換後列表內容不同。
2. 過期判斷以伺服器時間為準，本機時鐘偏差不影響判定。
3. 系統內建金鑰（平臺自身使用）會固定出現在列表裡，不計入普通統計。
4. 配額與用量來自兩個資料來源，更新節奏不同：用量準實時、配額改動即時生效；對不上時先重新整理頁面。
