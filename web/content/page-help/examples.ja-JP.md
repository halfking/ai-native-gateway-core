# 接続サンプルページのデータについて

このページは「どのように接続するか」を学ぶための教材ページです。開発者向けに、接続手順、コードサンプル、よくあるクライアントの設定を案内します。

## 構成内容

- **接続チェックリスト**：キーの申請から初回呼び出し成功までの全手順。
- **コードサンプル**：OpenAI 互換 API の呼び出しサンプル（コピー可能）。
- **自動設定**：一般的なクライアント（IDE、CLI ツール）向けのワンクリック設定の説明。

## データページとの関係

このページは**教材情報のみ**であり、動的な統計データは一切含まれません。「自動設定」で生成される URL/キーは、現在ログインしているアカウントの識別情報に基づきますが、ページ自体で使用量が消費されることはありません。

## よくある質問

1. サンプルどおりに呼び出したのに 401 になる：キーが有効化されていない、またはコピー時に空白が含まれている可能性があります。先にキーリストで状態を確認してください。
2. サンプル内のモデル名での呼び出しに失敗する：サンプルは汎用的な書き方なので、モデル名をカタログ内で実際に利用可能なものに変更してください。
3. ワンクリック設定の書き込みに失敗する：ツールのバージョンが古く、その設定ファイル形式に対応していません。手動でコピー＆ペーストしてください。
