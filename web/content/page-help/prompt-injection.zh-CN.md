# 提示注入防护页数据说明

这一页配置「越权指令防护」：识别用户输入里夹带的「无视规则/扮演系统」类攻击内容。

## 三个页签

- **策略**：总开关与运行模式。
- **LLM 引擎**：用模型做二次判定的引擎配置。
- **检测规则**：具体的攻击特征规则清单。

## 两种运行模式（关键区别）

- **观察模式（仅记录）**：只把检测结果记下来，**不拦截**任何请求——用于先看误报率再决定收紧。
- **强制模式**：按「严重度矩阵」执行动作（放行/需人工审批/直接拦截）；审批超时设 0 表示无限等待。

## 口径说明

- 规则命中数按「检测到」计；观察模式下的命中**不产生**拦截，统计里与强制模式分开。
- 严重度矩阵决定「同一命中在不同模式下分别怎么处理」——改矩阵要两列一起核对。

## 数字对不上时怎么自查

1. 看到命中但请求没被拦：多半在观察模式（设计如此）；切强制模式前先复核该规则的误报。
2. 误报高：按规则逐条看命中样本；常见误报是正常业务里含「忽略以上指令」等措辞，调整该规则而非关总闸。
3. 强制模式下全被送去审批：严重度矩阵把高级别都配成了「审批」，审批人没空时表现为「全卡住」；调整矩阵或审批超时。
