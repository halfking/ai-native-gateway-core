# Page de détail de l’analyse des tâches

Profil des volumes d’utilisation et de la qualité d’une catégorie de tâches (regroupées par type de tâche).

## Définition des indicateurs

Le type de tâche est attribué automatiquement par l’agent IA ; les échantillons mal classés peuvent être corrigés manuellement.

## Comment vérifier les écarts lorsque les chiffres ne concordent pas

- 1.Total des tâches ≠ nombre total de sessions : les sessions non classées figurent dans « Autres » ; le taux de couverture de la classification augmente avec l’amélioration de l’annotation.
- Le score de qualité diffère de celui de la page de corrélation de la qualité : cette page agrège les données par type de tâche, tandis que l’autre les répartit en tranches selon les caractéristiques.
