# Page des options de filtrage

Gérez les options disponibles dans les filtres de chaque page de liste (contenu déroulant : modèles, clés, tenants, etc.).

## Règles de calcul

Source des options = valeurs réellement observées + liste blanche gérée manuellement ; les deux sources sont fusionnées et dédupliquées.

## Que faire lorsque les chiffres ne correspondent pas

- 1. Impossible de filtrer une valeur sur une page de liste : vérifiez d’abord ici si l’option est enregistrée ; les valeurs dynamiques apparaissent automatiquement avec les données.
- Une option supprimée réapparaît : du trafic réel génère cette valeur ; la suppression ne concerne que la partie gérée manuellement.
