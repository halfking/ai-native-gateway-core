# 承認設定ページ

手動承認が必要な操作、そのトリガー条件、承認者、タイムアウトポリシーを定義します。

## 基本考え方

ポリシー＝条件＋承認者＋タイムアウトの3要素。設定を変更しても、影響するのは変更後に新たにトリガーされる承認のみです。

## 数字が合わない場合の確認方法

- 1.設定したのに承認が生成されない場合：トリガー条件の範囲（テナント/キー粒度）と有効・無効の状態を確認してください。
- タイムアウトによる自動承認/却下が反映されない場合：タイムアウト値が 0 の場合は無期限に待機するため、自動的に完了しません。
- 承認者に通知が届かない場合：承認者アカウントが引き続き有効になっているか確認してください。
