# Explication des données de la page des classements

Cette page décompose l’analyse des conversations en trois classements : **qui l’utilise** (les personnes), **qui travaille** (les agents intelligents), **ce qui est le plus utilisé** (les modèles).

## Colonnes des tableaux de classement

- Nombre de conversations / nombre de requêtes / nombre de Token : chaque élément est compté indépendamment (conversations dédupliquées, requêtes comptées une par une, Token additionnés).
- Coût : **total** des coûts internes et des crédits externes ; il sert uniquement à comparer les niveaux et ne doit pas être interprété comme un montant (deux unités).
- Taux de réussite / taux de succès du cache / durée moyenne : indicateurs d’efficacité de l’élément concerné.

## Tri et période

- Sélectionnez la période en haut de la page ; le classement est trié selon l’indicateur sélectionné, et vous pouvez changer de critère de tri en cliquant sur l’en-tête de colonne.
- « Variation du classement » = déplacement de la position par rapport à une période précédente de même durée ; une nouvelle entrée est signalée par « Nouveau ».

## Comment vérifier les écarts de chiffres

1. Le nombre de conversations diffère entre deux emplacements pour une même personne : le classement regroupe les données sur la période sélectionnée ; la page de détail peut utiliser une autre période par défaut. Commencez par aligner les périodes.
2. La colonne « Coût » ne correspond pas à la facturation : cette colonne totalise deux mesures et sert uniquement à la comparaison ; pour le rapprochement, utilisez 반드시 la page « Rapport de rapprochement ».
3. Nom anonyme/nom affiché incohérent : le nom d’affichage défini est prioritaire ; à défaut, le nom de compte système est utilisé. Après un changement de nom, les données historiques sont regroupées sous la même identité et ne sont pas scindées en deux personnes.
4. Total du classement ≠ total de la page d’aperçu : le classement affiche uniquement la liste Top ; les éléments à faible volume qui constituent la longue traîne n’y figurent pas, tandis que la page d’aperçu les inclut tous.
