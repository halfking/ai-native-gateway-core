# Vue d’ensemble du routage

Catalogue général du système de routage : règles, hiérarchie et configuration des stratégies regroupées sur un seul écran.

## Explication du périmètre

Cette page présente une vue d’ensemble de la configuration, sans statistiques dynamiques ; les effets dynamiques sont disponibles sur la page des décisions.

## Comment vérifier les écarts lorsque les chiffres ne concordent pas

- 1. Le nombre de règles ne correspond pas à celui de la page des décisions : la vue d’ensemble inclut les règles non activées ; la page des décisions ne reflète que les règles en vigueur.
