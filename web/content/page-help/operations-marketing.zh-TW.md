# 營銷管理頁資料說明

這一頁管理四類營銷工具：套餐、加油包、優惠碼、活動。

## 四個頁籤

- **套餐**：月包的定義（含多少訂閱額度、什麼價）。
- **加油包**：一次性購買的額外額度包。
- **優惠碼**：客戶兌換後獲得折扣或積分的碼。
- **活動**：限時的折扣/贈送策略（草稿 → 生效 → 結束）。

## 生效規則

- **折扣型活動**：租戶領取後，下一張訂單自動按比例折減；用完即止。
- **贈送型活動**：領取即發放積分，立刻到賬。
- 活動「草稿」不影響任何訂單；「生效」後對領取過的租戶生效；「結束」後不可再領取，已領取的權益按各自規則繼續用完。

## 數字對不上時怎麼自查

1. 優惠碼「已領取 N 次」但訂單沒打折：折扣只作用於領取後的**下一張**訂單；更早訂單不受影響。
2. 贈送積分沒到賬：確認活動狀態是「生效」而非「草稿」，且該租戶在領取名單裡。
3. 套餐價格與賣價頁不一致：套餐是「打包價」，與按 Token 計費的標價是兩套體系；套餐使用者按套餐扣額度，不逐 Token 扣錢。
