# Key Request Page

Centrally manage key request tickets: who submitted the request, what permissions are requested, and whether to approve it.

## Guidelines

One request per ticket; once approved, a key is generated automatically and the applicant is notified.

## How to Self-Check When the Numbers Do Not Match

- 1.Request approved but no key received: The key is displayed only once and must be reset after it expires; the notification may be in the spam folder.
- Same person has multiple requests: Each request is a separate ticket, and older requests are not merged automatically.
