# Détails de l’analyse des clients

Une profil d’utilisation d’un client connecté (IDE/CLI/application).

## Méthodologie de calcul

Les clients sont regroupés par identifiant d’intégration ; plusieurs versions d’un même client sont regroupées dans les statistiques.

## Comment vérifier les écarts lorsque les chiffres ne concordent pas

- 1. L’utilisation côté client et l’utilisation côté utilisateur ne concordent pas : un utilisateur peut utiliser plusieurs clients, et un même client peut être partagé par plusieurs utilisateurs ; les deux perspectives ne se superposent pas.
- Client inconnu : toutes les intégrations dépourvues d’identifiant standard sont classées dans la catégorie « inconnu », sans incidence sur le comptage.
