# API Key Details Page

The complete profile of an individual key: status, quota, usage trends, and recent calls.

## Calculation Notes

Usage trends are aggregated over the selected time window; the four status states are consistent with the list page.

## How to Reconcile Discrepancies in the Numbers

- 1.Detail usage ≠ billing: Billing is calculated by calendar day (UTC), while the details time window can be customized. Align the time windows first.
- Recent calls is empty but usage is nonzero: Recent calls shows only sampled detail records, not the full transaction history.
