# 會話分析總覽頁資料說明

這一頁回答「大家怎麼在用」：會話有多少、平均多長、花在哪些任務上、趨勢如何。

## 核心指標卡

| 卡片 | 含義 | 演算法 |
| --- | --- | --- |
| 會話總數 | 時間段內的對話數量 | 去重計數：一個會話算一次，不論它含多少輪 |
| 平均 Token 數 | 每個會話平均消耗的文字量 | 全部會話的 Token 總量 ÷ 會話總數 |
| 平均會話時長 | 每個會話平均持續多久 | 各會話首末時間差求平均 |
| 平均輪次 | 每個會話平均幾問幾答 | 全部輪次數 ÷ 會話總數 |
| 內部成本（美元） | 平臺支付給上游的美元成本 | 按上游定價逐筆累加 |
| 外部成本（積分） | 向租戶收賬的積分 | 按平臺定價逐筆累加 |

**內部成本與外部成本不合計**：美元與積分是兩種單位，加起來沒有業務含義。頁面頂部的趨勢圖也分別按兩種單位展示。

## 趨勢與排名

- 趨勢圖按天聚合（世界標準時 UTC 切日），展示會話數或成本的逐日變化。
- 「較上一週期」＝當前視窗與等長的上一視窗相比的百分比變化。
- 排行頁（人員/智慧體/模型）按所選指標排序；「花費」排序使用後端相容欄位 `total_cost`，其值是美元內部成本與積分外部成本的原始數值相加，沒有匯率換算。列表可能仍以美元樣式顯示該值，因此它不是金額、不能跨幣別比較；請分別查看內部成本（USD）與外部成本（積分）。

## 資料新鮮度

這一頁讀的是系統定時彙總的「聚合快照」，不是逐筆明細。快照有新鮮度預算（約 90 分鐘）；超期時頁面顯示「聚合資料正在重新整理」橫幅並拒絕返回過期數字——這是保護機制，不是故障。

## 數字對不上時怎麼自查

1. 時間範圍：本頁與請求記錄頁視窗不同，數字必然不同；先對齊時間。
2. 快照延遲：最近的請求可能還沒進聚合快照，等重新整理後再對。
3. 口徑差異：本頁按「會話」聚合，請求記錄頁按「單次呼叫」展開，條數天然不等。
4. 去重規則：會話數按會話去重，同會話多輪不重複計；輪次數才是逐輪計數。
