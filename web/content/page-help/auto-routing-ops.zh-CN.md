# AUTO 路由运营页数据说明

这一页是「自动调参」的闭环工作台：标注 → 统计 → 档案建议 → 调参审批。系统据此越来越会挑模型，但**每一次生效都要过门禁并经人工批准**。

## 四个页签构成一条流水线

- **标注工作台**：人工给历史请求标注「效果好坏」，是后续一切统计的原料。
- **标注统计**：标注量的汇总（今日待标注、累计标注、参与人数）。
- **任务画像**：按任务类型看模型表现，产出「某类任务更适合某模型」的档案建议。
- **调参审批**：系统提出的参数调整建议在此等待人工批准或驳回。

## 口径说明

- 「今日待标注」按自然日（UTC）计算；昨天没标完的会累计到「累计标注」的待办里。
- 调参提案有置信度门槛：系统只对有把握的建议发起审批，低置信度的自动搁置，不会打扰审批人。
- 每次调参生效前都有「旧值快照」：批准后若发现效果不对，可以一键回退到调整前。

## 数字对不上时怎么自查

1. 标注数与请求数对不上是正常的：不是每笔请求都需要标注，系统只挑有代表性的抽样。
2. 提案被驳回不会重复出现同一建议：同族建议会参考历史审批结论。
3. 调参生效后指标没变化：参数生效有延迟（热加载间隔），且效果要在新流量上才体现。
4. 深链页签不对：本页四个旧页面已合并为一页四页签，旧链接会自动跳转。
