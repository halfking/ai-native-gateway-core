# Page des types de travail

Gestion du système de classification des tâches : définition des types de tâches et des mots-clés de reconnaissance.

## Explication des règles

Chaîne de reconnaissance = requête → intention → type de travail ; les mots-clés déterminent la précision de la classification.

## Comment vérifier l’écart lorsque les chiffres ne correspondent pas

- 1. Classification imprécise : ajouter des mots-clés de reconnaissance pour ce type ou corriger l’exemple dans l’atelier d’annotation.
- La répartition des types diffère de celle de la page Statistiques : les statistiques sont établies selon la classification finale, tandis que la répartition sur cette page inclut des états intermédiaires non finalisés.
