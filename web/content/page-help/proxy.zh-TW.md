# 代理管理頁資料說明

這一頁管理閘道器訪問上游時走的「代理出口」：訂閱來源、節點池、當前用哪個出口。

## 三個頁籤

- **狀態概覽**：總覽卡（訂閱數、節點總數、可撥號/健康數）+ 當前選中出口 + 自動切流狀態。
- **訂閱管理**：代理訂閱源（匯入一批節點的連結），可設「地區黑名單」過濾出口。
- **節點管理**：逐個節點的手工登記與維護。

## 關鍵口徑

- **可撥號**＝節點當前能建立連線；**健康**＝連續探測正常的節點。可撥號但反覆失敗的節點不算健康。
- **自動切流**：當前出口連續失敗達到閾值時自動換下一個節點；「連續失敗次數」實時累加，成功後清零。
- 「最近主動探測」是系統自己發起的連通性檢查時間，不是業務請求時間。

## 數字對不上時怎麼自查

1. 節點總數 ≠ 可撥號數：正常現象——總數是登記量，可撥號是當下連通量。
2. 切流後業務仍失敗：切流有探測週期，幾秒內完成；持續失敗看「連續失敗次數」是否還在漲。
3. 訂閱更新後節點數沒變：訂閱源內容可能相同；對比更新前後節點的指紋而不是數量。
4. 黑名單地區不生效：地區程式碼要按節點上報的地區值精確匹配（大小寫敏感），配錯寫法不會報錯但不會過濾。
