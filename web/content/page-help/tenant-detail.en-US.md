# Tenant Details Page

Management profile for a single tenant, providing an overview of members, keys, quotas, and usage.

## Calculation Basis

Quota = subscription + wallet, with the two pools displayed separately; usage is calculated separately for this tenant.

## How to Reconcile Discrepancies

- 1.Detail usage ≠ Overall dashboard: The Overall dashboard includes internal consumption by the default tenant; use the Detail view as the source of truth for tenant billing.
- The member list differs from the Users page: This page lists only members of the current tenant, while the Users page lists all users.
