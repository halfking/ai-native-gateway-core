# Round Filter Options Page

Maintenance of options for the round list filter (dropdown values such as project/client).

## Definition

Options = actual observed values + manually registered entries, merged and deduplicated.

## How to Self-Check When Numbers Do Not Match

- 1. Unable to filter by a project: The project name appears automatically when it has not been registered and there is new traffic; it can also be registered manually.
- 2. Options do not match the list: Refresh the options cache and try again.
