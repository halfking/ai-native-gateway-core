# Datenerläuterungen zur Hilfemanualseite

Diese Seite ist das **vollständige Dokumentationshandbuch** der gesamten Plattform: ausführliche Anleitungen zu Installation und Bereitstellung, täglichem Betrieb und Fehlerbehebung.

## Unterschied zwischen dieser Seite und dem „?“ oben rechts auf der Seite

- Das „?“ oben rechts: eine Kurzreferenz zur Datenlogik der **aktuellen Seite** (welche Zahlen diese Seite behandelt und wie sie berechnet werden).
- Diese Seite: das vollständige **seitenübergreifende Handbuch** (wie man etwas installiert, konfiguriert und Fehler behebt).

Die beiden ergänzen sich: Mit dem „?“ die Bedeutung einer bestimmten Zahl nachschlagen; auf dieser Seite nachschlagen, wie eine bestimmte Aufgabe ausgeführt wird.

## Tipps zur Nutzung

- Das Suchfeld oben ermöglicht die Volltextsuche; über den Verzeichnisbaum können Sie zu den gewünschten Kapiteln springen.
- In der oberen rechten Ecke von Codeblöcken befindet sich eine Schaltfläche zum Kopieren, mit der Sie Befehle einfach übernehmen können.

## Aktualität der Inhalte

Das Handbuch wird mit den Versionen aktualisiert. Wenn Sie feststellen, dass das Handbuch vom tatsächlichen Verhalten der Seite abweicht, richten Sie sich nach dem tatsächlichen Verhalten der Seite und melden Sie dies dem Administrator zur Aktualisierung des Handbuchs.
