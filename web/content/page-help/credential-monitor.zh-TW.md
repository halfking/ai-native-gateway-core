# 憑據監控頁資料說明

這一頁監控上游「憑據」（接入各模型供應商的賬號鑰匙）的可用狀況，幫你在使用者報障之前先發現問題。

## 頁籤說明

- **列表**：每條憑據一行的健康總表（當前狀態、最近錯誤、禁用原因）。
- **熱力圖**：按時間看每條憑據什麼時候出過錯，顏色越深錯誤越多。
- **路由日誌**：憑據層面的事件流水（啟用/禁用/切換）。
- **錯誤趨勢**：按小時的錯誤曲線，看錯誤是突發還是持續。
- **探測健康**（僅超管）：系統主動試呼叫每條憑據的結果。

## 狀態標籤的口徑

- 「正常」＝最近沒有失敗記錄。
- 「手工禁用」＝管理員手動下線；自動探測不會重新啟用它。
- 「自動管控」＝系統因連續失敗自動下線（例如多次確認故障）；可手工強制下線，也可等待自動恢復。
- 禁用原因徽標優先於健康狀態顯示：一條憑據同時有錯誤又有禁用原因時，頁面展示禁用原因。

## 健康分與錯誤數

- 錯誤數統計的是**已完成的失敗呼叫**，按所選時間窗累加。
- 同一筆請求的失敗只計入當時使用的那條憑據；重試成功不消除已記錄的失敗。

## 數字對不上時怎麼自查

1. 時間窗不一致：本頁篩選與看板的視窗要對齊後再比較。
2. 「探測」流量是系統自己發起的檢查性呼叫，它與使用者流量分開統計；憑據可用性以探測+真實流量兩方面綜合判斷。
3. 剛恢復的憑據短時間內錯誤數仍顯示舊值：圖表按小時聚合，當前小時的完整結果要等下一小時。
4. 列表為空先查篩選：憑據型別/租戶/狀態的過濾組合可能把結果篩空了。
