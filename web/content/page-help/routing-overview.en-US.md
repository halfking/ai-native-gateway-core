# Routing Overview Page

The master directory of the routing system: rules, hierarchy, and policy configurations summarized on one screen.

## Scope Notes

This page provides a configuration overview and does not include dynamic statistics. To see dynamic results, go to the Decision page.

## How to Self-Check When Numbers Do Not Match

- 1. If the rule count does not match the Decision page: the overview includes inactive rules, while the Decision page reflects only active rules.
