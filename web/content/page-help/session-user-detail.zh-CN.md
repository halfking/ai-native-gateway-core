# 会话用户详情页数据说明

这一页看**一个人**的完整使用画像：他的会话、项目、任务、常用模型与花费趋势。

## 内容构成

- **概要卡**：会话数、Token、花费、成功率、缓存命中率、平均时长。
- **趋势区**：该用户所选窗口内的会话/花费逐日曲线。
- **明细表**：按项目 / 任务 / 智能体 / 模型拆分的用量行。

## 口径说明

- 所有数字只统计**该用户发起**的会话；协作参与（别人的会话里他出现）不计入。
- 「花费」两口径并存展示；「排名」卡显示该用户在全体排行中的位置与较上期的变化。

## 数字对不上时怎么自查

1. 详情合计 ≠ 列表页该行数字：先对齐两页的时间范围（详情页顶部有自己的范围选择）。
2. 项目/任务明细合计 ≠ 概要总量：未归类到项目/任务的会话只进总量；明细表底部有「未归类」行时以它解释差额。
3. 「排名变化」方向反了：变化以**排名序位**计（升=名次变好），不是数值增减。
