# Página de solicitud de claves

Centraliza la gestión de las solicitudes de claves: quién las solicita, qué permisos se solicitan y si se aprueban o rechazan.

## Criterios de actuación

Cada solicitud genera un ticket independiente; tras su aprobación, la clave se genera automáticamente y se notifica al solicitante.

## Qué revisar cuando las cifras no coincidan

- 1.Solicitud aprobada, pero no se ha recibido la clave: la clave solo se muestra una vez y, una vez caducada, debe restablecerse; es posible que la notificación haya acabado en la carpeta de spam.
- Varias solicitudes de la misma persona: cada solicitud genera un ticket independiente y las anteriores no se combinan automáticamente.
