# AIエラー分析ページのデータ説明

このページでは、AIが「リクエストが失敗した理由」を分析します。エラーキュー内の失敗を1件ずつ（または一括で）AIエージェントに分析させ、原因の判定と修正提案を生成します。

## 2つのタブ

- **エラーキュー**：未分析の失敗レコード一覧（1行につき1件の失敗リクエスト）。
- **分析結果**：AIの分析によって得られた結論の一覧（原因区分、根拠、提案）。

## 上部の6つのカードの集計基準

- 合計 / 未分析 / 分析済み / 失敗：**エラーキュー**の統計値（キュー領域）。
- 誤報率 / 平均処理時間：**分析結果**の統計値（結果領域）。
- 3つのカードと残り3つのカードでは統計範囲が異なるため、合計しても意味がありません。ページでは領域ごとにグループ表示します。

## 修正提案の適用方法

- AIの提案（ルール変更／レベル調整／マッチング式変更）は**人手による承認**Grab，才能适用。承認時には信頼度の基準が設定されており、信頼度が低い提案は保留され、再確認が求められます。
- 適用するたびに「変更前の値のスナップショット」が保存され、ワンクリックで元に戻せます。

## 数字が一致しない場合の確認方法

1. キュー件数とリクエスト記録ページの失敗数が異なる場合：キューには**分析対象範囲に含まれる**失敗タイプのみ登録されます。事前ブロック（例：認証失敗）されたリクエストはキューに入りません。
2. 「分析済み」なのに結果ページに見つからない場合：分析結果の保存に一時的な遅延があります。再読み込み後に確認してください。
3. 同じエラーが繰り返し発生する場合：同じパターンのエラーはまとめて分析されるため、キューには代表サンプルが表示されます。
