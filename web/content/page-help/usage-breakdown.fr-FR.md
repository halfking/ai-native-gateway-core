# Notes sur la ventilation de l’utilisation

La liste des opérations utilise les données du tableau de bord pour le classement. Le détail affiche les totaux, les tendances et la ventilation pour le modèle, le fournisseur, le client ou le tenant sélectionné sur la période choisie.

Les totaux détaillés privilégient les données des requêtes et utilisent au besoin les agrégats par minute. Les tendances et la ventilation utilisent les données par minute. Alignez le périmètre et la date de mise à jour avant de comparer les coûts, les requêtes et les tokens.
