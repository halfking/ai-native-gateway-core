# AUTOルーティング運用ページのデータ説明

このページは、「自動調整」の閉ループワークベンチです。アノテーション → 統計 → プロファイル提案 → 調整承認の流れを一元化します。この仕組みによりモデル選択の精度は向上しますが、**調整が実際に適用されるたびに、ゲートチェックと人手による承認を必ず経る必要があります**。

## 4つのタブで1つのパイプラインを構成

- **アノテーションワークベンチ**：人手で過去のリクエストに「効果の良否」をアノテーションし、以降のすべての統計の基データとします。
- **アノテーション統計**：アノテーション量の集計（本日の未アノテーション、累計アノテーション、参加者数）。
- **タスクプロファイル**：タスク別にモデルのパフォーマンスを確認し、「あるタスクにはあるモデルが適している」というプロファイル提案を提示します。
- **調整承認**：システムが提案したパラメータ調整を、このタブで人手による承認または却下を受け付けます。

## 集計基準

- 「本日未アノテーション」は自然日（UTC）基準で計算します。昨日に完了できなかった分は、「累計アノテーション」の未処理タスクに繰り越されます。
- パラメータ調整提案には信頼度のしきい値があります。システムは高信頼度の提案だけを承認フローに載せ、低信頼度のものは自動的に保留するため、承認者を煩わせません。
- パラメータ調整が実際に適用されるたびに、適用前の「旧値スナップショット」が保存されます。承認後に効果が想定と異なることが判明した場合、ワンクリックで調整前の状態に戻せます。

## 数字が合わないときの確認方法

1. アノテーション数とリクエスト数が一致しないのは正常です。すべてのリクエストにアノテーションする必要はなく、システムは代表的なサンプルだけを対象にするためです。
2. 却下された提案と同じ提案が再表示されることはありません。同種の提案は、過去の承認結果を参照します。
3. パラメータ調整の適用後も指標が変化しない場合、パラメータの反映には遅延（ホットリロード間隔）があり、効果は新しいトラフィックで現れるためです。
4. ディープリンクのタブが正しくない場合：本ページの4つの旧画面は1ページ・4タブに統合されており、旧リンクから自動的に遷移します。
