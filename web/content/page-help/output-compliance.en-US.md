# Output Compliance Page

Check whether model responses cross any compliance red lines (sensitive content and formatting requirements).

## Evaluation Criteria

Each check is classified as “Pass” or “Violation” based on its rule; violation records include matched excerpts (displayed with sensitive information masked).

## How to Self-Check When the Numbers Do Not Match

- 1. The number of violations differs from the number of blocks: a violation is a “record”; whether it is blocked depends on the policy, and observation mode records violations without blocking them.
- Multiple violations in the same content segment: multiple rules are each triggered, so review them separately by rule.
