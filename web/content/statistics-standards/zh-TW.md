## 跨報表統計與對帳標準

比較前先對齊時間範圍與時區、租戶、流量範圍、計數單位及資料更新時間。統一區間含開始、不含結束。上方說明列出目前報表口徑，部分報表仍使用不同的視窗或資料來源。

| 指標 | 計算標準 |
| --- | --- |
| 用戶端請求數 | 每筆已記錄的閘道用戶端請求計一次。已完成包含成功、失敗、限流及已終止的取消，處理中另列。重試或切換供應商沿用原請求。 |
| 供應商傳送次數 | 每次實際送往供應商的呼叫計一次，包含重試、並行嘗試和平台自動化。閘道拒絕且沒有向上游傳送時，只計用戶端請求。現有日快照彙整閘道終態流水，逐次呼叫涵蓋率仍待補齊。 |
| 活躍與新工作階段 | 區間內有用戶端請求的工作階段去重計為活躍。首次請求落入區間者計為新工作階段。無工作階段的請求仍納入請求總數。 |
| 成功率 | 成功數除以已完成數，用戶端請求與供應商呼叫分開計算。分母為零時顯示無資料。 |
| 輸入、輸出與總 Token | 分別累加正規化的輸入與輸出。總 Token 為輸入加輸出。快取及推理明細另列，避免重複計數。 |
| 快取 Token 與命中率 | 分別累加快取讀取與寫入。有可比快取資料時，Token 命中率為快取讀取 Token 除以完整輸入 Token（含快取）。請求命中率為命中請求除以具可比快取資料的請求。保留分母與涵蓋率。 |
| 供應商估算成本 | 按每次呼叫的計費用量、當時的供應商成本單價與幣別計算。缺用量或缺價另列。 |
| 供應商回傳金額 | 回應明確提供金額時保留原值與幣別。另以供應商帳單核對最終應付金額。 |
| 內部點數與金額 | 計算已入帳的扣費、沖銷與調整淨額，保留單位與適用換算規則。點數和貨幣分開列示。 |
| 平台自動化維運 | 探測和自我檢查歸屬專用用戶端，計入供應商成本和平台用量，排除於租戶扣費。現有流量範圍以上方說明為準。 |

零是已知為零。缺用量、缺價、未分配、未出帳與延遲資料應分別標明。金額對帳使用相同幣別與精度。
