## レポート共通の集計・照合基準

比較する前に、期間とタイムゾーン、テナント、トラフィックの範囲、集計単位、データの更新時点をそろえます。標準の期間は開始を含み、終了を含みません。上のページ説明は現行仕様を示します。現在も一部のレポートでは期間やデータソースが異なります。

| 指標 | 計算基準 |
| --- | --- |
| クライアントリクエスト数 | ゲートウェイに記録されたクライアントリクエストを各1件と数えます。完了には成功、失敗、レート制限、確定したキャンセルを含めます。処理中は別表示です。再試行やプロバイダー切替でも同じ1件です。 |
| プロバイダー送信数 | 実際に送信した呼び出しを各1件と数えます。再試行、並列試行、プラットフォーム自動処理を含みます。送信前の拒否はクライアント側だけに計上します。現行の日次スナップショットはゲートウェイの完了記録を集計しており、試行ごとの完全な把握は今後の対応です。 |
| アクティブ／新規セッション | 期間内にクライアントリクエストがあったセッションを重複なく集計します。初回リクエストが期間内なら新規です。セッションがないリクエストもリクエスト総数に含めます。 |
| 成功率 | 成功件数 ÷ 完了件数。クライアントとプロバイダーで別々に計算します。分母がゼロの場合はデータなしです。 |
| 入力・出力・合計トークン | 正規化した入力と出力を別々に加算し、その和を合計とします。キャッシュや推論などの内訳は別表示にして二重計上を防ぎます。 |
| キャッシュトークンとヒット率 | 読み取りと書き込みを別々に合計します。比較可能なキャッシュデータのある入力について、トークンのヒット率は読み取り ÷ キャッシュ分を含む全入力です。リクエストのヒット率はヒット件数 ÷ 比較可能な件数です。分母と対象範囲を示します。 |
| プロバイダー概算費用 | 呼び出しごとの課金対象使用量に、当時の原価単価と通貨を適用します。使用量や単価が欠けている呼び出しは別に示します。 |
| プロバイダー応答の金額 | 応答に金額が明示されていれば、原額と通貨を記録します。最終支払額は請求書と照合します。 |
| 内部クレジットと金額 | 記帳済みの請求、取消、調整の純額を集計し、単位と換算規則を保持します。クレジットと通貨は別表示です。 |
| プラットフォーム自動処理 | プローブや自己診断は専用クライアントに割り当て、プロバイダー費用とプラットフォーム使用量に含めます。テナントには請求しません。現行の範囲はページ説明をご確認ください。 |

ゼロは値が確定している場合に使います。使用量・単価の欠落、割り当てなし、未計上、データの遅延を区別します。金額の比較には同じ通貨と精度を使用します。
