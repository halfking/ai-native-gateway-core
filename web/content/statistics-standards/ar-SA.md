## معايير الإحصاء والمطابقة بين التقارير

وحّد المدة والمنطقة الزمنية والمستأجر ونطاق الحركة ووحدة العد ووقت تحديث البيانات قبل المقارنة. تشمل المدة القياسية بدايتها وتستثني نهايتها. توضح ملاحظات الصفحة طريقة الحساب الحالية. لا تزال بعض التقارير تستخدم مددًا أو مصادر مختلفة.

| المؤشر | طريقة الحساب القياسية |
| --- | --- |
| طلبات العملاء | يُعدّ كل طلب عميل مسجل لدى البوابة مرة واحدة. تشمل الطلبات المكتملة النجاح والفشل وتقييد المعدل والإلغاء النهائي. تُعرض الطلبات قيد المعالجة منفصلة. يبقى الطلب نفسه عند إعادة المحاولة أو تبديل المورّد. |
| مرات الإرسال إلى المورّد | يُعدّ كل إرسال فعلي، بما فيه إعادة المحاولة والمحاولات المتوازية وعمليات المنصة الآلية. يُحسب رفض البوابة قبل الإرسال ضمن طلبات العملاء فقط. تلخّص اللقطات اليومية الحالية السجلات النهائية للبوابة. تغطية كل محاولة قيد الاستكمال. |
| الجلسات النشطة والجديدة | تُعدّ الجلسة التي تتضمن طلب عميل داخل المدة جلسة نشطة، مرة واحدة. وتُعدّ جديدة إذا وقع طلبها الأول داخل المدة. تبقى الطلبات بلا جلسة ضمن الإجمالي. |
| معدل النجاح | عدد الحالات الناجحة مقسومًا على الحالات المكتملة. يُحسب لكل من طلبات العملاء واستدعاءات المورّد على حدة. المقام صفر يعني عدم توفر بيانات. |
| رموز الإدخال والإخراج والإجمالي | تُجمع قيم الإدخال والإخراج الموحّدة منفصلة، ومجموعهما هو الإجمالي. تُعرض تفاصيل التخزين المؤقت والاستدلال منفصلة لتجنب التكرار. |
| رموز التخزين المؤقت ومعدلات الإصابة | تُجمع رموز القراءة والكتابة منفصلة. يقسم معدل الرموز قراءات التخزين المؤقت على الإدخال الكامل الذي تتوفر عنه بيانات قابلة للمقارنة، ويشمل الإدخال المخزّن. يقسم معدل الطلبات عدد الطلبات المستفيدة على الطلبات ذات البيانات القابلة للمقارنة. اعرض المقام والتغطية. |
| تكلفة المورّد المقدّرة | تُحسب لكل استدعاء باستخدام الاستهلاك القابل للفوترة وأسعار التكلفة السارية وقتها وعملتها. تُميّز الأسعار أو بيانات الاستهلاك الناقصة. |
| المبلغ الوارد من المورّد | يُحفظ المبلغ الأصلي وعملته عندما يردان صراحة في الاستجابة. تُستخدم فاتورة المورّد لمطابقة المبلغ النهائي المستحق. |
| الأرصدة والمبالغ الداخلية | تُجمع صافي الرسوم المقيدة والإلغاءات والتعديلات مع حفظ الوحدة وقواعد التحويل المطبقة. تُعرض الأرصدة والمبالغ النقدية منفصلة. |
| عمليات المنصة الآلية | تُنسب عمليات الفحص والتحقق الذاتي إلى عميل مخصص. تدخل ضمن تكلفة المورّد واستخدام المنصة وتُستبعد من رسوم المستأجر. توضح ملاحظات الصفحة نطاق الحركة الحالي. |

الصفر قيمة معروفة. ميّز الاستهلاك أو الأسعار الناقصة، والسجلات غير المنسوبة، والرسوم غير المقيدة، والبيانات المتأخرة. قارن المبالغ بالعملة والدقة نفسيهما.
