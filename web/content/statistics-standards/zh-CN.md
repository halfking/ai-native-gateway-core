## 跨报表统计与对账标准

比较前先对齐时间范围和时区、租户、流量范围、计数单位和数据更新时间。统一标准使用含开始、不含结束的时间区间。上方页面说明列出现有报表的取数口径，部分报表仍使用不同的窗口或数据源。

| 指标 | 计算标准 |
| --- | --- |
| 客户端请求数 | 每个到达网关并进入统计的客户端请求计一次。已完成请求包含成功、失败、限流及已终止的取消。进行中单列。一次请求即使重试或切换供应商也只计一次。 |
| 供应商发送次数 | 每次实际发送到供应商的调用计一次，含重试、并发竞速和平台自动化。网关直接拒绝且未发上游的请求只计入客户端请求。当前日快照按网关终态流水汇总，逐次调用覆盖仍待补齐。 |
| 活跃会话数 / 新会话数 | 活跃会话是窗口内有客户端请求的去重会话。新会话按首次请求入窗计数。无会话的请求保留在请求总量。 |
| 成功率 | 成功数 ÷ 已完成数，客户端请求和供应商调用分别计算。分母为零时显示无数据。 |
| 输入 / 输出 / 总 Token | 分别累加归一化输入和输出 Token。总 Token＝输入＋输出。缓存、推理等明细单列，避免和输入或输出重复累计。 |
| 缓存 Token / 缓存率 | 缓存读和缓存写分别累加。Token 缓存命中率＝缓存读 Token ÷ 有可比缓存数据的完整输入 Token（含缓存）。请求缓存命中率＝命中请求数 ÷ 有可比缓存数据的请求数。保留分母和覆盖量。 |
| 供应商测算成本 | 按每次调用的计费用量、当时适用的供应商成本单价和币种计算。缺价或缺量单列。 |
| 供应商返回金额 | 仅在响应明确提供金额时记录原值和币种。供应商账单另用于核对最终应付。 |
| 内部积分 / 内部金额 | 按已入账的扣费、冲正和调整净额统计，保留单位和适用换算规则。积分与货币分别列示。 |
| 平台自动化运维 | 探测、自检等平台流量归属独立客户端，计入供应商成本和平台用量，排除在租户扣费之外。当前覆盖以页面的流量范围说明为准。 |

零表示已知为零。缺量、缺价、未分配、未出账与延迟数据应分别标明。跨报表核对时先统一范围，再按相同币种和精度比对。
