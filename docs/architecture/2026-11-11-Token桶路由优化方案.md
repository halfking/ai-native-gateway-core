# Token桶路由优化方案

> **编制时间**: 2026-11-11  
> **状态**: 方案设计阶段 - 待审计验证  
> **目标**: 优化429/并发错误处理，实现Token桶概念，建立两层路由架构

---

## 一、现状分析

### 1.1 当前架构概览

通过代码审查，当前系统的路由架构包括：

**核心模块**：
- `domains/streaming/executors/executor_dispatch.go` - 多层派发管道
- `domains/credential/breaker.go` - 断路器（状态机：CLOSED/OPEN/HALF_OPEN/QUARANTINED）
- `domains/credential/ratebackoff.go` - 429限流累计升级退避器
- `domains/credential/writer.go` - 凭据状态写入器
- `domains/nodehealth/reducer.go` - 节点健康评估

**当前429处理机制**：
```
1. 断路器策略（breaker.go）：
   - Wave 1 A4 (2026-09-22) 定版：429 **不进断路器失败计数**
   - 理由：限流不是被验证的失败证据
   - HALF_OPEN探针撞429不加计数

2. 绑定级冷却（ratebackoff.go + writer.go）：
   - 单次429基准冷却：3分钟（RateBackoffBase）
   - 累计升级：3min → 6min → 12min → 24min → 30min封顶
   - 遗忘窗：30分钟（距上次429超过30min ⇒ 计数归零）
   - Retry-After信任上限：1小时

3. 节奏校准（W1，2026-11-08）：
   - 窗口重灌估计（routing.rate.window_refill_seconds，默认60s）
   - 两次429间隔 ≥ 窗口 ⇒ 计数归零（节奏正常不罚）
   - 快速连击 ≥ 阈值（routing.rate.pace_violation_threshold，默认3）才升级
```

### 1.2 识别的问题

**问题1：429处理不够精细**
- ✗ 当前：429后简单冷却凭据-模型绑定，正在执行的任务被中断
- ✗ 缺失：保持正在执行任务、拒绝新请求、渐进式探测恢复

**问题2：缺少Token桶抽象**
- ✗ 当前：(凭据, 模型) 绑定分散在多个表和结构中
- ✗ 缺失：统一的Token桶概念，包含容量、质量、类型等属性

**问题3：单层路由架构**
- ✗ 当前：直接从候选凭据列表选择
- ✗ 缺失：Auto类型的任务分析 → 模型序列 → 桶优先序列的两层路由

**问题4：会话粘性策略不完善**
- ✓ 已有：stickyCredID会话亲和
- ✗ 缺失：详细的历史记录（延时、成功率）、失败后的渐进重试

**问题5：成功率指标混淆**
- ✗ 缺失：客户端成功率vs桶成功率的分离统计
- ✗ 缺失：质量指标体系（模型指纹可信度、响应速度等）

## 二、核心概念定义

### 2.1 Token桶（TokenBucket）

**定义**：Token桶 = (模型, 凭据) 的路由单元，包含容量、质量、状态等完整属性。

```go
// TokenBucket 是路由的基本单元
type TokenBucket struct {
    // 标识
    BucketID     string // "provider_id/credential_id/model_raw"
    ProviderID   int
    CredentialID int
    ModelRaw     string // 原始模型名称
    
    // 容量属性
    Capacity     BucketCapacity
    
    // 质量属性
    Quality      BucketQuality
    
    // 状态属性
    State        BucketState
    
    // 类型分类
    Type         BucketType
}

// BucketCapacity 桶的容量信息
type BucketCapacity struct {
    // RPM限制（requests per minute）
    RPMLimit       int
    RPMUsed        int
    RPMResetAt     time.Time
    
    // 并发限制
    ConcurrencyMax int
    ConcurrencyUsed int
    
    // Token限制（TPM - tokens per minute）
    TPMLimit       int
    TPMUsed        int
    TPMResetAt     time.Time
}

// BucketQuality 桶的质量指标
type BucketQuality struct {
    // 成功率（桶级别）
    BucketSuccessRate float64 // 该桶接受的所有请求的成功率
    
    // 响应速度
    AvgLatencyMs      int64 // 平均延时(ms)
    P95LatencyMs      int64 // P95延时
    
    // 模型指纹可信度
    FingerprintScore  float64 // 0-1，模型输出与预期的匹配度
    
    // 稳定性
    FailStreak        int     // 连续失败次数
    LastSuccessAt     time.Time
    
    // 综合评分（向上影响凭据和供应商质量）
    OverallScore      float64 // 0-1，综合评分
}

// BucketState 桶的状态
type BucketState struct {
    // 可用性
    Available         bool
    UnavailableReason string
    RecoverAt         *time.Time
    
    // 断路器状态
    CircuitState      CircuitState // CLOSED/OPEN/HALF_OPEN/QUARANTINED
    
    // 限流状态
    RateLimitState    RateLimitState
    
    // 探测状态
    ProbeState        ProbeState
}

// RateLimitState 限流状态（核心优化点）
type RateLimitState struct {
    // 是否处于限流状态
    IsRateLimited     bool
    
    // 限流开始时间
    LimitedSince      time.Time
    
    // 当前冷却结束时间
    CooldownUntil     time.Time
    
    // 连续429计数
    ConsecutiveCount  int
    
    // 正在执行的任务数（关键：429时不中断这些任务）
    InFlightTasks     int
    
    // 是否接受新请求
    AcceptNew         bool // 429时 = false
    
    // 探测状态
    ProbePhase        ProbePhase // NONE/INITIAL/GRADUAL/RECOVERED
    ProbeInterval     time.Duration // 当前探测间隔
    NextProbeAt       time.Time
    
    // 探测结果
    ProbeSuccessCount int
    ProbeFailCount    int
}

// ProbePhase 探测阶段
type ProbePhase string
const (
    ProbePhaseNone     ProbePhase = "none"     // 正常状态，无需探测
    ProbePhaseInitial  ProbePhase = "initial"  // 初始探测（1分钟一次）
    ProbePhaseGradual  ProbePhase = "gradual"  // 渐进恢复（成功后逐步增加）
    ProbePhaseRecovered ProbePhase = "recovered" // 已恢复
)

// BucketType 桶的类型
type BucketType string
const (
    BucketTypePaid    BucketType = "paid"     // 付费桶
    BucketTypeFree    BucketType = "free"     // 免费桶
    BucketTypeTrial   BucketType = "trial"    // 试用桶
    BucketTypeReserved BucketType = "reserved" // 保留桶（特殊用途）
)
```

## 三、核心优化方案

### 3.1 优化点1：精细化429处理机制

**目标**：429时保持正在执行的任务，拒绝新请求，通过探测渐进恢复。

#### 3.1.1 状态转换

```
正常状态 (NORMAL)
    ↓ 收到429
进入限流状态 (RATE_LIMITED)
    - 正在执行的任务：继续执行（InFlightTasks不变）
    - 新请求：拒绝（AcceptNew = false）
    - 启动探测定时器（初始1分钟）
    ↓
定时探测 (PROBING)
    - 每1分钟发送1个探测请求
    - 成功 → 进入渐进恢复
    - 失败 → 延长探测间隔（1min → 2min → 5min → 10min）
    ↓
渐进恢复 (GRADUAL_RECOVERY)
    - 第1次成功：接受10%新请求
    - 第2次成功：接受25%新请求
    - 第3次成功：接受50%新请求
    - 第4次成功：接受75%新请求
    - 第5次成功：恢复100%（回到正常状态）
    - 任一失败 → 回到限流状态
```

#### 3.1.2 实现模块

```go
// Package ratelimithandler 实现精细化429处理
package ratelimithandler

// Handler 429处理器
type Handler struct {
    bucketStates sync.Map // map[bucketID]*RateLimitState
    probeScheduler *ProbeScheduler
}

// OnRateLimit 处理429错误
func (h *Handler) OnRateLimit(bucketID string, retryAfter time.Duration) {
    state := h.getOrCreateState(bucketID)
    
    state.mu.Lock()
    defer state.mu.Unlock()
    
    // 标记限流
    state.IsRateLimited = true
    state.LimitedSince = time.Now()
    state.ConsecutiveCount++
    
    // 计算冷却时间（复用ratebackoff逻辑）
    cooldown := calculateCooldown(state.ConsecutiveCount, retryAfter)
    state.CooldownUntil = time.Now().Add(cooldown)
    
    // 拒绝新请求，但保持正在执行的任务
    state.AcceptNew = false
    // state.InFlightTasks 保持不变！
    
    // 启动探测
    state.ProbePhase = ProbePhaseInitial
    state.ProbeInterval = 1 * time.Minute
    state.NextProbeAt = time.Now().Add(state.ProbeInterval)
    
    h.probeScheduler.Schedule(bucketID, state.NextProbeAt)
}

// ShouldAcceptRequest 判断是否接受新请求
func (h *Handler) ShouldAcceptRequest(bucketID string) (accept bool, reason string) {
    state := h.getState(bucketID)
    if state == nil {
        return true, ""
    }
    
    state.mu.RLock()
    defer state.mu.RUnlock()
    
    if !state.IsRateLimited {
        return true, ""
    }
    
    // 正在限流
    if state.ProbePhase == ProbePhaseInitial {
        return false, "rate_limited_probing"
    }
    
    // 渐进恢复阶段：按比例接受
    if state.ProbePhase == ProbePhaseGradual {
        acceptRatio := h.calculateAcceptRatio(state)
        if rand.Float64() < acceptRatio {
            return true, ""
        }
        return false, fmt.Sprintf("rate_limited_gradual_%.0f%%", acceptRatio*100)
    }
    
    return false, "rate_limited"
}

// ProbeScheduler 探测调度器
type ProbeScheduler struct {
    probes chan ProbeTask
    handler *Handler
}

func (ps *ProbeScheduler) Schedule(bucketID string, at time.Time) {
    go func() {
        time.Sleep(time.Until(at))
        ps.probes <- ProbeTask{BucketID: bucketID, ScheduledAt: at}
    }()
}

// Worker 探测工作协程
func (ps *ProbeScheduler) Worker() {
    for task := range ps.probes {
        result := ps.executeProbe(task.BucketID)
        ps.handler.OnProbeResult(task.BucketID, result)
    }
}

// OnProbeResult 处理探测结果
func (h *Handler) OnProbeResult(bucketID string, result ProbeResult) {
    state := h.getState(bucketID)
    if state == nil {
        return
    }
    
    state.mu.Lock()
    defer state.mu.Unlock()
    
    if result.Success {
        state.ProbeSuccessCount++
        
        if state.ProbePhase == ProbePhaseInitial {
            // 第一次探测成功：进入渐进恢复
            state.ProbePhase = ProbePhaseGradual
            state.ProbeInterval = 30 * time.Second
        } else if state.ProbePhase == ProbePhaseGradual {
            // 渐进恢复中的成功：增加接受比例
            if state.ProbeSuccessCount >= 5 {
                // 5次成功：完全恢复
                state.IsRateLimited = false
                state.AcceptNew = true
                state.ProbePhase = ProbePhaseRecovered
                state.ConsecutiveCount = 0
                return
            }
        }
        
        // 调度下一次探测
        state.NextProbeAt = time.Now().Add(state.ProbeInterval)
        h.probeScheduler.Schedule(bucketID, state.NextProbeAt)
        
    } else {
        // 探测失败
        state.ProbeFailCount++
        state.ProbeSuccessCount = 0 // 重置成功计数
        
        // 延长探测间隔（指数退避）
        state.ProbeInterval = min(state.ProbeInterval*2, 10*time.Minute)
        state.NextProbeAt = time.Now().Add(state.ProbeInterval)
        
        // 如果在渐进恢复阶段失败，回到初始探测
        if state.ProbePhase == ProbePhaseGradual {
            state.ProbePhase = ProbePhaseInitial
            state.AcceptNew = false
        }
        
        h.probeScheduler.Schedule(bucketID, state.NextProbeAt)
    }
}

func (h *Handler) calculateAcceptRatio(state *RateLimitState) float64 {
    switch state.ProbeSuccessCount {
    case 1:
        return 0.10 // 10%
    case 2:
        return 0.25 // 25%
    case 3:
        return 0.50 // 50%
    case 4:
        return 0.75 // 75%
    default:
        return 0.0
    }
}
```

### 3.2 优化点2：Token桶管理器

**目标**：统一管理所有Token桶，提供查询、更新、评分接口。

```go
// Package tokenbucket 提供Token桶管理
package tokenbucket

// Manager Token桶管理器
type Manager struct {
    buckets sync.Map // map[bucketID]*TokenBucket
    db      *pgxpool.Pool
    cache   *redis.Client // 高速缓存
    
    // 质量评分器
    qualityScorer *QualityScorer
    
    // 429处理器
    rateLimitHandler *ratelimithandler.Handler
}

// GetBucket 获取Token桶
func (m *Manager) GetBucket(providerID, credentialID int, modelRaw string) (*TokenBucket, error) {
    bucketID := MakeBucketID(providerID, credentialID, modelRaw)
    
    // 1. 尝试从内存缓存获取
    if cached, ok := m.buckets.Load(bucketID); ok {
        return cached.(*TokenBucket), nil
    }
    
    // 2. 从Redis获取
    if bucket, err := m.loadFromCache(bucketID); err == nil {
        m.buckets.Store(bucketID, bucket)
        return bucket, nil
    }
    
    // 3. 从数据库构建
    bucket, err := m.buildFromDB(providerID, credentialID, modelRaw)
    if err != nil {
        return nil, err
    }
    
    // 4. 回写缓存
    m.buckets.Store(bucketID, bucket)
    m.saveToCache(bucket)
    
    return bucket, nil
}

// UpdateOnSuccess 成功时更新桶
func (m *Manager) UpdateOnSuccess(bucketID string, latency time.Duration, tokensUsed int) {
    bucket := m.mustGetBucket(bucketID)
    
    bucket.mu.Lock()
    defer bucket.mu.Unlock()
    
    // 更新容量
    bucket.Capacity.RPMUsed++
    bucket.Capacity.TPMUsed += tokensUsed
    bucket.Capacity.ConcurrencyUsed--
    
    // 更新质量
    bucket.Quality.FailStreak = 0
    bucket.Quality.LastSuccessAt = time.Now()
    bucket.Quality.updateLatency(latency)
    bucket.Quality.BucketSuccessRate = m.qualityScorer.RecalculateSuccessRate(bucketID)
    bucket.Quality.OverallScore = m.qualityScorer.CalculateOverallScore(&bucket.Quality)
    
    // 如果桶处于限流状态，通知恢复
    if bucket.State.RateLimitState.IsRateLimited {
        m.rateLimitHandler.OnSuccess(bucketID)
    }
    
    // 异步持久化
    m.asyncPersist(bucket)
}

// UpdateOnFailure 失败时更新桶
func (m *Manager) UpdateOnFailure(bucketID string, errKind errorsx.ErrorKind, detail string) {
    bucket := m.mustGetBucket(bucketID)
    
    bucket.mu.Lock()
    defer bucket.mu.Unlock()
    
    // 更新容量
    bucket.Capacity.ConcurrencyUsed--
    
    // 更新质量
    bucket.Quality.FailStreak++
    
    // 根据错误类型处理
    switch errKind {
    case errorsx.KindRateLimit:
        m.rateLimitHandler.OnRateLimit(bucketID, parseRetryAfter(detail))
        bucket.State.RateLimitState = *m.rateLimitHandler.GetState(bucketID)
        
    case errorsx.KindConcurrent:
        bucket.State.CircuitState = CircuitStateOpen
        bucket.State.RecoverAt = timePtr(time.Now().Add(2 * time.Minute))
        
    case errorsx.KindAuth, errorsx.KindQuota:
        bucket.State.Available = false
        bucket.State.UnavailableReason = string(errKind)
        // ... 更多处理
    }
    
    // 重新计算评分
    bucket.Quality.BucketSuccessRate = m.qualityScorer.RecalculateSuccessRate(bucketID)
    bucket.Quality.OverallScore = m.qualityScorer.CalculateOverallScore(&bucket.Quality)
    
    m.asyncPersist(bucket)
}

// QualityScorer 质量评分器
type QualityScorer struct {
    successRateWindow time.Duration // 成功率统计窗口
    latencyWeight     float64       // 延时权重
    reliabilityWeight float64       // 可靠性权重
    fingerprintWeight float64       // 指纹权重
}

// CalculateOverallScore 计算综合评分
func (qs *QualityScorer) CalculateOverallScore(q *BucketQuality) float64 {
    // 成功率分数 (0-1)
    successScore := q.BucketSuccessRate
    
    // 延时分数 (0-1，越低越好)
    latencyScore := 1.0 - min(float64(q.P95LatencyMs)/10000.0, 1.0)
    
    // 可靠性分数 (0-1)
    reliabilityScore := 1.0
    if q.FailStreak > 0 {
        reliabilityScore = max(0, 1.0-float64(q.FailStreak)*0.1)
    }
    
    // 指纹分数
    fingerprintScore := q.FingerprintScore
    
    // 加权平均
    overall := successScore*0.4 +
               latencyScore*qs.latencyWeight +
               reliabilityScore*qs.reliabilityWeight +
               fingerprintScore*qs.fingerprintWeight
    
    return overall
}

```go
// Package taskrouter 实现任务分析与模型选择
package taskrouter

// TaskRouter 任务路由器
type TaskRouter struct {
    analyzer  *TaskAnalyzer
    recommender *ModelRecommender
}

// RouteTask 分析任务并返回模型序列
func (tr *TaskRouter) RouteTask(req *RoutingRequest) ([]string, error) {
    // 1. 分析任务特征
    task := tr.analyzer.Analyze(req)
    
    // 2. 如果是Auto类型，进行任务分析
    if req.IsAuto {
        return tr.routeAutoTask(task, req)
    }
    
    // 3. 用户指定模型
    if req.Model != "" {
        return []string{req.Model}, nil
    }
    
    // 4. 根据历史和偏好推荐
    return tr.recommender.Recommend(task, req.SessionID)
}

// routeAutoTask Auto类型任务的模型选择
func (tr *TaskRouter) routeAutoTask(task *Task, req *RoutingRequest) ([]string, error) {
    // 根据任务类型和特征选择模型序列
    switch task.Type {
    case TaskTypeCodeGeneration:
        // 代码生成：优先代码专精模型
        return []string{
            "deepseek-coder-v3",
            "gpt-4-turbo",
            "claude-opus-4",
        }, nil
        
    case TaskTypeLongContext:
        // 长上下文：优先大窗口模型
        return []string{
            "claude-opus-4",
            "gemini-pro-1.5",
            "gpt-4-turbo-128k",
        }, nil
        
    case TaskTypeReasoningHeavy:
        // 推理密集：优先推理能力强的模型
        return []string{
            "o1-preview",
            "claude-opus-4",
            "gpt-4-turbo",
        }, nil
        
    case TaskTypeChat:
        // 普通对话：平衡性能和成本
        return []string{
            "gpt-4-turbo",
            "claude-sonnet-5",
            "deepseek-v4",
        }, nil
        
    default:
        // 默认序列
        return []string{
            "gpt-4-turbo",
            "claude-opus-4",
        }, nil
    }
}

// TaskAnalyzer 任务分析器
type TaskAnalyzer struct {
    // 特征提取器
    extractors []FeatureExtractor
}

// Analyze 分析请求并提取任务特征
func (ta *TaskAnalyzer) Analyze(req *RoutingRequest) *Task {
    task := &Task{
        Features: make(map[string]interface{}),
    }
    
    // 提取各种特征
    for _, extractor := range ta.extractors {
        extractor.Extract(req, task)
    }
    
    // 分类任务类型
    task.Type = ta.classifyTaskType(task.Features)
    
    return task
}

// 特征提取器示例
type MessageLengthExtractor struct{}

func (e *MessageLengthExtractor) Extract(req *RoutingRequest, task *Task) {
    totalTokens := 0
    for _, msg := range req.Messages {
        totalTokens += len(msg.Content) / 4 // 粗略估计
    }
    task.Features["total_tokens"] = totalTokens
    task.Features["message_count"] = len(req.Messages)
    
    // 判断是否长上下文
    if totalTokens > 30000 {
        task.Features["is_long_context"] = true
    }
}

type CodePatternExtractor struct{}

func (e *CodePatternExtractor) Extract(req *RoutingRequest, task *Task) {
    // 检查是否包含代码特征
    hasCodeBlock := false
    hasCodeKeywords := false
    
    for _, msg := range req.Messages {
        if strings.Contains(msg.Content, "```") {
            hasCodeBlock = true
        }
        if containsAny(msg.Content, []string{
            "function", "class", "import", "def ", "const ",
            "编写代码", "写一个函数", "debug", "代码实现",
        }) {
            hasCodeKeywords = true
        }
    }
    
    task.Features["has_code_block"] = hasCodeBlock
    task.Features["has_code_keywords"] = hasCodeKeywords
}

// Package bucketrouter 实现桶选择与排序
package bucketrouter

// BucketRouter 桶路由器
type BucketRouter struct {
    bucketMgr     *tokenbucket.Manager
    sessionMgr    *SessionAffinityManager
    capacityMgr   *CapacityManager
    rateLimitHandler *ratelimithandler.Handler
}

// SelectBuckets 为指定模型选择桶序列
func (br *BucketRouter) SelectBuckets(
    model string,
    sessionID string,
    req *RoutingRequest,
) ([]string, error) {
    // 1. 获取该模型的所有可用桶
    candidates := br.findCandidateBuckets(model)
    
    // 2. 应用会话粘性
    if sessionID != "" {
        if sticky := br.sessionMgr.GetStickyBucket(sessionID, model); sticky != "" {
            candidates = br.promoteStickyBucket(candidates, sticky)
        }
    }
    
    // 3. 过滤不可用的桶
    available := br.filterAvailable(candidates)
    
    // 4. 应用容量过滤
    hasCapacity := br.capacityMgr.FilterByCapacity(available)
    
    // 5. 应用限流过滤
    acceptingNew := br.filterAcceptingNew(hasCapacity)
    
    // 6. 排序（质量评分）
    sorted := br.sortByQuality(acceptingNew)
    
    // 7. 如果所有桶都限流，考虑限流但接受部分请求的桶
    if len(sorted) == 0 {
        partial := br.findPartialAcceptBuckets(hasCapacity)
        sorted = append(sorted, partial...)
    }
    
    // 8. 提取桶ID
    bucketIDs := make([]string, len(sorted))
    for i, bucket := range sorted {
        bucketIDs[i] = bucket.BucketID
    }
    
    return bucketIDs, nil
}

// filterAcceptingNew 过滤接受新请求的桶
func (br *BucketRouter) filterAcceptingNew(buckets []*tokenbucket.TokenBucket) []*tokenbucket.TokenBucket {
    result := make([]*tokenbucket.TokenBucket, 0, len(buckets))
    for _, bucket := range buckets {
        accept, _ := br.rateLimitHandler.ShouldAcceptRequest(bucket.BucketID)
        if accept {
            result = append(result, bucket)
        }
    }
    return result
}

// findPartialAcceptBuckets 查找处于渐进恢复阶段的桶
func (br *BucketRouter) findPartialAcceptBuckets(buckets []*tokenbucket.TokenBucket) []*tokenbucket.TokenBucket {
    result := make([]*tokenbucket.TokenBucket, 0)
    for _, bucket := range buckets {
        accept, reason := br.rateLimitHandler.ShouldAcceptRequest(bucket.BucketID)
        // 渐进恢复阶段：可能接受
        if !accept && strings.Contains(reason, "gradual") {
            result = append(result, bucket)
        }
    }
    return result
}

// sortByQuality 按质量评分排序
func (br *BucketRouter) sortByQuality(buckets []*tokenbucket.TokenBucket) []*tokenbucket.TokenBucket {
    sorted := append([]*tokenbucket.TokenBucket{}, buckets...)
    
    sort.Slice(sorted, func(i, j int) bool {
        qi := sorted[i].Quality.OverallScore
        qj := sorted[j].Quality.OverallScore
        
        // 质量评分降序
        if qi != qj {
            return qi > qj
        }
        
        // 评分相同，比较延时（升序）
        return sorted[i].Quality.AvgLatencyMs < sorted[j].Quality.AvgLatencyMs
    })
    
    return sorted
}

package sessionaffinity

// SessionAffinityManager 会话粘性管理器
type SessionAffinityManager struct {
    cache *redis.Client
    local sync.Map // 本地缓存
}

// SessionHistory 会话历史
type SessionHistory struct {
    SessionID    string
    Requests     []RequestRecord
    mu           sync.RWMutex
}

// RequestRecord 请求记录
type RequestRecord struct {
    RequestID    string
    Timestamp    time.Time
    Model        string
    BucketID     string
    Latency      time.Duration
    Success      bool
    ErrorKind    errorsx.ErrorKind
    TokensUsed   int
}

// RecordRequest 记录请求
func (sam *SessionAffinityManager) RecordRequest(record RequestRecord) {
    history := sam.getOrCreateHistory(record.SessionID)
    
    history.mu.Lock()
    defer history.mu.Unlock()
    
    // 添加记录
    history.Requests = append(history.Requests, record)
    
    // 保持最近100条
    if len(history.Requests) > 100 {
        history.Requests = history.Requests[len(history.Requests)-100:]
    }
    
    // 异步持久化到Redis
    go sam.persistHistory(history)
}

// GetStickyBucket 获取粘性桶
func (sam *SessionAffinityManager) GetStickyBucket(sessionID, model string) string {
    history := sam.getHistory(sessionID)
    if history == nil {
        return ""
    }
    
    history.mu.RLock()
    defer history.mu.RUnlock()
    
    // 查找该模型最近的成功记录
    for i := len(history.Requests) - 1; i >= 0; i-- {
        req := history.Requests[i]
        if req.Model == model && req.Success {
            // 检查该桶的最近表现
            if sam.isBucketStable(history, req.BucketID, model) {
                return req.BucketID
            }
            break
        }
    }
    
    return ""
}

// isBucketStable 判断桶是否稳定
func (sam *SessionAffinityManager) isBucketStable(
    history *SessionHistory,
    bucketID string,
    model string,
) bool {
    // 统计该桶最近10次请求
    count := 0
    successCount := 0
    
    for i := len(history.Requests) - 1; i >= 0 && count < 10; i-- {
        req := history.Requests[i]
        if req.BucketID == bucketID && req.Model == model {
            count++
            if req.Success {
                successCount++
            }
        }
    }
    
    if count == 0 {
        return false
    }
    
    // 成功率 >= 80% 认为稳定
    successRate := float64(successCount) / float64(count)
    return successRate >= 0.8
}

// ShouldSwitchBucket 判断是否应该切换桶
func (sam *SessionAffinityManager) ShouldSwitchBucket(
    sessionID string,
    currentBucket string,
    model string,
) bool {
    history := sam.getHistory(sessionID)
    if history == nil {
        return false
    }
    
    history.mu.RLock()
    defer history.mu.RUnlock()
    
    // 统计当前桶最近的失败
    recentFailures := 0
    for i := len(history.Requests) - 1; i >= 0 && i >= len(history.Requests)-5; i-- {
        req := history.Requests[i]
        if req.BucketID == currentBucket && req.Model == model && !req.Success {
            recentFailures++
        }
    }
    
    // 最近5次请求中有3次失败 → 应该切换
    return recentFailures >= 3
}

type MetricsCollector struct {

// ClientWindow 客户端窗口统计
type ClientWindow struct {
    SessionID     string
    TotalRequests int
    SuccessRequests int // 最终给客户端成功的请求数
    FailedRequests int  // 最终失败的请求数
    
    // 明细：路由重试不影响客户端成功率
    AttemptStats  AttemptStats
}

type AttemptStats struct {
    TotalAttempts   int // 总尝试次数（含重试）
    SuccessAttempts int // 成功的尝试次数
    FailoverCount   int // 故障转移次数
    AvgAttemptsPerRequest float64 // 平均每请求尝试次数
}

// RecordClientRequest 记录客户端请求结果
func (cm *ClientMetrics) RecordClientRequest(sessionID string, success bool, attempts int) {
    cm.mu.Lock()
    defer cm.mu.Unlock()
    
    window := cm.getOrCreateWindow(sessionID)
    
    window.TotalRequests++
    window.AttemptStats.TotalAttempts += attempts
    
    if success {
        window.SuccessRequests++
    } else {
        window.FailedRequests++
    }
    
    if attempts > 1 {
        window.AttemptStats.FailoverCount++
    }
    
    // 重新计算平均值
    window.AttemptStats.AvgAttemptsPerRequest = 
        float64(window.AttemptStats.TotalAttempts) / float64(window.TotalRequests)
}

// GetClientSuccessRate 获取客户端成功率
func (cm *ClientMetrics) GetClientSuccessRate(sessionID string) float64 {
    cm.mu.RLock()
    defer cm.mu.RUnlock()
    
    window := cm.windows[sessionID]
    if window == nil || window.TotalRequests == 0 {
        return 0
    }
    
    return float64(window.SuccessRequests) / float64(window.TotalRequests)
}

// BucketMetrics 桶成功率统计
type BucketMetrics struct {
    mu sync.RWMutex
    windows map[string]*BucketWindow // bucketID -> window
}

// BucketWindow 桶窗口统计
type BucketWindow struct {
    BucketID      string
    TotalRequests int // 该桶接受的所有请求
    SuccessRequests int // 该桶成功的请求
    FailedRequests int

    FailuresByKind map[errorsx.ErrorKind]int
    
    // 质量指标
    TotalLatencyMs int64
    TokensServed   int
}

// RecordBucketAttempt 记录桶尝试
func (bm *BucketMetrics) RecordBucketAttempt(
    bucketID string,
    success bool,
    latencyMs int64,
    errKind errorsx.ErrorKind,
    tokensUsed int,
) {
    bm.mu.Lock()
    defer bm.mu.Unlock()
    
    window := bm.getOrCreateWindow(bucketID)
    
    window.TotalRequests++
    
    if success {
        window.SuccessRequests++
        window.TotalLatencyMs += latencyMs
        window.TokensServed += tokensUsed
    } else {
        window.FailedRequests++
        if window.FailuresByKind == nil {
            window.FailuresByKind = make(map[errorsx.ErrorKind]int)
        }
        window.FailuresByKind[errKind]++
    }
}

    }

// RoutingEngine 路由引擎（门面）
type RoutingEngine struct {
    // 第一层
    taskRouter *taskrouter.TaskRouter
    
    // 第二层
    bucketRouter *bucketrouter.BucketRouter
    
    // 支撑组件
    bucketMgr        *tokenbucket.Manager
    rateLimitHandler *ratelimithandler.Handler
    sessionMgr       *sessionaffinity.SessionAffinityManager
    metricsCollector *metrics.MetricsCollector
}

// RouteRequest 路由请求（总入口）
func (re *RoutingEngine) RouteRequest(req *RoutingRequest) (*RoutingPlan, error) {
    // 第一层：选择模型序列
    models, err := re.taskRouter.RouteTask(req)
    if err != nil {
        return nil, err
    }
    
    // 第二层：为每个模型选择桶序列
    plan := &RoutingPlan{
        RequestID: req.RequestID,
        SessionID: req.SessionID,
        Stages:    make([]RoutingStage, 0, len(models)),
    }
    
    for _, model := range models {
        buckets, err := re.bucketRouter.SelectBuckets(model, req.SessionID, req)
        if err != nil {
            continue // 跳过该模型
        }
        
        plan.Stages = append(plan.Stages, RoutingStage{
            Model:   model,
            Buckets: buckets,
        })
    }
    
    if len(plan.Stages) == 0 {
        return nil, errors.New("no available routing path")
    }
    
    return plan, nil
}

// ExecuteWithRetry 执行请求（带重试）
func (re *RoutingEngine) ExecuteWithRetry(
    ctx context.Context,
    req *RoutingRequest,
    plan *RoutingPlan,
) (*Response, error) {
    totalAttempts := 0
    var lastErr error
    
    // 遍历模型 × 桶的二维序列
    for _, stage := range plan.Stages {
        for _, bucketID := range stage.Buckets {
            totalAttempts++
            
            // 检查是否接受请求
            accept, reason := re.rateLimitHandler.ShouldAcceptRequest(bucketID)
            if !accept {
                slog.Debug("bucket not accepting", "bucket", bucketID, "reason", reason)
                continue
            }
            
            // 获取桶
            bucket, err := re.bucketMgr.GetBucketByID(bucketID)
            if err != nil {
                continue
            }
            
            // 检查容量
            if !re.hasCapacity(bucket) {
                continue
            }
            
            // 执行请求
            startTime := time.Now()
            resp, err := re.executeOnBucket(ctx, req, bucket)
            latency := time.Since(startTime)
            
            if err == nil {
                // 成功
                re.onSuccess(req, bucket, resp, latency, totalAttempts)
                return resp, nil
            }
            
            // 失败：记录并继续尝试
            lastErr = err
            re.onFailure(req, bucket, err, latency)
            
            // 如果是不可重试的错误，直接返回
            if !re.isRetryable(err) {
                break
            }
        }
    }
    
    // 全部失败
    re.metricsCollector.ClientMetrics.RecordClientRequest(req.SessionID, false, totalAttempts)
    return nil, fmt.Errorf("all attempts failed: %w", lastErr)
}

func (re *RoutingEngine) onSuccess(
    req *RoutingRequest,
    bucket *tokenbucket.TokenBucket,
    resp *Response,
    latency time.Duration,
    totalAttempts int,
) {
    // 1. 更新桶状态
    re.bucketMgr.UpdateOnSuccess(bucket.BucketID, latency, resp.TokensUsed)
    
    // 2. 记录会话历史
    re.sessionMgr.RecordRequest(sessionaffinity.RequestRecord{
        RequestID:  req.RequestID,
        Timestamp:  time.Now(),
        Model:      bucket.ModelRaw,
        BucketID:   bucket.BucketID,
        Latency:    latency,
        Success:    true,
        TokensUsed: resp.TokensUsed,
    })
    
    // 3. 记录客户端指标
    re.metricsCollector.ClientMetrics.RecordClientRequest(req.SessionID, true, totalAttempts)
    
    // 4. 记录桶指标
    re.metricsCollector.BucketMetrics.RecordBucketAttempt(
        bucket.BucketID, true, latency.Milliseconds(), "", resp.TokensUsed,
    )
}

func (re *RoutingEngine) onFailure(
    req *RoutingRequest,
    bucket *tokenbucket.TokenBucket,
    err error,
    latency time.Duration,
) {
    errKind := errorsx.ClassifyError(err)
    detail := err.Error()
    
    // 1. 更新桶状态
    re.bucketMgr.UpdateOnFailure(bucket.BucketID, errKind, detail)
    
    // 2. 记录会话历史
    re.sessionMgr.RecordRequest(sessionaffinity.RequestRecord{
        RequestID: req.RequestID,
        Timestamp: time.Now(),
        Model:     bucket.ModelRaw,
        BucketID:  bucket.BucketID,
        Latency:   latency,
        Success:   false,
        ErrorKind: errKind,
    })
    
    // 3. 记录桶指标
    re.metricsCollector.BucketMetrics.RecordBucketAttempt(
        bucket.BucketID, false, latency.Milliseconds(), errKind, 0,
    )
}

## 六、风险与缓解

### 6.1 风险识别

**风险1：状态同步复杂性**
- 问题：多实例部署时，429状态、探测状态如何同步？
- 缓解：
  - 短期：进程内状态（与slowrest同款，已知局限）
  - 长期：Redis共享状态（需评估性价比）

**风险2：探测请求成本**
- 问题：大量桶同时探测会产生额外请求
- 缓解：
  - 探测批次控制（每分钟最多N个）
  - 探测请求使用最小化参数
  - 探测失败延长间隔（指数退避）

**风险3：渐进恢复策略调优**
- 问题：10%→25%→50%的比例可能需要调整
- 缓解：
  - 作为配置参数（settings热加载）
  - 监控恢复效果
  - A/B测试优化参数

**风险4：向后兼容性**
- 问题：现有系统依赖credential_model_bindings表结构
- 缓解：
  - Token桶作为新抽象层，底层仍写入现有表
  - 渐进式迁移，保持双写一段时间
  - 完善的回滚机制

### 6.2 回滚策略

**降级开关**：
```go
// 在settings中配置

routing.rate_limit.gradual_recovery = false  // 禁用渐进恢复

```

**数据回滚**：
- Token桶状态存储在独立表，不影响现有表
- 删除新增表即可完全回滚
