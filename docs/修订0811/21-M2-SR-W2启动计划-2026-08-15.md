## 3. 工作项分解（按 doc 18 §18 SR-05/06/07 收口）

### SR-05 ExecuteAttempt 固定语义入口
- 定义 `ExecuteAttempt(ctx, attemptCtx)` 单 attempt 执行契约：**关闭 Handler Goal 外循环、旧 async fallback、跨 attempt 递归**（doc 18 §17 Phase 0 定义）。
- 落点：`executors/executor.go:1901 Execute` 的候选循环（:2659 附近）之上包一层 attempt 级入口；ownership 按 retryowner 区分 survival owner（单次透传，W0 已冻结）与非 survival（沿用旧路径）。
- 验收：无 Goal/async/recursive 嵌套重试；attempt context 真正生效。

### SR-06 SurvivalCoordinator 连接内循环
- 状态机：doc 18 §5.1/§7（running→waiting→retry→终态，30min InteractiveDeadline）。
- 核心循环：ExecuteAttempt → AggregateTaskOutcome → TaskAction 分派（retry-now 立即换候选 / wait-recovery 刷新候选池再试 / terminal 渲染终止 / ResumeBlocked 透传已提交内容）。
- **恢复语义**：可恢复耗尽在 commit_state<content 时不写终止帧 → Discard attempt → 刷新候选（复用 autoroute 候选重取路径）→ 重试；commit_state≥content 一律 ResumeBlocked 不再重试（doc 18 §10.3，W1 outcome 已实现该分类）。
- keepalive：等待/重试间隙经 SerializedStreamWriter 发注释帧（严格客户端只收注释，doc 18 §9.1）。
- 7 个桥接线点（stream.go:439、responses_stream.go:37、responses_bridge.go:296/557、anthropic_stream.go:85、anthropic_bridge.go:134/322）已全部有 MayWriteTerminal 门控（M1 审计确认超前接入），W2 只需在 Coordinator 侧持有 gate 所有权。
