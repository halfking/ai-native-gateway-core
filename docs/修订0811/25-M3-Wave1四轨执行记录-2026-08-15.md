## 2. GATE 轨（SR-W3 前置门禁）

- `secret/aad.go`：domain-separated `EncryptWithAAD/DecryptWithAAD`（AES-256-GCM）。三域登记 `llm-gateway:durable-request:v1` / `durable-result:v1` / `sanitize:v1`（与 doc 18 §11.2 原文一致，已核对）；AAD = domain + (TenantID, TaskID, RequestHash) 长度前缀规范拼接；envelope `v2|<domain>|<kid>|<b64(nonce||ct||tag)>` 返回实际 key_id；fail-closed 三条件哨兵错误 `ErrAADNoKey/ErrAADUnknownVersion/ErrAADMismatch`；与既有 credential 域 `EncryptAESGCM` 双向不可解（测试钉住）。密钥完全复用 `secret.Keyring`（单 keyring、多 AAD domain）。
- `pending/`：`FallbackSource` 接口 + `NewStoreWithFallback`（显式注入式开关，既有 `NewStore` 调用点 fallback=nil 行为与 main 逐字节一致，有测试钉住）；`PGSource` 从 `durable_llm_tasks` 回源（按 doc 18 §11.1 列名），completed 带 `result_ciphertext` 用 durable-result 域解密，completed 无密文/无密钥/篡改一律 fail closed；Redis miss/error 均回源，回源错误向上传播。
- **门禁边界（诚实声明）**：durable_llm_tasks 建表 migration、请求路径接线、真实 PG 联调属 Wave 2；本轨为 pgxmock 代码级验证 + miniredis 回源行为验证。SR-W3 启动条件据此判定为「原语与回源路径就绪」，非「部署态验证完成」。
