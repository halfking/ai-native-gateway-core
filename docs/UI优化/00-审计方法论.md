# LLMGo UI 审计方法论

> 审计站点：https://llmgo.kxpms.cn  
> 审计账号：admin（super_admin + 默认租户）  
> 审计日期：2026-07-14

## 四维检查清单

| 维度 | 检查项 | 记录方式 |
|------|--------|----------|
| **视觉/display** | 反色块、对比度、按钮/文字字号、控件宽度、不应折行/错位、表格列溢出 | 截图 + 文字描述 |
| **功能组织** | 信息分组是否合理、主次是否清晰、视觉平衡 | 结构图 + 建议 |
| **数据布局** | 左→右、上→下；简洁紧凑直观完整；空态/加载态 | 布局区块图 |
| **多语言** | 8 语言切换；key 泄漏、截断、RTL 错位 | 每种语言 1 条结论 |

## 优先级定义

- **P0**：信息丢失、i18n key 泄漏、布局严重错位、功能不可用
- **P1**：可读性差、折行/溢出、i18n 部分缺失
- **P2**：间距/对齐/美观微调

## 视口与工具

- 主视口：1920×1080
- 抽样视口：1366×768（复杂表格页）
- 工具：cursor-ide-browser 实测 + `npm run i18n:check` 静态交叉验证
