# 仪表盘V2快速启动指南

## 🚀 立即体验

### 1. 编译前端
```bash
cd web
npm run build
```

### 2. 启动服务
```bash
# 如果已经在运行，重启即可
./llm-gateway-go
```

### 3. 访问仪表盘
打开浏览器访问：`http://localhost:__PORT_12__/`

页面顶部会显示版本切换器，点击 **V2 新版（泳道）** 即可体验新功能。

## 📊 功能演示

### 紧凑统计行
- 9个核心指标在一行显示
- 鼠标悬停卡片会高亮
- 支持横向滚动

### 实时请求流
1. **选择分组维度**：点击 `按原厂` / `按供应商` / `按模型`
2. **查看图例**：图例下方显示Top5统计
3. **点击图例**：高亮对应色块，其它暗化
4. **再次点击**：取消选择
5. **点击色块**：打开请求详情

### 统计抽屉
- 点击 `📊 API Key 排行` 查看高用量Key
- 点击 `📈 模型统计` 查看按模型汇总
- 点击右上角 `✕` 关闭抽屉

### WebSocket控制
- **连接状态**：绿点=已连接，黄点=重连中
- **暂停/恢复**：控制实时数据推送
- **缓存统计**：显示当前缓存的请求数

## 🔧 故障排查

### 问题1：页面空白
**可能原因**：前端编译失败  
**解决方法**：
```bash
cd web
npm install
npm run build
```

### 问题2：实时流不更新
**可能原因**：WebSocket连接失败  
**检查步骤**：
1. 查看连接状态（应该是绿点）
2. 点击连接状态查看WebSocket地址
3. 检查浏览器控制台是否有错误
4. 检查后端日志

### 问题3：统计数据不准确
**可能原因**：数据漂移  
**解决方法**：系统每5分钟自动重新校准，也可以点击 `刷新` 按钮手动同步

### 问题4：色块显示乱码
**可能原因**：字体加载失败  
**解决方法**：色块已配置字体回退方案，应该不会出现。如果出现，请检查浏览器字体设置

## 📱 移动端适配

V2版本已适配移动端：
- 统计卡片：横向滚动
- 控制按钮：纵向堆叠

## 🎯 使用技巧

### 技巧1：快速定位高频模型
1. 选择 `按模型` 分组
2. 查看图例，前5个就是高频模型
3. 点击图例高亮对应色块

### 技巧2：监控错误分布
1. 查看状态图例的右侧
2. 红色/橙色边框的色块是错误请求
3. 点击色块查看详细错误信息

### 技巧3：分析供应商性能
1. 选择 `按供应商` 分组
2. 观察各泳道的色块密度
3. 密度高的供应商请求量大

### 技巧4：暂停分析
1. 点击 `暂停` 按钮
2. 仔细观察当前泳道状态
3. 点击色块查看详情
4. 完成后点击 `恢复` 继续
