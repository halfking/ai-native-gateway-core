## 📞 技术细节

### 已实现的架构优势

**懒加载优化**：
- zh-CN + en-US 静态打包（336 KB gzip: 125 KB）
- 其他 6 种语言按需加载
- 首次加载性能优化

**Fallback 机制**：
```typescript
// App.vue line 158
{{ item.labelKey ? t(item.labelKey) : item.label }}
```
- labelKey 存在 → 使用 t() 翻译
- labelKey 不存在 → 显示原 label（中文）
- 确保向后兼容

**RTL 支持**：
```typescript
// i18n.ts line 76-79
if (code === 'ar') {
  document.documentElement.dir = 'rtl'
}
```
- 阿拉伯语自动切换到 RTL 布局
- CSS 已通过 postcss-rtlcss 预处理
