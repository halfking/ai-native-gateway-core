## 现状评估

| 维度 | 结论 | 优先级 |
|------|------|--------|
| 视觉/display | 配置键直接展示，偏技术向。 | P1 |
| 功能组织 | 按模块分组合理。 | P2 |
| 数据布局 | 分组→键值表。 | P2 |
| 多语言 | 配置key为英文dot notation（预期）；标签需i18n。 | P1 |
