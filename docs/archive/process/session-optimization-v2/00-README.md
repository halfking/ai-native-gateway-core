- ⏸️ HTTP 202 Retry 协议：提案阶段，未实现

### Schema 名称勘误

⚠️ **重要**：Session V2 实际使用 `gateway.*` schema，不是历史设计文档中的 `public.*`

```sql
-- 正式表名（生产环境）
gateway.sessions
gateway.session_turns
gateway.session_bodies
gateway.session_turn_logs
```

详见 [31-当前实现基线与修正决策.md](./31-当前实现基线与修正决策.md) § ADR-V2-001。

### Phase 前缀规范

为避免混淆，所有 Phase 必须带作用域：

- `V2-P0`, `V2-P1` ... → Session V2 存储
- `Goal-P0`, `Goal-P1` ... → Goal 模式
- `Handoff-P3` ... → Handoff 协同

禁止无前缀的"Phase 2"等模糊表述。
