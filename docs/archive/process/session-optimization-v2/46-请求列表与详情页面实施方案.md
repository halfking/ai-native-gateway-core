# 请求列表与详情页面实施方案

> **文档版本**: v1.0  
> **创建日期**: 2026-08-06  
> **文档性质**: 实施方案（Implementation Plan）  
> **关联审计**: [43-会话轮次表优化审计报告.md](./43-会话轮次表优化审计报告.md)

## 📋 执行摘要

本方案旨在**新增基于 V2 表的请求列表和详情页面**，同时**保留旧页面作为回退保障**，实现：

1. **新请求列表页面**：从 `session_turns` 表读取，按轮次展示
2. **原始请求详情页面**：展示单个轮次的原始请求（request_delta）
3. **完整会话详情页面**：展示完整会话上下文（动态拼接所有轮次）
4. **旧页面保留**：保留基于 `request_logs` 的旧页面作为 fallback

## 2. 需求分析

### 2.1 用户场景

#### 场景 1：运维人员查看最近请求

**需求**：
- 按时间倒序查看最近的所有请求（跨会话）
- 快速定位问题请求（错误、高延迟）
- 过滤条件：时间范围、租户、模型、状态码

**现状**：
- `session_list.go` 只能查看会话（按 session 聚合）
- 无法按请求维度查看

#### 场景 2：开发人员调试单个请求

**需求**：
- 查看单个请求的原始输入/输出
- 查看该请求在会话中的上下文（前几轮）
- 对比 request_delta 和 outbound_body 的差异

**现状**：
- `request_trace.go` 提供链路追踪，但不展示消息体
- `session_detail_v2.go` 提供完整数据，但只有增量

#### 场景 3：产品经理分析会话质量

**需求**：
- 查看完整会话对话记录
- 理解压缩后的实际发送内容（outbound_body）
- 评估压缩策略的效果

**现状**：
- `session_detail_v2.go` 返回 delta，未拼接
- 需要前端自己拼接，增加复杂度

package admin

// RequestDetailV2API 提供单轮次详情查询
type RequestDetailV2API struct {
    pool *pgxpool.Pool
}

type RequestDetailResponse struct {
    // 元数据（from session_turns）
    RequestID    string    `json:"request_id"`
    SessionID    string    `json:"session_id"`
    TurnNo       int       `json:"turn_no"`
    Ts           time.Time `json:"ts"`
    Model        string    `json:"model"`
    // ...

    // 消息体（from session_bodies）
    RequestDelta        []Message `json:"request_delta"`
    ResponseDelta       []Message `json:"response_delta"`
    OutboundBody        []Message `json:"outbound_body"`
    RequestAttachments  []Attachment `json:"request_attachments,omitempty"`
    ResponseAttachments []Attachment `json:"response_attachments,omitempty"`

    // 上下文导航
    PrevTurns []int `json:"prev_turns"` // 前面的轮次号
    NextTurns []int `json:"next_turns"` // 后面的轮次号
}

func (api *RequestDetailV2API) ServeHTTP(w http.ResponseWriter, r *http.Request) {
    // 从 URL 提取 request_id: /api/admin/v2/requests/{request_id}
    requestID := extractRequestID(r.URL.Path)
    if requestID == "" {
        http.Error(w, "request_id required", http.StatusBadRequest)
        return
    }

    ctx, cancel := context.WithTimeout(r.Context(), 5*time.Second)
    defer cancel()

    detail, err := api.queryRequestDetail(ctx, requestID)
    if err != nil {
        writeJSONError(w, http.StatusInternalServerError, err.Error())
        return
    }

    if detail == nil {
        writeJSONError(w, http.StatusNotFound, "request not found")
        return
    }

    writeJSON(w, http.StatusOK, detail)
}

func (api *RequestDetailV2API) queryRequestDetail(
    ctx context.Context,
    requestID string,
) (*RequestDetailResponse, error) {
    // JOIN session_turns + session_bodies
    query := `
        SELECT 
            t.request_id, t.session_id, t.turn_no, t.ts, t.model, t.provider,
            t.status_code, t.prompt_tokens, t.completion_tokens, t.cost_usd,
            b.request_delta, b.response_delta, b.outbound_body,
            b.request_attachments, b.response_attachments
        FROM gateway.session_turns t
        LEFT JOIN gateway.session_bodies b
            ON t.session_id = b.session_id
            AND t.turn_no = b.turn_no
            AND t.partition_date = b.partition_date
        WHERE t.request_id = $1
    `

    // 执行查询并解析 JSONB 字段
    // ...

    // 查询同一会话的其他轮次（用于上下文导航）
    prevTurns, nextTurns := api.queryAdjacentTurns(ctx, detail.SessionID, detail.TurnNo)
    detail.PrevTurns = prevTurns
    detail.NextTurns = nextTurns

    return detail, nil

### 4.3 完整会话上下文 API

#### 文件：`admin/session_context_v2.go`

```go
package admin

import (
    "github.com/kaixuan/llm-gateway-go/domains/session/v2"
)

// SessionContextV2API 提供完整会话上下文查询
type SessionContextV2API struct {
    pool    *pgxpool.Pool
    reader  *v2.TurnReader
    builder *v2.OutboundBuilder
}

func NewSessionContextV2API(pool *pgxpool.Pool) *SessionContextV2API {
    reader := v2.NewTurnReader(pool)
    builder := v2.NewOutboundBuilder(reader)
    return &SessionContextV2API{
        pool:    pool,
        reader:  reader,
        builder: builder,
    }
}

type SessionContextResponse struct {
    SessionID   string    `json:"session_id"`
    TotalTurns  int       `json:"total_turns"`
    Messages    []Message `json:"messages"` // 完整拼接后的消息数组
    Metadata    ContextMetadata `json:"metadata"`
}

type ContextMetadata struct {
    TotalTokens        int     `json:"total_tokens"`
    TotalCostUSD       float64 `json:"total_cost_usd"`
    CompressionApplied bool    `json:"compression_applied"`
    FirstTurnAt        time.Time `json:"first_turn_at"`
    LastTurnAt         time.Time `json:"last_turn_at"`
}

func (api *SessionContextV2API) ServeHTTP(w http.ResponseWriter, r *http.Request) {
    sessionID := extractSessionID(r.URL.Path)
    if sessionID == "" {
        http.Error(w, "session_id required", http.StatusBadRequest)
        return
    }

    tenantID := r.URL.Query().Get("tenant")
    if tenantID == "" {
        tenantID = "default"
    }

    // 可选：只加载最近 N 轮
    lastN := parseIntParam(r.URL.Query().Get("last_n"), 0)

    ctx, cancel := context.WithTimeout(r.Context(), 10*time.Second)
    defer cancel()

    context, err := api.buildSessionContext(ctx, sessionID, tenantID, lastN)
    if err != nil {
        writeJSONError(w, http.StatusInternalServerError, err.Error())
        return
    }

    writeJSON(w, http.StatusOK, context)
}

func (api *SessionContextV2API) buildSessionContext(
    ctx context.Context,
    sessionID, tenantID string,
    lastN int,
) (*SessionContextResponse, error) {
    // 使用 OutboundBuilder 动态拼接增量
    messages, meta, err := api.builder.BuildFromDeltas(
        ctx, tenantID, sessionID,
        lastN,
        true, // preserve compression markers
    )
    if err != nil {
        return nil, fmt.Errorf("build from deltas: %w", err)
    }

    // 查询会话元数据
    sessionMeta, err := api.querySessionMetadata(ctx, sessionID, tenantID)
    if err != nil {
        return nil, fmt.Errorf("query session metadata: %w", err)
    }

    return &SessionContextResponse{
        SessionID:  sessionID,
        TotalTurns: meta.TotalTurns,
        Messages:   messages,
        Metadata: ContextMetadata{
            TotalTokens:        sessionMeta.TotalTokens,
            TotalCostUSD:       sessionMeta.TotalCostUSD,
            CompressionApplied: meta.HasCompression,
            FirstTurnAt:        sessionMeta.CreatedAt,
            LastTurnAt:         sessionMeta.UpdatedAt,
        },
    }, nil
}
```

## 7. 数据对比验证

### 7.1 双读验证

在灰度期间，同时调用 V1 和 V2 API，对比结果：

```go
func validateV2Response(v1Response, v2Response) error {
    // 对比关键字段
    if v1.TotalCount != v2.TotalCount {
        return fmt.Errorf("total count mismatch: v1=%d, v2=%d", 
            v1.TotalCount, v2.TotalCount)
    }

    // 对比请求列表
    for i, v1Item := range v1.Requests {
        v2Item := v2.Requests[i]
        if v1Item.RequestID != v2Item.RequestID {
            return fmt.Errorf("request_id mismatch at index %d", i)
        }
        if abs(v1Item.Tokens - v2Item.Tokens) > 5 {
            // 容忍 5 token 差异（压缩估算误差）
            return fmt.Errorf("token mismatch at index %d", i)
        }
    }

    return nil
}
```

### 7.2 数据一致性检查

定期运行一致性检查脚本：

```sql
-- 检查 V1 和 V2 的请求数量
SELECT 
    'V1' AS source,
    COUNT(*) AS request_count
FROM request_logs
WHERE tenant_id = 'default'
  AND ts > NOW() - INTERVAL '7 days'

UNION ALL

SELECT 
    'V2' AS source,
    COUNT(*) AS request_count
FROM gateway.session_turns
WHERE tenant_id = 'default'
  AND ts > NOW() - INTERVAL '7 days';
```
