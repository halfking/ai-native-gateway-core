模块依赖验证系统架构

session_analytics 依赖门禁与 UI 交互流程

前端核心变更

  • • 修正中文文案冲突（enabledAction/disabledAction）
  • • 新增依赖区块（状态图标 + 跳转按钮）
  • • 新增主操作按钮（启用/禁用）
  • • 左侧 toggle 根据 can_toggle_enabled 禁用
  • • doToggle() 增加依赖验证

后端核心变更

  • • 新增 ModuleDependency 类型（7 字段）
  • • ModuleWithStatus 扩展状态字段
  • • moduleStatusMap() 计算依赖阻塞
  • • handleModulesToggle() 启用前验证
  • • session_analytics 声明 4 个依赖

关键数据流

  • • GET /api/admin/modules → ModuleWithStatus[]
  • • can_toggle_enabled: false（依赖未满足）
  • • blocked_reason: "需先启用依赖模块: ..."
  • • dependencies[].enabled: 实时状态
  • • PUT /toggle → 409 Conflict（依赖未满足时）
