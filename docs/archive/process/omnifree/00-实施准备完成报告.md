## 🏗️ 技术架构总览

### 从 OmniRoute 借鉴的核心模式

```
OmniRoute Pattern                        → SI-LLM-Gateway 实现
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. freeModelCatalog (516模型)            → free_resource_catalog (SQL表)
2. FREE_TIER_TOS (ToS判定)               → tos_verdict 列 + 审查流程
3. virtualFactory (动态combo)            → VirtualFactory.Build() (Go)
4. openrouterFreeWindow (双窗口)         → QuotaTracker (5h/day/week/month)
5. quotaPreflight (账号轮换)             → Preflight() + 凭据选择集成
6. NOAUTH_PROVIDERS (keyless)            → keyless_providers 表
```

### 三层架构

```
┌─────────────────────────────────────────────────────────┐
│  用户层: auto/free, auto/best-free, auto/coding:free    │
└────────────────────┬────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────┐
│  路由层: AutoComboResolver + VirtualFactory             │
│  - 解析 auto/* 模型                                      │
│  - 动态构建候选池 (凭据 + keyless)                       │
│  - 评分与选择 (6维评分 + 分层轮换)                      │
└────────────────────┬────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────┐
│  数据层: free_resource_catalog + free_quota_tracker     │
│  - 免费资源目录 (15→50+ 提供商)                          │
│  - 本地配额追踪 (双窗口 + 429校准)                      │
│  - ToS 合规过滤                                          │
└─────────────────────────────────────────────────────────┘
```

### 核心数据模型

**4张新表**:
1. `free_resource_catalog`: 免费资源元数据（配额、ToS、限制）
2. `free_quota_tracker`: 本地配额计量（双窗口 + 429校准）
3. `auto_combo_templates`: 虚拟路由模板（过滤规则 + 评分权重）
4. `keyless_providers`: 无认证提供商注册表

**扩展3张现有表**:
- `provider_catalog`: 添加 `has_free_tier` 标识
- `credentials`: 添加 `is_free_tier` 标识
- `model_offers`: 添加 `is_free_model` 标识

### 风险监控指标

```sql
-- 每日运行监控查询
WITH daily_stats AS (
  SELECT 
    provider_code,
    COUNT(*) as resource_count,
    SUM(CASE WHEN is_exhausted THEN 1 ELSE 0 END) as exhausted_count,
    MAX(last_429_at) as last_429
  FROM free_quota_tracker
  WHERE window_start >= current_date
  GROUP BY provider_code
)
SELECT 
  provider_code,
  resource_count,
  exhausted_count,
  ROUND(100.0 * exhausted_count / NULLIF(resource_count, 0), 2) as exhaustion_rate,
  last_429
FROM daily_stats
WHERE exhaustion_rate > 50  -- 超过50%耗尽率告警
ORDER BY exhaustion_rate DESC;
```
