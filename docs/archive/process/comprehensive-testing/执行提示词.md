# LLM Gateway 本地 Mock 全场景压力测试 - 执行提示词

## 任务概述

在本地使用 60 个 Mock 供应商、100+ 并发客户端、15 个模型，对 llm-gateway-go 进行完整的、高压力的、全场景测试验证。测试方案位于 `docs/全方面测试/` 目录，包含 16 个测试场景，覆盖 15+ 种故障模式。

## 测试目标

1. 验证 Gateway 在高并发下的路由、故障转移、熔断恢复能力
2. 验证多维度路由决策（成本/延迟/并发/指纹slot/健康状态）
3. 验证 TokenPlan/CodePlan 配额耗尽自动切换与快速恢复
4. 验证 Sticky Session 连续性和故障时切换
5. **验证无可用节点时的错误处理 (S13)**
6. **验证模型不存在时的快速失败 (S14)**
7. **验证跨组故障迁移能力 (S15)**
8. **验证充值后快速恢复 < 5秒 (S16)**

### 第八步: 生成报告

```bash
# 汇总所有场景结果
python3 -c "
import json, os, glob
results = {}
for f in sorted(glob.glob('/tmp/test-results/*.json')):
    name = os.path.basename(f).replace('.json', '')
    with open(f) as fh:
        data = json.load(fh)
    results[name] = data

# 生成表格摘要
print(f'{'场景名称':40s} | {'总请求':>8s} | {'成功率':>7s} | {'P95延迟':>10s} | {'P99延迟':>10s}')
print('-' * 85)
for name, data in results.items():
    total = data.get('total_requests', 0)
    success = data.get('success_count', 0)
    rate = (success / total * 100) if total else 0
    p95 = data.get('p95_latency_ms', 0)
    p99 = data.get('p99_latency_ms', 0)
    print(f'{name:40s} | {total:8d} | {rate:6.1f}% | {p95:8.0f}ms | {p99:8.0f}ms')
"
```
