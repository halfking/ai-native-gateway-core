# 全方面测试审计与整改记录（2026-08-06）

## 审计结论

审计前的测试方案不能作为统一验收入口：文档存在 S01–S16/S01–S19/S17–S28 多套编号，严格 runner 已声明但缺失 C01/P01/R01，loadtest 未验证 SSE 完成，S17 取消请求不是确定的流式请求，S18 未调用 system-health 探针，S19 两把默认 key 属于同一租户，S20–S23 仍有 TODO/历史日志假证据，且旧结果不符合统一契约。

因此历史报告中的“全部通过”只作为背景资料，不作为本次发布证据。

## 当前整改

- `tools/result_contract.py` 提供唯一 envelope、原子写入、契约校验和 legacy migration；`PASS` 不允许 false check、非空 failures 或非布尔检查。
- `run_all.sh` 使用 run-scoped `results/runs/<run_id>` 和 manifest；环境门禁分为 Gateway/DB 预检与 mock 启动后的全量预检；缺脚本、缺结果、非零脚本退出会产生 INVALID/FAIL。
- `tools/loadtest.py` 区分 HTTP 200 与 202，记录错误分类、TTFB、SSE JSON chunk、`[DONE]`、流解析失败、取消和吞吐。
- 新增 `C01_concurrency.sh`、`P01_performance.sh`、`R01_reliability.sh`，分别覆盖 steady/burst、流/非流性能基线、长稳探针/故障阶段/恢复清理。
- 修复 S06 `quota_429` 状态、S07/S10/S15 结果文件名、S11 wave 覆盖、S16 时间差计算、压缩 mock CLI 与 `/healthz` 接口。

## 覆盖矩阵与边界

| 维度 | 当前入口 | 证据 | 硬门禁 | 边界 |
|---|---|---|---|---|
| 功能场景 | `run_all.sh --suite functional` | 每场景 envelope + manifest | 状态/检查/错误分类/延迟 gate | S21 未实现时 SKIPPED |
| 并发 | `C01_concurrency.sh` | steady/burst metrics | 99%/95% 成功率、阶段完成 | 未采集资源指标不宣称容量 |
| 性能 | `P01_performance.sh` | P50/P95/P99、TTFB、SSE | 非流/流成功率、SSE 完成、解析错误 | CPU/RSS/DB/Redis 需 `/metrics`/外部采集 |
| 可靠性 | `R01_reliability.sh` | 长稳阶段、healthz probes、故障阶段 | 探针零失败、故障阶段有结果、supplier 清理 | 未模拟 PG/Redis 重启时不宣称依赖恢复 |
| 路由专项 | `tests/routing/run_all_tests.sh` | 独立日志 | 按其自身 runner 结果 | 不与场景 fixture 混用 |
| 多模态/压缩 | `tools/multimodal_*`、压缩脚本 | 专项结果 | 需专项客户端/报告器 | 不自动计入主 suite |
| S60 跨环境 | `24-S60跨环境网络模拟测试.md` | 明确 PARTIAL_PASS/BLOCKED | 需 Gateway/schema/resource/fault gate | Nginx→Mock 链路不等于网关验收 |

## 运行建议

```bash
# 快速功能 smoke
bash docs/全方面测试/scenarios/run_all.sh --suite functional --fast

# 并发/性能/可靠性 smoke
C01_DURATION=10 C01_BURST_DURATION=5 \
  bash docs/全方面测试/scenarios/run_all.sh --suite concurrency
P01_DURATION=10 \
  bash docs/全方面测试/scenarios/run_all.sh --suite performance
R01_DURATION=30 R01_FAULT_DURATION=5 \
  bash docs/全方面测试/scenarios/run_all.sh --suite reliability

# 发布前全量：不使用 --allow-skipped
bash docs/全方面测试/scenarios/run_all.sh --suite all
```
