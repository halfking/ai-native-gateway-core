## 1. 四条链路的验证命题

| 链路 | 核心命题 | 出处（source） | 去向（sink） | 可还原性 |
|---|---|---|---|---|
| **压缩 compression** | 会话历史压缩后不丢关键信息 | `request_logs` / `session_bodies` / SessionCache | outbound body + `outbound_msg_hashes` + `compression_meta` | `tail` 可从缓存还原，`whole` 仅摘要 |
| **缓存 cache** | L1/L2/L3 三层状态一致 | `SessionState` / `SessionStateV2` | L1 内存 / L2 Redis / L3 PG | 逐层可回退（fail-over） |
| **脱敏 sanitize** | 密钥/PII 不进摘要与出站 | request/response body | `[REDACTED]` / caveman placeholder | caveman 可还原，safety/secretmask 单向 |
| **安全检查 safety** | 敏感内容在入口被拦截 | request body / response body | 拦截响应 | N/A（拦截即终态） |

**总验收原则**：
- **有出处**：每个验证对象都能追溯到明确的表 / Redis key / 函数返回值。
- **有去向**：每个写入都能指明目标表 / 层 / 字段。
- **无丢失**：压缩/缓存处理前后，关键字段（hash、marker、msgcount、msg_hashes）有完整性校验。
- **能还原**：临时处理（caveman placeholder、media prune、delta-append）可通过逆操作还原到处理前。

## 3. 溯源表：每个字段的出处与去向

### 3.1 `PrepareResult` 字段溯源

| 字段 | 出处（计算来源） | 去向（写入目标） | 可还原验证 |
|---|---|---|---|
| `OutboundBody` | `BuildOutboundMessages` / summary / trim | 转发上游 + `request_logs.outbound_body` + `session_bodies` | 与 `lastOutboundBody` 对比 delta |
| `MsgHashes` | `computeHashes(mustExtractMessages(body))`（每消息 sha256） | `request_logs.outbound_msg_hashes` | 重算 hash 比对 |
| `MsgCount` | `countMessages(body)` | `SessionState.MsgCount` | 与 body 实际消息数比对 |
| `TokenEst` | `estimateBodyTokens(body)` | `SessionState.TokenEstimate` | 与 `compression_meta.token_estimate` 比对 |
| `CompressionStrategy` | `delta_append` / `mechanical_trim` / `sliding_window_*` / `strip_only` | `request_logs.compression_strategy` + `compression_meta` | 与 `classifyLossiness` 联动 |
| `SummaryMarker` | `injectSummaryMarker`（`smm_v1`） | `compression_meta.summary_marker` | 出站 body 首条 assistant content 含 marker |
| `CompressedPrefixHash` | `prefix.Stabilize().PrefixHash` | `cache_v2.CompressedPrefixHash` | 重跑 `Stabilize` 比对 |
| `Degraded` | `winResult.Degraded`（互斥窗口） | `compression_meta.degraded` | 与 `mechanicalTrim` 路径联动 |
| `Lossiness` | `classifyLossiness(strategy, marker)` | `compression_meta.lossiness` + Prometheus 标签 | none/tail/whole 三态断言 |

### 3.2 `SessionState`（L1/L2 缓存）字段溯源

| 字段 | 出处 | 去向 | 说明 |
|---|---|---|---|
| `SchemaVersion` | 常量 | L1/L2 | 版本门禁，防混用 |
| `LastOutboundHash` | `sha256Hex(outboundBody)` | L1/L2 | **缓存完整性核心校验** |
| `MsgCount` / `TokenEstimate` | PrepareResult | L1/L2 | 一致性 |
| `SummaryMarker` | PrepareResult | L1/L2 | 摘要标记 |
| `ToolsHash` | `applyToolsCaching`（`sha256Hex(toolsRaw)`） | L1/L2 | 工具缓存比对 |
| `LastCompressedAt` / `RecentlyCompressedAt` | `time.Now()` | L1/L2 | 窗口触发状态 |
