# 数据库双向同步指南

## 概述
本指南说明如何在本地 PostgreSQL 和 252 服务器 PostgreSQL 之间进行数据库结构的双向同步。

## 环境信息
- **本地 PostgreSQL**:
  - 容器: `llm-gateway-pg`
  - 用户: `llm_gateway`
  - 数据库: `llm_gateway`
  - 端口: `5432`

- **252 服务器 PostgreSQL**:
  - 容器: `pg-252-pg17`
  - 用户: `llm_gateway`
  - 数据库: `llm_gateway`
  - 端口: `172.16.2.210:5432`
  - SSH: `root@115.29.212.252:25022`

## 同步流程

### 1. 检查差异
```bash
cd /Users/xutaohuang/workspace/official-deploy/services/llm-gateway-go
./scripts/pg-bidirectional-sync.sh check
```

### 2. 本地 → 252 同步
```bash
# 同步特定表
./scripts/pg-bidirectional-sync.sh local-to-remote <table_name>

# 示例：同步 self_check_runs 表
./scripts/pg-bidirectional-sync.sh local-to-remote self_check_runs
```

### 3. 252 → 本地同步
```bash
# 同步特定表
./scripts/pg-bidirectional-sync.sh remote-to-local <table_name>

# 示例：同步 providers 表
./scripts/pg-bidirectional-sync.sh remote-to-local providers
```

## 手动同步步骤

### 手动同步表结构

#### 本地 → 252
```bash
# 1. 导出表结构
docker exec llm-gateway-pg pg_dump -U llm_gateway -d llm_gateway -t <table_name> --schema-only --no-owner --no-privileges > /tmp/table_ddl.sql

# 2. 传输到 252
export SSHPASS='Kaixuan2026&#*9527'
sshpass -e scp -P 25022 /tmp/table_ddl.sql root@115.29.212.252:/tmp/

# 3. 在 252 上执行
sshpass -e ssh -p 25022 root@115.29.212.252 "docker exec -i pg-252-pg17 psql -U llm_gateway -d llm_gateway < /tmp/table_ddl.sql"
```

#### 252 → 本地
```bash
# 1. 从 252 导出表结构
export SSHPASS='Kaixuan2026&#*9527'
sshpass -e ssh -p 25022 root@115.29.212.252 "docker exec pg-252-pg17 pg_dump -U llm_gateway -d llm_gateway -t <table_name> --schema-only --no-owner --no-privileges > /tmp/table_ddl.sql"

# 2. 传输到本地
sshpass -e scp -P 25022 root@115.29.212.252:/tmp/table_ddl.sql /tmp/

# 3. 在本地执行
docker exec -i llm-gateway-pg psql -U llm_gateway -d llm_gateway < /tmp/table_ddl.sql
```

## 同步内容说明

### 结构同步（DDL）
- 表结构（列、约束、默认值）
- 索引（主键、唯一索引、普通索引）
- 视图
- 函数
- RLS 策略
- 触发器

### 数据同步（DML）
- **默认不同步数据**，只同步结构
- 如需同步数据，使用 `pg_dump` 不加 `--schema-only` 参数

## 常见问题

### Q: 同步后索引数量不一致？
A: 检查是否有遗漏的索引，使用以下命令查看：
```bash
# 本地索引
docker exec llm-gateway-pg psql -U llm_gateway -d llm_gateway -c "\di <table_name>"

# 252 索引
sshpass -e ssh -p 25022 root@115.29.212.252 "docker exec pg-252-pg17 psql -U llm_gateway -d llm_gateway -c '\di <table_name>'"
```

### Q: 同步后 RLS 策略不一致？
A: RLS 策略需要单独同步，使用以下命令：
```bash
# 导出 RLS 策略
docker exec llm-gateway-pg pg_dump -U llm_gateway -d llm_gateway --schema-only --no-owner --no-privileges | grep -A 20 "ALTER TABLE.*ENABLE ROW LEVEL SECURITY"
```

### Q: 同步后函数不一致？
A: 函数需要单独同步，使用以下命令：
```bash
# 导出函数
docker exec llm-gateway-pg pg_dump -U llm_gateway -d llm_gateway --schema-only --no-owner --no-privileges | grep -A 30 "CREATE FUNCTION"
```
