## 🔍 技术细节

### Outbox 表设计

**事件 envelope**（7 个字段）：
- event_id (UNIQUE), event_type, schema_version
- tenant_id, aggregate_id, aggregate_version, occurred_at

**状态管理**（5 个字段）：
- status, attempts, last_error, last_attempt_at, next_retry_at

**索引策略**：
1. **Dispatcher 轮询** - (status, next_retry_at, created_at)
2. **版本排序** - (tenant_id, aggregate_id, aggregate_version)
3. **租户查询** - (tenant_id, occurred_at DESC)
4. **失败监控** - (status, attempts, last_attempt_at)

### Writer 设计

**职责**：
- 在给定事务中写入事件
- 不管理事务生命周期（由调用方控制）
- 验证必填字段和约束
- 序列化 payload 为 JSONB

**API**：
```go
writer := outbox.NewWriter(tx)
err := writer.Write(ctx, outbox.EventEnvelope{...})
```
