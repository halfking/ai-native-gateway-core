# 完整状态机与数据流

> 四层状态 + 绑定状态统一管理，原子写入，级联传播。

## 1. 状态层级

### 1.1 状态结构

```go
type ProviderState struct {
    ProviderID      int
    Enabled         bool
    ManualDisabled  bool
    DisplayName     string
    UpdatedAt       time.Time
}
func (s *ProviderState) IsAvailable() bool {
    return s.Enabled && !s.ManualDisabled
}

type CredentialState struct {
    CredentialID       int
    ProviderID         int
    Status             string  // active/inactive
    LifecycleStatus    string  // active/retired
    AvailabilityState  string  // ready/auth_failed/suspended
    HealthStatus       string  // healthy/warning/unhealthy
    QuotaState         string  // ok/exhausted/periodic/permanent
    ManualDisabled     bool
    ConsecutiveFailures int
    RecoverAt          *time.Time
    UpdatedAt          time.Time
}
func (s *CredentialState) IsAvailable() bool {
    return s.Status == "active" &&
           s.LifecycleStatus == "active" &&
           !s.ManualDisabled &&
           s.AvailabilityState != "auth_failed" &&
           s.AvailabilityState != "suspended" &&
           s.QuotaState != "permanently_exhausted" &&
           s.QuotaState != "balance_exhausted"
}

type ModelState struct {
    CredentialID     int
    RawModel         string
    StdModel         string
    OfferAvailable   bool
    BindingAvailable bool
    ProbeState       string  // unknown/recovering/healthy_confirmed/broken_confirmed
    UnavailableReason string
    UpdatedAt        time.Time
}
func (s *ModelState) IsAvailable() bool {
    return s.OfferAvailable &&
           s.BindingAvailable &&
           s.ProbeState != "broken_confirmed"
}

type NodeState struct {
    CredentialID        int
    RawModel            string
    ConsecutiveFailures int
    SuccessCount        int64
    FailureCount        int64
    LastSuccessAt       *time.Time
    LastFailureAt       *time.Time
    Disabled            bool
    DisabledUntil       *time.Time
    RecoverAt           *time.Time
    LastError           string
    UpdatedAt           time.Time
}
func (s *NodeState) IsAvailable() bool {
    if s.ConsecutiveFailures >= 3 {
        return false
    }
    if s.Disabled && s.DisabledUntil != nil && time.Now().Before(*s.DisabledUntil) {
        return false
    }
    return true
}
```

| 事件 | Provider | Credential | Model | Node |

## 2. 数据流

### 2.1 查询路径

```
请求 → handler
  → router.SelectNode
    → BindingLookup (L1: Redis → L2: local)
      → hit + 强绑定: 直接返回 (跳过所有状态检查)
      → miss/软绑定重评估:
        → ProviderCache.Get(providerID)
          → L1: local (10s TTL) → L2: Redis (5min TTL) → L3: DB
        → CredentialCache.Get(credentialID)
          → 同上三层
        → ModelCache.Get(credentialID, rawModel)
          → L1: local → L2: Redis → L3: DB
        → NodeCache.Get(credentialID, rawModel)
          → L1: local → L2: Redis
    → CostScorer.Score(candidates)
    → P2C.Select
    → ResourceGate.AcquireFP → AcquireConc → CB.Allow
  → Execute → Record/Rlease
```

### 2.2 写入路径

```
成功:
  → StateRecorder.Record(success)
    → 原子更新: node success count + last_success_at
    → 清理 node consecutive
    → 更新 binding last_success_at + consecutive_success
    → 如果 consecutive_success >= 3:
      → model probe_state = healthy_confirmed (如果之前是 probe_pending/broken_confirmed)

失败 (非客户端错误):
  → StateRecorder.Record(failure, kind, error_origin)
    → 原子更新: node failure count + last_failure_at + consecutive++
    → Circuit.RecordFailure(consecutive)
    → HealthTracker.OnError(滑动窗口)

  → shouldWriteDBDegradation:
    → true: 级联传播
      → node: disabled_until = now + cooldown
      → model: probe_state = probe_pending (if >=3 consecutive)
        → credential: 检查是否多个模型同时 broken
          → provider gate: 检查是否多个凭据 broken
      → emitter.broadcast(CacheInvalidation)

  → shouldWriteDBDegradation:
    → false: 仅 circuit 层面保护, 不写 DB, 不通知路由
```

### 2.3 原子写入

```go
// 使用 Redis Lua 保证原子性:
local nodeKey = KEYS[1]
local modelKey = KEYS[2]
local credKey = KEYS[3]
local providerGateKey = KEYS[4]

local success = ARGV[1]       -- "true" | "false"
local kind = ARGV[2]          -- error kind
local consecutive = tonumber(ARGV[3])
local cooldown = tonumber(ARGV[4]) -- seconds

if success == "true" then
    redis.call('HSET', nodeKey, 'consecutive', 0, 'last_success_at', os.time())
    return 0
end

redis.call('HSET', nodeKey, 'consecutive', consecutive, 'last_failure_at', os.time())
if consecutive >= 3 then
    -- model level
    redis.call('HSET', modelKey, 'probe_state', 'probe_pending')
    -- credential level cascade
    local allBroken = checkAllModelsBroken(credKey)
    if allBroken then
        redis.call('HSET', credKey, 'availability_state', 'suspended',
                   'availability_recover_at', os.time() + cooldown)
    end
end
return 1

// DB 事务包装 (当 Redis 不可用时):
// BEGIN;
// UPDATE credential_model_bindings SET ... WHERE ...
// UPDATE credentials SET ... WHERE ...
// COMMIT;
```

## 3. 缓存设计

### 3.1 三层缓存

```go
type LayerCache[T any] struct {
    L1 map[string]*cacheEntry[T]   // 内存, 10s TTL
    L2 redis.UniversalClient       // Redis, 5min TTL
    L3 *pgxpool.Pool              // DB, 权威源
}

func (c *LayerCache[T]) Get(ctx context.Context, key string) (*T, error) {
    // L1 miss → L2 miss → L3 → 回填 L2 + L1
    // L1 hit → 直接返回 (10s TTL, L1 命中率 > 80%)
    // L2 hit → 回填 L1, 返回
    // L3 hit → 回填 L2 + L1, 返回
    // L3 miss → return nil
}

// 缓存失效:
//   主动 update → 级联失效
//   TTL 过期 → 被动刷新
//   广播 (redis pub/sub) → 其他节点本地缓存失效
```

## 4. 级联传播

### 4.1 自上而下

```
Provider.disabled → 所有 Credential.State.not_ready
Credential.auth_failed → 所有 ModelState.broken_confirmed
Model.broken_confirmed → NodeState.disabled_until
```

### 4.2 自下而上

```
Node 连续失败 >=3 → Model.probe_pending
Model 多个 broken → Credential.suspended
Credential 多个 broken → Provider gate 降权
```

### 4.3 恢复传播

```
探测成功: Node.available → Model.healthy_confirmed → Credential (自动恢复) → Provider gate 恢复
管理员恢复: 从任意层级清除 disabled 标志, 向下传播
定期恢复: RecoverAt 到期 → 清除降级, 向上或向下传播
```
