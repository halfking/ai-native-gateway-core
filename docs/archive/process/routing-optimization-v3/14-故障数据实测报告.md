## 4. 凭据维度故障（H.9-H.12 凭据细节）

### cred 21（1102 events）— 最大故障源（H.9）

- `executor: stream interrupted` × **1007 次**（reason=eof_without_done）
- `LOAD_SCORE_V2` × 69
- `non-resumable stream interrupted` × 5
- `credential state write pending failure confirmation` × 7
- **含义**：单一供应商协议问题——上游发完 chunks 但不发送 `[DONE]` 就关闭连接
- **影响**：client 收到的 SSE 流被切断，但 gateway 已发出部分内容 → 不可透明切换
- **修复方向**：与供应商协商 `[DONE]` 协议 / 加 retry-with-fresh-connection / 客户端 retry 文档化

### cred 19（145 events）— 自动降级触发链

- `credential binding marked degraded due to continuous failures` × 27
- `credstate: triggering active_probe` × 25
- `checker: model_offers mirror write failed` × 19
- `LOAD_SCORE_V2` × 57
- `executor: stream interrupted` × 7
- 触发条件：`model=minimaxai/minimax-m3, error_kind=transient, consecutive_fails=2/3, threshold=2`
- **含义**：minimax-m3 连续失败 2 次即触发主动探测（v3 方案建议 halfOpenFailures >= 3，当前门槛过紧）

### cred 11/12（127/126 events）— 探测 worker bug（H.10）

- `model probe v2: applyResult failed` × 87 each

- **修复方向**：探测 worker 独立 ctx + 超时 ≥ 5s + 失败不写 degraded（仅重试）

## 6. 新发现的关键故障（H.9-H.12）

### H.9 cred 21 流式 EOF without [DONE] 集中爆发

- **现象**：1001 次集中 14-17 时段，reason=eof_without_done
- **触发层**：上游供应商 → executor stream
- **当前处理**：stream interrupted → state degraded → user 收到不完整 SSE
- **修复方向**：凭据级 CB 立即 open；与供应商协商 `[DONE]` 协议；客户端 retry 文档化（呼应 v3 §06 S26/S27）

### H.10 model probe v2: applyResult failed 213 次

- **现象**：cred 11/12 主导（87 each），error=context deadline/canceled
- **触发层**：探测 worker
- **影响**：applyResult 失败 → probe state 不更新 → 凭据维持 degraded → 用户请求失败
- **修复方向**：探测 worker 独立 ctx（与请求 ctx 解耦）；超时 ≥ 5s；applyResult 失败不写 degraded（仅重试 3 次）

### H.11 safety_net_defer_fired 异常高频

- **现象**：14-17 时段 2994 次 vs http_request 7390 → 40% 触发
- **影响**：性能开销 + 隐藏真实错误
- **修复方向**：审计触发条件；增加 > 1000/min 告警；添加 metric `safety_net_trigger_total{reason}`

### H.12 session_cache 命中率异常低

- **现象**：2893 次 db load error，99.5% = no rows
- **影响**：每个请求都走 DB 查询 → DB 压力大
- **修复方向**：本地 cache 命中判定优化；session 创建路径审计；metric `session_cache_hit_ratio`
