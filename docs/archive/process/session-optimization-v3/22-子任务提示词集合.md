## 0. 使用说明

本文档为 [21 号文档](./21-任务分解与并行执行计划.md) 中的 **5 个子任务** 各提供一份 Handoff 提示词。

**使用方式**：
1. 复制对应任务的提示词
2. 在新会话中粘贴
3. AI 将自动加载上下文 + 开始任务

```go
func calculateHealthScore(sessionID string, db *sql.DB) float64 {
    // 50% 成功率 + 30% 延迟 + 20% 成本
    
    successRate := getSuccessRate(sessionID, db)   // 0-1
    avgLatency := getAvgLatency(sessionID, db)     // ms
    avgCost := getAvgCost(sessionID, db)           // $
    
    // 归一化
    successScore := successRate * 50
    latencyScore := (1 - min(avgLatency/10000, 1)) * 30  // 10s 为满分
    costScore := (1 - min(avgCost/1.0, 1)) * 20          // $1 为满分
    
    return successScore + latencyScore + costScore
}
```
