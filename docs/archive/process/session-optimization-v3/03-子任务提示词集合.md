## Task-DB-01: 数据库迁移脚本

### 提示词

```
你好！我需要你完成 llm-gateway-go 项目的数据库迁移任务。

【上下文】
- 项目: /Users/xutaohuang/workspace/official-deploy/services/llm-gateway-go
- 数据库: PostgreSQL 17
- 迁移工具: golang-migrate (版本化 SQL 文件)
- 现有迁移: deploy/sql/migrations/ 目录
- 参考文档: docs/会话优化v3/01-需求分析与架构设计.md

【目标】
创建两个新的数据库迁移脚本：
1. Migration 510: 为 request_logs 表添加请求链路追踪字段
2. Migration 511: 创建 request_state_transitions 状态变更历史表

【具体要求】

Migration 510 (请求链路追踪):
- 在 request_logs 表添加以下字段:
  * parent_request_id TEXT (可空，父请求 ID)
  * request_type TEXT (默认 'main'，枚举: main, title_gen, summary, sensitive_check, other)
- 创建索引: idx_request_logs_parent ON request_logs(parent_request_id) WHERE parent_request_id IS NOT NULL
- 确保向后兼容，现有数据不受影响

Migration 511 (状态变更历史):
- 创建新表 request_state_transitions:
  * id BIGSERIAL PRIMARY KEY
  * request_id TEXT NOT NULL
  * transition_type TEXT NOT NULL (枚举: route, node_switch, retry, error)
  * from_state TEXT
  * to_state TEXT
  * metadata JSONB (存储决策原因、节点信息等)
  * created_at TIMESTAMPTZ DEFAULT NOW()
- 创建索引: idx_state_transitions_request ON request_state_transitions(request_id, created_at DESC)
- 添加表注释说明用途

【约束】
1. 遵守项目现有迁移文件命名规范 (XXX_description.up.sql / XXX_description.down.sql)

【产物】
请将生成的迁移文件放在:

- deploy/sql/migrations/510_request_tracing_fields.down.sql

- deploy/sql/migrations/511_state_transitions_table.down.sql
