## 两重定价体系

```
┌─────────────────────────────────────────────────────────┐
│  第一重：MaaS 积分定价（现有）                            │
│  定位：外部 MaaS 定价，面向终端租户                        │
│  模式：积分 + 订阅 + 充值                                │
│  定价：管理员手动配置积分费率 + 折扣                       │
│  数据：maas_settings → model_credit_rates → consumption    │
├─────────────────────────────────────────────────────────┤
│  第二重：算力资源池动态价格（新增 — 本文档）               │
│  定位：内部算力成本定价，面向毛利率管理                     │
│  模式：Spot 竞价 + On-Demand 按需 + Reserved 预留           │
│  定价：GPU 利用率驱动 + 外部队价联动                       │
│  数据：gpu_metrics → compute_pools → dynamic_prices        │
└─────────────────────────────────────────────────────────┘
```

## 关键术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 算力现货 | Spot | 可被中断的低优先级算力，价格低但有被回收风险 |
| 按需实例 | On-Demand | 稳定算力，价格较高，保证可用 |
| 预留实例 | Reserved | 长期承诺的高优算力，价格最优惠 |
| 资源池 | Compute Pool | 裸金属 / K8s GPU 集群的统管抽象层 |
| 基准加价率 | Base Markup | 外部成本到内部售价的转换系数 |
| 毛利率 | Gross Margin | (收入 - 上游成本) / 收入 |
