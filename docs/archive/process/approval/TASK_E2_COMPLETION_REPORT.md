# 任务 E2 完成报告：实现审批请求列表和详情页

## 任务概述
实现审批请求的列表页和详情页，提供完整的审批流程管理界面。

## 完成内容

### 1. API 扩展 (`web/src/api/approval.ts`)

新增以下 API 函数和类型定义：

#### 类型定义
- `ApprovalItem` - 审批列表项
- `ApprovalDetail` - 审批详情（包含 snapshot）
- `ApprovalListParams` - 列表查询参数
- `ApprovalListResponse` - 列表响应
- `ApprovalStats` - 统计数据

#### API 函数
- `getApprovalList(params)` - 获取审批列表
- `getApprovalDetail(requestId)` - 获取审批详情
- `approveApproval(requestId, reason)` - 批准审批
- `rejectApproval(requestId, reason)` - 拒绝审批
- `getApprovalStats(params)` - 获取统计数据

### 2. 审批列表页 (`web/src/views/ApprovalListView.vue`)

#### 核心功能
- ✅ **待审批列表**：展示所有待处理的审批请求
- ✅ **历史记录**：查看已批准/已拒绝/已超时的历史记录
- ✅ **状态过滤**：pending/approved/rejected/timeout
- ✅ **风险等级过滤**：LOW/MEDIUM/HIGH/CRITICAL
- ✅ **搜索功能**：按 session_id 或 request_id 搜索
- ✅ **分页支持**：每页 20 条，支持翻页
- ✅ **实时更新**：每 30 秒自动刷新（仅待审批状态）

#### UI 组件
- **统计卡片**：
  - 待审批数量（高亮显示）
  - 今日新增数量
  - 已批准数量（绿色）
  - 已拒绝数量（红色）
  - 平均处理时间

- **过滤器**：
  - 状态下拉框
  - 风险等级下拉框
  - 搜索输入框
  - 重置按钮

- **数据表格**：
  | 列名 | 说明 | 特性 |
  |------|------|------|
  | 请求 ID | 可点击跳转详情 | 链接按钮 |
  | 会话 ID | Monospace 字体 | 截断显示 |
  | 风险等级 | 颜色标签 | LOW=绿, MEDIUM=黄, HIGH=橙, CRITICAL=红 |
  | 触发原因 | 检测原因 | 文本显示 |
  | 预估成本 | 金额 | 格式化显示 |
  | 创建时间 | 相对时间 | 悬停显示完整时间 |
  | 状态 | 颜色标签 | 对应状态颜色 |
  | 操作 | 按钮组 | 批准/拒绝/详情 |

- **快速操作**：
  - ✓ 按钮：快速批准（确认对话框）
  - ✕ 按钮：快速拒绝（输入原因）
  - 👁 按钮：查看详情

### 4. 路由配置 (`web/src/router.ts`)

新增路由：
```javascript
{ path: '/admin/approval-config', component: ApprovalConfigView, meta: { requiresSuper: true } }
{ path: '/admin/approvals', component: ApprovalListView, meta: { requiresSuper: true } }
{ path: '/admin/approvals/:id', component: ApprovalDetailView, meta: { requiresSuper: true } }
```

权限控制：所有路由均需 `super_admin` 角色。

## API 集成

### 后端端点
- `GET /api/admin/approvals` - 列表查询
- `GET /api/v1/approvals/{id}` - 详情查询
- `POST /api/v1/approvals/{id}/approve` - 批准操作
- `POST /api/v1/approvals/{id}/reject` - 拒绝操作
- `GET /api/admin/approvals/stats` - 统计数据

### 查询参数
- `status` - 状态过滤
- `risk_level` - 风险等级过滤
- `page` - 页码
- `page_size` - 每页数量
- `sort_by` - 排序字段
- `sort_order` - 排序方向（asc/desc）
- `session_id` - 会话 ID（搜索）
- `request_id` - 请求 ID（搜索）
