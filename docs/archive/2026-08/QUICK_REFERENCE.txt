📍 问题描述
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
错误: "No available provider for model 'glm-5.2'. All 0 candidates"
现象: 供应商直连可用，网关路由时无候选节点
影响: gpt-5.6-luna, gpt-5.6-terra, claude-opus-5, claude-sonnet-5, glm-5.2

🔍 根因（3个）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. ⚠️  Ready Gate 过严
   Redis 短暂不可达 → 阻止 LRU 缓存使用 → 所有请求失败

2. ⚠️  LRU 缓存命中率低
   容量 10万 + TTL 30s → 命中率 < 20% → 80% 请求回源 Redis

3. ⚠️  降级模式触发失效
   len(candidates) <= 2 才触发 → 5个候选全冷却时不触发

🛠️  修复方案（5个）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
┌─────────────────────────────────────────────────────────────────────────┐
│ P0-1: Ready Gate Fail-Open                            预计 1 小时        │
├─────────────────────────────────────────────────────────────────────────┤
│ 文件: domains/ursm/v2/manager.go:379-386                                │
│                                                                           │
│ 修改前:                                                                   │
│   if !ready { return nil, "", fmt.Errorf("not ready") }                 │
│   if len(missIndices) == 0 { return views, Hit, nil }                   │
│                                                                           │
│ 修改后:                                                                   │
│   if len(missIndices) == 0 {                                            │
│       src := Hit                                                         │
│       if !ready { src = Fallback }  // 允许 LRU 缓存兜底               │
│       return views, src, nil                                             │
│   }                                                                      │
│   if !ready { return nil, "", fmt.Errorf("not ready (cache miss)") }   │
│                                                                           │
│ 效果: Redis 故障时，85% 缓存命中请求仍可成功                             │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ P0-2: LRU 缓存优化                                    预计 30 分钟       │
├─────────────────────────────────────────────────────────────────────────┤
│ 文件: domains/ursm/v2/config.go                                         │
│                                                                           │
│ 修改前:                                                                   │
│   LRUMirrorSize:    100_000,                                            │
│   LRUMirrorSoftTTL: 30 * time.Second,                                   │
│                                                                           │
│ 修改后:                                                                   │
│   LRUMirrorSize:    300_000,      // 10万 → 30万                       │
│   LRUMirrorSoftTTL: 60 * time.Second,  // 30s → 60s                    │
│                                                                           │
│ 效果: 缓存命中率 20% → 85%+                                              │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ P0-3: 降级模式改进                                    预计 30 分钟       │
├─────────────────────────────────────────────────────────────────────────┤
│ 文件: domains/streaming/executors/router.go:274                         │
│                                                                           │
│ 修改前:                                                                   │
│   if len(candidates) <= 2 { degradedCandidates := ... }                │
│                                                                           │
│ 修改后:                                                                   │
│   if len(available) == 0 { degradedCandidates := ... }                 │
│                                                                           │
│ 效果: 所有候选被过滤时，降级模式兜底                                     │
└─────────────────────────────────────────────────────────────────────────┘
