# 72小时代码审计报告

**审计范围**: `git log --since='72 hours ago'`，截至 2026-08-08
**重点链路**: 消息格式转换、多轮消息存储、压缩/合并发送、V2 重建与缓存
**审计结论**: 关键 P0/P1 数据流问题已修复；真实 PostgreSQL RLS/迁移升级与全量 race 仍需部署环境验证。

## Findings and fixes

- **P0 V2 continuation shape**: `BuildLatestOutbound` 返回裸消息数组，而 compression diff 只接受请求对象，导致每次续接都回退完整客户端历史。`extractMessages` 现兼容对象与裸数组，并有跨包契约测试。
- **P1 structured content loss**: V2 mirror/body model 过去将 content 数组、null、tool blocks 强制解码为 string。新增 `ContentRaw` 与自定义 JSON round-trip，保留旧文本投影并覆盖 multimodal/Anthropic block 测试。
- **P1 concurrent stale delta**: previous outbound 查询原先在 advisory transaction lock 外执行。现在先开始事务并锁定 `(tenant_id, session_id)`，再读取快照、计算 delta、写 turn/body。
- **P1 outbound snapshot mismatch**: tools restoration 和 prefix stabilization 发生在早期 telemetry snapshot 之后。V2/WAL context 现在在所有请求变换完成后记录最终 `bodyBytes`。
- **P1 tenant uniqueness/join**: V2 turn/body 唯一约束、冲突键与 summary join 补充 tenant 维度；新增 startup migration 476 及 down 文件。
- **P1 OmniFree worker isolation**: quota reset/cleanup 的 UPDATE/DELETE 增加显式 `tenant_id` 条件；即使数据库角色绕过 RLS 也不会跨租户更新。
- **P1 OmniFree policy drift**: startup DDL 与 075 migration 统一逐表 policy 名称、`USING/WITH CHECK` 和 super-admin/bypass 条件，避免 additive permissive policies。
- **P2 E3 role merge**: 只合并 user/assistant 的纯消息；带 tool calls/tool IDs 或未知 role 的消息保留边界。
- **P2 V2 Redis lifecycle**: `SessionCacheV2.Close` 已接入 gateway graceful shutdown。
