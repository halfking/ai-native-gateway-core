## 核心功能

### 工作流程

```
1. 导出低置信度样本
   llm-gw-annotator export --start 2026-08-01 --end 2026-09-01 \
     --max-confidence 0.7 --limit 1000 --output annotations.csv

2. 人工标注（Excel/Google Sheets）
   - 填写human_provider（正确的provider）
   - 填写is_correct（TRUE/FALSE）
   - 填写reason（performance/cost/availability/quality/other/correct）
   - 填写annotator（标注人员）

3. 验证CSV格式
   llm-gw-annotator validate annotations.csv

4. 导入标注结果
   llm-gw-annotator import annotations.csv

5. 查看统计
   llm-gw-annotator stats
```

### 隐私保证

✅ **导出查询只访问结构化特征**:
- model_name, task_type, prompt_tokens
- is_streaming, has_vision, region, profile
- auto_provider, confidence

❌ **不访问敏感字段**:
- prompt（用户输入）
- messages（对话历史）
- response（模型输出）
- summary, keywords（可能包含内容）

## 技术亮点

### 1. 隐私合规设计
- 查询中明确列出字段，不使用 `SELECT *`
- CSV只包含非可逆的结构化特征
- 标注人员无法通过request_id反查原始内容

### 2. 数据完整性
- 多层验证：header验证、字段验证、范围验证
- 去重逻辑：导出排除已标注、导入跳过重复
- 约束检查：confidence范围、reason白名单、is_correct格式

### 3. 错误处理
- 导入错误不中断，收集所有错误
- 详细的错误报告（行号、字段、原因）
- 友好的用户提示

### 4. 性能优化
- 批量导入（pgx.Batch）
- 4个索引（request_id, annotator, annotated_at, is_correct）
- 4个预定义视图（常用统计查询）

### 5. 代码质量
- 清晰的包结构（types, exporter, importer, stats）
- 完善的单元测试（所有测试通过）

### P2.2集成（后续）
将人工标注集成到训练数据导出：

```sql
-- 导出时优先使用human_label
SELECT 
  COALESCE(tha.human_label, ars.selected_provider) AS label,
  CASE 
    WHEN tha.human_label IS NOT NULL THEN 1.0
    ELSE ars.confidence
  END AS label_confidence
FROM auto_route_selections ars
LEFT JOIN training_human_annotations tha ON tha.request_id = ars.request_id;
```
