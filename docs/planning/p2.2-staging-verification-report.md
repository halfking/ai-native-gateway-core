### 4.2 反馈日志写入验证

预期：反馈记录**所有**被路由的 AUTO 决策（A/B 门控只决定 10% 流量是否采用优化器
推荐，不减少记录行数），因此行数 ≈ 成功的 AUTO 请求数而非 ≈10 条。
异步批量按 100 条或 5s 刷盘 —— 计数前至少等待 5 秒（或观察
`llmgw_routingopt_feedback_writes_total{result="ok"}` 增量）。

```sql
-- 查询测试窗口内的反馈日志
SELECT 
  COUNT(*) as total_feedback,
  COUNT(DISTINCT user_id) as unique_users,
  COUNT(DISTINCT task_type) as task_types,
  AVG(confidence) as avg_confidence
FROM routing_feedback_log
WHERE created_at >= '[测试开始时间]'
  AND created_at <= '[测试结束时间]';
```
