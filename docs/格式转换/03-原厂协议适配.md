# 原厂协议适配

状态基于当前代码、测试和历史审计文档核对。兼容 OpenAI/Anthropic 的原厂不能自动继承全部能力。

| 原厂/家族 | 当前路径 | 请求与响应 | 工具 | 多模态 | 结论 |
|---|---|---|---|---|---|
| OpenAI | OpenAI Chat、Responses | native/bridge | Chat `tool_calls`、Responses items | image、audio/file 子集 | partial |
| Anthropic | Messages parser/serializer、SSE bridge | native/bridge | `tool_use`/`tool_result` | image、document、thinking 子集 | partial |
| Google Gemini | `ParseGemini`/`SerializeGemini`、stream parser | native generateContent | functionCall/functionResponse | image/audio/video/document inline/file | verified for covered fixtures |
| DeepSeek | OpenAI-compatible + provider stripper/extensions | compatibility | OpenAI shape，reasoning/cache 依 profile | 不因兼容层自动获得 vision | partial |
| GLM/Zhipu | OpenAI-compatible + provider fields | compatibility | OpenAI shape，私有字段受 profile | model-specific | partial |
| MiniMax | OpenAI/Anthropic compatibility | compatibility | `tool_call_id` 兼容、错误分类 | model/endpoint specific | partial |
| Qwen/DashScope | OpenAI-compatible/provider profile | endpoint/model specific | OpenAI-like | image/audio/video shape varies | partial |
| Ollama | OpenAI compatibility；native `/api/chat` 需单独 profile | compatibility/native boundary | OpenAI-like or native message tools | model-dependent image | partial |
| Doubao/Volcengine | OpenAI-compatible + provider fields | provider family specific | OpenAI-like | model/endpoint specific | partial |

## Provider 边界规则

1. `provider catalog code` 决定私有字段、usage extractor、stripper 和 capability；不能只看 model 前缀。
2. `volcengine-coding` 等聚合入口不能直接当成 Doubao 原厂，必须使用独立 profile。
3. OpenAI-compatible 只代表 wire shape 的兼容，不代表原厂完整能力。
4. provider 私有字段恢复必须通过 `TransportContext` 的同厂判断。

## 代码证据

- `domains/transformation/ir_converter.go`: Extensions 提取、恢复和 circuit breaker。
- `domains/streaming/handler.go`: GLM、DeepSeek、Doubao 等响应字段清理。
- `internal/ir/parse_gemini.go` / `serialize_gemini.go`: Gemini native 请求链。
- `internal/ir/parse_gemini_stream.go`、`internal/ir/stream.go` 相关实现及 `gemini_stream_test.go`: Gemini 流式事件。
- `errorsx/classify.go`: MiniMax/OpenAI 工具 ID 错误分类。
