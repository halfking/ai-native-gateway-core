## 六、数据流

### 标注流程
```
1. 用户访问 /routing-v2/annotations
2. 前端调用 GET /api/admin/annotations/samples?annotated=false
3. 用户点击"标注"按钮，打开抽屉表单
4. 填写表单：选择供应商、判断正确性、选择原因、输入标注人
5. 提交后调用 POST /api/admin/annotations
6. 后端插入 ml_routing_annotations 表
7. 前端刷新样本列表
```

### 统计分析流程
```
1. 用户访问 /routing-v2/annotations/stats
2. 前端调用 GET /api/admin/annotations/stats
3. 后端执行SQL聚合查询：
   - 整体统计（总数、准确率）
   - 按供应商分组统计
   - 按标注人分组统计
   - 按原因分组统计
4. 前端渲染卡片、表格、进度条
```
