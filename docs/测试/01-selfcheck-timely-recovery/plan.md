# 01 自检及时恢复 — 测试方案

## 目标

验证当天成功过的模型节点能被及时、不过量地探测；错误/额度/偶发网络恢复后，节点状态能同步到路由可见面。

## 范围

- 网络/超时类错误的探测退避（短链，上限 60s）
- 额度类错误保持固定 2m/5m，不走 6h 长尾
- 直连探测成功即写回 binding / credential / 缓存
- 业务成功 `MarkNodeProbeHealthy` 同步写回
- `ProbeNow` 成功后通知路由缓存失效
- 当天成功节点 15 分钟扫描，跳过刚探过的健康节点

## 验证层

| 层 | 方式 |
|---|---|
| L1 单测 | `go test ./bg ./errorsx -count=1` |
| L2 契约 | 源码/SQL 钉死写回与通知 |
| L3 运行 | 不连生产库；无 UI 改动 |

## 不做

- 不重开 hourly `cycleAll` / consensus modelProbe
- 不探测当天未成功过的冷模型
