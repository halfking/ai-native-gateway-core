## 🎓 关键学习

### 技术亮点

1. **并发安全的UPSERT**: PostgreSQL `ON CONFLICT` 保证原子性
2. **智能窗口计算**: 自动处理 UTC 日历日/月边界
3. **灵活的响应头解析**: 支持多种 429 格式
4. **双窗口追踪**: 同时追踪短期和长期配额
5. **自动重置**: 过期窗口自动解除耗尽状态

### 从 OmniRoute 学到的

1. **免费资源分类**: 6种 free_type 精确分类
2. **Pool 去重**: 避免共享配额重复计数
3. **ToS 分级**: 降低法律风险
4. **虚拟路由**: 零配置用户体验
5. **本地计量**: 解决无 usage API 问题
