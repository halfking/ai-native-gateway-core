### Step 2: 统计新逻辑触发次数

```bash
ssh -i "$SSH_KEY_154" -p "$SSH_PORT_154" "$SSH_HOST_154" "
  echo '=== 新逻辑触发统计（1小时内）==='
  echo -n '冷却期延长: '
  journalctl -u llm-gateway-go --since '1 hour ago' --no-pager | \
    grep -c 'cooldown_extended_due_to_failure' || echo 0
  
  echo -n '实际流量恢复: '
  journalctl -u llm-gateway-go --since '1 hour ago' --no-pager | \
    grep -c 'recovered_with_actual_success' || echo 0
  
  echo -n '恢复后再失败: '
  journalctl -u llm-gateway-go --since '1 hour ago' --no-pager | \
    grep -c 'after_recovery' || echo 0
"
```

**预期结果**:
- 如果商汤/NVIDIA NIM 节点失败，应该看到 `cooldown_extended` > 0
- 如果有节点恢复，应该看到 `recovered_with_actual_success` > 0

---

### Step 3: 查看最近的节点事件

```bash
ssh -i "$SSH_KEY_154" -p "$SSH_PORT_154" "$SSH_HOST_154" "
  journalctl -u llm-gateway-go --since '1 hour ago' --no-pager | \
    grep -E '(disabled_reason|node.*disabled|node.*recovered)' | \
    tail -10
"
```

**重点关注**:
- `disabled_reason` 字段的值
- 是否出现新的原因：`cooldown_extended_due_to_failure`、`recovered_with_actual_success`、`consecutive_3_failures_after_recovery`

---

### Step 4: 计算请求成功率

```bash
ssh -i "$SSH_KEY_154" -p "$SSH_PORT_154" "$SSH_HOST_154" "
  LOGS=\$(journalctl -u llm-gateway-go --since '1 hour ago' --no-pager)
  TOTAL=\$(echo \"\$LOGS\" | grep -c '\"msg\":\"http_request\"' || echo 0)
  SUCCESS=\$(echo \"\$LOGS\" | grep '\"msg\":\"http_request\"' | grep -c '\"status\":200' || echo 0)
  
  echo \"总请求: \$TOTAL\"
  echo \"成功: \$SUCCESS\"
  
  if [ \$TOTAL -gt 0 ]; then
    echo \"成功率: \$(awk \"BEGIN {printf \\\"%.2f%%\\\", (\$SUCCESS / \$TOTAL) * 100}\")\"
  fi
"
```

**基线对比**:
- 修复前成功率: 75-85%
- 预期提升到: 82-90%
