# 02 · 常用模型分级自检（2026-08-13）

需求补充：**针对常用模型，强化自检操作；其它模型可以减少自检的频度。**

## 常用模型判定

常用模型 = **静态精选 `routing_policy.featured_models` ∪ 用量 Top-N**（`request_logs_hot` 近窗口成功调用最多的 N 个）。与 daily-selfcheck 的 `featured→most_used` 分级一致，最贴合"常用"语义。

- 由 `bg/model_tier.go::ModelTier` 每 10min 刷新一次，`atomic.Value` 无锁读。
- 用量 Top-N 走 hot 表索引，ms 级；`probe.featured_usage_top_n=0` 即回退为纯静态精选（kill-switch）。
- 进程级单例 `bg.SetGlobalModelTier` + `globalIsFeaturedModel`，probe 各路径零侵入读取。

## 加强手段（常用模型）↔ 减弱手段（其它模型）

| 维度 | 常用模型 | 其它模型 | 配置 |
|---|---|---|---|
| 周期 | 专用深 ping 周期（默认 15min） | 不走深 ping；健康态 watchdog ×倍（默认 ~8h 才再探） | `probe.featured_cycle_seconds`(900) / `probe.nonfeatured_watchdog_multiplier`(4) |
| 深度 | chat-ping（Layer 4，计费 token） | 共识 `/v1/models` list（免费） | featuredCycle vs consensus cycle |
| 队列优先级 | 高（默认 80，抢占式先执行） | 60 | `probe.featured_queue_priority`(80) |
| 失败回退 | 缩短（默认 ×0.5，更快重试恢复） | 标准 7 步链 | `probe.featured_backoff_multiplier`(50%) |

## 触发点

- **深 ping 周期**：`ModelProbeRunner.featuredCycleLoop`（`bg/model_probe.go`）。新模式（`LLM_GATEWAY_USE_NEW_PROBE_MODE=true`，默认）下用 `StartFeaturedOnly` 单独启动此周期（共识环不跑，避免与 NodeProbeWorker/CredentialSelfcheckWorker 重复写状态）。SQL 去掉静态谓词、改为 Go 内 `globalIsFeaturedModel` 过滤（统一 static ∪ usage）。
- **非常用降频**：`applyResult` 的 `healthy_confirmed` 分支乘 `nonfeatured_watchdog_multiplier`（仅健康态；`broken_confirmed`/失败回退不动，不掩盖故障）。
- **队列优先级**：`NodeProbeWorker.submitViaQueue` 用 `FeaturedQueuePriority(model, 60)`。
- **回退缩短**：`ProbeService.Run` 的 7 步 `backoff`，常用模型乘 `featured_backoff_multiplier`。

## kill-switch / 回退

- `probe.featured_usage_top_n=0`：仅静态精选，关闭用量分级行为。
- `probe.featured_cycle_seconds` 调大即降低常用模型深 ping 频度。
- `probe.nonfeatured_watchdog_multiplier=1`：非常用模型与常用同频。
- `probe.featured_backoff_multiplier=100`：常用与非常用回退一致。
- 不改 routing 决策路径（`routing_policy.featured_models` 谓词读取不动），仅影响自检调度。

## 资源竞争

- 用量缓存 `atomic.Pointer[featuredSet]`（无锁读），单 goroutine ticker 刷新。
- `ModelProbeRunner.done` 用 `sync.Once` 关闭，`StartFeaturedOnly`（无共识环）与 `Start`（有共识环）两种用法下 `Stop()` 均不死锁。
- 深 ping 保留 2s rate-limit（`featuredCycle` 内 `time.Sleep(2s)`）。
