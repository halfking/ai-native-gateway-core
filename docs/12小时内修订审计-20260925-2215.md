## 四、发现清单（在制侧，按严重度）

### F1【P1·数学性回归】手搓 exp() 恒返回 1.0

`autoroute/scoring.go:495`：

```go
func exp(x float64) float64 {
    if x == 0 { return 1 }
    if x < 0 { return 1 / exp(-x) }
    half := exp(x / 2)
    return half * half
}
```

- x>0：递归折半直到浮点下溢为精确 0（约 1074 层），`exp(0)=1`，回栈全为 1²=1 → **恒 1.0**
- x<0：`1/exp(-x)` = 1/1 = **恒 1.0**
- 注释宣称的 Padé [3/3] 公式 `(120+60x+12x²+x³)/(120-60x+12x²-x³)` **根本没写进代码**
- 后果链：`scoreStrengthMatch` 的 `coverage = 1 - exp(-hits/2)` 恒 0 → score 恒 50 → **该维度对排序零贡献**。且这不是死代码：`Score()`（scoring.go:191-192，8 维主路径）直接调用它
- 对照：被删的 scoring_new.go（HEAD 版）用的是 Taylor 级数 + ±5 截断，**数学上可用**——本重构是用坏实现替换了好实现
- 修复（一行）：`scoring_v2.go` 已 import math，无任何依赖顾虑——删掉手搓 exp，`coverage := 1 - math.Exp(-float64(hits)/2.0)`，注释公式（hits=1→0.39、hits=4→0.86、hits=8→0.98）与 math.Exp 完全一致，无需改
