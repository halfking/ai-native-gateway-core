**原因**: macOS 文件系统扩展属性，Linux 不支持
**解决**: 已正常部署，可忽略

### 2. 前端 chunk 较大警告

**现象**: 
```
Some chunks are larger than 500 kB after minification
```

**影响**: 首屏加载可能稍慢（500-800ms）
**优化建议**: 
- 使用 dynamic import() 代码分割
- 配置 manualChunks 优化分块
