## 2. 部署执行

### 2.1 构建 & 上传

**本地执行**:
```bash
cd "${LLM_GATEWAY_REPO_DIR}"

# 使用无缝部署脚本（推荐）
bash scripts/deploy-245.sh

# 或者手动指定 seq
# bash scripts/deploy-245.sh --seq 1028
```

**deploy-245.sh 流程**:
1. 本地编译 gateway 二进制（Go 1.26）
2. 编译前端（Vue3 + Vite）
3. 打包到 releases/v<version>-<seq>/
4. 上传到 245:/opt/llm-gateway/releases/
5. 校验 checksum
6. 运行 DB 迁移（如有）
7. 原子切换符号链接 current → new version
8. 重启服务（systemctl restart llm-gateway）
9. healthz 检查
10. 成功 or 自动回滚

**预计耗时**: 3-5 分钟

### 2.2 部署参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 目标主机 | `${LLM_GATEWAY_PREPROD_HOST}:${LLM_GATEWAY_PREPROD_SSH_PORT}` | 预发环境 |
| 数据库 | `${LLM_GATEWAY_DB_HOST}:${LLM_GATEWAY_DB_PORT}` | 共享 PG |
| 前端 | 同时部署 | 完整验证 |
| DB 迁移 | 自动执行（如有） | 已全部完成 |
| build_seq | 自动递增 | 例如 1028 |

## 6. 常见问题处理

### 问题 1: API 返回 404

**症状**: 所有质量画像 API 返回 404

**可能原因**:
- 路由未注册
- handler 创建失败
- profileUpdater 为 nil

**排查**:
```bash
# 检查日志
journalctl -u llm-gateway -n 100 | grep "质量画像 API"

# 预期看到:
# "质量画像 API 已启用"
```

**解决**:
- 确认代码版本正确
- 重启服务
- 检查数据库连接

### 问题 2: API 返回 500

**症状**: API 返回 `{"code": 50001, "message": "服务器内部错误"}`

**可能原因**:
- 数据库查询失败
- 数据格式错误
- 代码 panic

**排查**:
```bash
# 查看详细错误
journalctl -u llm-gateway -n 100 | grep -A 5 "ERROR"
```

**解决**:
- 检查数据库连接
- 检查表结构
- 查看完整堆栈

### 问题 3: 数据为空

**症状**: API 返回 `{"code": 40402, "message": "暂无质量数据"}`

**可能原因**:
- 252 数据库无数据
- 连接了错误的数据库

**排查**:
```bash
# 检查 245 连接的数据库
cat /opt/llm-gateway/current/.env | grep DATABASE_URL

# 应该指向 252:
# DATABASE_URL=postgres://${LLM_GATEWAY_DB_USER}@${LLM_GATEWAY_DB_HOST}:${LLM_GATEWAY_DB_PORT}/${LLM_GATEWAY_DB_NAME}
```

**解决**:
- 在 252 插入测试数据
- 手动触发一次计算

### 问题 4: 更新器未启动

**症状**: 日志显示"质量画像更新器已禁用"

**可能原因**:
- 环境变量 PROFILE_UPDATER_ENABLED=false

**排查**:
```bash
cat /opt/llm-gateway/current/.env | grep PROFILE_UPDATER_ENABLED
```

**解决**:
- 如需启用，修改环境变量或删除该配置（默认启用）
- 重启服务
