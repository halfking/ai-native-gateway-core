## 📋 项目概述

Phase 3 供应商质量画像项目旨在为 LLM Gateway 提供供应商和模型的质量评估能力，通过五维评分体系（可用性、性能、稳定性、成本效益、综合质量）帮助运维人员和决策者快速了解各供应商的服务质量。
