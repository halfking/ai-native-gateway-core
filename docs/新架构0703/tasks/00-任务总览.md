## 🎯 如何使用

### 1. 选择任务
查看任务列表，选择一个符合你技能的任务

### 2. 检查依赖
确认依赖任务已完成或可以基于Mock进行开发

### 3. 打开提示词
```bash
# 进入任务目录
cd docs/新架构0703/tasks

# 查看任务提示词
cat task-A1-hook-framework.md
```

### 4. 启动新会话
在新的AI会话中，粘贴完整的任务提示词

### 5. 开始开发
按照提示词的指导进行开发

### 6. 提交代码
开发完成后提交代码评审
