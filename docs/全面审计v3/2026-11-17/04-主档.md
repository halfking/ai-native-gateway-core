## 四、通用式（本轮沉淀）

1. **「多轮自审计后的残留面」要用独立轮再扫一遍**——本轮 5/5 检验点在前三轮自审计后仍然开放；并行列车修的是它审计表上的行，不在表上的行为它而留。
2. **请求级参数不得写进长生命周期共享对象**——SetBatchSize 型 API 一旦暴露给 handler，就是「一次请求永久改后台配置」+ data race 的双重缺陷；请求级走局部参数副本。
3. **「孤儿终态」要独立于「正常路径终态」**——IncrementRetry 的 failed 分支只救「活着走到的」行；回收器必须自带耗尽→终态分支，否则孤儿行永久僵尸。
4. **注释声称的幂等必须有守卫**——「注释即契约」在本仓已是登记教训（自述与实现不符），F4 是又一例。
5. **出网点点校验只对初始 URL 有效**——任何带 Authorization 的出网 Client 都要自答「重定向跟随吗」；不跟随是最便宜的 fail-closed。
