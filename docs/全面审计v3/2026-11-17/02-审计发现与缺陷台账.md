## 一、已修复（5 项）

### F1（P1）手动触发与后台 worker 的 data race + 全局配置劫持
- **位置**：`admin/pi_analysis_handler.go:441`（原 `h.analyzer.SetBatchSize(req.BatchSize)`）× `domains/promptinjection/error_analyzer.go`（`ClaimPendingErrors(ctx, ea.batchSize)` 裸读）
- **事实**：每次 `POST /trigger` 写共享 `batchSize`（普通 int）——① 与后台 worker 读并发（`-race` 可报）；② 任意一次手动触发**永久改变**后台 worker 的批大小；两个并发 POST 互相覆盖。
- **修法**：新增 `ProcessBatchN(ctx, limit)`（局部 limit，clamp 1..100）；`ProcessBatch` 收敛到共同实现 `processBatchLimit`；handler 改走 `ProcessBatchN`，**不再触碰共享字段**；`SetBatchSize` 注释钉死「boot 期专用」。
- **钉测**：`TestErrorAnalyzer_ProcessBatchN_UsesLocalLimitNotSharedState`——① sqlmock 绑定断言领取 LIMIT＝**请求值 3**；② 事后断言 `ea.batchSize` 仍是 10（共享字段未被污染）。

### F2（P1）PI collector/worker 生命周期未接停机 ⇒ 关库后访问 + goroutine 泄漏
- **位置**：`cmd/gateway/main.go:7712`（原 `initPIAgent(context.Background(), …)` 且 worker 返回值 `_` 丢弃）
- **事实**：停机序列里 `piSQLDB` 的 defer Close 会先于 collector drain / worker 循环退出执行 ⇒ 后台协程对已关 `*sql.DB` 发查询；worker 的 `Stop()` 全仓无调用方。
- **修法**：装配点派生 `piAgentCtx` + 保留 worker；函数顶声明 `piAgentStopForShutdown`（仓内 `xxxForShutdown` 既有范式）；在停机 goroutine 里、**关 DB 之前**执行 `piWorker.Stop()` + `piAgentCancel()`。
- **验证**：build/vet 绿；停机顺序注释锚定「先停 PI 再关 DB」。

### F3（P2）`ReclaimStaleClaims` 耗尽重试的孤儿行永久卡 `processing`
- **位置**：`domains/promptinjection/error_collector.go:659`（谓词 `retry_count < max_retries` 把已耗尽行整类跳过）
- **事实**：孤儿行（processor 崩溃/被杀）恰恰走不到 `IncrementRetry` 的终态分支 ⇒ 耗尽的 processing 行既不回 pending 也不落 failed ⇒ 统计面永久「处理中」僵尸。
- **修法**：补第二条 UPDATE——耗尽孤儿 → `status='failed', completed_at=NOW()`；返回值=两腿之和。
- **钉测**：`TestErrorCollector_ReclaimStaleClaims`（改判：期望两腿 3+2=5）+ `TestErrorCollector_ReclaimStaleClaims_ExhaustedPredicate`（**谓词编进 sqlmock 正则**：`'pending'…retry_count < max_retries` / `'failed'…completed_at…retry_count >= max_retries`——任何一侧丢谓词或写反方向 ⇒ 匹配不上 ⇒ 红）。

### F4（P2）`ErrorAnalysisWorker.Start` 非幂等（注释与实现不符）
- **位置**：`domains/promptinjection/error_analysis_worker.go:47`
- **事实**：注释写「幂等：重复调用只生效一次」，实现无守卫 ⇒ 每次 Start 再起一条 `bg.SpawnLoop`（重复 LLM 花费 + 双倍队列争抢）。
- **修法**：`started atomic.Bool` + `CompareAndSwap` 早退；nil analyzer 早退**不**置位（一次误调用不会永久堵死合法 Start）。
- **钉测**：`TestErrorAnalysisWorker_StartIsIdempotent` + `TestErrorAnalysisWorker_StartNilAnalyzerDoesNotArmGuard`。

### F5（P2）`GatewayLLMClient` 跟随重定向 ⇒ 端点校验被 30x 绕过
- **位置**：`domains/promptinjection/llm_client_gateway.go`（http.Client 无 CheckRedirect）
- **事实**：`validateAnalysisEndpoint` 只校验**初始 URL**（禁私网/回环、强制 https）；默认 Client 会把带 Authorization 的请求跟着 30x 转到任意主机（含私网）⇒ SSRF 防线绕过 + 分析 API key 泄给重定向目标。
- **修法**：`CheckRedirect: http.ErrUseLastResponse`——不跟随，3xx 落到既有非 2xx 错误分支（fail-closed）。
- **钉测**：`TestGatewayLLMClient_RefusesRedirects`——302 必须报错**且重定向目标处理器从未被命中**（key 泄漏路径钉死）。
