## 2. 与既有裁决的关系

- F-1 是本轮方案档「W5+W6 合起来＝F4『用尽期 0 探测』的补全」论证的**边界补充**：论证默认
  「用尽凭据都有重置点」，而生产实况是 23/29 用尽凭据**没有**重置点（balance/permanent 族设计上即无）
  ⇒ 「用尽期 0 探测」只对 **6/29** 成立；余者的恢复感知依赖充值事件，而**充值事件链在
  `balance_floor_guard` 一侧断了一环**（静默翻 ok 不发通知）⇒ 与 W6 的回拉分级同族，
  补的是「事件源」而不是「回拉分级」。
- F-2 是第 50 轮 F-1/F-2「同族第二处未登记」的延续，但性质不同：**不是漏改，是错误前提**
  ⇒ 判据自身失真（与「看半截就下结论会误改一把本来正确的门」同族：ctid 方案仍安全，
  但它的理由句是假的；本轮只订正理由，不动实现）。
- F-3/F-4 是 C 组指出的「判据只钉一半接线点」——与第 49 增量 P-1（双侧白名单）教训同族：
  **形态断言钉了 SQL 文本，没钉实参端与第二条路径**。
- F-10 的裁决过程本身是本轮的一条方法论：**子代理的静态推断（基于两段 SQL 谓词交集）被生产读数否证**
