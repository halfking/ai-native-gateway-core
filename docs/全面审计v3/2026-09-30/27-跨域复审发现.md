# 四十三轮跨域复审发现（2026-09-30）

## 范围与证据边界

本轮在既有 D01–D17 覆盖清点上，对 D01–D06、D08–D11、D13、D15–D17 做了只读复审；D07、D12 沿用现有审计证据，本轮未重新运行。代理审阅基于隔离工作树 `cc867aa3c2098d6c9f5c8bc7f09f748af682a61a`，并交叉检查 `origin/main=4b00d57f8cdda24d3335913a46f578641560964d`；相关审阅者没有编辑文件、运行测试或部署。下面区分源码缺口、测试存在性和真实环境门，不将其混为一类。

## 复核结果

| 域 | 级别 / 状态 | 证据与仍开放事项 |
|---|---|---|
| D01 IR | P1，开放 | 三层 original→sanitized→compressed 的 block identity/occurrence 和反向解析尚未完整闭合；Messages 顶层 `system`、Responses `instructions` 的 SanitizedMessageRefs 缺 identity/occurrence；IR v3 仍为设计。请求级 `InternalRequest.Extensions` 不落库，“无界 TTL”旧发现已撤回；`ProviderExtensions` 抽取器无生产调用者的问题应归 D17。 |
| D02 协议 | P3 覆盖缺口 | F04 请求/探针已共享“不支持 Responses”判断，但两路仍独立构造回退请求，缺少同一错误输入下的选择 parity 联测；客户端协议×上游协议×stream/非 stream 黄金矩阵仍未建立。 |
| D03 缓存 | P1，开放 | sanitizer refs 与 compressed map 缺少可对账 identity/occurrence；顶层 system/instructions 仍缺 refs。三层一致性目前只做较弱对齐检查；session censors 的过期/淘汰策略仍需复核。历史 assistant/tool、prompt-only Completions 已有部分修复，不等于逐 block 全覆盖。 |

| D05 压缩 / handoff | 机制存在，客户端门开放 | 1M handoff 默认及阈值实现已有代码/测试；尚未证明真实 handler 的 202/resume packet 契约、客户端 `/new` 行为和跨副本幂等；多轮压缩还需以重要事实保留断言补强。 |

| D09 自检 / F04 | P1 + P2，开放 | **P1 误恢复风险**：凭据级探测成功会调用 `restoreAllBindingsOnCredentialSuccess`；SQL 排除 manual、`model_probe_broken`、`admin_protected`，但未排除 404/410 写入的 `auto_model_not_found`、`auto_model_deprecated`，可能提前恢复仍失效的模型绑定。**F04 持久能力部分已在 main**：`CredentialProbeV2` 写/读 `(credential, model)` Redis verdict；`node_probe`、`probe_http`、`active_probe_executor` 等路径未统一写入，业务请求发现 unsupported 也不写回。另有能力 verdict 与 node-health 共用 Redis key TTL、普通健康写入可能续期能力 TTL；探针 verdict 使用实例共享单槽，并发执行可能丢结论。真实 Redis/跨实例恢复测试仍未跑。 |
| D10 统计 | P1 架构裁决，开放 | 来源枚举、更正、幂等重放、差异待办和月结锁定有代码/测试；`usage_facts` 仍无法表达费用 confidence，也没有 attempt_no，成功请求终态只投影一条 usage fact。需先裁定账本 schema，再用“多候选失败、最终成功”样本逐 attempt 对账。 |

| D14 安全 / F02 | 本地代码门通过，外部门开放 | 本轮 F02 补 Messages/Responses 非流式和普通/survival 流的 interceptor、策略阻断终态及失败归因；sanitizer restore 排在 output compliance 前，确保检查恢复后的客户端可见文本。相关 byte-level handler 测试、包测试、race、build、vet 通过；真实 SDK、PG/Redis、durable stream 与供应商/部署验证未做，不能标记端到端关闭。 |
