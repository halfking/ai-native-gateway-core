### 4.2 安全模式变更 - 行为影响分析

#### 新增配置项
```yaml
security:
  mode: observe  # 或 block
  enabled: true
```

#### 行为变化矩阵

| 场景 | 旧行为 | 新行为 (observe) | 新行为 (block) |
|------|--------|-----------------|----------------|

### 4.4 会话压缩摘要 - 信息保真度

#### 新增机制
```
1. 分段抽取: 将长会话分成多个段
2. 段内摘要: 每段提取关键信息
3. 分层合并: 递归合并段摘要
4. 段缓存: 缓存中间结果
```

#### 信息损失风险
```
场景 1: 跨段上下文丢失
  - 段 A 的问题在段 B 才回答
  - 摘要可能割裂上下文

场景 2: 关键细节被过滤
  - 抽取式摘要可能漏掉重要但不常见的信息
  - 技术细节、数字、专有名词风险高

场景 3: 合并产生歧义
  - 多层合并可能引入理解偏差
```

#### 需要验证
```
1. ✗ 摘要后的会话是否仍能正确理解用户意图
2. ✗ 对比原始会话 vs 摘要会话的模型响应质量
3. ✗ 是否有回退机制在摘要质量不佳时使用原文
4. ✗ 段缓存失效策略是否合理
```
