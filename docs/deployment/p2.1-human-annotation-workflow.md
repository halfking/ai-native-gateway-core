## 概述

### 目标

为低置信度AUTO路由样本建立人工标注流程，提升ML训练数据质量。

### 核心功能

1. **导出低置信度样本**: 从`auto_route_selections`导出置信度<0.7的样本到CSV
2. **人工标注**: 标注人员在CSV中填写正确的provider、是否正确、标注原因
3. **导入标注结果**: 将标注后的CSV导入`training_human_annotations`表
4. **统计分析**: 查看ML准确率、分provider准确率、标注人员统计等

### 技术栈

- **数据库**: PostgreSQL (新增表`training_human_annotations`)
- **CLI工具**: `llm-gw-annotator` (Go)
- **标注格式**: CSV (便于Excel/Google Sheets编辑)
- **Go包**: `annotation/` (exporter, importer, stats)

### CSV格式

#### 导出格式（待标注）

```csv
request_id,model_name,task_type,prompt_tokens,is_streaming,has_vision,region,profile,auto_provider,confidence,human_provider,is_correct,reason,annotator
req_001,gpt-4,chat,150,false,false,us-east-1,balanced,openai,0.65,,,,,
req_002,claude-3-opus,chat,200,true,false,eu-west-1,quality,anthropic,0.58,,,,,
```

#### 导入格式（已标注）

```csv
request_id,model_name,task_type,prompt_tokens,is_streaming,has_vision,region,profile,auto_provider,confidence,human_provider,is_correct,reason,annotator
req_001,gpt-4,chat,150,false,false,us-east-1,balanced,openai,0.65,openai,TRUE,correct,alice
req_002,claude-3-opus,chat,200,true,false,eu-west-1,quality,anthropic,0.58,aws_bedrock,FALSE,cost,bob
```

**标注字段说明**:

- `human_provider`: 人工标注的正确provider（必填）
- `is_correct`: ML预测是否正确，TRUE或FALSE（必填）
- `reason`: 标注原因（可选）
  - `correct`: ML预测正确
  - `performance`: 性能原因（延迟、吞吐）
  - `cost`: 成本原因
  - `availability`: 可用性原因
  - `quality`: 质量原因（输出质量）
  - `other`: 其他原因
- `annotator`: 标注人员用户名或邮箱（必填）

## 数据库Schema

### Migration 664: training_human_annotations

```sql
CREATE TABLE training_human_annotations (
  id BIGSERIAL PRIMARY KEY,
  request_id TEXT NOT NULL,
  auto_label TEXT NOT NULL,
  auto_confidence FLOAT NOT NULL,
  human_label TEXT NOT NULL,
  is_correct BOOLEAN NOT NULL,
  annotation_reason TEXT,
  annotator TEXT NOT NULL,
  annotated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  annotation_metadata JSONB,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

### 视图

1. **annotation_stats**: 总体统计（总数、准确率、标注人数）
2. **annotation_accuracy_by_provider**: 分provider准确率
3. **annotation_stats_by_annotator**: 标注人员统计
4. **annotation_reason_distribution**: 标注原因分布

## 隐私合规

### 导出隐私保证

✅ **只导出结构化特征字段**:
- model_name, task_type, prompt_tokens
- is_streaming, has_vision, region, profile
- auto_provider, confidence

❌ **不导出敏感字段**:
- prompt (用户输入)
- messages (对话历史)
- response (模型输出)
- summary, keywords (可能包含内容)

### 查询隐私审计

导出查询只访问白名单列:

```sql
SELECT 
  ars.request_id,
  ars.model_name,
  ars.task_type,
  ars.prompt_token_count,
  ars.is_streaming,
  ars.has_vision,
  ars.region,
  ars.profile,
  ars.selected_provider,
  ars.confidence
FROM auto_route_selections ars
-- 不访问: prompt, messages, response, summary, keywords
```

### 标注人员权限

- 标注人员只看到CSV中的结构化特征
- 无法通过request_id反查原始prompt/response
- 标注系统不提供request_id的详情查询接口

## 故障排查

### 问题1: 导出时提示"No samples to export"

**原因**: 时间范围内没有符合条件的样本

**解决**:
```bash
# 检查是否有低置信度样本
psql $DATABASE_URL -c "
  SELECT COUNT(*), MIN(confidence), MAX(confidence)
  FROM auto_route_selections
  WHERE timestamp >= '2026-08-01' AND timestamp < '2026-09-01'
    AND confidence < 0.7;
"

# 调整confidence范围
llm-gw-annotator export \
  --start 2026-08-01 \
  --end 2026-09-01 \
  --max-confidence 0.8 \
  --limit 100 \
  --output annotations.csv
```

### 问题2: 导入时提示"already annotated"

**原因**: 该request_id已有标注记录

**解决**:

```bash
# 检查已标注的request_id
psql $DATABASE_URL -c "
  SELECT request_id, annotator, annotated_at
  FROM training_human_annotations
  WHERE request_id = 'req_xxx';
"

# 删除重复标注（谨慎操作）
psql $DATABASE_URL -c "
  DELETE FROM training_human_annotations
  WHERE request_id = 'req_xxx';
"
```

### 问题3: 验证失败 "invalid reason"

**原因**: reason字段使用了不在白名单中的值

**解决**:

有效的reason值:
- `correct`
- `performance`
- `cost`
- `availability`
- `quality`
- `other`

### 问题4: 数据库连接失败

**解决**:

```bash
# 检查DATABASE_URL环境变量
echo $DATABASE_URL

# 或显式传递
llm-gw-annotator --db "postgresql://user:pass@host:5432/dbname" export ...

# 测试连接
psql $DATABASE_URL -c "SELECT 1;"
```

## 最佳实践

### 1. 标注批次管理

**建议**: 每周导出一个批次，避免单次标注量过大

```bash
# Week 1: 2026-08-01 ~ 2026-08-07
llm-gw-annotator export \
  --start 2026-08-01 --end 2026-08-08 \
  --max-confidence 0.7 --limit 500 \
  --output annotations_week1.csv

# Week 2: 2026-08-08 ~ 2026-08-14
llm-gw-annotator export \
  --start 2026-08-08 --end 2026-08-15 \
  --max-confidence 0.7 --limit 500 \
  --output annotations_week2.csv
```

### 2. 多人标注一致性检查

**建议**: 随机抽取10%样本由多人标注，计算一致性

```sql
-- 查找多人标注的样本
SELECT * FROM calculate_annotation_agreement()
WHERE num_annotators > 1 AND agreement_rate < 0.9;
```

### 3. 标注质量监控

**建议**: 定期检查标注人员统计，识别异常

```bash
# 查看标注人员统计
llm-gw-annotator stats

# 检查是否有准确率异常低的标注人员
# 如果某人准确率 < 60%，可能需要重新培训
```

### 4. 渐进式标注

**建议**: 先标注100条验证流程，再扩大到1000条

```bash
# 阶段1: 小批量验证（100条）
llm-gw-annotator export \
  --start 2026-08-01 --end 2026-09-01 \
  --max-confidence 0.7 --limit 100 \
  --output pilot_annotations.csv

# 标注 + 导入 + 检查统计

# 阶段2: 扩大规模（1000条）
llm-gw-annotator export \
  --start 2026-08-01 --end 2026-09-01 \
  --max-confidence 0.7 --limit 1000 \
  --output full_annotations.csv
```

### 5. 标注指南文档

**建议**: 为标注人员提供明确的标注指南

示例指南内容:
- **目标**: 标注ML预测是否正确，并给出原因
- **human_provider选择原则**:
  - 优先考虑性能（延迟）
  - 其次考虑成本
  - 最后考虑质量
- **reason选择原则**:
  - `correct`: ML预测正确
  - `performance`: 其他provider延迟更低
  - `cost`: 其他provider成本更低
  - `availability`: ML预测的provider不可用
  - `quality`: 其他provider质量更好
  - `other`: 其他原因

## 下一步集成

### 1. 训练数据导出

将人工标注集成到训练数据导出:

```sql
-- 导出时优先使用human_label
SELECT 
  ars.request_id,
  ars.model_name,
  ars.task_type,
  -- ... 其他特征
  COALESCE(tha.human_label, ars.selected_provider) AS label,
  CASE 
    WHEN tha.human_label IS NOT NULL THEN 1.0
    ELSE ars.confidence
  END AS label_confidence
FROM auto_route_selections ars
LEFT JOIN training_human_annotations tha ON tha.request_id = ars.request_id;
```

### 2. 样本权重

在ML训练时，给予人工标注更高权重:

```python
# 样本权重
weights = []
for row in training_data:
    if row['has_human_annotation']:
        weights.append(2.0)  # 人工标注样本权重x2
    else:
        weights.append(1.0)  # 自动标注样本权重x1

clf.fit(X_train, y_train, sample_weight=weights)
```

### 3. 主动学习

识别ML最不确定的样本优先标注:

```bash
# 导出置信度在0.4-0.6范围的样本（最不确定）
llm-gw-annotator export \
  --start 2026-08-01 --end 2026-09-01 \
  --min-confidence 0.4 --max-confidence 0.6 \
  --limit 500 \
  --output uncertain_samples.csv
```

### C. SQL查询示例

#### 查询ML准确率

```sql
SELECT 
  COUNT(*) AS total,
  SUM(is_correct::int) AS correct,
  ROUND(AVG(is_correct::int) * 100, 2) AS accuracy_percent
FROM training_human_annotations;
```

#### 查询最常见的错误原因

```sql
SELECT 
  annotation_reason,
  COUNT(*) AS count
FROM training_human_annotations
WHERE is_correct = false
GROUP BY annotation_reason
ORDER BY count DESC;
```

#### 查询特定provider的准确率

```sql
SELECT 
  auto_label,
  COUNT(*) AS total,
  ROUND(AVG(is_correct::int) * 100, 2) AS accuracy_percent
FROM training_human_annotations
WHERE auto_label = 'openai'
GROUP BY auto_label;
```
