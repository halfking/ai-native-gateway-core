### 3.1 Vant Cell：箭头与可点性绑在同一个开关（一手核对 2026-10-05）

本仓对 [Vant `Cell` 组件 README](https://github.com/youzan/vant/blob/main/packages/vant/src/cell/README.zh-CN.md)
做了逐字核对（`web.dev`/转述不算，读到组件正文为止）：

| 属性 | 官方原文 | 对本仓契约的意义 |
| --- | --- | --- |
| `is-link` | 「是否展示右侧箭头**并开启点击反馈**」 | **箭头与可点是一个开关**的两个表现——页面不能单独决定「要箭头但不可点」或「可点但不给箭头」。直接依据 [03 §3.3](./03-列表卡片与弹窗.md) 第 3/4 条 |

| `url` / `to` | 「点击后跳转的链接地址」/「跳转的目标路由对象」直接挂在 cell 上 | 导航由行自身承担，**不另设「详情」按钮**——03 §3.3 第 1/2 条的同款选择 |

## 4. 原生壳边界：远端 SPA 不自动继承插件

**[已落地]** 这是本专题最重要的一条工程事实，写在这里以免被「Capacitor 能装什么」误导。

**远端提供的 SPA 不自动继承原生插件。** 三个原因叠加：

1. 引导页 `location.replace` 到远端后**可能不在 WebView 里**（[04 §3](./04-Hybrid外壳.md)）
2. Capacitor 默认把外部 URL 交给**系统浏览器**
3. 即便在 WebView 里，桥注入也是**逐页**的，不跨 origin 继承

**因此**：

| 必须做 | 实现 |
| --- | --- |
| 显式批准 origin 列表 | `APPROVED_ORIGINS`，**不用 `['*']`** |
| 能力四关 fail-closed | `capabilities.ts` |
| 前端**不假设**留在 WebView | 降级为普通 Web，**不谎报能力** |

> **放开 `['*']` 等于让任意用户输入的地址获得全量原生能力。**
> 白名单外的降级（被系统浏览器打开）功能仍可用，只是没有原生壳能力 ——
> 这是**已知且可接受**的代价，好过开放面。
