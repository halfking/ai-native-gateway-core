**不要拿本文档的数值去改 llm-gateway-go 的断点。**

| 项 | nbjl3 | 本项目 | 原因 |
| --- | --- | --- | --- |
| 窗口四档 | compact <600 / medium <960 / expanded <1280 / large ≥1280 | **compact <768 / medium 768–1023 / expanded 1024–1439 / large ≥1440** | 沿用本仓 `config/breakpoints.ts` SSOT 与 `responsive-audit.mjs` 白名单。切 600/960/1280 要覆盖 95 个视图并重写审计门，收益为零、回归风险为正 |

## 一句话产品形态

**一套 Vue SPA，三种入口：**

1. 桌面浏览器（≥1024）—— 现状专业顶栏 + 高密度表 + 居中弹窗，**本轮零回归**
2. 手机 / 窄屏浏览器与 PWA（compact <768）—— 底栏、抽屉、账户 Sheet、强制卡片
3. iOS / Android Hybrid 壳（Capacitor）—— 壳只装引导页，业务来自部署机 origin

不写第二套移动代码，不加独立 RN/Flutter 业务层。

## Hyper 模式框架

Hyper = **页面与层级导航上下文 + 返回仲裁 + 能力协商 + 受控原生能力**。
已实现部分与目标部分在 00 §3.3 的缺口表里逐项区分；**文档提交不代表能力已实现**。

  徽章的类型 class 挂在内层 `sup.el-badge__content` 上，**不在**外层 `.el-badge` 上
  ⇒ **Element 组件的 class 名要 dump 真实 DOM，别凭 `em()` 语义推**
- ★ **台账第七种成因，也是迄今占比最高的一类**（切片十七，7 条「门未红」里 6 条）：
  **「门未红」的第一成因是「我根本没断那一条」**，不是实现绕过了断言。
  前六种成因全都是「实现绕过断言」，这一种是「断言不存在」——
  **症状一样（门绿），处置完全相反**。判别动作：把那一条的判据句子读出来，
  看它断言的到底是哪个节点、哪个属性；**读不出来就是没断过**。
- 三条接入通则（切片十七）：① **`CardList.text()` 只认 `null`/`undefined`，空串 `''` 会渲染成空白**
  —— 桌面 `x || 破折号` 的列在卡片侧必须补 `format`（**与切片十五/十六那两处差异方向相反**，
  别当通则套用）；② **徽章 tone 必须从 `<style>` 的实际色值反查**，
