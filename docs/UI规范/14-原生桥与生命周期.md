# 14 — 原生桥与生命周期

> 状态标记：**[已落地]** / **[部分落地]** / **[未落地]**。
> 壳工程：`llm-gateway-client`（Capacitor 8.5.2）。

## 1. 壳层与 Web 层的责任

**[已落地]**

| 壳层（原生） | Web 层（SPA） |
| --- | --- |
| 进程、启动屏、图标 | 业务规则、请求、渲染 |
| 系统栏、inset | `env(safe-area-inset-*)` 的**消费** |
| 生命周期事件 | 页面可见性 |
| 桥与插件注册 | **能力协商**（不假定存在） |
| 网络豁免 | 鉴权（Token 在 `sessionStorage`） |

**一句话**：壳提供"可能"，Web 通过协商"确认"，**协商不通过就降级**。

## 2. 远端 SPA 必须先过能力门

**[已落地] 门控 / [未落地] 验证**

引导页 `location.replace` 到业务 origin 后，**页面不一定在 WebView 里**。
不在 WebView 里 ⇒ 桥没注入 ⇒ 插件全不可用。

```ts
// lib/shell/hyper/capabilities.ts —— 四关 fail-closed
桥存在 → 协议版本相符 → origin 精确匹配 → 能力注册表非空
```

**任一关不过即整体降级为普通 Web**，页面功能不变、无原生能力。

**[未落地] 见效性未取证**：[04 §7 A-2](./04-Hybrid外壳.md) / [09 V-1](./09-原生与AI能力调研.md)。
**这是所有原生能力的总闸，未验证前不应开发任何原生能力。**

## 3. 安全区、视口与键盘：只有一个消费策略

**[已落地]**

```ts
plugins: { SystemBars: { style: 'DARK', insetsHandling: 'css' } }
```

`css` = 原生不 padding，只由 Web 侧 `env(safe-area-inset-*)` 避让 —— **单次消费**。
另有 `native`（原生 padding）与 `disable`（全不管），本项目都不选。

**视口 meta 必须含 `viewport-fit=cover`**，否则插件认为不需要 passthrough，
改走 native padding，与 CSS inset **叠加**（双倍避让）。

### 三条禁止回退的实测结论

| # | 禁止 | 实测后果 |
| --- | --- | --- |
| 1 | `MainActivity` 手工调 `setDecorFitsSystemWindows` | `TypeError: Cannot read properties of null (reading 'style')` → **白屏** |
| 2 | 引导页用 `env(safe-area-inset-*)` | 该阶段尚未注入 → **无避让** |
| 3 | 去掉 `viewport-fit=cover` | inset **双倍避让** |

**键盘（软键盘）避让未实现。** `[未落地]`。
iOS 与 Android 的键盘行为不同（`visualViewport` 高度变化时机不一样），
未实测前不要凭单端经验实现。

## 4. 页面存在 / 页面可见 / App 活跃是三件事

**[部分落地]**

| 概念 | 含义 | 本仓状态 |
| --- | --- | --- |
| 页面存在 | 组件已挂载 | ✅ Vue 生命周期 |
| 页面可见 | 页面在栈顶 | ✅ 路由状态 |
| **App 活跃** | 壳在前台 | **[未落地]** 未接 `App` 插件的 `appStateChange` |

**连续加载的 `pause()` 已就绪**（`createHyperPages.pause()`），
但**没有页面调用它** —— 缺少 App 活跃状态这一环。

**接入时**：`appStateChange` → inactive 时 `pause()`（断开 observer），
active 时 `resume()`。**必须断开，不能只置一个 flag** ——
observer 不断开会继续在后台触发请求。

## 7. 零凭据红线

**[已落地]** 每轮交付都要重跑核验。

| 检查 | 结果 |
| --- | --- |
| 原生 java/xml 有无 token 字面量 | 无 |

**"grep 命中一条"不等于泄露** —— 必须看清命中的那一行是什么。
本例命中的是**禁止这件事的注释**，所以是安全证据而不是风险。
