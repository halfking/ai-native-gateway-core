## 4. 性能目标与测量方式

**[未落地] 以下全部是目标值，本仓未实测。**

| 指标 | 目标 | 测量方式 | 状态 |
| --- | --- | --- | --- |
| 冷启动到引导页可交互 | < 1.5s | `adb shell am start -W` | 未测 |
| 引导页切到业务首屏 | < 2.5s | DevTools Performance + `performance.mark` | 未测 |
| 页面切换 | < 300ms | 同上 | 未测 |
| 连续加载追加一页 | < 500ms | 慢 4G 节流 | 未测 |
| 2000 行滚动 | 无掉帧 | Perfetto / `adb` gfxinfo | 未测 |
| APK 体积 | < 8 MB | 当前 4.41 MB ✅ | **唯一已达标的指标** |

**测量必须用慢网节流**。模拟器默认网络太快，会掩盖真实设备上的问题。
**性能数字必须写取数环境**，否则无法复现也无法对比。
