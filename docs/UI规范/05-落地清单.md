## 4. 明确禁止

| # | 禁止 | 后果 |
| --- | --- | --- |
| 1 | 在组件里写 `var(--不存在的令牌, #字面值)` | 字面兜底是「暗色漏白」通道；去掉兜底后颜色解析为空 |
| 2 | 用 CSS 隐藏代替 `v-if` 做形态切换 | 节点仍在 DOM、可被读屏聚焦、事件可能命中 |
| 3 | 建第二套覆盖层栈 | ESC 与系统返回会关掉不同的层 |
| 4 | 在 `MainActivity` 调 `setDecorFitsSystemWindows` | 实测白屏（与 SystemBars 插件抢所有权） |
| 5 | `allowNavigation: ['*']` | 任意用户输入的地址获得全量原生能力 |
| 6 | 在原生工程里放 JWT / API Key | 零凭据红线；Token 只在 SPA `sessionStorage` |
| 7 | 媒体查询用 Level 4 范围语法 | `responsive:check` 拦截；Safari 15 不支持 |
| 8 | 为让门禁变绿而改门禁或改 baseline | 门禁的价值在于「因正确理由」通过 |
| 9 | 用 `color:baseline:update` 一次性豁免存量 | 把欠账藏起来；存量应单独立项 |
| 10 | 新建媒体查询而不更新 `config/breakpoints.ts` | 断点分裂 |

## 6. 工程门禁（规范的自动化镜像）

**[已落地]** 规范里每条「不可省的约束」都有对应门禁，且**都做过变异验证**证明有牙。

| 规范条款 | 门禁 | 位置 |
| --- | --- | --- |
| 死选择器（`hyper.css` 类名必须真实存在） | 跨文件门禁 | `lib/shell/hyper/gates.spec.ts` |
| 令牌必须存在、无字面兜底 | 令牌存在性门禁 | 同上 |
| 弹层层级顺序 | 层级门禁 | 同上 |
| compact 强制卡片、切换不发请求、三态统一 | 行为 + 源码断言 | `components/ui/ResponsiveDataView.spec.ts` |
| 自动加载四条约束 | 行为 + 源码断言 | `components/ui/HyperLoadMore.spec.ts` |
| revision 闸门 / 去重 / 单飞 / 淘汰 | 行为门禁 | `lib/shell/hyper/hyperPages.spec.ts` |
| 标题解析次序 / 作用域隔离 | 行为门禁 | `lib/shell/hyper/title.spec.ts` |
| 去敏持久化 | 行为门禁 | `lib/shell/hyper/context.spec.ts` |

> 没验证过的门只是装饰。本专题的 48 条变异记录在 00 §9.5.3，
> 其中「判据无牙」的 5 条成因已逐条查清（双层防御 / 不可达守卫），**不要把无牙当成已验证**。
