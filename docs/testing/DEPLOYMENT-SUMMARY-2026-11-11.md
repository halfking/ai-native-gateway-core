## 二、遇到的问题

### 2.1 真机连接问题（阻塞）
**问题描述**: 
- iPhone (2) 设备显示为"Devices Offline"
- xcodebuild 无法识别该设备
- UDID: 00008110-000450DA2101401E

**原因分析**:
设备可能未信任此Mac，或未启用开发者模式，或设备锁定

**当前方案**:
使用 iPhone 模拟器（nbjl-6s-size-263）进行功能验证，该模拟器配置为接近 iPhone 6s 的屏幕尺寸

**需要用户操作**:
1. 在 iPhone 上信任此 Mac（弹窗确认）
2. 在 iPhone 设置中启用开发者模式
3. 确保设备解锁并保持连接

### 2.2 Maestro 环境变量问题
**问题描述**:
配置文件中的 `${NODE_CARD_INDEX}` 变量未正确解析

**临时方案**:
使用 `-e` 参数直接传递环境变量：
```bash
maestro test -e NODE_CARD_INDEX=0 -e MAESTRO_USERNAME=admin ...
```

**永久方案**:
需要修复 Maestro 配置或使用 `--config` 参数
