# LLM Gateway 测试计划

## 1. 测试目标

全面验证 LLM Gateway 应用的功能特性、性能表现和用户体验，确保：
- 所有核心功能正常运作
- 系统在高负载下保持稳定
- UI在不同主题下保持一致性和可用性
- 与 RedClaw 和已有 llm-gateway-go 风格保持一致

## 2. 测试范围

### 2.1 功能测试（Maestro）
使用 Maestro 工具进行UI自动化测试，覆盖以下功能：

1. **认证与授权**
   - 登录流程
   - 权限验证
   - 会话管理

2. **API密钥管理**
   - 创建密钥
   - 查看密钥列表
   - 禁用/启用密钥
   - 删除密钥

3. **模型管理**
   - 查看可用模型
   - 模型状态监控
   - 模型配置

4. **请求监控**
   - 实时请求列表
   - 请求详情查看
   - 请求过滤和搜索

5. **会话管理**
   - 会话列表
   - 会话详情
   - 会话历史

6. **系统设置**
   - 配置管理
   - 系统状态监控

7. **主题切换**
   - 明暗主题切换
   - 主题一致性验证

### 2.2 性能测试（k6）
使用 k6 工具进行性能和压力测试：

1. **API负载测试**
   - 并发请求处理
   - 响应时间测量
   - 错误率统计

2. **流式响应测试**
   - SSE连接稳定性
   - 流式数据完整性
   - 连接数上限

3. **管理端点测试**
   - CRUD操作性能
   - 并发管理操作

4. **尖峰测试**
   - 突发流量处理
   - 系统恢复能力

### 2.3 主题测试
验证UI在不同主题下的表现：

1. **配色一致性**
   - 无明显大块反色
   - 与RedClaw/llm-gateway-go风格一致
   - 菜单配色与主题匹配

2. **可读性**
   - 文字对比度
   - 元素可辨识度

3. **交互反馈**
   - hover状态
   - active状态
   - disabled状态

### 3.2 生产环境
- 服务器: 211
- 端口: 按实际部署配置

## 4. 测试工具

- **Maestro**: UI自动化测试
- **k6**: 性能和压力测试
- **自定义脚本**: 主题和截图对比

## 5. 测试执行

### 5.1 本地测试
```bash
# 启动本地服务
cd scripts/testing
./setup-local-env.sh

# 运行所有测试
./run-tests.sh

# 只运行功能测试
./run-tests.sh --maestro-only

# 只运行性能测试
./run-tests.sh --k6-only

# 只运行主题测试
./run-tests.sh --theme-only
```

### 5.2 生产环境测试
```bash
# 运行生产环境测试
./run-tests.sh --env=production --host=211
```

## 6. 测试报告

测试完成后，报告将保存在 `test-reports/` 目录：

- `maestro/`: Maestro测试结果
- `k6/`: k6性能测试结果
- `screenshots/`: 主题测试截图
- `test-summary-*.json`: 测试总结

## 7. 验收标准

### 7.1 功能测试
- ✓ 所有Maestro flows通过率 ≥ 95%
- ✓ 无P0/P1级别的功能缺陷

### 7.2 性能测试
- ✓ P95响应时间 < 2秒
- ✓ 错误率 < 1%
- ✓ 系统在100并发下稳定运行
- ✓ 流式响应无中断

### 7.3 主题测试
- ✓ 无明显大块反色区域
- ✓ 菜单配色与主题一致
- ✓ 所有交互元素在两种主题下均清晰可见

## 8. 问题跟踪

发现的问题将记录在 `test-reports/issues.md`，包含：
- 问题描述
- 严重程度
- 复现步骤
- 截图/日志
- 状态（待修复/已修复/已验证）

## 9. 测试时间表

| 阶段 | 时长 | 说明 |
|------|------|------|
| 准备 | 2小时 | 搭建测试环境和编写测试脚本 |
| 本地测试 | 4小时 | 执行本地完整测试 |
| 问题修复 | 按需 | 修复发现的问题 |

## 10. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 测试环境不稳定 | 高 | 提前验证Docker环境 |
| 性能测试影响生产 | 高 | 在非高峰时段执行 |
| 测试脚本覆盖不全 | 中 | 持续补充测试用例 |
| 主题测试主观性强 | 中 | 定义明确的验收标准 |
