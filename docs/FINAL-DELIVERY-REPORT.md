**架构设计**:
```
          请求流量
             │
             ↓
    ┌────────────────┐
    │  敏感度检测    │
    └────────┬───────┘
             │
             ↓
    ┌────────────────┐
    │  智能路由      │  
    │  90% → L1      │
    │  10% → L2      │
    └────────┬───────┘
             │
     ┌───────┴────────┐
     ↓                ↓
┌─────────┐    ┌──────────┐
│L1 Native│    │L2 Casdoor│
│秒级响应 │    │完整流程  │
└─────────┘    └─────┬────┘
                     │
                     ↓
               Webhook回调
```

**技术亮点**:
1. **Provider接口抽象** - 解耦、可测试、可扩展
2. **敏感度智能路由** - 关键词/阈值/跨部门检测
3. **Webhook v2签名** - 防重放、防篡改、密钥轮换
4. **自动降级机制** - Casdoor不可用→Native
5. **完整监控指标** - 5个Prometheus指标

**性能目标**:
- L1审批: < 5秒
- L2审批创建: < 2秒
- Webhook处理: < 1秒
- 降级率: < 1%
