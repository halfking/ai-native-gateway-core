### 1.（P1）schema 镜像三向收敛——build-image 构建门红→绿
- **发现（子代理实测 + 主会话复现）**：`verify-stats-schema-mirror.sh` rc=1（`cmp -s` 字节等价要求 sql/schema ↔ deploy baseline），`deploy/build-image.sh:56` 在 set -e 下调用它 → **镜像构建当下必败**。守卫死于两关：baseline 缺整个 566 governor 子系统（revision 列/序列/2 函数/3 触发器，47ff5d717 起从未回灌，one-click 纯 psql 形态 policy_publisher 42703 死）、baseline↔embeddata 也漂移（api_key_auto_profile_pkey 单侧缺、self_check CHECK 两版）。上轮 §四.7"窄版触发器"只是冰山一角。
- **修法**：先把角点同步进 SSOT（self_check_runs 两约束 + selection_strategy 注释，取 baseline 的 644 宽版形态——SSOT 自己反而是旧的），再三向收敛（`cp sql/schema/01-schema.sql` → baseline + embeddata）。收敛安全面逐一核过：566 全幂等且 DROP+CREATE 触发器本就是宽版、608 pg_constraint 判存、763 全守卫、805 IF NOT EXISTS 且 SSOT 不建 session_dim、无裸 CREATE TRIGGER 撞车。
