## 本机环境备忘

- `make` / `bash` **不在 PATH**；bash 用 `C:\Program Files\Git\bin\bash.exe`，且要加进 `$env:PATH`（否则 `sql/schema` 假红）。
- `Out-File -Encoding utf8NoBOM` 在 PowerShell 5.1 **不存在**（R44 踩过：写文件静默失败 → `git commit -F` 读了上一轮遗留的 `COMMIT_MESSAGE.txt`，提交信息变成了别人的）。写提交信息用 `write` 工具或 `[System.IO.File]::WriteAllText`。
- `Select-Object -First N` 提前关闭管道会把原生命令杀掉，`$LASTEXITCODE` 变成 -1 —— 那是**采集失败**，不是门红。
- 删文件走 `rm -- "<path>"`（可恢复）；`Remove-Item` 被硬安全策略拒绝。
- 无 `TEST_DATABASE_URL` ⇒ 所有真库门 SKIP；`CGO_ENABLED=0` ⇒ **`-race` 跑不了**（`go: -race requires cgo`）。
