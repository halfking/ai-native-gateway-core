## Critical Bugs Fixed

### Bug 1: Missing Quota Commit (Commit `0a3a7359a4`)

**Problem**:
- Commit `273c3478c7` added `CheckAndReserve` but forgot `CommitUsage`
- Quota was reserved but never confirmed
- Reserved quota leaked, causing incorrect quota exhaustion

**Solution**:
- Added `actuallyWrote` boolean to track new writes vs dedup hits
- Call `CommitUsage(ctx, tenant, size)` only when `actuallyWrote == true`
- Non-blocking: log warning on commit failure but don't fail the save

### Bug 2: Missing Database Migration (Commit `09e99bf5ed`)

**Problem**:
- Quota infrastructure code referenced `tenant_attachment_quotas` table
- No migration existed to create this table
- Production deployment would fail on database operations

**Solution**:
- Created migration 633 with complete schema
- Includes up and down migrations for safe rollback
- Matches exact schema expected by `quota.go` SQL queries

### Bug 3: Incomplete Anthropic Path (Commit `09e99bf5ed`)

**Problem**:
- `messages.go` was not extracting/passing tenantID to extractor
- Anthropic Claude requests would bypass quota enforcement

**Solution**:
- Extract `keyInfo.TenantID` before calling extractor
- Pass tenantID to `ExtractFromAnthropicBody()`
- Now matches OpenAI path implementation

## Deployment Checklist

### Prerequisites

1. **Apply Database Migration**:
   ```bash
   psql -d llm_gateway -f sql/migrations/startup/up/633_tenant_attachment_quotas.sql
   ```

2. **Configure Quota Limits** (via environment or config):
   ```go
   config := attachments.QuotaConfig{
       DefaultMaxBytes:       10 * 1024 * 1024 * 1024, // 10GB
       DefaultMaxFilesPerDay: 1000,
   }
   ```

3. **Enable Quota Manager** (in gateway startup):
   ```go
   quotaManager := attachments.NewQuotaManager(dbPool, config)
   storage.SetQuotaManager(quotaManager)
   ```

### Rollback Plan

If quota enforcement causes issues:

1. **Disable quota manager** (restart without SetQuotaManager call)
2. **Rollback migration** (if needed):
   ```bash
   psql -d llm_gateway -f sql/migrations/startup/down/633_tenant_attachment_quotas.sql
   ```
