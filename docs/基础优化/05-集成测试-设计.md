## 2. 测试场景

### 2.1 正常流程测试

```
用户请求
    ↓
[Content Safety - Request Check] → 检查请求内容
    ↓
[Circuit Breaker] → 检查熔断状态
    ↓
[WRR Scheduler] → 选择凭据
    ↓
[Unified Adapter] → 转换请求格式
    ↓
[模拟 LLM API 调用]
    ↓
[Unified Adapter] → 转换响应格式
    ↓
[Content Safety - Response Check] → 检查响应内容
    ↓
[Prometheus Metrics] → 记录所有指标
    ↓
返回结果
```

### 2.2 异常场景测试

| 场景 | 触发条件 | 预期行为 |
|------|---------|---------|
| **内容拦截** | 请求含 API Key | Safety 拦截，返回错误 |
| **熔断触发** | 连续失败 5 次 | Circuit 打开，快速失败 |
| **凭据耗尽** | 所有凭据不可用 | Scheduler 返回错误 |
| **转换失败** | 无效请求格式 | Adapter 返回错误 |
| **API 超时** | 模拟超时 | Circuit 记录失败 |

### 3.3 熔断器触发

```go
func TestIntegration_CircuitBreakerTrip(t *testing.T) {
    // Given: 配置低阈值熔断器
    circuit := circuit.NewCircuitBreaker(circuit.Config{
        FailureThreshold: 3,
        Timeout: time.Second,
    })
    
    // When: 连续失败 5 次
    for i := 0; i < 5; i++ {
        gateway.HandleWithFailure()
    }
    
    // Then: 熔断器打开
    assert.Equal(t, circuit.State(), circuit.StateOpen)
    
    // And: 后续请求快速失败
    start := time.Now()
    _, err := gateway.Handle(normalReq)
    duration := time.Since(start)
    
    assert.Error(t, err)
    assert.Less(t, duration, time.Millisecond) // 快速失败
    
    // And: 指标已记录
    m := metrics.Metrics()
    assert.Greater(t, m.CircuitTrips, int64(0))
}
```

### 3.4 负载均衡验证

```go
func TestIntegration_LoadBalancing(t *testing.T) {
    // Given: 3 个凭据，权重 5:1:1
    creds := []Credential{
        {ID: 1, Weight: 5},
        {ID: 2, Weight: 1},
        {ID: 3, Weight: 1},
    }
    scheduler := scheduler.NewWRRScheduler(creds)
    
    // When: 发送 700 个请求
    selections := make(map[int]int)
    for i := 0; i < 700; i++ {
        cred, _ := scheduler.Select(context.Background())
        selections[cred.ID]++
    }
    
    // Then: 分布符合权重比例 (±10%)
    assert.InDelta(t, 500, selections[1], 50)  // 5/7 * 700 = 500
    assert.InDelta(t, 100, selections[2], 10)  // 1/7 * 700 = 100
    assert.InDelta(t, 100, selections[3], 10)  // 1/7 * 700 = 100
}
```

### 3.5 适配器转换

```go
func TestIntegration_AdapterConversion(t *testing.T) {
    // Given: OpenAI 和 Anthropic 适配器
    openai := adapter.NewOpenAIAdapter()
    anthropic := adapter.NewAnthropicAdapter()
    
    // When: 统一请求转换为两种格式
    unified := &UnifiedRequest{
        Model: "gpt-4",
        Messages: []Message{
            {Role: "system", Content: "You are helpful"},
            {Role: "user", Content: "Hello"},
        },
    }
    
    openaiReq, err1 := openai.ToProviderRequest(unified)
    anthropicReq, err2 := anthropic.ToProviderRequest(unified)
    
    // Then: 都成功转换
    assert.NoError(t, err1)
    assert.NoError(t, err2)
    
    // And: OpenAI 保留 system
    assert.Equal(t, 2, len(openaiReq.Messages))
    
    // And: Anthropic 提取 system
    assert.Equal(t, 1, len(anthropicReq.Messages))
    assert.NotEmpty(t, anthropicReq.System)
}
```
