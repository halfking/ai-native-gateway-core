## 1. 背景与目标

### 1.1 背景

Phase 1 各模块需要完善的结构化日志，以便：
- 快速定位问题
- 追踪请求链路
- 性能分析
- 审计与合规

### 1.2 目标

- ✅ **结构化日志**: JSON 格式，便于解析
- ✅ **上下文传递**: TraceID/SpanID 贯穿全链路
- ✅ **分级记录**: Debug/Info/Warn/Error
- ✅ **性能友好**: 零分配或低分配
- ✅ **可配置**: 动态调整日志级别

## 4. 实施方案

### 4.1 Logger 包装器

创建统一的 Logger 接口，封装 slog：

```go
// pkg/logger/logger.go
package logger

import (
    "context"
    "log/slog"
)

// Logger 统一日志接口
type Logger interface {
    Debug(msg string, args ...any)
    Info(msg string, args ...any)
    Warn(msg string, args ...any)
    Error(msg string, args ...any)
    With(args ...any) Logger
}

// SlogLogger slog 适配器
type SlogLogger struct {
    logger *slog.Logger
}

func New(module string) Logger {
    return &SlogLogger{
        logger: slog.Default().With("module", module),
    }
}

func (l *SlogLogger) Debug(msg string, args ...any) {
    l.logger.Debug(msg, args...)
}

func (l *SlogLogger) Info(msg string, args ...any) {
    l.logger.Info(msg, args...)
}

func (l *SlogLogger) Warn(msg string, args ...any) {
    l.logger.Warn(msg, args...)
}

func (l *SlogLogger) Error(msg string, args ...any) {
    l.logger.Error(msg, args...)
}

func (l *SlogLogger) With(args ...any) Logger {
    return &SlogLogger{
        logger: l.logger.With(args...),
    }
}

// WithContext 从上下文提取 trace_id
func WithContext(ctx context.Context, module string) Logger {
    logger := slog.Default().With("module", module)
    
    if traceID := ctx.Value("trace_id"); traceID != nil {
        logger = logger.With("trace_id", traceID)
    }
    
    if spanID := ctx.Value("span_id"); spanID != nil {
        logger = logger.With("span_id", spanID)
    }
    
    return &SlogLogger{logger: logger}
}
```

```go
type ContentFilter struct {
    // ... existing fields
    logger logger.Logger
}

func (cf *ContentFilter) Check(ctx context.Context, content string) (*Result, error) {
    logger := logger.WithContext(ctx, "safety")
    
    logger.Debug("checking content",
        "content_len", len(content),
        "rules_count", len(cf.rules),
    )
    
    result := cf.applyRules(content)
    
    if result.Action == ActionBlock {
        logger.Warn("content blocked",
            "action", result.Action,
            "severity", result.Severity,
            "hits", len(result.Hits),
        )
    }
    
    return result, nil
}
```

## 5. 配置与控制

### 5.1 日志级别配置

```yaml
# config.yaml
logging:
  level: info              # debug/info/warn/error
  format: json             # json/text
  output: stdout           # stdout/file
  file:
    path: /var/log/llm-gateway/app.log
    max_size: 100          # MB
    max_backups: 10
    max_age: 30            # days
    compress: true
  
  # 模块级别覆盖
  modules:
    circuit: debug
    safety: info
    scheduler: info
    adapter: debug
    metrics: warn
```

## 6. 性能考虑

### 6.1 零分配优化

```go
// ✅ 预分配 slog.Attr
attrs := []slog.Attr{
    slog.String("module", "circuit"),
    slog.String("state", state),
}

// ✅ 避免字符串拼接
logger.Info("request failed", "error", err.Error())

// ❌ 避免格式化
logger.Info(fmt.Sprintf("request failed: %v", err))
```

### 6.2 条件日志

```go
// 仅在 Debug 级别才序列化复杂对象
if logger.Enabled(slog.LevelDebug) {
    logger.Debug("detailed state",
        "credentials", marshalCredentials(creds),
    )
}
```
