## 二、本轮新发现与落地修复（随本文档同批 commit）

### 1（P2，已修）empty_response 指标链路生产激活
四座桥都以 `MarkInterruptedWithReason` 上报「上游 200 零内容」（responses_bridge.go 的 anthropic_/openai_empty_response、stream.go 的 empty_stream_no_content/early_empty_detection），但 audit.go isInterruptionCode 白名单全数缺席 → failure_detail_code 恒缺席 → streamErrorKindForDetailCode 落兜底 stream_error 且 `llm_gateway_empty_response_attempts_total` 恒零。**修法**：白名单补 4 code（唯一调用点 audit.go:825，影响面=该族进真实失败分类+指标）+ detailCode case 补 openai_empty_response（二十轮漏的第三条串）+ 空响应族回归测试（audit_test/table 两处）。附带：删除 `RecordURSMSoftEmptyResponsePenalty` 死指标（R45 起零调用、恒零序列，与 RecordEmptyResponseAttempt 同病）。

### 2（P1，已修）`POST /api/admin/sessions/summary` 的 LLM 调用是占位桩
`callLLMForSummary` 写死 `http://localhost:8080/v1/chat/completions` + `gpt-4o-mini`、无 Authorization（生产不可达），失败静默落入 `summary[:200]` **字节**截断伪摘要（CJK 截成非法 UTF-8）——而同仓 title 走真链路 callAdminLLMChat，一真一假。**修法**：删桩；`SessionSummaryV2API` 增 llmCall 注入缝 + `Handler.SessionSummaryLLMCaller()`（session_summary work_type + auto + 显式 fallback 重试 + pickFirstAvailableAPIKey，与 title 同管线）；`summary_source: llm|fallback` 响应字段诚实标注来源（反馈闭环）；fallback 改 rune 截断；buildSummaryCorpus 同款 rune 化。instant-summary 端点（session_turns_v2.go）与 main.go 装配点同步接线。

### 3（P3 脚炮，已修）hotzone retention/maxBytes 非正删库
`GetPlatformInt` 不做 spec Min/Max 钳制（settings_kv 直写 0 可达），构造路径无校验：retention≤0 → cutoff≥now 阶段 1 删光全部文件；maxBytes≤0 → 阶段 2 的 `onDiskBytes<=maxBytes` 恒假同样删光（applyReload 的 >0 守卫只保护热重载路径）。当前缓解=hotzone 目录无写入方（潜伏）。**修法**：TrimOnce 两相 fail-safe 守卫（不清理优于误清理）+ `TestHotZoneTrimmerNonPositiveLimitsKeepFiles`。getPlatformInt 全局 spec 钳制登记不修（影响全部消费方，owner 决策）。

### 4（P3，已修）探针降级 body 绕过清洗纪律 + fbOK 残留失败文本
`responsesUnsupportedDetail` 把上游原始 body 片段（≤512B）直入 errMsg/errDetail（进 model_probe_runs 等 admin 可见面），同文件既有路径都过 truncateProbeBody（R8 P1 纪律）→ 在该单一收口补 truncateProbeBody(300)。active_probe fbOK 分支 `res.ErrMsg +=` 保留失败文本 → 对齐 node_probe/probe_http 改整体覆盖（保留降级注记叙事）。

### 5（P2，已修）降级契约接齐窗口内接口
no_topic_session（3 处）、session_task_project_api（summary/sessions/tasks/daily-costs 8 处，daily-costs 静默置空假「成本 0」一并升格）、session_title（loadTaskLogsForTitle）、session_summary_v2（writeSummaryError 统一出口）：存储不可用 → `IsStorageUnavailable` → 503 `WriteStorageDegraded`（新 component 常量 `summary`），其余维持 500。与十七轮已接齐的 tree/unified/detail 面对齐。
