## 🛠️ 修复方案与实施

### Phase 1: 紧急修复（P0）

#### 1.1 新增 Migration 432
**文件**: `sql/migrations/startup/432_fix_submit_mode_constraint.sql`

```sql
-- Drop the existing constraint
ALTER TABLE gateway.session_turns 
  DROP CONSTRAINT IF EXISTS session_turns_submit_mode_check;

-- Re-create with the additional 'attachment_only' mode
ALTER TABLE gateway.session_turns 
  ADD CONSTRAINT session_turns_submit_mode_check 
  CHECK (submit_mode IN ('full', 'delta', 'snapshot', 'inferred_compressed', 'attachment_only'));
```

**回滚脚本**: `432_fix_submit_mode_constraint.down.sql` ✅

#### 1.2 重构 SessionWriterV2.detectSubmitMode
**关键变更**:
- 删除简化版 `detectSubmitMode` 函数（258-271 行）
- 使用真正的 `SubmitModeDetector` 实例
- 增加 `getPreviousAttachments` 辅助方法
- 传递完整 `DetectionContext` 包含附件信息
- `ProcessedRequest` 增加 `SubmitModeHeader` 字段

**代码片段**:
```go
// 使用真正的检测器
detector := NewSubmitModeDetector()
previousAttachments, err := w.getPreviousAttachments(ctx, req.SessionID, req.TenantID)

submitMode := string(detector.Detect(DetectionContext{
    SubmitModeHeader:    req.SubmitModeHeader,
    ClientMessages:      req.RequestBody,
    LastOutboundBody:    req.LastOutboundBody,
    CompressionApplied:  req.CompressionApplied,
    CurrentAttachments:  req.Attachments,
    PreviousAttachments: previousAttachments,
}))
```
