## 3. 数据库性能验证

### 3.1 查询热点分析

```sql
-- 连接到 PG (假设端口 4100)
psql -h localhost -p 4100 -U llm_gateway -d llm_gateway

-- 查看最频繁的查询
SELECT 
  query,
  calls,
  mean_exec_time,
  total_exec_time
FROM pg_stat_statements
WHERE query LIKE '%credential%' OR query LIKE '%session%' OR query LIKE '%request_wal%'
ORDER BY calls DESC
LIMIT 20;

-- 查看慢查询
SELECT 
  query,
  calls,
  mean_exec_time,
  max_exec_time
FROM pg_stat_statements
WHERE mean_exec_time > 50  -- 超过 50ms
ORDER BY mean_exec_time DESC
LIMIT 10;

-- 重置统计 (验证前)
SELECT pg_stat_statements_reset();
```

### 5.2 审计 Hook 同步写入

```bash
# 监控 request_wal 写入延迟
psql -h localhost -p 4100 -U llm_gateway -d llm_gateway -c "
SELECT 
  pg_stat_get_backend_pid(s.backendid) AS pid,
  pg_stat_get_backend_activity(s.backendid) AS query,
  now() - pg_stat_get_backend_activity_start(s.backendid) AS duration
FROM pg_stat_get_backend_idset() s
WHERE pg_stat_get_backend_activity(s.backendid) LIKE '%request_wal%'
ORDER BY duration DESC;
"
```
