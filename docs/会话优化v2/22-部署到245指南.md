## 2. 快速部署命令

### 2.1 编译 + 部署

```bash
# 1. 本地编译 (macOS arm64 → Linux amd64)
make build

# 2. 上传到 245
scp -P 25022 bin/gateway root@8.136.114.245:/opt/llm-gateway/gateway-new

# 3. 备份 + 替换
ssh -p 25022 root@8.136.114.245 "
  cd /opt/llm-gateway
  cp gateway gateway.bak.\$(date +%Y%m%d-%H%M%S)
  mv gateway-new gateway
  chmod +x gateway
"

# 4. 重启服务
ssh -p 25022 root@8.136.114.245 "systemctl restart llm-gateway"

# 5. 验证启动
ssh -p 25022 root@8.136.114.245 "
  systemctl status llm-gateway
  curl -s http://localhost:8080/healthz | jq '.'
"
```
