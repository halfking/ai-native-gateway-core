### P1 — handler.go 手写 JSON envelope（不改，留档）

`domains/streaming/handler.go:298 writePrewarmedStreamErrorWithKind` 用 `fmt.Sprintf` + `%q` 手写 JSON envelope。Standards axis 标为 P1 风险：
- `%q` 是 Go 字符串 quoting，不是 JSON 兼容转义；
- 字段顺序硬编码，下一次加字段易破坏向后兼容。

**决策**：不改。理由：
1. 这是**client-visible byte contract**，spec 明确说 "7 个旧调用点零改动"；
2. `TestWritePrewarmedStreamError_BackCompat` 钉住 envelope 形状；
3. 改 `encoding/json.Marshal` 会产生微字节差异，影响线上 SDK。

如未来要重构，需要：
1. 新加 `wireFormatVersion` 字段；
2. SDK 端协商升级；
3. 灰度发布观察。
