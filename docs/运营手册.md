## 系统概览

### 架构组件

LLM Gateway 运营体系包含以下核心组件：

- **用户管理系统**：租户和用户的完整生命周期管理
- **配额管理系统**：API调用配额的分配、监控和告警
- **统计分析系统**：多维度的使用统计和成本分析
- **监控告警系统**：实时健康检查和异常告警
- **审计日志系统**：完整的操作审计轨迹

### 系统要求

- PostgreSQL 14+
- Redis 6+
- Go 1.21+
- 4GB+ RAM
- 20GB+ 磁盘空间

## 用户管理

### 用户角色

系统支持以下角色：

- **super_admin**: 超级管理员，拥有所有权限
- **admin**: 租户管理员，管理本租户内资源
- **user**: 普通用户，只能使用API服务

### 用户操作

#### 创建用户

```bash
curl -X POST http://localhost:8080/api/admin/users \
  -H "Authorization: Bearer ${ADMIN_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "newuser",
    "password": "secure_password",
    "tenant_id": "default",
    "role": "user",
    "email": "user@example.com"
  }'
```

#### 查询用户列表

```bash
curl -X GET http://localhost:8080/api/admin/users \
  -H "Authorization: Bearer ${ADMIN_TOKEN}"
```

#### 更新用户

```bash
curl -X PATCH http://localhost:8080/api/admin/users/{user_id} \
  -H "Authorization: Bearer ${ADMIN_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "role": "admin",
    "enabled": true
  }'
```

#### 删除用户

```bash
curl -X DELETE http://localhost:8080/api/admin/users/{user_id} \
  -H "Authorization: Bearer ${ADMIN_TOKEN}"
```

### 租户管理

#### 创建租户

```bash
curl -X POST http://localhost:8080/api/admin/tenants \
  -H "Authorization: Bearer ${ADMIN_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "company-a",
    "name": "Company A"
  }'
```

## 配额管理

### 配额类型

- **请求次数配额**：限制API调用次数
- **Token配额**：限制消耗的Token总量
- **成本配额**：限制产生的费用
- **并发配额**：限制同时进行的请求数

### 配额配置

#### 查看凭证配额状态

```bash
curl -X GET http://localhost:8080/api/admin/credentials/monitor \
  -H "Authorization: Bearer ${ADMIN_TOKEN}"
```

#### 更新凭证配额

```bash
curl -X PATCH http://localhost:8080/api/admin/routing/credentials/{id} \
  -H "Authorization: Bearer ${ADMIN_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "concurrency_limit": 10,
    "quota_state": "ok"
  }'
```

### 配额告警

系统会在配额使用达到以下阈值时发送告警：

- 80%：警告级别
- 90%：严重警告
- 95%：紧急告警
- 100%：配额耗尽

## 故障处理

### 常见问题

#### 数据库连接失败

**症状**：应用无法启动，日志显示数据库连接错误

**排查步骤**：
1. 检查PostgreSQL服务状态：`systemctl status postgresql`
2. 检查数据库连接配置：查看 `DATABASE_URL` 环境变量
3. 测试连接：`psql $DATABASE_URL -c "SELECT 1"`

**解决方案**：
```bash
# 重启PostgreSQL
systemctl restart postgresql

# 检查连接数
psql $DATABASE_URL -c "SELECT count(*) FROM pg_stat_activity"
```

#### Redis连接失败

**症状**：缓存功能不可用，性能下降

**排查步骤**：
1. 检查Redis服务：`systemctl status redis`
2. 测试连接：`redis-cli ping`
3. 查看连接数：`redis-cli CLIENT LIST`

**解决方案**：
```bash
# 重启Redis
systemctl restart redis

# 清理连接
redis-cli CLIENT KILL TYPE normal
```

#### 配额耗尽

**症状**：用户请求被拒绝，返回配额不足错误

**排查步骤**：
1. 查看配额状态：
```bash
curl http://localhost:8080/api/admin/credentials/monitor \
  -H "Authorization: Bearer ${ADMIN_TOKEN}"
```

2. 查看使用统计：
```bash
curl "http://localhost:8080/api/admin/stats/summary?days=1" \
  -H "Authorization: Bearer ${ADMIN_TOKEN}"
```

**解决方案**：
- 临时提升配额
- 添加新的API凭证
- 优化请求策略

#### 性能下降

**症状**：响应时间变长，吞吐量下降

**排查步骤**：
1. 检查系统资源：`top`, `free -h`, `df -h`
2. 检查数据库性能：
```bash
./scripts/diagnose-db.sh
```

3. 查看慢查询：
```sql
SELECT * FROM pg_stat_statements 
ORDER BY mean_exec_time DESC 
LIMIT 10;
```

**解决方案**：
- 优化数据库查询
- 增加缓存
- 扩展数据库连接池
- 清理历史数据

## 安全管理

### 访问控制

#### API密钥管理

```bash
# 创建API密钥
curl -X POST http://localhost:8080/api/admin/api-keys \
  -H "Authorization: Bearer ${ADMIN_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "production-key",
    "tenant_id": "default",
    "scopes": ["read", "write"]
  }'

# 撤销API密钥
curl -X DELETE http://localhost:8080/api/admin/api-keys/{key_id} \
  -H "Authorization: Bearer ${ADMIN_TOKEN}"
```

#### 密码策略

- 最小长度：8个字符
- 必须包含大小写字母、数字
- 密码过期：90天
- 密码历史：不能重复最近5个密码

### 审计日志

#### 查询审计日志

```sql
-- 查看最近的管理操作
SELECT * FROM routing_audit_log 
ORDER BY created_at DESC 
LIMIT 100;

-- 查询特定用户的操作
SELECT * FROM routing_audit_log 
WHERE actor = 'admin@example.com' 
ORDER BY created_at DESC;

-- 查询特定类型的操作
SELECT * FROM routing_audit_log 
WHERE action = 'user_create' 
ORDER BY created_at DESC;
```

### 敏感数据保护

#### 凭证加密

所有API密钥和凭证都使用AES-256-GCM加密存储。

#### 日志脱敏

系统自动脱敏以下敏感信息：
- API密钥
- 密码
- 邮箱地址
- 电话号码

### 合规性

#### GDPR合规

```bash
# 导出用户数据
curl -X GET "http://localhost:8080/api/admin/users/{user_id}/export" \
  -H "Authorization: Bearer ${ADMIN_TOKEN}"

# 删除用户数据
curl -X DELETE "http://localhost:8080/api/admin/users/{user_id}/gdpr-delete" \
  -H "Authorization: Bearer ${ADMIN_TOKEN}"
```
