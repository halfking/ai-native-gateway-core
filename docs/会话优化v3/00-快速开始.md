## ⚠️ 常见问题

### Q1: 后端任务之间有冲突怎么办？

**A**: 使用独立分支：
```bash
git checkout -b feature/v3-task-be-a1  # 会话 A
git checkout -b feature/v3-task-be-a2  # 会话 B
git checkout -b feature/v3-task-be-a3  # 会话 C
```

完成后逐个合并到主分支。

### Q2: 前端依赖后端 API 但后端未完成怎么办？

**A**: 使用 Mock 数据先开发 UI：
```typescript
// src/api/__mocks__/queue.ts
export const mockQueueSnapshot: QueueSnapshot = {
  timestamp: new Date().toISOString(),
  total_queue: { depth: 12, waiting_ms_p50: 50, waiting_ms_p95: 120 },
  model_queues: [
    { model: 'claude-sonnet-4', depth: 5, waiting_ms_avg: 45 },
  ],
  node_queues: [],
};
```

### Q3: 测试失败怎么办？

**A**: 按优先级修复：
1. 单元测试失败 → 立即修复（代码逻辑错误）
2. 集成测试失败 → 检查依赖（数据库迁移是否执行？）
3. E2E 测试失败 → 检查环境（端口冲突？权限不足？）

### Q4: 性能不达标怎么办？

**A**: 按瓶颈优化：
1. 队列指标收集慢 → 降低采样频率
2. 子请求查询慢 → 添加更多索引
3. 前端渲染卡顿 → 启用虚拟滚动
