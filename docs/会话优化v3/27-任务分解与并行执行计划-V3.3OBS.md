## 3. 风险与回退
- 动作事件量：有界队列 + 丢弃计数，SSE 聚合批量发送（≤500ms tick）。
- SSE 兼容：新事件类型 optional，旧前端忽略；`sourceVersion` 字段做版本协商。
- 性能门禁：1000 卡片 ≥30FPS；发射器旁路化，热路径零同步 IO。
