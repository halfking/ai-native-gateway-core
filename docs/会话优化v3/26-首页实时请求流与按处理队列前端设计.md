# 26 — 首页实时请求流与按处理队列前端设计（V3.3-OBS）

> 状态：CURRENT（设计稿，2026-08-15）
> 上游：23/24/25 号。本文冻结首页信息架构、组件改造清单与交互。

## 1. 首页信息架构（现状 → 目标）

现状（`DashboardViewV2.vue`）：四个 tab——看板（board）/ 实时请求流（stream）/ 会话与统计（stats）/ 自检（selfcheck）。

目标调整：
1. **实时请求流 tab** 内部增加二级视图切换：「按请求」（现状泳道）与「按处理队列」（新）。
2. **按处理队列**视图 = 队列透视（QueuePerspectivePanel 升级）+ 节点面板（可操作）+ 请求动作流。
3. **自检 tab** 按 25 号 §6.2 规则重排（大小形态、右侧进入、三态队列）。
4. **会话与统计 tab** 增加在线会话 → 轮次 → 扩展请求树下钻。

## 2. 按处理队列视图（核心新视图）

布局（自上而下）：

```
┌────────────────────────────────────────────────────────┐
│ 队列总览条：pipeline 深度/等待p50p95/in-flight + 降级标记  │
├──────────────┬─────────────────────────────────────────┤
│ 模型队列列表   │  请求动作流（时间线，右侧进入）              │
│  - model/auto │   [小形态卡片×N，按 request_id 聚合]       │
│  - depth/wait │   动作徽标：路由/选节点/切节点/回复/重试⭐   │
├──────────────┴─────────────────────────────────────────┤
│ 节点队列/节点面板（每节点一行）                              │
│  状态徽标组 · in-flight · 最近延迟 · 最近错误                │
│  [测试] [强制启用] [手工禁用▼: 手工/清除熔断/重置错误]        │
└────────────────────────────────────────────────────────┘
```

要点：
- **管道两端解耦**：请求卡左端显示客户端侧（协议、原始模型、会话），右端显示当前上游节点（凭据、供应商、转发模型）；auto 切换模型时右端标签变化，左端不变。
- 请求卡小形态：`stage` 徽标 + 最新动作 + 目标节点；点击展开大形态（完整动作时间线，含 retry 特别标与 node_switch 轨迹）。
- 节点行点击「测试」→ `POST /api/admin/providers/{id}/test-now`，结果以行内 toast + 小形态 probe 卡进入动作流。
- 「手工禁用」下拉里明确区分：手工禁用（需人工恢复）/ 系统降级说明（显示预计自动恢复时间，不可手工点掉，只能强制启用）。
- 禁用/启用操作后节点行立即以 `node_update` 事件刷新，无需整页刷新。

### 数据源
- 队列与节点：`queue_snapshot` + `node_update`（liveStreamStore 已有 `queueRef`/`nodesRef`）。
- 动作流：新增 `request_lifecycle` 事件 + `llmgw:live:actions` 回放（24 号 §4）。

## 3. 实时请求流「按请求」视图（现状增强）

- `LiveRequestStreamV2.vue` 泳道保持；卡片增加 `stage` 与 `retrySeq` 角标。
- 主从请求（R4）：卡片右上角子请求计数徽标（title/summary/sensitive_word），点击弹出子请求列表（复用 child_request 事件 + request_logs_hot.parent_request_id 查询兜底）。

## 4. 自检 tab（R8）

- 三段式：待请求（pending）/ 正在请求（in_flight）/ 已完成（completed，保留最近 N 条，从右侧进入旧数据左移）。
- pending 卡（小形态）：目标节点、模型、origin（scheduled/error/manual）、预计执行时间。
- in_flight 卡：实时耗时。
- completed 卡（大形态可展开）：结果、延迟、错误码、观察时间；失败卡显示下一跳退避时间（智能回退，25 号 §6.1）。
- 数据：`probeStreamStore.ts`（SSE `/api/admin/probe/stream`）+ `bg/probe_queue.go` 三态查询 API。

## 5. 会话与统计 tab（R5）

- 在线会话列表（Redis 索引，`admin/session_online.go`）：会话键、用户/项目、轮次数、健康度、最近活动。
- 会话详情：轮次时间线（`SessionTurnsPanel`/`SessionTurnDrawer` 升级）——每轮显示主请求卡 + 内联子请求树（title/summary/sensitive_word，parent_request_id 关联）。
- 空态/权限态沿用现有组件规范（Skeleton/Empty/ErrorBanner）。
