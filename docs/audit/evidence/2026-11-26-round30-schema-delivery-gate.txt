§7 边界（判据库的包注释里有同样的清单）
------------------------------------------------------------------------------------------------
  · 定义只认 CREATE TABLE (…) 与 ALTER TABLE … ADD [COLUMN]（含一条语句连做几个动作）、改名（只增不删）、
    分区（子表继承母表的列）；不认 DROP COLUMN ⇒ 「引用一个已被通道删掉的列」不报。
  · 动态 SQL（format/EXECUTE 里的表名列名）、运行时按路径读的 SQL 看不见。
  · 视图只记名字；已投递来源建成的视图，它的列不判。
  · 绑定靠词法不是语法树：多表语句里的裸列、别名声明在另一个字面量里的限定名 ⇒ 漏报（测试里标了「漏报」）。
  · ④⑤（代码自带 DDL、go:embed）只证明「二进制里有这段 SQL」，不证明每条启动路径都会执行它。
  · 认可投递位是显式目录清单（sql/schema、installer/migrations）；新开一种会被执行的目录要回来登记。
  · 生产面 ＝ 非 _test.go、且不在 tests/ 与 scripts/ 下。
