## 五、通用式（本轮沉淀）

1. **「列面在迁移文件里」≠「列面在生产库」**——canonical 视图被 890 重写过，`created_at→ts` 这种列改名只有对着**生产 information_schema** 才能定案；源码自洽的 SQL 也会在真库 42703。
2. **共享工作树的并行车是「活的」**——接活前先 `git log -1` 看 HEAD 是否刚变过；本轮亲眼见到 MERGE_HEAD 被对方提交、981 被重写。冲突的最优解常是**放弃自己的半成品、继承对方更完整的解**（我的三处豁免登记被他们的「重写+进通道+接刷新器」整体取代）。
3. **台账 sha 比文件快一步是常态**——正本重写后第一件事就是跑 `TestRegistryShaIsActuallyTheFile` 对账。
4. **npx vitest ≠ 项目 vitest**——npx 落到 `.npm` 缓存里的裸 vitest 没有 vue 插件 ⇒ 全部 .vue 测试假红；必须走 `npm test`（项目 node_modules）。
5. **i18n 键的「值里再带标签」是双前缀雷**——`internalCostDesc` 值含「内部成本：」而模板又拼 `<strong>内部成本：</strong>` ⇒ 用户看到两遍；标签与描述分离，标签独立键。
6. **「不知道」和「零」要分家**——窗口聚合不可用出 `—` 不出 0；`window_usage` 用 omitempty/nil 区分「没算」与「算出来是零」。
