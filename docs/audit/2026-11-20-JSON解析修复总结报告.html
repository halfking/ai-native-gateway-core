🔍 根因分析

问题现象

211网关日志中频繁出现JSON解析错误：

cannot unmarshal number into Go struct field .error.code of type string

频率：12次/12小时

影响：错误响应无法正确解析，客户端无法获得详细的错误信息

根本原因

位置：internal/ir/stream.go:264

原因：错误结构体的 Code 字段定义为 string 类型，但部分供应商返回数字（如 400）

供应商行为 返回格式 原实现 结果
返回字符串 {"error":{"code":"400"}} Code string ✅ 成功
返回数字 {"error":{"code":400}} Code string ❌ 失败

🛠️ 修复方案

技术方案

创建 FlexibleString 类型，通过自定义 UnmarshalJSON 方法同时支持字符串和数字：

type FlexibleString string func (fs *FlexibleString) UnmarshalJSON(data []byte) error { // 第一形态：字符串（供应商返回 "code": "400"） var s string if err := json.Unmarshal(data, &s); err == nil { *fs = FlexibleString(s) return nil } // 第二形态：数字（供应商返回 "code": 400） // json.Number 覆盖整型与浮点型 var n json.Number if err := json.Unmarshal(data, &n); err == nil { *fs = FlexibleString(n.String()) return nil } return fmt.Errorf("cannot unmarshal %s into FlexibleString", data) }
