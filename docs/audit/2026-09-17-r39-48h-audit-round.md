## 二、核实为健康的关键面（本轮留档，下轮不再重复怀疑）

- **mDNS 特性安全基线**：默认关闭全链路（env-only + 全部署面 grep 无置 true 点）；绑定失败仅 Error 日志降级不 crash；Stop 幂等 + double-close 安全（mu 全程持有）；TXT 仅 version/api/proto 三键无凭据；DiscoverGateways 通道无 send-on-closed panic（vendored 库非阻塞发送 + query 循环调用方同步返回）；vendored 依赖精确收敛 mdns+dns+传递（许可证齐备，x/tools 仅经 dns 的 tools.go 桩进入，运行时零编译）。
- **settle worker 合成轮过滤（93f530901）**：单一事实源定义 7 消费点零字面量复写；3 条统计 SQL 全覆盖；origin_actor 与统计列同 INSERT 原子落库无中间态；双实例幂等（settled_at IS NULL + PK ON CONFLICT）；合成行 reward=NULL 被下游 rollup 过滤封死训练面回灌；集成测试真 PG 行为级断言。
- **087/迁移通道**：跳过方向 fail-closed（存在性检查失败→启动失败不误跳）；087 账本只在表在位时登记；lite/sqlite 零牵连；716/718/719 五点同步逐字节一致 + 三漂移方向守卫在位；719 ensure 复活根治模式正确（创建者删除同 commit）。
- **探测修复健康面（D09 报告亲读确认）**：404 终态只作用 (cred,model) 绑定面；恢复闭环三通道（probe_ 前缀复验权/双路径节奏一致/真实流量 write-through）；applyOutcome 四层守卫链（本轮补上第 4 层队列熔断）；decrypt sweep 任意实例可安全代清；单一事实源切换面广，残留仅 probe_missing 一处（本轮已修）。
- **154 金丝雀模板闭环（0a015af51）**：角色集合↔worker 启动要求逐个对账闭合（traffic-only 例外为有意设计）；drift-repair 自动重装通道使模板修复下次部署自动生效；生产已实切验证（incident §5）。
- **deploy-local 修复面**：set -e 形状全部 if 化 + `-buildvcs=false` 全 4 位点；gate 默认 warn-only 语义与 `|| true` 形状保持。
