# 2026-11-19 销售看板图表可视化优化

## 需求
优化销售工作台（SalesWorkbenchView）的管理层看板，将文本列表改为图表可视化展示，提升数据洞察的直观性。

## 实施内容

### 1. 新增图表生成器模块
**文件**：`web/src/utils/salesChartOptions.ts`（新建）

实现四个图表生成函数：
- `createFunnelChartOption`：销售漏斗图（draft → won/lost）
- `createMarginPieOption`：毛利分布饼图
- `createLostReasonsBarOption`：丢单原因横向条形图
- `createTriggerDimensionsBarOption`：触发维度横向条形图

**设计特点**：
- 统一配色方案（漏斗：蓝→绿渐变；毛利：金色系；丢单/触发：语义色）
- 响应式设计（grid.containLabel）
- i18n 国际化支持
- 数据为空时的优雅降级

### 2. 视图层改造
**文件**：`web/src/views/operations/SalesWorkbenchView.vue`

**改动点**：
- 导入 ECharts 和图表生成器
- 添加 4 个计算属性生成图表配置
- 重构看板模板：
  - 销售漏斗独立区块（400px 高度）
  - 三卡片网格（触发率、丢单原因、毛利分布）
  - 移除旧的文本列表布局
- 更新样式：图表容器、指标卡片、响应式网格

### 3. 国际化文本补充
**文件**：`web/src/locales/*.json`（8 个语言文件）

新增翻译键：
- `sales.dashboardFunnel`：销售漏斗
- `sales.funnelStageWon`：赢单
- `sales.funnelStageLost`：丢单
- `sales.marginDistribution`：毛利分布
- `sales.lostReasonsChart`：丢单原因
- `sales.triggerDimensions`：触发维度

**语言覆盖**：zh-CN, en-US, ja-JP, ko-KR, zh-TW, de-DE, fr-FR, ru-RU
