### 3. 差异根因分析

#### 3.1 看板与供应商对账的数据源差异
**看板 (usage_facts)**:
- 数据源: 请求级事实表
- 统计口径: 终态请求(成功/失败/限流)
- 时间范围: 11/17 00:00 → 当前时刻
- 实际数据: 75,975 请求 / $8,631.54

**供应商对账 (report_snapshots)**:
- 数据源: 快照汇总表
- 统计口径: 按供应商聚合
- 时间范围: 11/17-11/23 (完整日期)
- 实际数据: 123,108 请求 / $11,450.96

#### 3.2 关键差异点

**请求数差异 (75,975 vs 123,108)**:
- 差值: 47,133 请求 (62% 更多)
- 可能原因:
  1. report_snapshots 包含了更多的请求状态
  2. 时间窗口定义不同（完整日 vs 零点到当前时刻）
  3. 聚合逻辑不同（可能包含重试/重复计数）

**费用差异 ($8,631.54 vs $11,450.96)**:
- 差值: $2,819.42 (33% 更多)
- 可能原因:
  1. report_snapshots 的 estimated_cost_cents 计算方式不同
  2. 包含了 usage_facts 中未记录的费用项
  3. 价格快照(price_snapshot)与实际计费有差异

#### 3.3 供应商对账页面数据异常
**数据库 vs 页面显示**:
- 页面显示: 144,958 请求 / $6,306.16
- 数据库实际: 123,108 请求 / $11,450.96
- **结论**: 页面查询逻辑可能有误，或使用了不同的筛选条件

## 附录：数据库查询记录

### A.1 usage_facts 查询
```sql
-- 近7天业务流量
SELECT 
  traffic_class,
  COUNT(*) as request_count,
  SUM(cost_amount) as total_cost
FROM usage_facts 
WHERE occurred_at >= '2026-11-17 00:00:00+08'::timestamptz
  AND occurred_at < NOW()
GROUP BY traffic_class;
```

### A.2 report_snapshots 查询
```sql
-- 按scope统计
SELECT 
  scope,
  COUNT(*) as record_count,
  SUM(request_count) as total_requests,
  SUM(estimated_cost_cents)/100.0 as total_cost_usd
FROM report_snapshots 
WHERE report_date >= CURRENT_DATE - INTERVAL '7 days'
  AND report_date <= CURRENT_DATE
GROUP BY scope
ORDER BY scope;
```

### A.3 供应商详细统计
```sql
-- 供应商维度详细数据
SELECT 
  rs.scope_key as provider_id,
  p.code as provider_code,
  p.display_name,
  SUM(rs.request_count) as total_requests,
  SUM(rs.success_count) as success_count,
  SUM(rs.error_count) as error_count,
  SUM(rs.estimated_cost_cents)/100.0 as total_cost_usd,
  ROUND(100.0 * SUM(rs.error_count) / NULLIF(SUM(rs.request_count), 0), 2) as error_rate_pct
FROM report_snapshots rs
LEFT JOIN providers p ON rs.scope_key = p.id::text
WHERE rs.report_date >= CURRENT_DATE - INTERVAL '7 days'
  AND rs.report_date <= CURRENT_DATE
  AND rs.scope = 'daily_by_provider'
GROUP BY rs.scope_key, p.code, p.display_name
ORDER BY total_requests DESC;
```
