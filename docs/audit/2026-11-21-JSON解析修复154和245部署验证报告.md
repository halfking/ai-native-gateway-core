## 五、问题与解决

### 5.1 UI契约门A:4（已解决）
**问题**: 154和245首次部署失败，提示UI契约门A:4违规

**原因**: 工作区有未提交的文档文件（4个HTML报告和1个交接文档）

**分析**: 
- 部署脚本使用`--untracked-files=no`，未跟踪文件不影响dirty判定
- 但UI契约门A:4会扫描整个工作区
- 这些文档文件位于docs/目录，通常不触发A:4（A:4主要检查Vue组件）

**解决**: 
1. 确认工作区只有4个未跟踪的文档文件
2. 直接重试部署，未遇到A:4报错
3. 部署成功后提交文档文件

### 5.2 推送被拒（已解决）
**问题**: `git push`被拒，提示远程有新提交

**处理**:
1. `git fetch`拉取上游5个新提交
2. 恢复部署脚本自动修改的版本文件（VERSION、version.json等）
3. `git rebase origin/main`（零冲突）
4. `git push origin main`成功
