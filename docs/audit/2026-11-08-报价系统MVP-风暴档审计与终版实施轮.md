## §0 结论（先说三条）

**结论一：《风暴档》的判据骨架全部成立，但「链路通了但没人走」的预言以字面方式应验了——
且链条上有一个 W1 交付时就存在的 P1：前端建单链路必 23514。**
8 张 sales 表在 211 真库全部 0 行（2026-11-08 活体读数）；前端建单 payload 不带
`confidence`/`cost_currency` ⇒ 版本置信 `''` 违反 945 CHECK ⇒ `CreateQuote` 必失败
（真库测试全部显式传 `Confidence:"trusted"` ⇒ 测试全绿掩盖了唯一真实用户路径）。
第一张真单（W0 上线门）会在第一次点击就撞墙。根修 = **服务端派生**：行成本/币种/置信档
一律从供给视图取，客户端声明不采信（C3 门从「客户端断言」变「服务端事实」）。

**结论二：审计另钉出 4 个 P2 + 一批 P3，全部收口。** P2 = ①公开面「限速」注释声称但实现为零；
②owner 语义文件头虚标（报价动作零所有权判定，`RevokeShare` 甚至**没有任何 API 面**——
「可撤销」只有服务半边）；③联系人最小化两条未落（供应商联系人/客户邮箱随 h.admin 全量下发）；
④五价坐标系快照恒 `'{}'`。P3 = 双提交竞态（不查 RowsAffected）、负数输入可造 >100% 毛利、
`quoted` 死值、过期探测污染埋点、审计行 `('','')` 稀释状态机、死代码、944 注释与 schema 矛盾。

**结论三：W2-T2（管理层看板 + 成本漂移 + PDF 兜底）+ 客户版页面本轮交付；W2-T1（940 同步器）
显式不落地**——它要读 salesdecorate 库（跨仓数据源），owner 未授权跨仓读面，登记为独立前置裁决
（风暴档 §8 待裁决族的第 9 条）。本轮实施的东西全部单库（llm_gateway）内闭环。

## §4 W2-T2 + 客户版交付清单

**后端**（`sales/dashboard.go` 新文件 + quote.go/service.go 扩展 + admin 接线）：
- `GET /api/admin/sales/dashboard`（super-only）：漏斗四数（含 **expired 派生态现算**——944 CHECK 闭集故意不含 expired 的既有裁决不被破坏）+ DealHub 突破率（status_log 面统计：`submitted = pending∨approved` 去重单数、`triggered = pending` 去重单数）+ trigger_reasons jsonb 逐维聚合 + 丢单原因（CloseQuote 强制回填）+ 毛利分桶。全部现算零新表。
- 成本漂移（风暴档 §3.4「成本漂移提醒」MVP 形态 = 提醒不自动撤）：`attachCostDrift` 只对活单（draft/pending/approved/sent）计算；口径 = 与派生**同一确定性选行**（同 `fetchSupplyViewRows` + `withholdNames`——抽出共用，两处永不漂移）；行级漂移 `max(|Δ|/old)`，旧价 0↔有 ⇒ 100%；币种变了跳过（拒绝假装可比）；won/lost 不漂（无收件人）。
- `SellableList.tier_coefficients` 下发（前端快填用）。

**前端**：
- 工作台第 4 页签「看板」（super-only 渲染）：漏斗 + 三卡 + 触发率告警条 + **实收侧「待激活」诚实标注**。
- 报价单清单：漂移徽标（`cost_drifted` ⇒ 「成本已漂移，建议重报」tag）。
- **建单弹窗化 + 模型选择器**（P1 形状修正）：行从可售清单选（手填 canonical 已不可能过服务端校验），成本列只读展示派生参考价，销售只填量/零售价/折扣——风暴档 §3.1「预填率目标 ≤5 次点击」的落地；三档快填按钮（系数 × 成本，settings 驱动）。

- 分享弹层：撤销按钮；`versionsQuoteId` 一名两用拆为 `sharesQuoteId`（前端审计 P3）。

**客户版页面**（`/public/quote/:token`，public 路由）：
