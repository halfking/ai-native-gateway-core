- **B（会话/排行族）**= 请求命中率：`count(cached_tokens>0)/count(*)`（`request_session_overview.go:58`、`request_session_rankings.go:41`）。

## 7. 仍读旧源的读点（非聚合报表的保留面，共 ~60 处 `request_logs_with_current_month` + v1 usage 全族）

**按用途分四类（迁移判据：这四类不是「统计聚合读面」，按交接决策按各自原始证据保留）**：
1. **明细/内容面**（标题、追踪、SSE、会话树、导出、泳道、画像列表）——读的是内容行不是聚合，投影表没有这些列。
2. **运维/诊断面**（凭据监控、路由诊断、拓扑、数据生命周期）——短窗口实时读，语义是「当前状态」不是「统计」。
3. **计费/预算面**（`usage_ledger_*`：key 累计花费、预算校验、供应商对账明细、租户 totals）——按交接决策「结算按数据各自的原始证据核对」。
4. **v1 端点保留面**（`/api/usage/*` 旧族、v1 看板 fallback、v1 report-rollup）——前端 V2 已全部切走（V2 审计 §2 十组对拍），端点退役是 owner 决策。

## 9. 时区与半开窗统一度

- **半开窗**：全部 V2 聚合读面统一 `occurred_at >= start AND < end`（`query.go:95-99` 共享构造器 + 各读点内联一致）✔
- **时区**：日桶/日聚合全部传参时区（`date_trunc(..., $tz)` / `AT TIME ZONE $tz`）；投影行 `occurred_date` 按 **UTC 日历日**折叠（本轮夹具钉住）——本地日视图由读侧 `AT TIME ZONE` 完成，两层语义清晰 ✔
- **去重**：投影键 `(request_id, occurred_at)` + 版本三元组 `(revision, finalized_at, fact_id)` upsert；跨租户同号按 (tenant, request) 各一行（夹具钉住）✔
- **遗留偏差（登记，不属本轮改动）**：v1 `BuildRangeReport` 的 `report_date` 是闭区间（`report.go:568-596`），与 V2 半开语义不同——v1 退役时消失，不单独修。
