## 二、口径与杠杆

计数口径是「**注释剥离后**的 CJK 连续段数」，落在 `src/**/*.{vue,ts,tsx,js,mjs}`，
排除 `src/locales/**`、`src/i18n/**`、`*.test|spec`。

量到的三件事决定了打法：

1. **计数的主体在模板侧**：50 个文件的 2364 段里，模板侧 1974、脚本侧 390。
2. **词频不是杠杆**：最高频的 44 个词加起来才 878 段；把词换成 key 并不省事。
3. **杠杆在「单一真值源」**：同一批词（模型 28 处 / 凭据 21 处 / 状态 23 处…）
   散在几十个视图里各写一份中文。**新增一个 `common.terms` 组，一个 key 解锁几十个调用点。**

⇒ 先建 `common.terms`（107 key，8 语种同步），再按 key 扫整串字面量。

## 三、`common.terms` 为什么是这个形状

- **不新增顶层扁平 key**：zh-CN `common.ts` 已有 `button` / `status` / `feedback` /
  `table` / `pagination` / `search` / `unit` / `error` / `theme` / `dateRange` 等**嵌套组**，
  再堆扁平 key 会与 `status` / `error` 这类组名撞车（后者会**整体覆盖前者**）。
  嵌套 `terms` 组零冲突。
- **不重复造既有 key**：已存在的直接复用 —— `common.credentialFallback`（凭据）、
  `common.unit.credits`（积分）、`common.status.success/failed/disabled/enabled`、
  `common.feedback.loading/noData`、`common.pagination.previous/next`、
  `common.button.apply/ok/edit/delete/cancel/confirm/refresh` 等。
- **8 语种键集合逐字一致**（107 = 107），由 `localeKeyParity` 门强制。

## 四、扫替换的三条硬规则（都是被实测打出来的）

### 规则 1：值比较位一律不动

`=== '可用'` 这种是**数据值**不是展示文案。换成 `$t('…')` 会把「比较字符串」
变成「比较译文」⇒ 逻辑**静默失效**（不报错，只是样式不再生效）。

⇒ 扫描器在比较右侧、下标/属性访问、对象字面量的**数据类字段**
（`value/key/id/type/name/code/mode/status/level/...`）前一律跳过。

**实测落点**：`NodeDetailDrawer.vue` 的 `headlineState === '可用' ? 'ready' : headlineState`。
这不是「躲过去」就完了 —— 它本来就是个**设计缺陷**（拿展示文案做逻辑），
所以顺手把 `useNodeDetailDrawerLoad.ts` 的 `headlineState` 改成**稳定 code**
（`available` / `manual_disabled` / `circuit_open` / `unreachable` / `recovering` / `unknown`），
展示文案另走 `headlineStateLabel`。
**行为逐字不变**：`statusClass()` 的白名单里本来就有 `available` ⇒ 仍是 `is-ok`；
其余五个 code 不在白名单 ⇒ 仍是 `is-bad`（与原来传中文时一致）。

### 规则 2：普通属性**不做插值**

⚠️ **实测打脸**：第一版扫描器把 `title="模型"` 改成 `title="$t('…')"`。
用 `@vue/compiler-dom` 3.5.43 编译：

```js
compile('<div title="$t(\'common.close\')">hi</div>', { mode: 'module' })
// ⇒ { title: "$t('common.close')" }   ← **静态字符串**，不是表达式
```

Vue 3 的普通属性不做插值 ⇒ tooltip / placeholder 会把 `$t('common.close')`
**这串字面量直接显示给用户**。
⇒ 改用绑定形式 `:title="$t('…')"`；改完全仓 `[^:]"$t(` 命中 **0**。

### 规则 3：文本节点只换「整串是一个词」的情况

`附加参数（可选）` 若只把「可选」换成 key，会变成「附加参数（Optional）」——
**半吊子混排**。⇒ 只有**整段就是一个可映射词**才换；
带「装饰前缀」（` · ` / `↻ ` / `:`，且不含中文）时，剥掉装饰、只翻中间那个词。

## 五、三次量具失败（都是读数错，不是行为错）

| # | 现象 | 真因 | 修法 |
|---|---|---|---|
| 1 | 插值内出现**嵌套花括号**，vue-tsc 报 49 个错（TS1161 Unterminated regular expression literal） | 扫描器把 `{{ }}` **内部**的中文字面量当文本节点换成了 `{{ $t(…) }}` | 按上下文分三种处理：文本节点 / 属性值 / **插值表达式**（表达式里换的是 `$t(…)` 不是 `{{ $t(…) }}`） |
| 2 | 同样 49 个错，换了上下文后仍在 | 插值替换区间算成整个 `{{ … }}`，把收尾的 `}}` 一起吞了 | 区间只覆盖**表达式本体**，`{{` 与 `}}` 原样保留 |
| 3 | 计数降到 5132，但 tooltip 会显示 `$t('…')` 字面量 | 普通属性不做插值（见规则 2） | 改绑定形式；用 `@vue/compiler-dom` 实测对拍 |

⇒ **通用式**：自动化改模板时，「编译通过」不等于「渲染正确」。
Vue 3 的普通属性静默变成静态字符串，**不报错、不红**，
只有拿编译器实跑一次编译输出才看得见。

| `common.close` vs `common.terms.off` | 「关闭」有**两种**语义：关闭对话框 / 开关关掉 | 23 处关闭按钮 → `common.close`；1 处开关 → `terms.off` | 一词两义，必须拆 |

## 七、第四道坎：挂载测试要装 i18n 插件

组件模板里用 `$t('…')` 取文案时，**挂载出来的 app 必须装 i18n 插件**，
否则渲染期抛 `TypeError: _ctx.$t is not a function`。
⇒ 全量 vitest 第一次跑出 **48 红 / 11 个测试文件**。

处置：

- 新增 `web/src/test-utils/i18n.ts`：导出 `testI18n`
  （`createI18n({ legacy:false, globalInjection:true, locale:'zh-CN', messages:{ 'zh-CN': zhCN } })`）。
  **注入真实 zh-CN 文案而不是空 messages** —— 空 messages 时 `$t('common.terms.model')`
  返回的是**键路径**，任何「界面上应当出现中文」的断言都会失配
  （而结构性的断言照样过 ⇒ 半绿不绿，最难查）。
- **逐文件补**，不挂全局 setup：VTU 的 `mergeGlobalProperties` 是**拼接**
  （`plugins: [...configGlobal.plugins, ...mountGlobal.plugins]`）
  ⇒ 全局 setup 会让**自带 i18n 的测试**变成双安装；
  而 vue-i18n 的 `install` 遇到已安装实例只 warn 不覆盖
  ⇒ 那批测试会拿到**全局那个** i18n，而不是它自己声明的 locale。
- `NodeDetailConcurrencyPanel.test.ts` 自带一个
  `createI18n({ messages: { 'zh-CN': {} } })`（空文案），
  它装在后面 ⇒ **覆盖**注入的那个 ⇒ 按钮文本变成键路径 ⇒ 断言失配。
  该测试断言的全是中文（`toContain('调整并发与槽位')`），所以正解是**去掉那个空实例**，
  统一用 `testI18n`。

## 八、遗留（诚实边界）

- **非中文语种下仍有混排**：50 个文件里还剩 ~900 段中文没翻（长尾：整句提示、
  一文件一用的业务词）。本轮按「整串 + 通用词」推进，**没有把 8 语言做到全一致**；
  `common.terms` 已把后续收口所需的**单一真值源**建好。
- **中文用户零变化**：`common.terms.*` 的 zh-CN 取值就是原来的中文 ⇒
  中文界面的观感与改动前逐字相同；收益在其它 7 个语种（从「整页中文」变成「部分已译」）。
- **`recovering` 仍是 `is-bad`**：「恢复中」原本传的是中文串 ⇒ `statusClass` 落到
  `is-bad`。本轮**刻意保持行为不变**（不夹带视觉改动），但它语义上更像 `is-warn` ——
  这是下一轮的候选。
