## 三、发现并根修的缺陷（6 个，全部生产实证）

| # | 缺陷 | 证据 | 修复（提交） |
|---|---|---|---|
| F1(P0) | **V2 开关一开必 boot panic**：stdlib `http.ServeMux` 同路径重复注册 panic；旧注释声称「后注册者获胜」是错误认知（R1.12 引入以来从未真实 boot 过） | SIGQUIT 栈：panic 在途→defer 展开 | v1 四端点裸注册收进 `if !v2DispatchEnabled`；订正注释（3bd889d52） |
| F2(P0) | **panic 冻结成僵尸进程**：`v2ShutdownPipeline` 调 `Publisher.Close()` 把**共享主 pool** 关掉→puddle Close 等在途连接→死锁→监听从未绑定、systemd 不拉起 | 栈转储 puddle WaitGroup.Wait；`PGPublisher.Close→pool.Close` | 不再调 Publisher.Close（所有权归 dbConn）+ AnalysisSQLDBs 有界关闭（3bd889d52） |
| F3(P1) | **governance_prompt_injection 对真实流量恒不可达**：管线按注册序执行；provider_discovery 挂内存 demo 凭据仓对真实模型恒失败回落 v1；security.check 对注入载荷阶段错误先行中断 | 逐请求日志：注入载荷停在 security、良性请求停在 provider_discovery，检测表恒空 | PI 阶段前移到 security 之前（e0a136cda+6761fba1b 两步） |
| F4(P1) | **检测审计写侧形状分歧**：245/154 活表带 315 四列（两列 NOT NULL），canonical INSERT 每条被拒「null value in column detection_score」；既有正典门对带四列的库直接 SKIP（只测自己前提成立的库） | journal error 原文 + information_schema 取证 | boot 期探测列集→双形状 INSERT（362ad7c7c） |

## 五、Maestro 实测

- **08-admin-data-ops：exit=0，106 步全绿**（含登录与全页断言）。
- 03-07：各深行 13-23 步（登录已过、列表页断言过）后卡**详情页断言**；取证（截图+服务端日志）：详情 XHR `/api/providers/2` 等全部 **401 authentication required**、翻页后 `/api/auth/me` 401——**会话 cookie 在 Maestro Chrome 里不持久**（fetch 登录当页 200、翻页即丢；真实浏览器同操作全程 200——我方 IAB 实证）。
- 登录链三轮根修（详见 login.yaml 头注）：①口令含 `&` 时 Maestro 键入/插值管道吞片段（request_bytes 63/67 漂移 vs 正确 68 ⇒ 401「password does not match users table」）；②v-model 与提交竞态；③本版 Maestro 的 evalScript 不做 `${}` 插值。终版混合式：inputText 键入（DOM 值完整）+ evalScript 从**字段读值** fetch `/api/auth/token`（README §6.3 正解，不依赖 v-model/Enter/插值）。
- **登记不修（量具环境缺陷，非产品缺陷）**：Maestro Chrome 会话 cookie 不留存 ⇒ 依赖详情页 XHR 的断言在 03-07 不可达；建议后续用 `maestro/tools/seed-session.mjs`（CDP 预置会话）或给 Maestro Chrome 显式 profile。
- 附带发现（并行车变更，登记）：`/` 已被营销落地页接管 ⇒ 旧「登录后仪表盘」断言过期（已在 login.yaml 移除该断言）。

## 七、遗留登记

1. **L1**：V2 管线 provider_discovery 的 demo 凭据仓 vs 真实候选面——管线要真承接路由需 DB 背书 ProviderStore（独立轮）。
2. **L2**：wrapper 对 preflight 错误一律回落 v1 ⇒ security.check 的 block 实际不拦（fail-open by design）；enforce 语义启用前需裁决「显式 block verdict 是否豁免回落」。
3. **L3**：Maestro Chrome cookie 环境缺陷（§五）。
4. **L4**：分析器 q9 的 JSON 解析成功率（glm-5.3-flash 偶发非 JSON）——可换结构化输出更强的模型或加固提示词。
