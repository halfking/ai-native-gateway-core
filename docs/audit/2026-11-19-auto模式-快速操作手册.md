## 🆘 应急处理

### 场景1: 成功率突然下降

**症状**: 成功率 < 95%

**排查步骤**:
```bash
# 1. 查看最近失败的请求
ssh 211 "docker logs --since 1h llm-gateway-211-b | grep 'auto.*fail' | tail -20"

# 2. 检查是否是特定模型的问题
# 如果是，可以临时禁用该模型

# 3. 如果问题严重，临时关闭换模开关
curl -X PUT http://llm.itestu.cn:8783/api/admin/settings \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -d '{"key": "dispatch_v2.allow_model_change", "value": false}'
```

### 场景2: 容器状态异常

**症状**: 容器不健康或重启

**排查步骤**:
```bash
# 1. 检查容器状态
ssh 211 "docker ps -a | grep llm-gateway-211"

# 2. 查看容器日志
ssh 211 "docker logs --tail 100 llm-gateway-211-b"

# 3. 如需重启
ssh 211 "docker restart llm-gateway-211-b"
```
