## 4. ★★ 判据自身修过的 8 个坑（都是自证 / 真仓抓到的）

| # | 坑 | 症状 | 修法 |
|---|---|---|---|
| 1 | `border(?:-[a-z]+)?` 把 `border-radius` 当描边 | 假阳性 | 描边只认 `border` / `border-top/right/bottom/left` |
| 2 | 顶层逗号切分切不动 `color-mix(in srgb, …)` | 纯内阴影被误判成抬升 | 括号深度感知切分 |
| 3 | 首个 `0` 无 `px` ⇒ blur 解析错位 | 误判 V9 | 偏移量单位可选 |
| 4 | `isColoredValue` 不认 `color-mix()`，且把 `transparent` 当中性 | 漏判一大片彩色 | 口径改成「**不是中性**」（中性令牌是封闭小表） |
| 5 | ★ **V3 第 1 版只认单行 `class="…"`** | 跨行 / `:class` 动态绑定漏判 | 重写成标签扫描器（写法全覆盖） |
| 6 | ★ **V3 第 2 版只认 class 名含 icon/glyph/symbol/emoji** | `btn-icon` / `check-mark` / `refresh-btn` 全在门外 | 位置信号扩到「按钮位 **或** class 含图标语义词」 |
| 7 | ★ **V3 第 3 版排除了插值** | `ThemeToggle` 的 `☾/☼` 整族漏判 | 插值里的**字面量**纳入判据 |
| 8 | ★ **门报的行号指向开标签** | 78 条里 20 条按行号找不到字形 | 改为指向**问题字符本身** |

★ **形态四的判据分层**（位置信号 / 形状信号 / 例外）：

```
位置 = 元素是 button|a  ‖  class 名按 -/_ 切词后整词命中「图标语义词」
形状 = 非 ASCII ∧ 非 CJK ∧ 非纯排印字符（— – · … ▍）
例外 = 流程箭头（→ ← ↔ ↕ ⇄ …）在**非按钮位**不判（流程连线不是图标系统）
```

★ **自证 45/45**（第 1 版 37 例；新增 S20a~S20h 覆盖跨行 / `:class` / 按钮位 / 排印占位 / 流程箭头 / 徽标星 / 插值）。
