```
GET    /api/admin/users              - 获取用户列表

DELETE /api/admin/users/{id}         - 删除用户
```

**数据表**:
- `users` - 用户基础信息
- `tenants` - 租户信息
- `routing_audit_log` - 用户操作审计

**测试覆盖**:

### 1.2 配额管理系统 ✅

**实现位置**: `admin/credential_monitor.go`, `admin/credential_status.go`

**核心功能**:
- ✅ 凭证配额监控
- ✅ 配额状态跟踪（ok, balance_exhausted, permanently_exhausted等）
- ✅ 并发限制管理（concurrency_limit）
- ✅ 配额告警机制

**配额类型**:

- 周期性配额（periodic quota）
- 并发配额（concurrency quota）

**API端点**:
```
GET    /api/admin/credentials/monitor     - 监控所有凭证状态
```

**数据表**:
- `credentials` - 凭证信息及配额字段
- `routing_candidate_bindings` - 绑定关系
- `credential_probe_events` - 配额检查事件

**实现位置**: `admin/stats.go`, `admin/stats_shadow.go`, `admin/tenant_stats_rollup.go`

**核心功能**:

- ✅ 实时统计和历史统计
- ✅ 趋势分析

- 请求量统计（总数、成功、失败）

- 延迟统计（平均、P50、P95、P99）
- 成本统计（按供应商、按模型）
- 错误统计（按类型、按来源）

**API端点**:
```
GET /api/admin/stats/summary          - 统计摘要
GET /api/admin/stats/trend            - 趋势数据
GET /api/admin/stats/monthly          - 月度报表
GET /api/admin/stats/breakdown        - 详细分解
```

**数据表**:

### 1.5 审计日志系统 ✅

**实现位置**: `admin/handler.go` (auditLog方法)

**核心功能**:
- ✅ 完整的操作审计
- ✅ 用户操作追踪
- ✅ 变更记录保存
- ✅ JSON格式存储详情

**审计事件类型**:
- 用户管理（user_create, user_update, user_delete）
- 凭证管理（credential_create, credential_update）
- 配置变更（config_update, route_update）
- 权限变更（permission_grant, permission_revoke）

**数据表**:
```sql
CREATE TABLE routing_audit_log (
    id SERIAL PRIMARY KEY,
    actor TEXT NOT NULL,           -- 操作者
    action TEXT NOT NULL,          -- 操作类型
    target_type TEXT NOT NULL,     -- 目标类型
    target_id INTEGER,             -- 目标ID
    after_json JSONB,              -- 变更详情
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```

**查询接口**:
```sql
-- 查看用户操作历史
SELECT * FROM routing_audit_log WHERE actor = 'admin' ORDER BY created_at DESC;

-- 查看特定资源的变更历史
SELECT * FROM routing_audit_log WHERE target_type = 'user' AND target_id = 123;
```
