## 2. 设计裁决（为什么这样做）

- **原生 Fullscreen API 而非 CSS 覆盖层**：element-plus 的 popper/overlay 挂在 `body` 下、不进任何自制 CSS 全屏层 ⇒ z-index 竞赛不可赢；原生 API 退出即恢复原布局，无事件穿透清理负担。ESC/系统手势退出免费获得。
- **按钮位置＝顶栏过滤栏右端**（「清空过滤」旁，同族样式同尺寸 24px 高）：顶栏是三栏整体的一部分，全屏后按钮仍可见可点（退出入口必须在全屏层内）。
- **`is-fullscreen` 类 + `:fullscreen` 伪类双轨**：`:fullscreen` 由 UA 匹配；`is-fullscreen` 类给未来布局微调留 CSS 挂点（当前只需补全屏层背景色防黑边）。
- **zh-TW 措辞**：'進入全螢幕/離開全螢幕' ≠ zh-CN 原文 —— i18n 值质量棘轮（same-as-source 只许降）的已知陷阱，首次运行抓到后改译收口，**未调基线**。
