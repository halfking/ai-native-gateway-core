## §五 主修复：模型建议列表（`model alternatives`）的结果缓存

### 病灶证据链

1. **错误榜首**：`canceling statement due to user request` × **2,230**/24h，
   语句 = `WITH policy AS … routing_policy … v_routable_credential_models …`
   （`domains/streaming/model_alternatives.go` 的 `alternativesSQL`），
   全天平坦分布、会话族⇒与负载无关。
2. **R148 的 ctx 守卫之后仍在涨**：10-26 修的「ctx 已死即返回」只挡**进来前
   已断开**的调用；本窗 2,230 次是**跑进查询后超 800ms 预算被杀**的形态。
   R148 时代三天 1,399 次 ≈ 466/天 ⇒ 本窗 2,230/天，**且 10-28 凌晨孤儿
   grep 时代冲到 ~137/h（10-27 干净日间 ~6/h）**⇒ 负载放大 ~20×，但干净窗
   仍有底数（内在成分）。
3. **内在成本实测**：干净负载（load 19）`EXPLAIN (ANALYZE, BUFFERS)` 全查询
   **1,273ms**——大头在 `routable` CTE：`v_routable_credential_models` 视图
   枚举 31,349 个凭据×模型对，只为收敛出 51 个可路由 canonical 模型；
   pgss 全量口径 mean **411ms** / max **1,734ms** ⇒ **均值与极值横跨 800ms
   同步预算两侧** ⇒ 预算命中即取消。
4. **用户可见后果**：这条查询在「零候选 503」失败路径上给客户端送「换个模型
   试试」的建议列表——2,230 次/天被杀 ⇒ **建议列表实际上从未送达**（预算内
   偶然完成的少数除外）。查询白烧 ~30min DB 时间/天且产出为零。

### 修法（`domains/streaming/model_alternatives.go`，全部照仓内既有先例）

按 **(tenant, taskType)** 键的结果缓存，三件套：

1. **TTL 2min + serve-stale-while-revalidate**：新鲜期内直接命中；过期条目
   继续服务（建议列表是「换个模型试试」的场景，2 分钟陈旧无感——数据源都是
   分钟级慢变量：可路由集=探针状态、featured=运营编辑、热度=7 天流量）。
2. **singleflight 后台重算**（`beginCompute` 抢权）：后台 goroutine 用与请求
   解耦的 ctx（`Background` + **5s 预算**——容得下 1.27s 内在成本，重算真正
   算完进缓存）；重算权每键同时只一个，竞争者拿 stale 即走。
3. **冷未命中保留一次 800ms 同步尝试**（维持既有失败路径延迟契约），失败
   才转后台。缓存空列表且新鲜是**有意义的答案**（当前无路由可达），照答
   不重算。请求级排除（别把自己建议给自己）从 SQL `$1` 排除改为 **Go 侧
   `filterAlternatives` 收口**（缓存存全量列表，按请求过滤+截断）。

**读数预期**：每个 (tenant, taskType) 键每 TTL 至多一次真算（失败驱动、
singleflight 合并）⇒ DB 侧从「2,230 次×0.8s 白烧」变为「≤720 次×1.3s 全部
有效」，**建议列表开始真正送达**；gateway 日志的 Warn 噪音同步消失。

### 验证

- 7 个新单测（缓存命中不重查 / TTL 过期服务 stale 且后台恰好重算一次 /
  singleflight 去重 / 新鲜空列表不重算 / 冷未命中失败转后台补缓存 /
  过滤与截断 / 死上下文守卫保持）——**race 检测器当场抓到一处真数据竞争**
  （`lookup` 返回活条目指针、调用方在锁外读字段，与后台 `store` 并发写；
  改为锁内返回快照）。
- **变异臂 5/5 全检出**（摘缓存查找 / 摘死 ctx 守卫 / TTL 失效 /
  singleflight 失效 / 服务路径摘过滤），还原后基线绿、md5 逐字一致。
- 预算接线断言：同步路径 ctx 必须带 ~800ms 预算、后台必须带 ~5s（测试内
  断言 `ctx.Deadline()`）——这是实现中曾真实漏掉的一处（首版把裸 ctx 传给
  同步路径），被测试骨架逼出来后补上。
- `go build ./...` ✓ / `go vet` ✓ / `domains/streaming` 全包 `-race` PASS

## §十一 量具坑（本轮新增 4 条）

1. **race 检测器是并发缓存的验收门**：`lookup` 返回活条目指针、调用方在锁外
   读字段——单测全绿、race 一跑就红。受锁保护的方法**只准返回值快照**，
   不准返回内部容器的指针。
2. **`sync.Once` 惰性初始化不得无条件覆盖已注入的缝**：`ensureCache` 首版把
   测试注入的缓存（假时钟）替换成默认实例 ⇒ TTL 测试静默失效。Once 的
   正确形态是「nil 才补默认」。
3. **252 podman 帧时间戳是 +08:00 CST 不是 UTC**（§四）——切片/窗口字面量
   直接用 CST，勿想当然换算。
4. **ssh 命令的内层双引号会被剥**（§四）⇒ SQL 一律文件通道；zsh
   `====WORD====` 展开坑第三次复发（§四）⇒ 分隔串改 `'----'`。
