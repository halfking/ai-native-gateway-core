```go
// ExtractPassiveFeatures 从真实会话提取特征
func ExtractPassiveFeatures(ctx context.Context, chunks []StreamChunk, usage Usage, metadata Metadata) (*PassiveFeatures, error)
```

**提取的特征**：

#### **Token 签名（25%权重）**

- ✅ Completion Token 计数

#### **内容特征（15%权重）**
- ✅ 格式特征位标（###, **, list, code）
- ✅ 词汇频率（可选）

---

### 2. **被动判定逻辑**

```go
// EvaluatePassive 执行被动判定
func EvaluatePassive(observed *PassiveFeatures, baseline *PassiveFingerprint) PassiveVerdict
```

**判定流程**：
1. ITT 分布 JSD 对比（JSD >0.40 → 异常）
2. TTFT 偏差检测（偏差 >40% → 异常）
3. Throughput 偏差检测（偏差 >50% → 异常）
4. 综合打分 + 置信度（基于样本量）

---

### 3. **JSD 计算核心**

```go
// ComputeJSD 计算 Jensen-Shannon Divergence
func ComputeJSD(p, q map[string]float64) float64
```

**特点**：
- 对称的概率分布差异度量
- 范围 [0, 1] bit
- 用于 ITT 分布对比
