**A-17 双币制细则（裁决一的操作化，六条）**：

1. **区域原生存币**：海外平台的市场价以 **USD** 记，国内平台以 **CNY** 记。判定依据是**平台的标价/结算币种**，不是厂商国籍（例：`deepseek` 是国内厂商但官网另有 USD 页 ⇒ 以注册表裁定为准，notes 登记边缘案例）。
2. **区域裁定唯一权威 = 网关侧 `market_platform_registry`**（§3.2）；同步器遇到未登记平台 ⇒ 拒绝族 `platform_unmapped_region`，**不允许**按名字猜测。
3. **双地板分开记账**：海外地板（USD 原生）与国内地板（CNY 原生）各记各的（各自的最低价、来源平台、独立平台数）；旧 `market_min_*` 列语义升级为「综合地板」（双地板折算后的最低），保 941 视图与既有消费者不破。
4. **同区比较零 FX**：评分优先在绑定与参照**同币种**时原生比较；跨区比较必须用**落库快照 `fx_rate`**（禁止运行时汇率），并记录 `fx_used` 可审计。
5. **展示三级**：运营面（价格对比分析等）「原币 + CNY + USD」三列齐示；客户面（价目表）CNY 为主 + 原币括注。
6. **计费不双币**：本裁决只作用于市场行情层；零售价（`model_credit_rates`/`model_price_versions`）、账单、钱包维持单一锚点（A-14）。

## 3. 双币市场价设计（裁决一的操作化 · 本稿核心）

### 3.1 六原则

见 §1 A-17 六条。补充一条工程红线：**「折算过的数」不能替代「原币的数」**——所有折算列只是派生视图，原币列是事实源；任何消费者不得只存折算值。

### 3.2 平台注册表 `market_platform_registry`（迁移 957）

```sql
CREATE TABLE public.market_platform_registry (
    platform_id     text PRIMARY KEY,             -- 与 salesdecorate platform 标识一致（'openai'/'bailian'/…）
    platform_name   text NOT NULL DEFAULT '',
    region          text NOT NULL,                -- 'overseas' | 'domestic'
    native_currency text NOT NULL,                -- 'USD' | 'CNY'（与 region 联动）
    is_ours         boolean NOT NULL DEFAULT false,-- ★ A-5：C2 地板计算时排除我方平台
    enabled         boolean NOT NULL DEFAULT true,
    notes           text NOT NULL DEFAULT '',     -- 边缘案例登记（如 deepseek 双币页）
    updated_at      timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT market_platform_registry_region_chk CHECK (region IN ('overseas','domestic')),
    CONSTRAINT market_platform_registry_currency_chk CHECK (native_currency IN ('USD','CNY')),
    CONSTRAINT market_platform_registry_pair_chk
        CHECK ((region='overseas' AND native_currency='USD')
            OR (region='domestic' AND native_currency='CNY'))
);
-- 平台表（superAdmin 管理面），无租户数据 ⇒ 不加 RLS；种子 ON CONFLICT DO NOTHING。
```

### 3.4 评分口径（C1/C2/C3 在双币下）

| 分 | 口径 | 双币规则 |
|---|---|---|
| **C1 采购折扣率** | `1 − supplier_blended / vendor_list_blended` | 绑定币种 == 厂商原生币 ⇒ **原币直除（零 FX）**；不同 ⇒ 厂商价按行快照折到绑定币种，`fx_used` 记录；NULL（无原厂价）≠ 0（等于原厂价）纪律不变 |
| **C2 市场位势** | `floor_blended / supplier_blended` | **双读数**：`vs_overseas`（海外地板 USD 折到绑定币）、`vs_domestic`（国内地板 CNY 折到绑定币）；**主列 = 绑定同区地板**（USD 绑定→海外地板、CNY 绑定→国内地板，原生比较零 FX），`market_ref_used` 记录用的是哪个；两地板各自带 `platform_count`（≥3 才可作判据，<3 降级参考——两地板**分别**适用此规则） |
| **C3 价格置信度** | trusted/suspect_symmetric/empty/unknown_currency 四档门 | 不变；`unknown_currency` 继续沿用「拒绝，不默认 USD」红线 |
| **MarketAdvantage（路由）** | `100 × clamp(1 − supplier/market_ref, 0, 1)` | `market_ref` = 绑定同区地板（与 C2 主列同源）；同区地板缺失（count=0 或未映射）⇒ 用综合地板折算；再无 ⇒ **无信号即中性（0）** |

### 3.5 展示口径

| 面 | 口径 |
|---|---|
| 运营面（/operations/price-compare、/operations/market-prices、compare 脚本 CSV） | **三级**：原币（按行 `vendor_list_currency`/地板原生币）+ CNY + USD；地板双列（海外/国内）并列，各自标注平台数 |
| 客户面（价目表「市场公开价区间」） | **CNY 为主 + 原币括注**（客户人民币结算；不给三列造成噪音） |
| 汇率标注 | 任何折算列展示必须伴随快照 `fx_rate` 与 `source_run_date`（「观测时点」纪律） |

### 3.6 同步器双币规则（`cmd/tools/sync-market-reference/`，G3）

- **必填参数不默认**：`-source-dsn`、`-run-date`、`-fx-rate`（当日锚，落库即快照）、`-out`（提案 CSV）。
- 流程：拉 `platform`（经 registry 校验/过滤）→ 每平台最新观测（`dimension='标准按量' × unit='per_1M_tokens'`）→ P1（`is_vendor` 且厂商一致，原生币）→ P2a 海外地板（`region='overseas' AND NOT is_ours` 取最低 + 平台数）→ P2b 国内地板（`region='domestic' AND NOT is_ours`）→ 综合地板（折算后最低）→ 归一 canonical（含 `canonical_id` 解析）→ 冲突整组 withhold。
- **拒绝族（9 个，逐条具名，禁止静默跳过）**：`model_alias_unresolved` / `no_vendor_price` / `conditional_price` / `conflict_same_canonical` / `currency_unknown` / `stale_source` / `canonical_unresolved`（底稿 AF-8） / ★`platform_unmapped_region`（不在 registry） / ★`fx_missing`（无可折算依据）。
- **三步法不变**：只出提案 CSV → 人审 diff → 走 `pricingImport` 形状导入通道；**禁止**一键写权威面。

### 3.7 与计费层的边界（防误解）

市场价双币 **≠** 计费双币：`maas_settings.cents_per_credit`（CNY 分/积分）单一锚点不变；`model_credit_rates`（积分现行价）/`model_price_versions`（版本史）不动；`billing_orders`/`maas_monthly_bills` 维持 CNY 记账。USD 在计费侧只作**观测口径**（毛利分析，经 `CNYToUSDFX`）。
