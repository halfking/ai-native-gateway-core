# runs/ —— 每轮子代理报告原文

每轮审计建一个子目录：`R<N>-<YYYY-MM-DD>/`，内放该轮全部域子代理的完整报告原文：

```
runs/
└── R34-2026-09-XX/
    ├── agent-D01-ir-lifecycle.md
    ├── agent-D07-hot-columnar.md
    └── ...
```

- 文件名：`agent-DXX-<slug>.md`，与派发的域文档一一对应。
- 报告结构见 `../conventions.md` §4。
- 原文留档的意义：主代理复核后的轮文档是"结论"，这里保留"线索全量"，供下轮追溯与复核差异。
- 未派发的域不建文件；轮 README 不需要，轮文档头部已有激活域清单。
