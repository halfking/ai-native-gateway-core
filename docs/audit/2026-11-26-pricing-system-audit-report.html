🚨关键断层识别

🔴 P0级 - 成本→积分桥接缺失
现象: session_turns.cost_usd (USD) 和 credit_ledger.amount (积分) 之间没有转换代码
影响: 无法追溯"某笔请求扣了多少积分"与"实际成本"的对应关系
理论公式: 
credits = (input_tokens * credits_per_1m_in + 
         output_tokens * credits_per_1m_out) / 1,000,000
实际状态: 代码路径未找到，request_logs.credits_charged 字段存在但无写入逻辑
🔴 P0级 - 缓存Token口径识别缺失
现象: CalcCost函数支持OpenAI/Anthropic两种口径，但生产侧永远传零值
实测影响:
  • 1,628行 Anthropic流量记成负成本
  • 4.5M cache token 在账上≈免费（占比96.2%）
  • 成本报表里这些行显示为NULL（算不出来）
根因: usage.go:509 注释明确 "生产侧没有任何调用方设置Convention参数"
修法位置: domains/streaming/handler.go:8050 的 AssignRequestCost 调用点
🔴 P0级 - Admin配置界面缺失
现象: 三层价格体系无统一管理界面
现状:
  • 基准价: 手工维护Python脚本 vendor_pricing_table.py
  • 供应商价: 直接操作数据库？
  • 租户零售价: 未找到配置入口
风险: 价格数据权威性依赖人工、易漂移、826迁移明确指出定时刷新cron已失效
