## §2 形态判定：怎么读、怎么被改

`dl_detect_resources()`（`scripts/deploy-local-lib.sh:416`）三级：

| Tier | 条件 | 结果 |
|---|---|---|
| **1 · 调用方配置** | `LLM_GATEWAY_DATABASE_URL` 非空 | ⇒ `DL_DB_MODE=external`，**Tier 2 被跳过** |
| **2 · 宿主服务** | `DL_DB_MODE == none` 且宿主 `psql` 探活成功 | ⇒ `DL_DB_MODE=host` |
| **3 · docker 容器** | **`DL_DB_MODE == none \|\| DL_REDIS_MODE == none`**（`:459`） | ⇒ **`DL_DOCKER=1`** + 找到容器则 `DL_DB_MODE=docker` |

⇒ ⇒ ★★★★★ **⇒ Tier 3 的守卫是 OR ⇒ 外部 DSN 把 `DB_MODE` 变成 `external` 后，只有 `REDIS_MODE` 也非 none 才会彻底关掉 docker 路径。**
⇒ ⇒ ★★★ **⇒ 我传了外部 DSN ⇒ `DB_MODE=external`；Redis 又被宿主探测认领 ⇒ `REDIS_MODE=host` ⇒ ⇒ ⇒ **两条路都断了 ⇒ `DL_DOCKER=0`。**

**Tier 2 为什么本该落空**：宿主 PG 探测（`:369`）用

```bash
psql -X -v ON_ERROR_STOP=1 -Atqc 'SELECT 1' -h 127.0.0.1 -p "$port" -U "$user" -d postgres
```

★ `user` 取自 `LLM_GATEWAY_PG_USER` → `PGUSER` → **`$USER`**（宿主用户名，容器里没有这个角色）⇒ ★★ **⇒ 探测必然失败** ⇒ ★★ **⇒ 只要【不传外部 DSN】，Tier 2 自然落空、`DB_MODE` 保持 none ⇒ Tier 3 进得来。**

⇒ ★★ **⇒ 这也解释了「上一次（2794）为什么是容器形态」**：那次**没有传外部 DSN** ⇒ 走的就是这条 docker 路径。

## §4 三条可复用的判据

1. ★★★★★ **「readiness gate failed」只说明「探针看到的版本不对」，它**不**说明「新版本起不来」。**
   ⇒ ★★ **判别动作：★ 同时读「`/version` 返回的版本」与「期望的 bundle 版本」—— 若前者是**旧**版本 ⇒ 是「没切过去」（本例：旧容器一直占着端口）；若两者一致却仍红 ⇒ 才是新版本自身的问题。**
2. ★★★★ **「部署形态」是编译期属性，不是运行期开关。**
   ⇒ ★★ `bin/` 下每个 release 只有**一个** `gateway` ⇒ 容器（Linux ELF）与宿主（macOS Mach-O）**互斥**；`bin/current` 是全局软链 ⇒ 切到另一形态的产物 ⇒ 另一形态的实例必然起不来。
3. ★★★★ **升级既有实例前，先确认「既有形态」与「本次编译目标平台」一致。**
   ⇒ ★★ 判别动作：`scripts/deploy-local.sh status` 会打印 `docker=… database=… redis=…` ⇒ ★★ **⇒ 那一行就是「本次会编译成什么平台」的决定性读数。**
4. ★★★★★ **（R72f 新增）★ 「页慢」的判定口径必须与「页慢」的定义**不同量纲**。**
   ⇒ ★★ `page-sweep-cdp.mjs` 的 `idleMs` =「等到网络静默 N ms」⇒ ★★ **实测 `idleMs ≈ idle-ms + 250~280ms`** ⇒ ⇒ ★★★ **⇒ 与 2000ms 阈值同量纲 ⇒ ⇒ ⇒ 「慢页」这个判定会被尺子自己触发 ⇒ ⇒ ⇒ 判「页慢」必须同时看**服务端耗时**（`slowApiMs`）与**是否不可复现**。**
5. ★★★★★ **（R72f 新增）★ 量具读数出现「单点异常」时，先问「有没有同源的并发客户端在污染它」。**
   ⇒ ★★ 本机 Chrome 与巡检的 headless Chrome **UA 同族**（`Chrome/155.0.0.0` on macOS）⇒ ⇒ ★★★ **⇒ 按 UA 分不出「我的页面」与「别人的页面」** ⇒ ⇒ ⇒ **判别动作：把并发变量去掉后**复现一次**——复现不了 ⇒ 就是污染（不是被测对象变慢）。**

★ ⇒ ★★★ **⇒ 附一条顺带订正**：★ **8781 不是「空端口 / 可供别人用」，它是部署机制里的 **cutover 候选槽**（`deploy-local.sh:1664-1669`：active=8782 ⇒ candidate=8781）** ⇒ ⇒ **⇒ 部署期间 8781 上必然有实例，这是设计，不是占用。**
