# 审计 — 探活成功触发独立可信度扫描（B 方案，2026-11-02）

## 目标

探活成功时**一起触发**指纹/可信度检查，但三者保持独立任务；有效、准确、低成本；**不浪费**探活预算。

## 设计

| 原则 | 落地 |
|---|---|
| 独立任务 | 可信度另发标定请求（`ScanNode`），**不复用**探活 HTTP 体 |
| 一起触发 | `node_probe` success → `NotifyProbeSuccess`（异步） |
| 低成本 | ① 成功后 30 天停泊 ⇒ 触发本身稀少；② cooldown 6h（verified）；③ featured 面；④ inflight 去重 |
| 准确 | suspected/diluted/unknown 用短冷却 1h 复测；四维判定仍走 `modelcredibility` |
| 防浪费 | **禁止**挂 `MarkNodeProbeHealthy`（业务成功高频） |

## 设置

| Key | 默认 | 含义 |
|---|---|---|
| `model_credibility.trigger_on_probe_success` | true | 总闸（与定时 `enabled` 独立） |
| `model_credibility.probe_success_cooldown_hours` | 6 | verified 冷却 |
| `model_credibility.probe_success_recheck_hours` | 1 | 异常/unknown 短冷却 |

定时扫描仍由 `model_credibility.enabled` 控制；可「关定时、只靠探活触发」。

## 代码
