### 2. F15 —— sessions 三列写入方 + 730 索引处置

**写入方（七处布线，全链）**：

| 层 | 文件 | 内容 |
|---|------|------|
| 采集 | domains/streaming/request_context.go | `gwAgentAttributionFromRequest`：X-Gw-Agent-Role 声明 > X-Gw-Source-Actor 推断（与 auto 路由判定同源）；新增 X-Gw-Parent-Session-Id 头（730 列注释点名的来源，声明式提示同信任级）；父任务复用 X-Gw-Task-Id |

| 持久 | session_aggregator.go upsertSessionSnapshot | INSERT 三列 + 冲突臂（见下） |
| 重放 | session_aggregate_outbox_reaper.go | outbox 编解码补三字段 |

**真库演练抓到自置 P1**：VALUES 臂空值归一 `COALESCE(NULLIF($20,''),'main')`
使 EXCLUDED.agent_role 恒非空，冲突臂 `COALESCE(NULLIF(EXCLUDED...))` 把
重放轮的归一默认 'main' 当真实值覆盖首写 'worker'（本地 PG17 演练实捕：
重放后 agent_role=main，pgxmock 雉形测试全绿——语义类缺陷字符串/pgxmock
测不出，真库三件套②的价值实证）。修正为**默认可精化**语义：
`CASE WHEN sessions.agent_role='main' THEN EXCLUDED.agent_role ELSE sessions.agent_role END`
——'main'（未归因默认）允许后续轮声明精化；任何已固化角色不被默认值降级。
修正后演练闭环：worker 首值固化不降级、父列 COALESCE 保持、计数累加、
ROLLBACK 零残留。parent 双列 `NULLIF($,'')` 归一保住部分索引 NULL 谓词语义。

**730 两条分区父表索引 —— 结构性豁免（F1 先例）**：真库实证
（information_schema + pg_index + pg_inherits）：两条索引已存在且 valid
（父表 ONLY 壳 + 全部 5 个月分分子索引自动派生、未来分区自动继承），
289,471 行的构建已在 730 应用时发生。735 重建唯一可行路径是
DROP+三段式重建同一结构——零收益、纯风险（重建窗口 + 消耗迁移号）；
PG17 对分区父表本就不支持 CREATE INDEX CONCURRENTLY（728 文件头同款 42809），
无法"补做三段式"。F15 的实际风险（SHARE 锁写停顿）属升级时点风险，
已随 730 应用关闭；索引随本轮写入方上线从"空索引预支成本"转为在用。
**728 模板（三段式）仍是未来大表加索引的标准**，登记不变。
