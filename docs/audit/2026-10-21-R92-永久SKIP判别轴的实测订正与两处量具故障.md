## §3 ★★★ 本轮自己踩的两处量具故障

### §3.1 故障 ①：`pg_dump --schema-only` 的输出**每次都不一样** ⇒ `pg_dump | md5` **不是**结构指纹

**实测**：同一个库**连取 3 次**：

| 次 | md5 | byte 数 |
|---|---|---|
| 1 | `40a18e98aff0d2f203c48a2a864be537` | 1,877,355 |
| 2 | `c07e16b6a649f28b8683fc1291e742da` | 1,877,355 |
| 3 | `6818ac02967ecf60aeaa0c547543b50e` | 1,877,355 |

⇒ `diff` 只有 **8 行** ⇒ 全部是**一对随机 token**：

```
< \restrict Ipq1eqKT62ExMfiYA2hrNjHfSf7cRKniOemhaHGmpIrTXVrAJeTYXAScgdLM9Vv
> \restrict 3JLvcrIF4DqJqFV7Dl1zTvVmQr0CwA3CaULsLgcYnt4KVzqFq1UX7j6sh4lVeCu
```

⇒ **PG 17.6+ 给每次 dump 加一对随机 `\restrict` / `\unrestrict`（防注入）** ⇒ ⇒ **`pg_dump | md5` 天然不可复现**。

⇒ ⇒ ⚠ **第一版量具据此报出「✗ 形态库有变化」** ⇒ ⚠ **那是个假读数** ——
若不复核就写进结论，会**凭空指控一道门破坏了生产形态库**。

⇒ ⇒ ★★ **仓里早就知道这个坑**：`scripts/_lib/db-init-lib.sh` 的 `db_init::dump_schema`
明确写着「strips pg_dump header noise (\restrict, version banner)」并逐行剥离：

```bash
  if s.startswith('\\restrict') or s.startswith('\\unrestrict'); then continue
```

⇒ ⇒ ⇒ **通用式：用 `pg_dump` 产物做指纹前，先看仓里现成的剥离逻辑** ——
本仓的现成答案就在 `db-init-lib.sh` 里，不必自己发明。

⇒ ⇒ ★ **R88 那次「零损伤」不受影响**：它用的是 **SQL 级 md5**（不是 `pg_dump`）⇒ 本轮已核。

### §3.2 故障 ②：`pg_class.relkind` 的类型是 `"char"` ⇒ 拼接报错 ⇒ **空输出看起来像「0 个对象」**

```sql
-- ✗ 报 operator does not exist: character || unknown
SELECT md5(string_agg(c.relname||':'||c.relkind, ',' ORDER BY c.relname)) …;
-- ✓
SELECT md5(string_agg(c.relname||':'||c.relkind::text, ',' ORDER BY c.relname)) …;
```

⇒ ⚠ 若 psql 的 stderr 被 `2>/dev/null` 吞掉，**stdout 就是空** ⇒ ⇒ **空输出看起来像「0 个对象」**。

⇒ ⇒ ★★ **这是 R63 轮已经记在案的同一个坑**（`relkind` 拼接歧义 ＋ 静默吞错）⇒ ⇒ **本轮第二次踩到**
⇒ ⇒ ⇒ **通用式：踩过第二次的坑，说明它没有被机制化挡住** ⇒ ⇒
本轮处置 = **把修法写进量具脚本本身**（`c.relkind::text` ＋ **指纹确定性自检**：连取 2 次必须逐字一致，否则**直接中止，不进入读数阶段**）。

### §3.3 ⇒ 两类「假读数」的共同形态

| 形态 | 表现 | 为什么危险 |
|---|---|---|
| **读到了别的东西** | `pg_dump` 的随机 token ⇒ 看起来是「库变了」 | **它看起来有值** |
| **读失败了但看起来像「值为空」** | `relkind` 拼接报错被吞 ⇒ 看起来是「0 个对象」 | **它看起来是 0** |

⇒ ⇒ ⇒ **两种都不会自己暴露** ⇒ ⇒ ⇒ **必须有一道「量具自检」在读数之前**
（本轮脚本里就有：连取 2 次指纹不一致 ⇒ 直接中止）。

## §6 通用式（本轮沉淀）

1. ⭐⭐⭐⭐⭐ **判「一道门跑不跑」必须先问「门探测的是哪个库」，再问「被探测对象在那个库里在不在」**
   ⇒ ⇒ 判别动作：读门里那个**连接是怎么来的**（直读 DSN？还是自建一次性库？）
   ⇒ ⇒ ⇒ **对「自建一次性库」的门，问「形态库里在不在」＝ 问了一个门根本不会碰的对象 ⇒ 结论必然是假的。**
2. ⭐⭐⭐⭐⭐ **「假读数」有两种形态，两种都不会自己暴露** ——
   **① 读到了别的东西**（看起来有值）／**② 读失败了但看起来像空/0**
   ⇒ ⇒ ⇒ **判别动作：打印原始输出的前几行，而不是只打印「读到 / 没读到」。**
3. ⭐⭐⭐⭐⭐ **结构指纹不要用 `pg_dump | md5`**（PG 17.6+ 的随机 `\restrict` token）
   ⇒ ⇒ ⇒ **判别动作：连取 2 次，比对是否逐字一致；仓里现成的剥离逻辑在 `scripts/_lib/db-init-lib.sh`。**
4. ⭐⭐⭐⭐ **踩过第二次的坑 ⇒ 缺的不是记��，是机制** ⇒ ⇒ ⇒ 本轮处置 = 把修法写进**量具脚本自身**（`relkind::text` ＋ 确定性自检），而不是再写一条 LESSONS。
5. ⭐⭐⭐ ★ **收到订正先复现，再改判词** ⇒ ⇒ 对方这条订正**成立**（实测复核，不是转述）⇒ ⇒ **并且订正之后，原文依赖该行的那个论证也要一起失效**（本轮：§19.20.37 的「结论一」塌掉）⇒ ⇒ ⇒ **⇒ 订正不是改一个格子，是要重推依赖它的那条链。**
