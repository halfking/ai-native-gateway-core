## §1 主题：动画只覆盖了「在路上」，没覆盖「到达 / 新行 / 更新」

勘察（改造前）：

| 层 | 已有 | 缺失 |
|---|---|---|
| 画布（TopologyCanvas） | 粒子沿贝塞尔飞行、流光虚线、节点 in-flight 光环 | ★ **粒子到达终点无声消失**——`ParticlePool.step()` 从建仓起就返回「本轮到达的粒子」，但 `frame()` 里 `pool.step(dt)` 的返回值**从未被接住**（`web/src/components/live-topology/TopologyCanvas.vue` 原帧循环）；★ 流光 `lineDashOffset` 用**正值**递增 ⇒ 图案向路径**起点**移动 ⇒ 与粒子流向**相反** |
| 网关大方块（GatewayCoreBox） | 存储带 ↕ 字符 opacity 脉动 | 模块格 count 变化无任何痕迹（「这个模块正在干活」只是静默跳数）；↕ 是字形（craft-floor 禁的形态）且只闪不流 |
| 左右面板（cp/pp） | 状态描边、probe 虚线 | **零动画**——新请求到达时整列表纹丝不动，「有新东西到达」这个实时流页面的核心信息没有任何表达 |
| 供应商统计（Rail） | 3px 占比条 | 60s 轮询刷新时数字/条宽硬跳变，分不清「活的」还是「忘了刷新」 |
| 页头连接 chip | 三态配色 | 「已连接」是一句静态文案，没有生命体征 |

★★ **核心认识**：实时系统展示的「活」，不是靠加装饰动画，而是把**每个数据事件**
（请求到达 / 处理命中 / 响应落地 / 统计更新 / 连接心跳）翻译成一个**克制的视觉事件**。
业界参照（Web 调研，2026-10-28）：

- **SigNoz Service Map**：粒子沿边流动，**密度/速度编码流量**（最贴近本页形态）
- **Kiali/Istio**：流量动画沿服务图边
- **Grafana Node Graph**：静态拓扑是常态，动画需自定义 + 自己处理 reduced-motion
- **数字 ticker / 脉动状态灯**（count-up、pulsing indicator）：更新事件的可视化惯例
- 动画最佳实践共识：**motion sparingly**——动画表达数据流方向与状态变化，
  GPU 友好，reduced-motion 必须有降级路径

## §2 方案：动画 ↔ 事件语义映射（每条动画都有数据语义，无纯装饰）

| 事件 | 动画 | 位置 | 实现 |
|---|---|---|---|
| 请求在路上 | 粒子**拖尾**（反向 3 采样点渐小渐淡） | 画布 | Canvas，渲染层反推，粒子库零改动 |
| 请求落地 | **到达扩散环**（按状态着色：成功绿/失败红/限流黄，460ms 扩散渐隐）挂边终点 | 画布 | 接线 `step()` 返回值（此前被丢弃） |
| 链路有流量 | 流光**按流量分级**：速度 `34→12ms/周期`、线宽 `1.2→2.3`、亮度按 log 流量 | 画布 | 同 SigNoz「密度/速度编码流量」 |
| 模块刚命中 | 模块格**激活脉冲**（470ms 边框+底色闪一次渐隐；首见不闪、count 降不闪） | 网关大方块 | watch stats count 增量 |
| 存储后转发 | ↕ 字符 → **竖向流动虚线**（进站向下、出站向上，0.9s/周期匀速） | 网关大方块 | repeating-gradient + background-position 位移 |
| 新请求/新响应 | **只有新行**做入场（300ms translateY(-8px)+fade；首帧全页不闪） | 左右面板 | `useNewArrivals` composable（头对头扫描判新） |
| 统计更新 | 占比条 width 平滑过渡（400ms）+ 大数字 scale 脉冲（320ms） | Rail | watch 数值变化 |
| 连接心跳 | chip 前置**呼吸圆点**（open 2.2s / connecting 1.1s；down 不呼吸——常亮红更醒目） | 页头 | ::before + 循环 opacity |

**纪律约束（本仓既有的门全部前置遵守）**：
动效门 M1~M7（缓动必须 `--kx-motion-ease-out`、一次性 ≤800ms、入场登记 entrances、
数据条 width 过渡登记 layoutDriven、循环 linear 必须真匀速、reduced-motion 中和）；
ai-smell（↕ 字形换 CSS 线条 = 少一个字形）；color（全走 CSS 变量）；
elevation（零新增 box-shadow）；主色纪律（脉冲用主色 16% 底、非实心）。

## §3 实施

### 3.1 画布层（`TopologyCanvas.vue`）

- `drawEdge` 签名 `flowPhase → nowMs`：流光速度 `speed = max(12, 34 - log2(requests+1)*5)`，
  亮度/线宽随 log 流量分级；★ `lineDashOffset = -((nowMs/speed)%16)`
  （**负号 = 图案沿路径正方向移动，与粒子同向**——原正值是反向的）。
- 粒子渲染加拖尾（`t - k*0.045`，k=1..3，半径 `*0.18k` 递减、alpha `0.4/k`）。
- 新增 `ArrivalRing`（本地池，cap 24，FIFO）：`frame()` 接住 `pool.step(dt)`
  返回的到达粒子 ⇒ 在边终点生成扩散环（半径 `3→16px`、线宽 `2→0.8` 渐隐 +
  前 40% 有内心光点）；`drawArrivalRings` 在非 reduced-motion 分支绘制；
  卸载清空。

### 3.2 网关大方块（`GatewayCoreBox.vue`）

- `flashing`（reactive Set）+ `watch(stats, deep)`：count **增加**的模块加 `is-flash`
  470ms（`gw-cell-flash` 主色脉冲 / `gw-cell-flash-error` 失败格红色变体）；
  首见不闪（prev undefined）、回落不闪。
- `↕` 字符 ×2 → `.gw__flow-line--down/--up`（2px 宽竖向虚线，
  `gw-flow-down/up` keyframes：background-position 匀速位移 7px/周期 = pattern 周期，
  无缝循环；M7 匀速成立）；原 `gw-store-pulse` 删除。

### 3.3 面板（`ClientRequestPanel` / `ProviderResponsePanel` / `ProviderTodayRail`）

- 新 composable `web/src/composables/useNewArrivals.ts`：
  **头对头扫描判新**——不记全量历史 id（Set 无限涨），只记上一帧头部 id，
  从头扫到它为止都是新增；首帧不标（初始化≠活动）；大换血（上帧头滚出列表）
  只标头部 ≤40 条；空列表重置头指针、恢复数据按大换血处理（断流恢复的反馈
  价值 > 少量旧 id 误标一次）。`fresh` 整体替换触发响应式（Set 原地改不保证）。
- 行上 `is-new` → `cp-row-in` / `pp-row-in`（独立命名：裁决簿按 name 记账）。
- Rail：`.rail__bar` width transition（layoutDriven 登记，数据条先例同
  QueuePerspectivePanel）+ `rail__total-value.is-pulse`（大数字变化那格闪一次）。

### 3.4 页头（`LiveTopologyView.vue`）

`.live-topology__conn::before` 呼吸圆点（currentColor，6px）。

### 3.5 reduced-motion 全覆盖

每个新增 CSS 动画都有 `@media (prefers-reduced-motion: reduce)` 中和块
（流线停为静态虚线——连接关系仍表达，信息不丢）；Canvas 侧到达环/拖尾/流光
走既有 `prefersReducedMotion` 开关（reduced 时画静态密度点，不画环）。

## §4 顺手修的既有缺陷：两族 Windows 路径 bug + 运行时尺浏览器面

★★ **门在 Windows 本地跑不起来 = 覆盖面为零的门**（main 上长期如此，非本轮引入）：

## §6 本轮明确没做（留给下一轮，别重复排查）

- **旧泳道页**（`/dashboard?tab=stream` 的 LiveRequestStreamV2）的动效——独立页，不在「live 页」范围；
- **粒子投放节奏**：preview 夹具是静态快照，新粒子投放依赖真实 SSE 的新请求（`spawnTimer` 头对头）⇒ 到达环/拖尾的「事件密度」效果需真实流量才能全量观察（211 部署后已验证连接与渲染，见部署档）；
- **移动端 web-mobile** 的 live 页（既有遗留工作线）；
- **RoutingDecisionTimeline**（选中请求后的决策列表）无动画——它只在点选后出现，属「按需查看」不是「实时流」，本轮刻意不动（克制原则）；
- 上游并行轮的既有遗留清单未动（页面级硬编码中文 · 语言包死键 · 字表正名单 · 后端下发的中文 等）。
