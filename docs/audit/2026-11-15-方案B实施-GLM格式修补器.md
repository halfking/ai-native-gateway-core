### 1. 核心修补器（security/sanitize/output_sensitive.go）

**新增函数**：`tryRepairToolJSON(text string, toolName string) (repaired string, ok bool)`

**修补能力**：

#### A. GLM 原生标记泄漏（rv-2089 主场景）
```
输入: {"description</arg_key><ac7a3bd7><arg_value><b88a6f17>查找项目目录</arg_value>...
修补: 提取 <arg_value>...</arg_value> 之间的内容
结果: {"value": "查找项目目录"}  或直接使用内部的合法 JSON
```

#### B. JSON 截断（网络闪动）
```
输入: {"command": "ls -la
修补: 补全未闭合的引号和大括号
结果: {"command": "ls -la"}
```

#### C. 组合修补
- 同时处理未闭合的引号、大括号、方括号
- 尝试多种组合直到找到合法 JSON
- 防御性设计：括号数量异常时返回 false

**接入点**：
```go
// security/sanitize/output_sensitive.go:209
if !json.Valid([]byte(text)) {
    // ★ 2026-11-15：尝试修补格式错误

        slog.Info("output_compliance: repaired malformed tool JSON", ...)

    } else {
        // 修补失败，返回 tool_json_invalid 拦截
        return &outputcompliance.ComplianceResult{Blocked: true, ...}
    }
}
```

## 设计原则

1. **保守修补**：只修补可识别的、有明确规律的格式错误
2. **验证优先**：修补后必须通过 `json.Valid()` 验证
3. **fail-safe**：修补失败时返回 false，让原有拦截逻辑生效
4. **可观测**：修补成功时记录 slog.Info 日志

## 限制

1. **只修补已知格式**：
   - GLM 原生标记（`<arg_key>` / `<arg_value>`）
   - JSON 截断（未闭合引号/括号）
   - 不处理未知的复杂损坏

2. **不保证 100% 修复**：
   - 72小时内 3 单，预计修复率 >90%
   - 无法修复的仍走原拦截流程

3. **不解决根本问题**：
   - 修补器是临时方案
   - 应推动上游修复（apiclaude.cc）

func tryRepairToolJSON(text string, toolName string) (repaired string, ok bool) {
    // A. 识别 GLM 原生格式
    if strings.Contains(text, "</arg_key>") && strings.Contains(text, "<arg_value>") {
        // 提取 <arg_value>...</arg_value> 之间的内容
        extracted := text[start+len(startTag) : end]
        if json.Valid([]byte(extracted)) {
            return extracted, true
        }
        // 或包装成 JSON 对象
        wrapped := fmt.Sprintf(`{"value": %q}`, extracted)
        if json.Valid([]byte(wrapped)) {
            return wrapped, true
        }
    }
    
    // B. 补全截断的 JSON（引号、大括号、方括号）
    attempts := []string{
        text + strings.Repeat(`"`, needCloseQuote),
        text + strings.Repeat("}", needCloseBraces),
        text + strings.Repeat("]", needCloseBrackets),
        // ... 组合尝试
    }
    for _, attempt := range attempts {
        if json.Valid([]byte(attempt)) {
            return attempt, true
        }
    }
    
    return "", false
}
