🔧 修复技术方案

问题根因

供应商返回的错误响应中，error.code字段类型不一致：

// 某些供应商返回字符串 {"error": {"message": "...", "code": "400"}} // 某些供应商返回数字 {"error": {"message": "...", "code": 400}}

修复方案

创建FlexibleString类型，实现自定义UnmarshalJSON方法：

type FlexibleString string func (fs *FlexibleString) UnmarshalJSON(data []byte) error { // 支持字符串: "code":"400" var s string if err := json.Unmarshal(data, &s); err == nil { *fs = FlexibleString(s) return nil } // 支持数字: "code":400 var n json.Number if err := json.Unmarshal(data, &n); err == nil { *fs = FlexibleString(n.String()) return nil } // 支持null *fs = "" return nil }

测试覆盖

  • ✅ 字符串类型: "code":"400"
  • ✅ 整数类型: "code":400
  • ✅ 浮点数类型: "code":400.0
  • ✅ null值: "code":null
  • ✅ 完整错误帧解析
