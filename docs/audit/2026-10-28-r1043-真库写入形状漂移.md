## 二、根因链（★ 逐环实测，不是推演）

### 2.1 生产代码要 `tenant_id`

★ `domains/stats/reconciliation.go`：

```go
ct, err := w.db.Exec(ctx, `
	INSERT INTO stats_reconciliation_diffs
		(run_id, tenant_id, dimension_type, dimension_key, metric,
		 source_value, projected_value, difference, resolution, created_at)
	VALUES ($1, $2, 'daily_rollup', $3, $4, $5, $6, $7, $8, now())
	ON CONFLICT (run_id, tenant_id, dimension_type, dimension_key, metric) DO NOTHING

```

★ ★★ ⇒ 它不仅写 `tenant_id`，★ 它的 **`ON CONFLICT` 仲裁目标**也依赖
★★ `(run_id, tenant_id, dimension_type, dimension_key, metric)` 这条**唯一索引**
★★ （★ 迁移 548 建的）⇒ ⇒ ⇒ **没有这条索引，INSERT 连仲裁都没有**。

### 2.2 真库那张表长什么样

```\d public.stats_reconciliation_diffs

      source_value / projected_value / difference / resolution / created_at

  索引：只有 pkey + idx_..._run
  ★★★ 没有 546 的 idx_..._run_dim_metric，也没有 548 的 idx_..._run_tenant_dim_metric
  ★★★ 没有 545 的 resolution CHECK
```

⇒ ⇒ ★★ **缺三样**：列、仲裁索引、CHECK 约束。
