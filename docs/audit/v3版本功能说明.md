### 6. 请求模拟
- **11阶段完整流程**：
  1. 鉴权/限流（12ms）
  2. 审批（80%跳过）
  3. 注入检测（15-45风险分）
  4. 脱敏（0-3处）
  5. 压缩（-20%至-60%）
  6. 路由（1-3候选）
  7. 供应商（选中）
  8. 首字节（200-800ms）
  9. 还原
  10. 计量（1000-5000 tok）
  11. 回复

- **自动生成**：每0.8-2秒生成新请求
- **最多25条**：自动滚动
- **真实动画**：阶段按时序推进

## 🎯 使用说明

### 切换模式
1. 打开页面，默认显示**完整模式**（118px高度）
2. 点击"📐 完整"按钮，切换到**紧凑模式**（40px单行）
3. 再次点击"📏 紧凑"，返回完整模式
4. 设置会保存到localStorage

### 切换主题
- 点击"🌙 暗色"切换到亮色主题
- 点击"☀ 亮色"返回暗色主题
- 设置会持久化

### 切换标签页
- 点击"Token桶"或"用户端"查看其他页面

### 控制模拟
- **速度**：点击"速度 4×"在1×/4×/8×/16×间循环
- **暂停**：点击"⏸ 暂停"停止生成新请求
- **清空**：点击"清空"移除所有请求

## 📊 技术实现

### 坐标系统（原版）
```javascript
const CLIENT_W=168    // 客户端节点宽度
const NODE_W=104      // 标准节点宽度
const PROVIDER_W=132  // 供应商节点宽度
const PITCH=112       // 列间距
const COL0_X=180      // 第1列X坐标

const SEND_Y=8        // 发送轨Y坐标
const SEND_H=42       // 发送轨节点高度
const RECV_Y=58       // 接收轨Y坐标
const RECV_H=28       // 接收轨节点高度
const BAND_H=118      // 总行高
```

### SVG连线算法
1. 发送轨：水平连接相邻节点（客户端→供应商）
2. 垂直转折：供应商→首字节
3. 接收轨：水平连接相邻节点（首字节→回复）
4. 回程：回复→客户端（含垂直段）
5. 每条线根据目标节点状态着色

### 状态传递
```
pending → active → done/failed/skipped
  ○        ◐         ✓  ✕    ⌀
```
