## 🎓 技术要点

### F1-F6修复概述

| 问题 | 根因 | 修复 | 代码位置 |
|-----|------|------|---------|
| F1 | 换模梯子被开关挡死 | 默认开启 | `settings/spec_dispatch.go` |
| F2 | 协议面不支持auto | 开关打开 | `autoroute/internal/legacyflags/` |
| F3 | 会话缓存不校验 | 增加重校验 | `autoroute/cache_revalidate.go` |
| F4 | 零候选直接503 | 零候选重选器 | `domains/streaming/auto_route_reselect.go` |
| F5 | 退路池太窄 | 扩展到32个 | `autoroute/reselect.go` |
| F6 | 判据不一致 | 对齐三道闸 | `autoroute/availability_filter_sql.go` |

### 任务识别架构

**当前实现（两层）**:
```
请求 → [启发式分类器] → [LLM分类器] → 任务类型
        (本地规则)      (远程调用)
```

**优化方向（三层）**:
```
请求 → [启发式] → [本地轻量模型] → [远程LLM] → 任务类型
        ≥0.85      0.5-0.85         <0.5
```

预期收益：
- 降低LLM调用 50-70%

不是改变决策逻辑，而是**增加决策后的退路**。
