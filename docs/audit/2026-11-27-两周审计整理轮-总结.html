七、本轮通用式（三条）

  • 「自动合并成功」不等于「编译通过」 —— 双方同名 go:embed 变量/map 键会叠出重复声明；对含注册表的文件，合并后必须以「与胜出侧逐字节 diff 为空」为判据，而不是相信 git 的无冲突报告。
  • 「同一改动、两条车道、两个 SHA」用 patch-id 收敛 —— git log 里的两条独立记录可能内容逐字相同；合并前 git show | git patch-id --stable 对拍是唯一机械判据。
  • 删任何工作树前先数 rev-list --count origin/main..HEAD —— 315M 的「垃圾」目录里藏着 132 笔未推送提交；「目录旧」与「内容未保全」是两件事。
