## 五、量具坑（本轮新增）

1. **podman 日志多行语句按行打前缀**：`STATEMENT:`/`DETAIL:` 子行自带
   `stderr F + PG 时间戳`，按「时间戳=新条目」切分会把 ERROR 与语句体拆开；
   且并发 pid 交错时按块归因会把 A 的语句并给 B 的错误——**错误→语句归因必须
   回原始日志逐行状态机配对**（本轮用 python 严格配对复核，纠正了两处 awk 块
   归因的假象）。
2. **`ls | head` 截断轮转文件清单**：当天 03:14 刚轮转出的
   `ctr.log-20261016`（800MB，未压缩）被 head 吃掉，差点把 24h 窗口当空洞。
   轮转目录必须全量 `ls`。
3. **共享 checkout 变异轮反噬实录**：首修 db.go 后（build/test 已绿），并行
   会话用 `git` 恢复类操作把 db.go 洗回干净态——备份 cp 拿到的已是裸文件，
   「变异→恢复」两步全空转。共享 checkout 上编辑→验证→**提交**必须一气呵成；
   备份必须在编辑后立即做，恢复后先 `grep` 关键串再下结论。
