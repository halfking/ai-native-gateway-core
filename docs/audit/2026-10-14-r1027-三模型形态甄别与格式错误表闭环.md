## 三、修复明细

1. **diagnose.go**（reqprobe）：paramRejectionHints 补 "input should
   be"/"allowed values"；namedParamPatterns 补冒号前缀值拒绝形态与补救句
   `set X to 'value'`；方向甄别——responses 指令句优先于 chat 提及级
   信号（chatDirectiveHints 子集），chat 指令句族行为不变（守卫钉住）。
2. **strip.go**：wireKeyAliases（output_config.effort / reasoning.effort
   / effort → reasoning_effort / reasoning，chat+responses 双载体）——
   named 剥参的同名假设首次被上游命名空间打破。
3. **sanitizer.go**：AdaptChatParamsToResponsesWire（native+reactive 腿
   choke point）——四个改名/删除规则，显式目标形态不覆盖。
4. **classify.go**（errorsx）：jsonModeWordRequiredRe → KindClientBug，
   两个分类器同臂（r1021 教训）——止住单次契约 400 的节点冷却级联。

判据：r1027_upstream_namespaced_param_test（真实捕获文案回放+前提在场+
方向守卫）、r1027_wire_adapter_test（executeOpenAI 同层四形态+不覆盖
守卫）、r1027_json_word_contract_test（双分类器+良性负向）。变异全部
红（落盘确认后）。
