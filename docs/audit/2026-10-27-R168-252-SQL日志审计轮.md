## §五 主修复：stats daily/monthly rollup 的 30s 击杀活锁（42 次/天 → 结构性收口）

### 病灶证据链

- **`WITH latest`（usage_facts ⋈ stats_event_dedup → INSERT stats_usage_daily）**
  statement timeout **284 次 / 7 天（~41 次/天）**，全天候平坦分布（262 个不同分钟）
  ⇒ 与负载尖峰无关，**内在成本问题**；另有 94 次贴线完成（max 29.8s）。
  每次被杀 = 整事务回滚 ⇒ 下一 tick 重做**完全相同的 3 天窗**（48h lookback 展开成
  整天边界）⇒ 30s rolconfig 下的活锁形态（R72 F2 同族）。
- 干净负载（load 7）下 `EXPLAIN (ANALYZE)` 同形 SELECT 臂实测 **1.22s**（31,616 行，
  Parallel Append + dedup Index Only）——单臂并不贵；贵在：**双实例每小时各自全量重建、
  无任何协调**（promote 有 advisory 锁、analyze 有任务行锁、matview 有 R12-F1 锁——
  rollup 三样都没有）⇒ 撞车时两边把语句预算烧在锁等待上，30s rolconfig 收割。
- 设计已读清：`DailyMonthlyRollup.Refresh` 单事务 DELETE+INSERT（daily）+
  DELETE+INSERT（monthly，6 维 UNION ALL 放大），无 SET LOCAL，无锁。

### 修法（`domains/stats/daily_monthly_rollup.go`，三件套，全部照抄仓内先例）

1. **事务内 `SET LOCAL statement_timeout = rollupRefreshBudget(2min)`**——
   天花板归自己，不等 rolconfig 的 30s（promote 60s / analyze 10min / archive 30min 同款）；
2. **单 runner advisory try-lock**（`pg_try_advisory_xact_lock`，FNV-1a
   `llm-gateway:stats-daily-rollup:`，与 promoteLockKey 同推导）——输家整个跳过本 tick，
   重建幂等且整窗，跳过零覆盖损失（R12-F1 matview 同语义）；
3. **`CloseEligibleMonths` 独立 30s 预算**——原先与刷新共享 2min ctx，
   刷新吃满则月度封存被饿死。

### 验证

- 形状测试 `TestDailyMonthlyRollup_StatementTimeoutAndPeerLockPinnedInsideTx`
  （Begin < SET LOCAL < advisory lock < DELETE < Commit 次序钉死 + 天花板必须派生自
  `rollupRefreshBudget` + Close 独立预算）+ 锁键派生钉；
- 集成测试 `TestRollup_PeerLockSkipsRebuild`（testcontainers 真 PG：peer 持锁 ⇒
  Refresh 返回 nil 且 0 行重建；释放 ⇒ 正常重建，锁不楔死 worker）；
- **变异两臂全检出**：M1 删 SET LOCAL 块 ⇒ 形状测试红（缺天花板 + 缺派生）；
  M2 `if false && !gotLock` ⇒ 集成测试红（peer 持锁下重建了 5 行）。
  还原后 `go build ./...` ✓ / `go vet` ✓ / stats 包全绿。
- 生效待下次部署（154/245 部署列车带二进制；部署属维护窗口动作，本轮不代执行）。

## §十 量具坑（本轮新增 5 条）

1. 提取器 flush 时机：PART 级别行到达时事件必须还活着（先判级别再 flush 新事件）；
2. 语句体定位用 `statement:` 标记而非 duration 尾（910 后新形态：头行空 statement + 续行体）；
3. archive 同日 .gz/.log 并存 ⇒ 重叠段双计（跑批清单先核对）；
4. `pkill -f` 模式串与自身 ssh 命令行同串 ⇒ 自杀退出 255（事实 108 第三次）；
   用 `ps | grep '[x]yz'` 枚举后按 PID 杀；
5. zsh 里裸 `===WORD===` 被当 glob/命令展开（`echo ===RESTORED===` 吃掉整段），
   分隔串用引号或换 `----`。
