## 3. 交付：五类分类学 + 登记册 + 门

### 3.1 分类轴（按「谁读它、读它为了什么」，不是名字形状）

| class | 语义 | 在事实源里？ |
|---|---|---|
| `dsn` | 整体 DSN，通用值可用 | ★ 在（由事实源承载） |
| `dsn_exclusive` | 整体 DSN，但**必须专用值** | ★ 必须不在 |
| `isolation` | 隔离开关（声明「本腿跑在隔离库上」） | ★ 必须不在 |
| `dangerous` | 危险开关（任意库 / 破坏性 / 本地 schema 变更） | ★ 必须不在 |
| `component` | 拼装型 / 夹具参数 / 外部依赖 / 杂项 | ★ 必须不在 |

★★ **后三类为什么必须不在事实源里**：事实源是**跑真库腿时被 source 的东西**；
「打开隔离声明 / 允许任意库 / 允许破坏性」都是**取消保护**的动作
⇒ 由事实源默认打开 = **把安全边界交给一个「忘了配环境变量」的人**。

★★ **`dsn_exclusive` 为什么必须不在**：它是整体 DSN，但**必须与通用 DSN 不同**。
`TEST_TENANT_DATABASE_URL` 必须指向**不可绕过 RLS 的独立角色**
⇒ 塞进事实源 = 所有腿拿到同一个值 = **专用隔离被悄悄抹平**。

## 4. 本轮自我订正 3 条（都是量具层面的）

1. ★★★ **分类轴第一版是错的**：用「文件内出现 `pgxpool.New`」当分类轴

   ★ 通用式：**跨轮次比读数前，先比「量具口径」** —— 库名、开关、基线都是口径的一部分。

## 7.1 建议改法（**供属主一键采纳；本轮未落库**）

★ 收益/代价都已量化，改法本身只有一行（外加把 `env \` 块缩到只剩 tenant 专用变量）：

```bash
# scripts/audit/run-integration-gate.sh：在 `env \` 块之前插入
source "$(cd "$(dirname "$0")" && pwd)/datasource_env.sh" "$GATE_URL"
# 然后 `env \` 块里除 TEST_TENANT_DATABASE_URL="$TENANT_DSN" 外逐个列出的名字可以删掉
# （事实源已导出同名变量，且值同为 $GATE_URL）
```
