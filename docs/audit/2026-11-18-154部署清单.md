① 「并行车零泄漏」不再是判据（并发车的改动**本轮就该上线**）⇒ 改为「**线上 release 产物 == 部署树**」；

### ★ 为什么 3050 被取代

3050 的前端 locale 带着本轮新增的 `value.meter`（**8 语种逐字相同**）⇒ 把 i18n 棘轮（只许降不许升）顶高

⇒ **3051 相对 3050 的差异面＝8 语种 locale ＋ `StageTreeBand.vue`（＝棘轮修复那 4 处）⇒ 严格超集修复，无其它行为变化。**
⇒ **不要回滚到 3050。**

### ★ 为什么 3060 的基点是「上一版在役树」而不是 `origin/main`

3060 动手时 `origin/main` 已在并行车手里（`48ae5917d`）⇒ 拿 main 发版＝**替并行车发版**。

```bash
# ① 四版部署的身份（不依赖任何 /private/tmp 目录）

#   cherry-picks=4c0c41026,2083bbe09
```
