## 1. 为什么是这一轮

### 1.1 病：声明了角色阶，写的却不是那个阶

`DESIGN.md` §4 早就写死了 9 档角色级字号阶，`DESIGN.md` §2 也写死了「字号 → `--kx-text-*`」这条消费规则。
但**仓内的真值与明文对不上**：

| 读数（用本轮判据扫 HEAD 的源码树，实测） | 值 |
|---|---|
| `font-size` 声明总数 | 2682 |
| **值落在角色阶上** | **2060（76.8%）** |
| **值离阶** | **397 处 / 139 个文件** |
| 其中 **rem 写法** | **63 处** |
| 令牌写法（`var(--kx-text-*)`） | 92（3.4%） |

⇒ **声明了阶，却有 397 处不在阶上**；而 3.4% 的令牌写法说明「阶」在绝大多数地方只是**文档里的装饰**。

离阶值的分布（实测）：

```
10px 181 · 15px 44 · 18px 40 · 9px 45 · 11.5px 17 · 12.5px 16 · 22px 10
10.5px 11 · 13.5px 7 · 8px 9 · 28px 8 · 7px 3 · 17px 3 · 32px 1 · 36px 1 · 26px 1
```

★ 最刺眼的是 **10px / 9px / 8px / 7px 合计 238 处** —— 这正是 impeccable `typeset.md` 点名的
「**adjacent sizes too close to carry different jobs**」：10px 与 11px 只差 1px，却各占一档，
人眼分不出，屏幕上只会读成「这一片糊了」。

### 1.2 ★★ 更深的病：**rem 与 px 是「同一阶的两份真值」**

仓内令牌层（`--kx-text-*`）全是 px，根字号固定 16px ⇒ 令牌层已经**用 px 定死了阶**；
而源码里另有 63 处用 rem 表达同一个阶 ⇒ 改根字号时 rem 那一半会动、令牌那一半不动 ⇒ **脱钩**。

⇒ 本轮把 rem 判红（第二条棘轮），不是审美偏好，是**消除双真值**。

### 1.3 ★★★ 最贵的病：**UA 默认字号** —— 源码门根本看不见

`web/src/style.css` 在本轮之前**没有** `h1~h6` 与 `button` 的排版重置（实测：全文件只有 `input/select/textarea` 的字号声明）。
后果有两处：

1. **标题层级由浏览器决定**：UA 的 `h1 = 2em`（⇒ 14px 根上 28px）、`h3 = 1.17em`（⇒ 16.38px）
   ⇒ **16.38px 这种值根本不在角色阶上，而源码里没有这条声明** ⇒ **源码门永远看不见它**；
2. **按钮不继承字号与字体**：`<button>` 落到 UA 的 13.33px **和 UA 字体（实测 Arial 79 个按钮）**
   ⇒ 按钮与全站**不是同一个字体**（与 craft-floor「引用的字体必须真的被加载」同族）。

⇒ **源码门看不见 ⇒ 只有运行时尺能看见** ⇒ 这是本轮**必须做第二把尺**的直接原因。

### 1.4 选主题时排除的两条路（不要重试）

- ❌ **新增 10px 档**：10px 与 11px 只差 1px ⇒ 正是 impeccable 点名的「相邻两档太近，扛不住不同职责」⇒ 反而**加重**问题。
- ❌ **按类名做角色对齐**（见 §5.3 的实测反例）：**同名 ≠ 同角色** ⇒ 这条路已被证伪，本轮放弃。

## 2. 判据（唯一实现：`web/src/design/typeScale.ts`）

### 2.1 一条判据

> **`font-size` 的静态长度值必须落在 `DESIGN.md` §4 声明的角色阶上。**

- **阶的事实源 = `web/src/style.css` 里 `--kx-text-*` 的实际定义**，**运行时解析、绝不硬编码**
  ⇒ 改令牌 = 改判据（单一真值）。
- 不判（单独计数，不算违规）：`em` / `clamp()` / `calc()` / `var()` / `inherit` —— 相对父级或视口，静态不可定值。
  ★ `em` **不判**：它是有意的相对语义；`rem` **要判**：绝对值的相对写法。

### 2.2 「图标承载」是**形状豁免**，不是写法豁免

仓里有一批 `font-size` **不是用来控制文字的**，而是控制**图标/字形**的尺寸（Element Plus 图标是 1em）。
判据落在**元素角色**上：

> 「这个 class 在模板里的**全部**用法都是图标承载」⇒ 它的 `font-size` 不是字号。

证据由模板自动推导（宿主是 `<i>` / 带 `aria-hidden="true"` / 内容是 `@element-plus/icons-vue` 导入的图标组件），
⇒ **不需要人工登记簿**，每个豁免都能报出它的证据行。

★ **按类名判会误伤文字徽标**（`.badge` / `.dep-badge` / `.src-badge` 里是**真文字**）⇒ 那是写法判，不是形状判。
★ 唯一需要人工登记的是**字形（emoji）**形态（`<span class="tool-icon">{{ tool.icon }}</span>`）⇒ 5 条，带 witness。

### 2.3 判据的唯一实现与复用面

| 能力 | 落点 |
|---|---|
| 阶解析 / 值分类 / CSS 扫描 / 内联样式扫描 / 图标证据推导 / 文件遍历 | `web/src/design/typeScale.ts`（**唯一实现**） |
| 源码门（薄壳） | `web/scripts/design-type-scale-guard.mjs` |
| 双棘轮 | `web/scripts/design-type-scale-baseline.json` |
| 人工裁决簿（语义平局 / 图标豁免 / 死 CSS） | `web/scripts/design-type-scale-decisions.json` |
| 批量收敛器（**复用判据的豁免**） | `web/scripts/design-type-scale-migrate.mjs` |
| 运行时尺（第二把尺） | `web/scripts/design-type-scale-runtime-check.mjs` |

★ 迁移脚本**必须复用判据的豁免** —— 否则闸②会把门放过的图标算成违规（同一类错第二次犯，见 §6.5）。

### 3.2 双棘轮（只降不升）

| 指标 | 含义 | 基线 |
|---|---|---|
| `offScaleFontSizes` | 静态 `font-size` 声明里，值**不落在**角色阶上的声明数 | **0** |
| `remFontSizes` | 用 rem 表达的声明数（同一阶的第二份真值） | **0** |

★ 两个指标都是**新建**的（此前没有），基线从 0 起 ⇒ 任何回退都立刻被抓住。

### 3.3 自证 20/20（源码门）+ 8/8（运行时尺）

自证覆盖：阶从 `style.css` 解析（不是硬编码）· 值的分类正确 · rem 可静态换算 · `em/clamp/var` 不判 ·

**对照：在阶上的值绝不能被报成离阶（判据不是恒真）**。

## 4. 运行时尺（第二把尺）

源码门**看不见 UA 默认字号**（§1.3）⇒ 必须有一把量「浏览器真的渲染成多少」的尺。

```
node scripts/design-type-scale-runtime-check.mjs --selftest
node scripts/design-type-scale-runtime-check.mjs --pages=/free-pool,/admin/proxy
node scripts/design-type-scale-runtime-check.mjs --json=/tmp/rt.json
```

判据 = **承载文字的元素（自身有直接文本节点）渲染字号必须落在阶上**；
同时量**横向溢出**（`scrollWidth > clientWidth`）⇒ 用来证明「字号变大没有撑破布局」。

★ **两把尺的作用域不同**（源码尺 vs 运行时尺），最终裁决以运行时尺为准，边界写在本档 §8。

## 6. ★ 本轮抓到的真缺陷

### 6.1 ★★★ 普查脚本用「最后一个类名」做角色对齐 ⇒ 误改真文字

`.mini-card__value small` 的 10px 被误改成 16px ⇒ 普查/判据改用**完整选择器精确匹配**。

### 6.2 ★★★ 「同名 ≠ 同角色」（§5.3）

⇒ 放弃按类名做角色对齐。

### 6.3 ★★★ 媒体查询方向反了（§5.2）⇒ 整轮回滚 + 确定性重放。

### 6.4 ★★★ 闸③（判据自检）自己错了三次

闸③要证明「**非 font-size 内容逐字未变**」。三个错法依次是：

1. 固定占位符比较 ⇒ 长度天然不等 ⇒ 必然失败；
2. 剔除区间 ⇒ 必须用**各自文本的长度**；
3. ★ **区间坐标与被比较的文本不同源** ⇒ 正解 = **用同一个扫描器在两份文本上各算区间**，再删值比较。

⇒ ★★ **「判据自己错了」比「数据错了」更隐蔽** ⇒ 判据必须先被当成待审对象。

### 6.5 ★★ 迁移脚本没复用判据的豁免 ⇒ 同一类错第二次犯

闸②会用判据的判据复查改写结果，而迁移脚本若不认图标豁免 ⇒ **闸②会把门放过的图标算成违规**。
⇒ 迁移脚本改为**复用判据的豁免**（同一份真值）。

### 6.6 ★ 图标组件检测漏了带属性的组件

`<CaretBottom v-if="…" />` 这类带属性的组件，首字母大写法认不出 ⇒ 改用
**`@element-plus/icons-vue` 的 import 列表**作事实源（仓内唯一的图标来源）。

### 6.7 ★ 标签正则被 `:class="{… > 0}"` 里的 `>` 截断 ⇒ 改为能跳过带引号的属性值。

### 6.8 ★★★ 注释里写 `/* … */` 把块注释提前闭合（TS 语法错）。

### 6.9 ★★★ 正则里**不能出现裸反引号**

`web/src/design/typeScale.ts` 的声明正则原本写成 `/font-size\s*:\s*([^;}"' ]+)/gi`（含裸反引号）
⇒ copy-quality 门按「反引号 = 模板字符串起点」提取文本 ⇒ 把后续中文注释整段吞进去
⇒ 误判「否定转折当骨架」⇒ **1 处假红**。
修法：把反引号写成 `\x60` 转义。

★★ 而这只是**症状**：真因是 **copy-quality 门的提取器不认识正则字面量** ⇒ 见 §7.4。

⇒ 肉眼可见的差异：**`/admin/proxy` 的 h1「代理管理」由 28px（UA）变 24px（角色阶）**。

### 7.4 ★★★ copy-quality 门的根因缺陷：提取器不认识正则字面量

§6.9 的那处假红只是症状。真因（实测定位）：

> `copy-quality-audit.mjs` 的提取器分两步：① `stripComments`（靠引号配对剥注释）② 再用正则找引号。
> 而**正则字面量里可以有引号**（`/[^;}"']+/`）⇒ ① ② **各自在那儿错位** ⇒ 两个方向的错：

- **假红**：后面的行注释不再被剥 ⇒ 注释里的中文被当作文案判红；
- **假绿**：真实字符串的边界被吞掉 ⇒ 真字符串整段漏判。

★ 实测影响面（逐文件对拍 2185 个受扫文件）：**59 个文件**的抽取结果变了；
其中含中文的字符串：**原版有新版无 678 条**（逐条复核，**全部是「代码块 + 注释」的碎片**，
唯一的「像一句话」的 18 条也逐条看过：全在测试文件或 `src/i18n/` 下，而这两面**本就不在扫描面**），
**原版无新版有 2225 条**（真实字符串被找回来了）。
⇒ 抽取总量对拍：web 语言包 50577 → 50578 · 源码面 53889 → **53975**（更多真字符串进入视野，不是假绿）。

⇒ **修法是让提取器认识正则**（单遍统一扫描器：`scanSource` 一次扫描同时判定「什么是注释」「什么是字符串」「什么是正则」）
⇒ **不是**去改那句注释（改注释只是把假红藏起来）。

**自证 32/32**（新增 2 条，正反成对）：

| 夹具 | 期望 |
|---|---|
| 正则字面量（含引号）+ **注释**里的违规句 | 判绿（注释不是文案） |
| 同一条正则 + **真字符串**里的违规句 | 判红（修法没把判据废掉） |

**真仓变异臂 4/4**，并做**旧版对照**（同一套臂跑 HEAD 原版）：

| 臂 | 新版 | 旧版 |
|---|---|---|
| M1 正控：真字符串里的否定转折 ⇒ 报出 | ✓ 报出 | ✓ 报出 |
| M2 阴控：同一句放 `//` 注释 ⇒ 不得报出 | ✓ 不报 | （rc 受既有红影响，见下） |
| M3 对照：正则 + 注释里的违规句 ⇒ 不得报出 | ✓ 不报 | ✗ **误报（假红）** |
| M4 对照：正则 + 真字符串的违规句 ⇒ 报出 | ✓ 报出 | ✗ **漏报（假绿）** |

★★ **判据落在「门输出里有没有出现探针短语」，不是 rc** —— 因为旧版在未被注入的树上就已有 1 处红
（`typeScale.ts` 的注释假红）⇒ 用 rc 判会把那处既有红误记成「臂通过」。
★ 探针必须放在**串首**：门的输出把值截到 90 字 ⇒ 探针放串尾会被截掉 ⇒ 「探针没出现」会被误读成「门没报」。

★ 同族未修（留给下一轮）：`i18n-hidden-key-guard.mjs` 与 `craft-floor-audit.mjs` 各有**自己的一份** `stripComments`
⇒ 同样的缺陷仍在（它们当前读数为 0，不影响本轮，但**下一次有人往那两处加带引号的正则就会复发**）。
