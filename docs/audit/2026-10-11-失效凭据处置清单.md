## 处理完如何验收

```bash
ssh 245
export $(grep '^LLM_GATEWAY_DATABASE_URL=' /etc/llm-gateway-go/env | xargs)
psql "$LLM_GATEWAY_DATABASE_URL" -A -F"|" -c \
  "select availability_state, count(*) from credentials group by 1 order by 2 desc;"
# auth_failed 应归零或大幅下降

# 路由成功率（真实口径，剔除探针与无效 key）
psql "$LLM_GATEWAY_DATABASE_URL" -A -F"|" -c \
  "select count(*) n, round(100.0*count(*) filter (where success)/nullif(count(*),0),1) pct_ok
   from request_logs_hot where ts > now() - interval '6 hours'
   and coalesce(error_kind,'') not like 'probe_direct%'
   and coalesce(error_kind,'') <> 'invalid_key';"
# 基线：n=2212, pct_ok=73.2（固定锚点 16:35–22:35；滑动窗口数字会略低）
```

`api_models_ok` / `health_status` 由自愈流程异步回写，充值后无需手工干预，等一个
健康检查周期再复核即可。
