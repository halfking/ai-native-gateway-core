## 四、24 小时观测期

### 4.1 观测指标（每 6-12 小时采集一次）

**脚本**：
```bash
#!/bin/bash
# save as: collect-post-p0-metrics.sh

cat > /tmp/post-p0-metrics.sql << 'EOF'
-- 时间戳
SELECT NOW() as collection_time;

-- 不可用绑定数
SELECT COUNT(*) as unavailable_count 
FROM credential_model_bindings 
WHERE available = FALSE;

-- 总体可用率
SELECT 
    COUNT(*) as total,
    COUNT(*) FILTER (WHERE available = TRUE) as available,
    COUNT(*) FILTER (WHERE available = TRUE) * 100.0 / COUNT(*) as available_pct
FROM credential_model_bindings;

-- 探测间隔分布
SELECT 
    percentile_cont(0.50) WITHIN GROUP (ORDER BY EXTRACT(EPOCH FROM (NOW() - last_attempt_at))/60) as p50_minutes,
    percentile_cont(0.95) WITHIN GROUP (ORDER BY EXTRACT(EPOCH FROM (NOW() - last_attempt_at))/60) as p95_minutes,
    percentile_cont(0.99) WITHIN GROUP (ORDER BY EXTRACT(EPOCH FROM (NOW() - last_attempt_at))/60) as p99_minutes
FROM node_probe_state
WHERE last_attempt_at IS NOT NULL;

-- 24h 探测覆盖率
SELECT 
    COUNT(*) as total,
    COUNT(*) FILTER (WHERE last_attempt_at > NOW() - INTERVAL '24 hours') as probed_24h,
    COUNT(*) FILTER (WHERE last_attempt_at > NOW() - INTERVAL '24 hours') * 100.0 / NULLIF(COUNT(*), 0) as coverage_pct
FROM node_probe_state;
EOF

echo "=== Post-P0 Metrics Collection $(date '+%Y-%m-%d %H:%M:%S') ===" | tee -a /tmp/post-p0-metrics-log.txt
ssh 211 'docker exec -i acc-pg17 psql -U llm_gateway -d llm_gateway' < /tmp/post-p0-metrics.sql | tee -a /tmp/post-p0-metrics-log.txt
```

### 4.2 成功标准

**至少满足 3/4 条**：

| 指标 | 基线 (11-09 10:19) | 目标 (24h 后) | 判定标准 |
|---|---|---|---|
| ① 不可用绑定数 | 747 | <600 | 下降 ≥20% |
| ② P95 探测间隔 | 16,476 min (~11 天) | <120 min (2h) | 下降 99%+ |
| ③ P99 探测间隔 | 38,566 min (~27 天) | <360 min (6h) | 下降 99%+ |
| ④ 24h 探测覆盖率 | 73.9% | >90% | 提升 16+ pp |

**附加观测**：
- Featured 模型探测频率：每个模型至少 1 次/小时
- Model_tier static count：应 > 基线（routing_policy + canonical）
- 无探测相关错误日志增加
