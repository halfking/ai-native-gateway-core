# 多标签版实现计划

## 新增结构

### 1. 标签导航栏
```
┌─────────────────────────────────────────────────────┐
│ [实时拓扑] [Token桶] [用户端]  🌙 暗色  📏 紧凑  ⏸... │
└─────────────────────────────────────────────────────┘
```

### 2. Tab1: 实时拓扑（当前功能）
- 保留所有现有功能
- 优化模型选择为多选组件

### 3. Tab2: Token桶
**显示内容**：
- 供应商节点列表（卡片式）
- 每个节点显示：
  - 节点名称、供应商
  - 支持的模型（标签）
  - 状态：在线/离线/维护
  - 成本价格（¥/1M tokens）
  - 并发限制（当前/最大）
  - 余额/配额
  - QPS、延迟
  
**过滤功能**：
- 模型多选（只显示支持该模型的节点）
- 供应商筛选
- 状态筛选

### 4. Tab3: 用户端
**主视图**：
- 用户列表（表格/卡片）
- 显示：用户名、总请求、成功率、Token消耗、成本

**详情视图**（点击用户）：
- 智能体工具列表
- 每个工具的消耗量
- 会话操作的项目和任务

**过滤功能**：
- 模型多选
- 时间范围

## 实现步骤

1. 添加标签导航组件
2. 重构为单页多标签结构
3. 实现优化的模型多选组件
4. 实现Token桶视图
5. 实现用户端视图
6. 联调所有功能
