**审计日期**：2026-11-17

## 一、当前架构分析

### 1.1 认证提供者架构

**设计架构**（pkg/authplugin）：
- ✅ **Registry 模式**：支持多个认证提供者注册和切换
- ✅ **已实现提供者**：
  - `native`：基于 PostgreSQL users 表 + bcrypt + JWT
  - `casdoor`：基于 Casdoor OAuth2
- ✅ **配置驱动**：通过 `PluginConfig` 选择使用哪个提供者
- ✅ **默认值**：未配置时默认使用 `native`

**实际状态**（cmd/gateway/main.go）：
```go
// Line ~7678: Registry 初始化
authRegistry := authplugin.NewRegistry(&authplugin.PluginConfig{
    AuthProvider: "native",  // 硬编码，未从配置读取
    // ...
})
```

### 1.2 登录流程

**后端流程**（admin/auth.go）：
1. ✅ 验证码检查（`verifyLoginCaptcha`）
2. ✅ 从 Registry 获取 AuthProvider
3. ✅ 调用 `authProvider.Authenticate()`
4. ✅ 成功后签发 JWT token
5. ✅ 记录审计日志

**前端流程**（web/src/components/LoginModal.vue）：
1. ⚠️ **缺失**：没有验证码输入框
2. ⚠️ **缺失**：没有验证码图片显示
3. ⚠️ **缺失**：没有处理 `captcha_required` 错误
4. ✅ 基本的用户名/密码输入

### 1.3 验证码机制

**后端实现**（admin/auth_captcha.go）：
- ✅ 验证码生成端点：`GET /api/auth/captcha`
- ✅ 失败计数追踪：`loginFailuresGlobal`
- ✅ 自适应要求：失败次数达到阈值后要求验证码
- ✅ 验证码验证：`verifyLoginCaptcha`

**前端实现**：
- ❌ **完全缺失**：没有任何验证码相关UI和逻辑

## 二、发现的问题

### P1 - 验证码前端缺失

**问题描述**：
- 前端登录表单没有验证码输入框
- 当后端返回 `captcha_required` 错误时，前端无法响应
- 用户无法输入验证码完成登录

**影响**：
- 登录失败超过阈值后，用户**完全无法登录**
- 本次验证中遇到此问题，需要重启容器才能清除失败计数

**复现**：
1. 多次使用错误密码登录
2. 后端返回 400 + `{"error":{"code":"captcha_required",...}}`
3. 前端无法显示验证码，用户无法继续

### P2 - 认证提供者配置硬编码

**问题描述**：
- `cmd/gateway/main.go` 中 AuthProvider 硬编码为 `"native"`
- 没有从环境变量或配置文件读取
- 无法通过配置切换到 Casdoor

**影响**：
- 虽然架构支持多提供者，但实际无法切换
- 需要修改代码并重新编译才能使用 Casdoor

### P3 - 配置管理界面缺失

**问题描述**：
- 没有管理界面让管理员选择认证提供者
- 没有 Casdoor 连接配置界面

**影响**：
- 用户体验差，需要手工编辑配置文件或环境变量

## 三、修正方案

### 3.1 前端验证码支持（P1）

**新增文件**：
- `web/src/components/CaptchaInput.vue`：验证码输入组件

**修改文件**：
- `web/src/components/LoginModal.vue`：集成验证码
- `web/src/api/auth.ts`：添加验证码API
- `web/src/locales/*/login.ts`：添加验证码文案（8语种）

**功能**：
1. 检测 `captcha_required` 错误
2. 自动调用 `/api/auth/captcha` 获取验证码
3. 显示验证码图片
4. 提供刷新验证码按钮
5. 在登录请求中携带 `captcha_id` 和 `captcha_code`

### 3.2 认证提供者配置（P2）

**环境变量**：
```bash
LLM_GATEWAY_AUTH_PROVIDER=native|casdoor  # 默认 native

# Casdoor 配置（当 AUTH_PROVIDER=casdoor 时需要）
LLM_GATEWAY_CASDOOR_ENDPOINT=https://casdoor.example.com
LLM_GATEWAY_CASDOOR_CLIENT_ID=xxx
LLM_GATEWAY_CASDOOR_CLIENT_SECRET=xxx
LLM_GATEWAY_CASDOOR_ORGANIZATION=org
LLM_GATEWAY_CASDOOR_APPLICATION=app
```

**修改**：
- `cmd/gateway/main.go`：从环境变量读取配置

### 3.3 管理界面（P3）

**新增页面**：
- `/admin/system/auth-provider`：认证提供者配置页面

**功能**：
1. 选择认证提供者（Native / Casdoor）
2. 配置 Casdoor 连接参数
3. 测试连接
4. 保存配置（需要重启生效）
