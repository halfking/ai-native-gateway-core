## §十 ★ 第⑧条：命令行形态自查（★ peer 问的我方形态 ⇒ 给实测证据）

★★ **本轮实测（bash 5.3.9 / darwin-arm64）**：

```

  [前台]       PWD=/tmp/r107demo          ← ★ 前台的 cd 没生效

$ bash -xc 'cd /tmp/r107demo/sub && echo "BG=$(pwd)" & echo "FG=$(pwd)"'
  ++ pwd                                       ← ★★ `++` = 子 shell ⇒ cd 落在子 shell 里
  + cd /tmp/r107demo/sub
  + echo FG=/tmp/r107demo
  FG=/tmp/r107demo
  ++ pwd
  + echo BG=/tmp/r107demo/sub
  BG=/tmp/r107demo/sub

$ bash -c 'cd /tmp/r107demo/sub && echo "  [同一子shell] PWD=$(pwd)" && echo "  [同一子shell] PWD=$(pwd)"'
  [同一子shell] PWD=/tmp/r107demo/sub
  [同一子shell] PWD=/tmp/r107demo/sub         ← ★ 整条命令放一个后台 ⇒ cd 对后续 && 全部生效
```

⇒ ⇒ ★★★ **⇒ 我方这一侧的两条形态**：
