## 三、magpie 学习（结论与本轮落点）

仓内已有源码级对比文档 `docs/03-design/02-feature-design/simple-mode-v2-magpie-comparison.md`
（2026-11-16，magpie @ `ca3e57f94`，10 条事实 F1–F10、借鉴 B1–B5、不照搬 N1–N5）。
本轮在其上**补一轮「总览页专项」对照**：

| magpie 事实（源码级） | 本轮落点 |
|---|---|
| **F2 首页即清单**、**F6 关停折叠+计数** —— 已在 v2 落地（接入清单），本轮保留 | 不动 |
| **F10 页内标签而非新页面** —— magpie 在 Agents 页下挂 Allowances/Usage 页签 | 趋势卡用**指标切换**（请求数/Token/成本）而非三个页面 |
| **B1 首页清单化** 的反面教训（对比文档风险表 G1 自己登记过）：「首页换成清单后，今天花了多少变弱」——**这正是 owner 现在抱怨的点** | ⇒ 统计/趋势/系统状态补强在清单之上（G1 的处置补完） |
| magpie 的「一屏读三件事」：能用吗 → 用了多少 → 下一步 | 状态条(①) + 统计/趋势(②) + issue 动作/快捷操作(③) 的顺序纪律 |
| magpie 无租户/配额/审计（N2 不照搬） | 保留接入清单/上游健康/密钥面全部既有语义 |

**专家面「总监+看板」的可复用资产**（本轮真正借来的）：
`BoardOpsBar.vue`（后台任务+自检 chips，同一组件直接复用）、
`BoardHeroRow` 的 sparkPoints 模式（提成纯函数 `sparkPolylinePoints`）、
board `days=7` 端点口径（`trendBucketMinutes`: today=5m / 7d=15m / 30d+=1h，`admin/board_time_range.go:49`）。

## 四、修法（与专家面完全同口径，零新表零新端点）

### 4.1 数据面：3 请求 → 4 请求（全部既有端点）

```
fetchDashboardBoard({days:1})   今日口径 + operational（原有）
fetchDashboardBoard({days:7})   近 7 日 trends + summary（新增；= 专家面看板 7d 预设同一次调用）
getProviders()                  上游健康（原有）
getKeys()                       接入清单（原有）
```
四源 `Promise.allSettled` **独立降级**；days=7 失败只降级趋势卡，不拖累今日口径。

### 4.2 派生层（`simpleOverviewModel.ts`，全部纯函数 + 单测 55 条）

| 新增 | 语义 |
|---|---|
| `aggregateTrendByDay(trends)` | 15min 桶 → **UTC 日**聚合（与看板/对账日窗口径一致）；乱序桶升序输出；脏桶跳过不 NaN 中毒 |
| `fillMissingDays(points)` | 首末日之间补零日（数据源健康时 0 是真值：那天确实没流量）；**不发明数据范围外的日子**（新部署 3 天的系统不画 4 根凭空零柱）；400 日防死循环 |
| `lastDailyPoints(points, 7)` | 只留最近 7 个 UTC 日 |
| `deriveFailureCount(summary, errorsPie)` | 失败笔数：**pies.errors 求和优先，summary 推导兜底**（与 `BoardHeroRow.errorCount` 同口径）；两者都不可得 ⇒ **null 不是 0**；明细含脏数据 ⇒ 弃明细走兜底（半张表的和比兜底更错） |
| `sparkPolylinePoints(trends)` | 今日请求卡迷你趋势线（最近 16 桶，专家面英雄区同款） |
| `deriveOverviewStats` 扩展 | 成功率卡新增 `failures` 语境行；scope 语义订正 `active`→`enabled`（启用密钥）+`inUse`（在用模型） |

### 4.3 视图层（`SimpleOverviewView.vue`）

1. **状态条 issue 行内「去处理」按钮**（F3）：`ISSUE_ACTION_ROUTES` 映射
   （provider 族→`/providers`；selfcheck 族→`/dashboard?tab=selfcheck`）；
   权限不足/稍后重试两类**没有自助动作** ⇒ 不渲染按钮只留文案。
   映射表的路由字面量被**死链契约测试**扫描（写一个不存在的路径测试立刻红）。
2. **运维状态 chips**（F2）：复用专家面 `BoardOpsBar`（后台任务 + 系统自检，
   自检 chip 点击跳 selfcheck tab）——同一组件同一口径同一交互，**不另造一套**。
3. **统计卡**（F4/F5）：成功率卡语境行「失败 N 笔 · 今日口径」；
   请求卡带当日 5min 桶 spark；标签订正 **启用密钥 / 在用模型**（8 语种）。
4. **近 7 日消耗卡**（F1，新增区块）：指标切换（请求数/Token/成本，复用专家面文案键）+
   每日柱条（值标注在柱顶、UTC 日 M/D 标签）+ 7 天合计行（来自 days=7 summary）；
   **降级诚实**：days=7 失败 / `degraded_trends` / summary 降级 ⇒ 显示「趋势数据暂时读不到」
   占位符，**绝不画零线**（零线=「这七天一点消耗都没有」，是谎话）。
5. **最常用模型花费列**（F6）：`fmtUsd(m.cost_usd)`（今日口径，专家面同源）+ 面板口径提示行。

### 4.4 明确不动的（逐一检查后判定正确）

快捷操作 4 按钮（动作密度门禁；消耗入口由趋势卡承担，避免重蹈 /usage 死链）；
接入清单两分页列表+折叠计数；上游健康四档分级+截断披露；三步接入（完成自动消失）；
`pageHeader` 主按钮与模式 chip。
