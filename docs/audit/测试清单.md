## 3. 失败场景显示
### 网关失败（黄色）
- [ ] 鉴权限流：⚠ 网关失败 · auth · 请求频率超限
- [ ] 注入检测：⚠ 网关失败 · injection · 检测到注入攻击
- [ ] 路由失败：⚠ 网关失败 · route · 未找到可用路由

### 上游失败（红色）
- [ ] 供应商超时：⚡ 上游失败 · first_byte · 上游服务响应超时
- [ ] 上游状态码显示：HTTP 504

## 预期失败率
约15%的请求会失败，其中：
- 网关失败（auth/injection/route）：约10%
- 上游失败（upstream timeout）：约5%
