## ⚠️ 发现的系统性问题

### 1. 远程锁残留问题（高优先级）

**影响范围**：所有三个环境（211/154/245）

**表现**：
- 锁路径：`/var/lib/llm-gateway-go/deploy.lock/`（目录形式）
- 锁内容：`metadata` 文件包含已死进程信息
- 典型案例：
  ```
  pid=72146 (本地已不存在)
  source_host=niuerdeMacBook-Pro.local
  started_at=2026-11-24T19:42:37Z
  ```

**根因分析**：
- 部署脚本在异常中断时未正确清理锁
- 跨机器来源的锁无法自动判活
- 锁目录结构导致简单的文件检查失效

**解决方案**：
- **短期**：使用 `DD_FORCE_FOREIGN_LOCK=1` 环境变量
- **长期**：改进锁清理机制，增加超时自动过期

**建议**：
```bash
# 部署前清理残留锁
ssh <host> "sudo rm -rf /var/lib/llm-gateway-go/deploy.lock"

# 或使用强制选项
DD_FORCE_FOREIGN_LOCK=1 ./scripts/deploy-<env>.sh
```
