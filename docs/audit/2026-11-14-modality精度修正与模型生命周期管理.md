## 一、Modality 规则精度修正

### A1 问题定案

**现象**：211 生产库中 o1-mini/o3-mini-high/o4-mini-high 等模型 modality='text'，尽管现行规则表有 `{"o1-", "vision"}` 前缀规则。

**根因**：
1. 规则表中 `{"o1-", "vision", 1}` 前缀规则会把 o1-mini 等推断为 vision
2. 但 o1-mini 按 OpenAI 文档疑似**纯文本推理模型**（未公开披露图片支持）
3. 需要**精确例外规则**（priority 0）在前缀规则（priority 1）之前执行

**实证链**：
- 211 生产库：o1-mini (id=6) / o3-mini-high (id=2664494) / o4-mini-high (id=2664466) = text
- OpenAI 官方文档只披露 o1 (bare) 支持 text+image，o1-mini 能力未披露
- 规则推断逻辑：精确匹配优先级 0 > 前缀匹配优先级 1

## 二、模型生命周期管理功能

### B1 需求背景

**运营痛点**：2年前的大模型基本不再使用，但仍占用：
- 路由候选池空间（降低匹配效率）
- 监控资源（探针、健康检查）
- 管理后台显示噪声

**解决方案**：自动隐藏陈旧模型，同时保留运营灵活性。

### B2 数据库层（迁移 966）

**新增列**：`models_canonical.released_at TIMESTAMPTZ`

```sql
ALTER TABLE models_canonical
  ADD COLUMN released_at TIMESTAMPTZ;

CREATE INDEX idx_models_canonical_released_at
  ON models_canonical(released_at)
  WHERE released_at IS NOT NULL AND status != 'disabled';
```

**新增设置**：`settings_kv` 表

```sql
INSERT INTO settings_kv (key, value, value_type, scope, category)
VALUES (
  'model_lifecycle.stale_threshold',
  '"2 years"'::jsonb,
  'string',
  'platform',
  'routing'
);
```

**回滚脚本**：`966_model_lifecycle.down.sql` 提供完整回滚路径。

### B3 数据回填工具

**工具**：`cmd/tools/backfill-release-dates/main.go`

**数据源**：
- OpenAI: platform.openai.com/docs/models

**安全特性**：
- 只填充 NULL released_at（幂等，可重跑）
- 不触碰手动设置的日期
- 升级型（never changes existing non-NULL dates）

### B4 路由层过滤逻辑

**位置**：`provider/client.go` 候选加载 SQL

**过滤条件**（插入 WHERE 子句）：

```sql
AND (
    COALESCE(mo.manual_priority, 0) > 0  -- manual priority always included
    OR mc.released_at IS NULL            -- unknown age: fail-open (include)
    OR (
        mc.released_at IS NOT NULL
        AND age(now(), mc.released_at) <= (
            SELECT COALESCE(
                (value::text)::interval,
                '2 years'::interval
            )
            FROM settings_kv
            WHERE key = 'model_lifecycle.stale_threshold'
        )
    )
)
```

**设计要点**：
1. **手动优先级豁免**：`manual_priority > 0` 的模型不受年龄限制（运营可强制保留任何模型）
2. **Fail-open**：released_at IS NULL 放行（未回填的模型继续可用，不阻断业务）
3. **动态阈值**：从 settings_kv 读取，可通过管理 API 热更新
4. **默认 2 年**：平衡模型新鲜度与候选池大小
