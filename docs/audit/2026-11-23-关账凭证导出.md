# 2026-11-23 关账凭证导出

关账窗为北京时间 **2026-11-23 00:00:00（含）至 2026-11-24 00:00:00（不含）**，即 UTC `[2026-11-22 16:00:00Z, 2026-11-23 16:00:00Z)`。数据库记录用一个 PostgreSQL 连接，在同一个 `REPEATABLE READ READ ONLY` 事务内导出。导出脚本适用于经授权的 211 同源隔离恢复库。分布式恢复库须使用同一次协调器与工作节点一致性恢复的副本。

## 凭证清单

| 文件 | 来源和范围 | 保留的对账信息 |
| --- | --- | --- |
| `00-snapshot.csv` | 整批共用的事务 | 恢复件编号、数据库名、事务起点、快照标记、关账窗、隔离级别和只读标记 |
| `01-attempts.csv` | `provider_call_attempts`，确认发送按 `sent_at` 入窗。其余按 `prepared_at` 入窗 | 一次发送一行，保留确认状态、业务或平台归属、请求及父请求键、供应商请求 ID、原始计量、合同快照、测算金额和响应原币金额 |
| `02-invoices.csv`、`03-invoice-lines.csv` | 账期与日窗重叠的 `provider_invoices` 与其完整 `provider_invoice_lines` | 原结算账户、凭据范围、币种、原账期、账面应付、导入内容哈希、原始行项键及分桶计量。仅两端都相同的账期标记 `exact_close_day`。长账期的整账应付保留原值，不摊派为日金额 |
| `04-contract-rates.csv` | 生效期与日窗有交集的 `supplier_contract_rates` | 供应商、凭据、模型、原币、计价条款、版本、生效期、导入时间及内容哈希。逐次核对优先用发送行已冻结的合同快照。补查费率版本时同时核对发送时是否已导入，回填的合同版本单独标明 |
| `05-request-postings.csv` | `credit_ledger_with_current_month`，按记账时间入窗 | 原始带符号积分、过账 ID、租户、请求、积分池和类型。`consume` 为负值时计入毛实扣。`refund`、`reversal` 单独核对。`adjust`、`adjustment` 计入净过账，保留原类型 |
| `05b-post-close-returns.csv` | 同一快照内，关账窗之后、采集前已记账且能关联到当日扣费请求的退款或冲正 | 保留原过账时间和请求链。请求关联用于找跨日候选，逐笔冲正指向以原始账务凭证为准 |
| `06-wal-receipts.csv`、`07-usage-facts.csv` | WAL 按收件时间，源事实按发生时间 | 保留租户、请求、父请求、状态及源事实版本，供同日两种口径交叉核对 |
| `08-v2-projection.csv` | 源库存在 V2 投影视图时导出当日投影 | 对拍源事实的 ID、版本、终态时间及覆盖。视图缺失在 `00-snapshot.csv` 标注，可用同批源事实继续核对 |
| `manifest.csv` | 数据库事务成功提交后在本地生成 | 每个 CSV 的记录数、字节数及 SHA-256。零数据行表示这份快照未观测到记录 |

供应商应付、供应商响应金额和内部积分各自保留原单位。若还要核对支付渠道或财务系统中的现金实扣、冲正，请同时提供同次采集的原始分录及对应快照或批次标记。数据库里的账单行是已存证的导入记录。若账单、合同或财务分录尚在外部系统，用同一结账截点的冻结版本和来源凭证标明，并记录归档哈希及与本批的对应关系。

## 只读导出命令

在能直连隔离恢复库的机器上运行，使用 PostgreSQL 原生 `psql` 客户端。先将本地 PostgreSQL service 指向当次授权的隔离恢复库，并配置相应凭据。在当前 shell 中为 `PGSERVICE` 设置该连接配置名（例如 `211-closeout-ro`），为 `CAPTURE_REF` 设置实际恢复件编号或一致性备份编号。账号须已有覆盖完整证据范围的只读权限。脚本设置 `row_security=off`，若行级策略会过滤查询则 PostgreSQL 报错，避免把权限过滤误记为缺凭证。

```bash
(
  set -eu
  umask 077
  : "${PGSERVICE:?请设置隔离恢复库的连接配置名}"
  : "${CAPTURE_REF:?请设置本次恢复件或一致性备份编号}"
  export PGSERVICE CAPTURE_REF
  export PGCLIENTENCODING=UTF8
  export PGOPTIONS='-c default_transaction_read_only=on'

  export_sql='/Users/niuer/.codex/worktrees/request-metrics-v2/llm-gateway-go-3/docs/audit/evidence/2026-11-23-closeout-readonly.sql'
  psql_bin="${PSQL_BIN:-psql}"
  out=$(mktemp -d "$HOME/closeout-2026-11-23.XXXXXX")
  printf '导出目录：%s\n' "$out"
  cd "$out"
  "$psql_bin" -X -w -v ON_ERROR_STOP=1 -v "capture_ref=$CAPTURE_REF" -f "$export_sql" >run.log 2>&1

  python3 - <<'PY'
import csv
import hashlib
from pathlib import Path
import sys

csv.field_size_limit(sys.maxsize)
snapshot_path = Path("00-snapshot.csv")
with snapshot_path.open(encoding="utf-8", newline="") as stream:
    records = list(csv.DictReader(stream))
if len(records) != 1:
    raise SystemExit("Expected one snapshot descriptor")
snapshot = records[0]
if snapshot["isolation"] != "repeatable read" or snapshot["read_only"] != "on":
    raise SystemExit("Expected a repeatable-read, read-only transaction")

files = [
    "00-snapshot.csv", "01-attempts.csv", "02-invoices.csv", "03-invoice-lines.csv",
    "04-contract-rates.csv", "05-request-postings.csv", "05b-post-close-returns.csv",
    "06-wal-receipts.csv", "07-usage-facts.csv",
]
if snapshot["has_v2_projection"] == "t":
    files.append("08-v2-projection.csv")

manifest = []
for name in files:
    path = Path(name)
    with path.open(encoding="utf-8", newline="") as stream:
        reader = csv.reader(stream, strict=True)
        header = next(reader)
        rows = 0
        for row in reader:
            if len(row) != len(header):
                raise SystemExit(f"Malformed row in {name}")
            rows += 1
    digest = hashlib.sha256()
    with path.open("rb") as stream:
        for block in iter(lambda: stream.read(1024 * 1024), b""):
            digest.update(block)
    manifest.append((name, rows, path.stat().st_size, digest.hexdigest()))

with Path("manifest.tmp").open("w", encoding="utf-8", newline="") as stream:
    writer = csv.writer(stream)
    writer.writerow(("file", "rows", "bytes", "sha256"))
    writer.writerows(manifest)
Path("manifest.tmp").replace("manifest.csv")
PY
  printf '导出完成：%s/manifest.csv\n' "$out"
)
```

如需指定客户端路径，可先设置 `PSQL_BIN`。命令使用 Python 3 生成本地校验清单。SQL 只执行查询和 `COPY TO STDOUT`，CSV 由 `psql` 写到本机目录。空值的 CSV 标记是未加引号的 `\N`。命令中断或报错时以 `run.log` 排查，缺少 `manifest.csv` 的目录视为未完成。重新导出会创建新目录，凭证整批使用。

交回私有目录路径及清单即可。导出包含供应商账号标识、关联键和合同条款，保留文件原字节用于核验。生产切换暂缓。
