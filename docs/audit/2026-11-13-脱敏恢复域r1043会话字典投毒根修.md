### 1.3 三条根因链（r1043 D1/D2/D3，本地以生产快照规则逐字复现）

| # | 形状（逐字） | 旧行为 | 危害 |
|---|---|---|---|
| D1 标记投毒 | `SSH_USER="[REDACTED:account]"` | account_declaration 命中，**标记本身**铸成占位符值 | 还原器此后把标记当真值永久写回输出；标记成为会话词汇表永久成员 |
| D2 代码投毒 | `if 'SSH_USER=' in l or l.startswith('[ -n "$SSH_USER" ]'):`（值文法的引号臂捕获 `' in l or l.startswith('`）、`user=\$(docker`、`DB_USER=${DB_USER:-$(whoami)}` | 模型代码片段被当「账号」铸造；**输入侧把含引号的 span 挖走换占位符** | 模型收到的代码语法残缺（成对引号被吃掉一侧）；模型按残缺理解重写文件 ⇒ `bash -n` 从未再通过＝**「命令执行失败」本体** |
| D3 知名账号触发 | `SSH_USER="root"` / `USER=root` | root 占位符化 | 模型发现「有过滤器在改我的文件」⇒ 开始写修补代码 ⇒ 引爆 D1/D2 |

事故时间线：D3 触发 → 模型写 Python 修补脚本在 `[REDACTED:account]`/占位符文本上做字符串手术 →
D2 把修补代码本身铸成毒值（account:34/35/22）→ D1 把标记铸成毒值（account:6/36）→
回显这些占位符时还原器写回毒值/标记 → 文件被写坏 → bash -n 失败 → 模型二分排查 →
进一步改写 → 循环。用户看到的即「敏感信息没有恢复，命令执行失败」。

### 1.4 既有防线为什么没挡住（同族第五/六次复发）

r1030/r1042 已给「网关自产标记的**回声**」做过检测免疫（`detectionExemptSpans`：
花括号原形、带词退化、无词尾巴）——但只覆盖 `{SENSITIVE:…}` 族，**不覆盖
`[REDACTED:…]` 遮蔽标记**（r1038 起标记一律带类型，形状恰落在声明族值文法内）；
也不覆盖「值是代码片段」。§705 的结论（自己产的 token 被自己的规则命中是一类
结构性误报）在**遮蔽标记**与**值文法过宽**两个新面上再次应验。

## 八、追加轮 r1045：owner 裁决「客户端一级一定要还原」（2026-11-13 同日）

> owner 原话：「我们需要对于脱敏的信息在客户端一级一定要还原，不然执行工具或
> 显示内容都会出错。」

### 8.1 裁决的工程翻译与穷举

把裁决落成不变量：**凡网关脱敏过的信息（字典有条目），在任何客户端可见
lane/协议/降级条件下都必须以原值到达客户端**——不允许裸占位符、也不允许
`[REDACTED:*]` 替代。逐面穷举后的结论：

| 面 | 结论 |
|---|---|
| 还原链（三协议×文本/tool args/function_call/anthropic input） | 请求级字典经 `r.Context()` 全程可达（handler.go 三处 `newInterceptingStreamWriter(..., r.Context(), ...)` 实证）；Redis 中途故障/字典丢失由 ctx 本地字典兜底（loadMap 错误回退 local）——**r1045 钉测钉住**（流式全 lane 往返 + 中途删键仍还原） |
| 非流式未知信封 | `maskUnrecognizedBody` 先还原已知值、残余 fail-closed——不变量成立 |
| 降级（无 session/双 map 皆空） | 该条件下出现的占位符必然是模型伪造（无可还原物）——mask/block 是正确语义，登记不修 |
| **mandatory 守卫的遮蔽改写** | **唯一的「客户端可见 mask」常规生产者**（`shouldRedact: mandatory⇒true` 把检测命中改写成 `[REDACTED:*]` 下发；thinking 等不可改写 lane 则 rewrite_refused 杀回合）——r1042 轮登记的 owner 裁决面（「关闭输出检查」两次尝试未果 + thinking 杀回合降级 observe），**本轮由 owner 本裁决落定** |

### 8.2 实施：拆「检查」与「遮蔽改写」（新开关 `sanitize.output_mask_enabled`，默认 false）

- **语义拆分**：输出**检查**（检测/台账/审核单/硬拦清单执行）不受影响，仍由
  `sanitize.output_check_enabled`（默认 true）总控；占位符**还原**链不涉本开关；
  本开关只管「把无字典条目的命中（模型自造值）改写成 `[REDACTED:*]`」。
- **默认 false**＝客户端字节原样下发，命中照常进 observe 台账/审核面；显式
  true 恢复旧行为（文本 lane 遮蔽、不可改写 lane rewrite_refused）。
- 接线三处：`shouldRedact`（流式 mandatory 臂）/`processBody`（非流式）/
  启动日志 `mask_enabled` 字段；`settings.Global == nil` 的纯单元环境回退
  legacy（与 `redactionMode()` 同款先例）。
- **硬底不变**：硬拦清单（egress sink/凭据字段）的 **Blocked 是拦不是遮**，
  与本开关正交——r1045 钉测钉住「mask 开关无论开关，Blocked 照拦」。
