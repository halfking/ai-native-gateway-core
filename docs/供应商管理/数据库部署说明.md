# 供应商画像系统数据库部署说明

## 迁移脚本位置

- **正向迁移**: `deploy/sql/migrations/2026-07-26-provider-profile-system.sql`
- **回滚脚本**: `deploy/sql/migrations/2026-07-26-provider-profile-system.down.sql`

## 部署到252服务器

```bash
# 方式1: 直接执行
psql -h 192.168.1.252 -U postgres -d llm_gateway -f deploy/sql/migrations/2026-07-26-provider-profile-system.sql

# 方式2: 通过SSH
ssh user@192.168.1.252
cd /path/to/llm-gateway-go
psql -U postgres -d llm_gateway -f deploy/sql/migrations/2026-07-26-provider-profile-system.sql
```

## 部署到本地Docker

根据你的Docker容器配置，选择以下方式之一：

### 方式1: 通过docker exec

```bash
# 找到正确的容器名称
docker ps | grep postgres

# 复制SQL文件到容器
docker cp deploy/sql/migrations/2026-07-26-provider-profile-system.sql <container_name>:/tmp/

# 执行迁移
docker exec <container_name> psql -U <username> -d llm_gateway -f /tmp/2026-07-26-provider-profile-system.sql

# 示例（需要替换实际的容器名和用户名）
docker exec distribution-bc-pg17 psql -U <actual_user> -d llm_gateway -f /tmp/2026-07-26-provider-profile-system.sql
```

### 方式2: 通过管道

```bash
cat deploy/sql/migrations/2026-07-26-provider-profile-system.sql | \
docker exec -i <container_name> psql -U <username> -d llm_gateway
```

### 方式3: 直接连接（如果本地PostgreSQL可访问）

```bash
psql -h localhost -p 5432 -U postgres -d llm_gateway -f deploy/sql/migrations/2026-07-26-provider-profile-system.sql
```

## 验证部署

执行以下SQL验证表是否创建成功：

```sql
-- 列出所有画像相关的表
SELECT tablename 
FROM pg_tables 
WHERE schemaname = 'public' 
  AND tablename LIKE 'provider_profile%'
ORDER BY tablename;

-- 应该看到以下6个表：
-- provider_cost_reconciliation
-- provider_credibility_tests
-- provider_profile_alerts
-- provider_profile_daily
-- provider_profile_metrics
-- provider_profile_whitelist

-- 验证credentials表的扩展字段
SELECT column_name, data_type 
FROM information_schema.columns 
WHERE table_name = 'credentials' 
  AND column_name LIKE 'auto_%'
ORDER BY column_name;

-- 应该看到4个字段：
-- auto_disabled_at
-- auto_disabled_reason
-- auto_enabled_at
-- auto_enabled_reason
```

## 注意事项

1. **备份**: 在生产环境执行前，建议先备份数据库
2. **权限**: 确保执行用户有CREATE TABLE和ALTER TABLE权限
3. **时区**: 所有TIMESTAMPTZ字段使用数据库时区设置
4. **索引**: 迁移会自动创建所有必要的索引
5. **幂等性**: 脚本使用`IF NOT EXISTS`，可以安全地重复执行
