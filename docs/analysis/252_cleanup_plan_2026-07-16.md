## 清理优先级

### P0 - 立即执行（预计释放10GB）

#### 1. 查看哪些表使用了columnar
```bash
sshpass -p "$SSH_PASS" ssh -p 25022 root@115.29.212.252 \
  'docker exec pg-252-pg17 psql -U llm_gateway -d llm_gateway -c "
SELECT 
    t.tablename,
    pg_size_pretty(pg_total_relation_size('"'"'public.'"'"' || t.tablename)) as size
FROM pg_tables t
WHERE EXISTS (
    SELECT 1 FROM columnar.options o 
    WHERE o.regclass = ('"'"'public.'"'"' || t.tablename)::regclass
)
ORDER BY pg_total_relation_size('"'"'public.'"'"' || t.tablename) DESC;
"'
```

#### 2. VACUUM FULL columnar表（预计释放8-10GB）
```bash
# 先备份
sshpass -p "$SSH_PASS" ssh -p 25022 root@115.29.212.252 \
  'docker exec pg-252-pg17 pg_dump -U llm_gateway -d llm_gateway \
   --schema-only > /tmp/schema_backup_before_vacuum.sql'

# VACUUM FULL（这会锁表，建议低峰期执行）
sshpass -p "$SSH_PASS" ssh -p 25022 root@115.29.212.252 \
  'docker exec pg-252-pg17 psql -U llm_gateway -d llm_gateway -c "
VACUUM FULL request_logs_hot;
VACUUM FULL request_logs_2026_07;
VACUUM FULL usage_ledger_2026_07;
VACUUM FULL request_wal_hot;
VACUUM FULL routing_decision_log_2026_07;
"'
```

#### 3. 清理旧数据
```sql
-- 清理3周前的失败日志（释放~10MB）
DELETE FROM candidate_failure_logs 
WHERE ts < NOW() - INTERVAL '21 days';

-- 清理7天前的handoff日志（释放~200MB）
DELETE FROM handoff_logs 
WHERE created_at < NOW() - INTERVAL '7 days';

-- 清理旧的self_check数据（释放~5MB）
DELETE FROM self_check_round_results 
WHERE created_at < NOW() - INTERVAL '7 days';
```

#### 4. 重建膨胀的索引（释放~500MB）
```sql
-- request_logs_hot索引从351MB重建
REINDEX TABLE request_logs_hot;

-- handoff_logs索引从232MB重建
REINDEX TABLE handoff_logs;
```

### P2 - 2周内实施

#### 7. 创建自动清理脚本
```bash
cat > /opt/scripts/cleanup_old_logs.sh << 'SCRIPT'
#!/bin/bash
# 每日自动清理旧日志

docker exec pg-252-pg17 psql -U llm_gateway -d llm_gateway << 'SQL'
-- 保留14天
DELETE FROM candidate_failure_logs WHERE ts < NOW() - INTERVAL '14 days';
DELETE FROM handoff_logs WHERE created_at < NOW() - INTERVAL '14 days';
DELETE FROM self_check_round_results WHERE created_at < NOW() - INTERVAL '14 days';

-- 每月归档
VACUUM ANALYZE candidate_failure_logs;
VACUUM ANALYZE handoff_logs;
SQL
SCRIPT

chmod +x /opt/scripts/cleanup_old_logs.sh

# 添加到crontab（每天凌晨2点）
echo "0 2 * * * /opt/scripts/cleanup_old_logs.sh >> /var/log/db_cleanup.log 2>&1" | crontab -
```

#### 8. 监控脚本
```bash
cat > /opt/scripts/monitor_db_size.sh << 'SCRIPT'
#!/bin/bash
# 每日监控数据库大小

SIZE=$(docker exec pg-252-pg17 psql -U llm_gateway -d llm_gateway -t -c \
  "SELECT pg_database_size('llm_gateway') / 1024 / 1024 / 1024;")

echo "$(date): Database size = ${SIZE}GB" >> /var/log/db_size.log

# 如果超过20GB发送告警
if (( $(echo "$SIZE > 20" | bc -l) )); then
    echo "WARNING: Database size exceeded 20GB!" | mail -s "DB Size Alert" admin@example.com
fi
SCRIPT

chmod +x /opt/scripts/monitor_db_size.sh
echo "0 3 * * * /opt/scripts/monitor_db_size.sh" | crontab -
```
