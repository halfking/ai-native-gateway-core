# 免费/低价 LLM 集成策略

## 目标与边界

免费服务不是固定容量或永久权益。供应商的价格、免费池、速率限制、模型可用性和资格条件都可能变化，必须在运行时从官方配置/控制台同步并记录生效时间；文档不承诺“无限量免费”、固定每日额度或固定月成本。

## 推荐运行模式

```text
结构化特征模型/规则（主路径）
          |
          +--> 官方免费池 shadow（默认不影响线上决策）
          |       记录 provider、版本、延迟、错误和结果元数据
          |
          +--> 低价直连模型（受预算、限流、健康检查控制的后备）
          |
          +--> 规则/本地结构化模型（最终降级）
```

免费池的用途是质量、延迟和可用性基准，以及受控实验；只有满足明确的离线和线上门槛后，才可在小流量灰度中影响决策。禁止把免费池当作容量保证或单点依赖。

## Provider 配置

每个 provider 至少维护：官方来源标识、配置版本、生效时间、模型 ID、当前价格/免费资格状态、请求/Token 限制、密钥状态、健康状态、预算上限和熔断策略。未知或过期配额按不可用处理，不按“0 成本”处理。

## 路由与降级

- 默认先走本地规则/结构化特征模型，避免为常规请求调用外部 LLM。
- shadow 请求应采样、限流并隔离预算；其失败不影响主请求。
- 需要外部分类时，优先使用当前官方免费池（若资格有效），再走低价直连后备。
- 发生配额耗尽、价格变化、超时、错误率升高或合规风险时，熔断并回退。
- 不复制任何请求正文到 provider 记录、优化存储、标注系统或训练集；外部调用所需的内容只在受控请求生命周期内存在。

## 成本与验收

不使用未经官方证实的免费额度，也不输出固定的月成本、覆盖率或 99% 节省结论。上线前按真实流量测量：外部调用率、输入/输出 token、单次成本、免费池命中率、后备成本、错误率、P95 延迟和预算消耗。预算以保守的低价直连成本为上限，免费池节省只能作为可能收益。
