# 免费/低价 LLM 服务调研与运行口径

本文件是 [06-free-llm-integration.md](./06-free-llm-integration.md) 的补充说明，不维护第二套供应商额度表。任何 provider 的免费额度、价格、RPM/RPD、模型名称和地区资格必须以当前官方信息为准，并通过版本化配置动态更新。

## 采用原则

- “免费”只表示当前观察到的官方免费池或试用资格，不表示永久免费、无限量或生产容量保证。
- 免费池默认 shadow；先比较结构化特征模型、免费池和低价直连的质量、延迟、错误率与成本。
- 生产后备使用可预算、可限流的低价直连；免费池不可用时不能阻塞主链路。
- OpenRouter、Groq、Gemini、DeepSeek 或其他 provider 仅作为可配置候选，不在文档中硬编码未经复核的额度和价格。
- 供应商响应可能包含正文，响应只在受控调用生命周期内解析为分类结果；不得写入 `auto_route_selections` 或标注/训练存储。

## 运行时状态

建议监控 provider 的配置版本、官方信息最后同步时间、可用资格、限流剩余量、预算、成功率、P95 延迟和熔断状态。配置缺失、信息过期或无法确认资格时，应降级到低价直连或本地规则/结构化模型。

## 验证清单

1. 记录官方文档或控制台的复核日期与适用地区。
2. 在目标账户和生产密钥下验证真实额度，不把公开宣传值当作保证。
3. 建立月度预算上限和单请求 token 上限。
4. shadow 期间比较人工确认标签与模型结果，未达门槛不放量。
5. 使用 `cmd/autoclass-bench` 在审核过的样本集（JSONL：`{"text":...,"label":...}`）上量化候选 provider 的 accuracy、macro-F1、标签合规率、P50/P95 延迟和 429/5xx 率；只有通过质量门槛的 provider 才进入 fallback 链，高错误率者仅用于 shadow。
6. 定期复核价格、条款、数据使用政策和模型弃用通知。
