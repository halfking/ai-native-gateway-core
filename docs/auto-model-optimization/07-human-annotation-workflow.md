# 人工标注工作流

## 目标

人工标注用于校验自动任务类型、模型选择和边界案例。标注系统是从 `auto_route_selections` 派生的工作队列，不是新的事实表。

## 标注数据边界

标注任务默认只包含：

- `auto_route_selections` 的行 ID 与请求/会话/租户关联 ID；
- task_type、profile、classifier、confidence、候选/实际模型、rank/score、成功/延迟/成本/奖励等元数据；
- 版本化结构化特征（语言、长度桶、布尔标志、复杂度桶等）；
- 触发原因、标注员 ID、时间、状态、质量评分和审核备注。

标注任务**不得复制** prompt、messages、response、summary、会话历史、关键词原文、截断文本、embedding 或可逆内容特征。标注 UI 只展示上述元数据；如业务确实需要查看正文，必须通过既有受控审阅入口按权限临时读取，不把正文提交、缓存或导出到标注系统。

## 触发策略

按低置信度、模型分歧、异常 reward、用户覆盖/重试/错误、罕见结构化特征组合和分层随机抽样入队。触发规则只引用事实表字段与结构化特征，不查询或复制正文。

## 标签与质量

人工标签包括任务类型、推荐模型（可选）、置信度、标注员/审核员、触发原因、状态和质量元数据。标签通过 `selection_id` 关联回事实表；不在标签表中复制自动分类整行。采用双标/抽检、冲突复核和按类别统计一致性，阈值由实际样本量和业务风险确定。

## 训练导出

训练导出从事实表与已审核标签派生，去重、按时间切分并保留 dataset version、特征 schema version、标签来源和质量门槛。导出内容只含结构化特征与标签，不含正文。
