## 1. 目标与范围

**目标**：为 v4 需求的全部功能点提供可执行、可追溯、分阶段门禁化的测试资产——三级队列与请求注册表、自愈调度（重试/换节点/换模型/预算）、客户端保活与思考帧回显、节点/凭据自愈（URSM/探测/36h 回看）、请求快照与重启语义、会话三级制品（FR-11）、首字节后流中断透明恢复（FR-12）、会话唯一成功持久化。

**范围内**：Go 后端单元/集成/混沌测试；契约 fixtures；管理端 API 只读投影断言；T12 混沌矩阵与 SLO 基线的执行方法。

**范围外**（仅衔接，不在本册展开）：T9 前端 vitest 用例（`web/` 内既有 vitest + i18n:check 管道，见规格 T9）；T8 245 生产部署验收的现场步骤（本册提供其自动化底座与证据格式，现场执行以规格 T8 为准）；154 生产日志审计（T1，只读运维任务）。

### 3.2 新增夹具（随首个消费任务落地）

1. **脚本化 mock provider（`tests/lib/v4prov`，Go 包）**：在 LocalMockProviders 基础上支持按 (credential, model) 脚本编排逐次响应——固定错误码、`Retry-After` 头、首字节延迟、N 字节后连接重置（RST）、慢滴（chunk 间隔可配）、eof_without_done、空回复、tool-call/reasoning 帧、以及**请求指纹记录**（验证 L0 同节点重发与 prompt-cache 亲和时断言两次请求体一致）。OpenAI 与 Anthropic 双协议各一套。
2. **SSE 探针客户端（`tests/lib/v4sse`）**：以真实 HTTP 客户端消费流式端点，记录 (字节偏移, 时间戳, 帧类型) 时间线；提供断言器：任意 ≤N 秒窗口必有字节（心跳间隙）、注释帧/语义帧分类、最终 answer 与思考内容隔离校验、Zod 严格模式模拟（遇未知事件字段即失败，验证 L4/注释兜底）。
3. **journey/DB 断言器（`tests/lib/v4journey`）**：等待 request_logs_hot 出现终态行（轮询+超时），断言 `routing_attempts`、`error_kind`、t0–t9、`gw_session_id`、attempt 数、node_switched/model_switched/retry_scheduled 事件序列；journey 三源（内存/Redis/PG）一致性抽查。
4. **fake clock / 时钟注入**：退避、心跳、holdback 窗口、RPM 翻转、TTL 类用例要求被测代码提供可注入 clock/sleeper（**实现侧前置改造**，各 T 任务验收项）；未注入前这类用例以真时间 + 缩小参数运行并标注不稳定风险。
5. **URSM 断言工具**：直接读 `ursm:v2:node:t:{tenant}:{cred}:{model}` key（available/fail_streak/cool_until_ms/source_priority）与 pub/sub 频道，供 L3 断言运行时真值。

## 6. 混沌验证（L4，T12 —— N1–N20 执行规格）

环境：`tests/chaos/compose.chaos.yml`（gateway + pg + redis + toxiproxy + v4prov×3 + 探针）。入口 `tests/chaos/run_matrix.sh [--only N1,N14]`，逐场景产出 `reports/chaos/N<N>.json`（行为/偏差/证据），汇总进 `reports/STABILITY_CHAOS_<日期>.md`（对齐规格 T12 产出物）。

注入与断言映射（预期行为列直接引用规格 §14.1，此处补工具与测量点）：

| # | 注入方法 | 测量点/断言器 |
|---|---|---|
| CH-N1 客户端空闲 | 上游首字节延迟 120s | v4sse：任意 30s 窗口有字节；心跳分布 |
| CH-N2 客户端断开 | 探针主动 RST 客户端侧 | journey client_aborted；上游调用停止（v4prov 计数不再增长）；凭据不降级 |
| CH-N3 慢客户端 | socat 限速消费 | 写 deadline 后按断开处理（G7）；其它请求不受影响 |
| CH-N4 抖动重发 | 探针同会话重发 | AffinityKey 粘滞命中；制品命中；唯一成功 |
| CH-N5 队列溢出 | 并发洪峰 | overflow+Retry-After；重试风暴不放大（上游 QPS 曲线） |
| CH-N6 堆积水位 | 制造 completed>50/未完成接近 300 | 淘汰与满拒事件；内存上界 |
| CH-N7 资源泄漏 | kill -9 网关进程 | fpslot TTL 回收窗口；实例心跳加速回收（若实现） |
| CH-N8 单请求 panic | 注入 panic 场景 | safety-net 日志 + 请求级隔离（`handler.go:1532` 机制） |
| CH-N9 Redis 短抖 | toxiproxy 对 redis 注入 10s 网络中断 | 档位行为一致（保护性拒绝或宽限窗）；恢复后自动回池 |
| CH-N10 Redis 全停 | 停 redis 容器 5min | 与冻结档位一致；恢复后 NodeMirror 回源收敛 |
| CH-N11 PG 慢查询 | pg 注入锁等待/慢查 | 请求成功路径不受影响；观测缺口可结算 |
| CH-N12 连接失败 | toxiproxy 上游 TCP 拒连 | 首字节前换节点 <5s（P95）；思考帧可见 |
| CH-N13 首字节超时 | 上游挂起不响应 | 等待期心跳；wait-recovery+retry_at 生效 |
| CH-N14 流中断 | 首字节后 RST/EOF | FR-12 阶梯：L0/L1 零感知率、L2 对齐成功率、L4 可见中断计数 |
| CH-N15 慢滴 | chunk 间隔 300s+ | chunk 超时窗口内心跳维持；判死后走恢复阶梯 |
| CH-N16 429 | v4prov 429+Retry-After | 退避遵守；RPM 满载排除；窗口翻转回归 |
| CH-N17 节点 3 连败 | v4prov 持续 5xx×N 节点 | 降级+在途切换+冷却恢复全链 |
| CH-N18 空回复/瞬时错 | v4prov 空回复/5xx 混合 | free 容忍（streak 累计不禁用）；进入重试循环 |
| CH-N19 全组合穷尽 | 全部节点×模型失败 | 聚合错误；终止优先级（穷尽<预算时提前停） |
| CH-N20 凭据 401 | v4prov 401 | auth_failed+告警+15min 恢复窗；重试换凭据不浪费在坏凭据 |

SLO 基线采集（随矩阵产出）：流中断率、客户端可见中断率、首字节 P95、组合穷尽率、无字节最长间隙分布（数据源=request_logs+journey+URSM 窗口，探针 `tests/chaos/probes/slo.go`）。
