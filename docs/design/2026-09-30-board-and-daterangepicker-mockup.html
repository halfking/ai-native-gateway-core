实施边界（确认点）

本次做
  • 看板 tab=board 按 A 节重构（纯前端，board API 契约不变；RPM/TPM 前端现算）
  • 供应商成本采购块：成本/积分取 board pies.providers 现成字段（零后端改动）；评分复用对账报表接口 quality_score；统计列表用现有 getUsageByProvider；卡片/行点击跳 /providers/:id，「更多」保留 ProviderUsageExplorer 抽屉
  • KxDateRangePicker / KxDatePicker 组件族 + 看板/高频页接入（P0+P1）
  • 长尾页迁移 P2、裸日期输入守卫测试、8 语言词条
不做（避免范围膨胀）
  • 不改后端 board/usage API 与数据口径；不新增 per-model 费用字段（模型分布表不虚构费用列）

  • 粒度选择首期为"自动"只读展示，手动覆盖档位待二期
  • 趋势图表库仍用 chart.js（不迁移 echarts）；全局顶栏不动（筛选条在看板内容区顶部）
