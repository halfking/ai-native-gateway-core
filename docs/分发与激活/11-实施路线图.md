# 11. 实施路线图

> 5 个里程碑，区分 **主控端** 与 **客户端** 任务。Master 任务由内部团队负责，Customer 任务面向最终客户。

## 总览

```
M0 (W1-2)        M1 (W3-5)        M2 (W6-8)        M3 (W9-10)        M4 (W11-12)
双版本骨架        License 算法       升级守护进程     防盗版加固         整合与发布
   │                │                  │                │                │
   ├─ 双入口        ├─ RSA 签名        ├─ 守护进程       ├─ 防回拨        ├─ e2e 测试
   ├─ Build tags    ├─ AES-GCM         ├─ 蓝绿切换       ├─ 反调试        ├─ 文档完善
   ├─ 前端 variant  ├─ 指纹采集         ├─ 用户 API       ├─ 反篡改        └─ v1.14 GA
   └─ 打包脚本      └─ 激活器           └─ SSE 推送
                    └─ 验证器
```

## 风险与缓解

| 风险 | 缓解措施 |
|------|---------|
| License Authority API 与客户端激活 API 不兼容 | M1 中早期就定 API 契约（OpenAPI 规范） |
| 蓝绿切换导致服务中断 | nginx reload 测试 + iptables 兜底 |
| 时钟防回拨误报 | 容差 300 秒 + NTP 校时 |
| 前端 variant 切换导致菜单错乱 | 单元测试覆盖所有路径 |
| 客户反编译二进制暴露算法 | 主控端不打包客户端代码；关键路径混淆 |
| 试用 15 天到期后强制停止引发投诉 | 降级到 Community（不停止） |
