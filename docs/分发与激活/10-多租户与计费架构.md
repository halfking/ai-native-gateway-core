## 二、计费维度（未来 v2.x）

### 2.1 三种计费模式

#### 模式 A：按月 + 用户数（订阅）

```
月费 = 基础月费 + 用户单价 × 活跃用户数

例：
  Pro 套餐基础月费：¥200
  用户单价：¥10/用户/月
  10 个用户的月度账单：¥200 + 10 × ¥10 = ¥300 / 月
```

#### 模式 B：按 Token 用量

```
月费 = 基础月费 + 超额 token × 单价

阶梯定价：
  包含 token：1 亿/月（包含在基础月费中）
  超额部分：每 100M tokens = ¥0.01

换算：1K tokens = ¥0.0000001 = ¥10⁻⁷

例：
  月用量 1B tokens：
  = ¥200 (基础) + (1B - 100M) / 100M × ¥0.01
  = ¥200 + ¥0.9
  ≈ ¥200.9 / 月
```

#### 模式 C：混合（推荐）

```
月费 = max(按月+用户, 按 token)  取较大者
```

### 2.2 套餐定义

| 套餐 | 基础月费 | 包含 token | 用户单价 | Overage 单价 | 适用 |
|------|---------|----------|---------|-------------|------|
| Community | ¥0 | 100K/月 | ¥0 | - | 个人/试用 |
| Standard | ¥200 | 1 亿/月 | ¥10/用户 | 100M tokens = ¥0.01 | 中小企业 |
| Pro | ¥999 | 10 亿/月 | ¥8/用户 | 100M tokens = ¥0.008 | 中大型企业 |
| Enterprise | 议价 | 不限 | 议价 | 议价 | 大企业/集团 |

### 4.3 月度账单生成

```go
// license-authority/internal/billing/invoice_generator.go

func GenerateMonthlyInvoice(licenseID int64, period time.Time) (*Invoice, error) {
    // 1. 计算 period 内总 token 用量
    totalTokens := usageStore.GetPeriodTokens(licenseID, period)
    
    // 2. 计算 overage
    includedTokens := license.IncludedTokensPerMonth
    overageTokens := max(0, totalTokens - includedTokens)
    
    // 3. 计算用户数（活跃用户）
    activeUsers := userStore.CountActiveInPeriod(licenseID, period)
    
    // 4. 计算金额
    baseAmount := getPlanBaseFee(license.SubscriptionTier)
    userAmount := float64(activeUsers) * license.OveragePricePerUser
    tokenOverageAmount := float64(overageTokens/100_000_000) * license.OveragePricePerMillionTokens
    totalAmount := baseAmount + userAmount + tokenOverageAmount
    
    // 5. 写入 invoices 表
    invoice := &Invoice{
        ID: uuid.New().String(),
        LicenseID: licenseID,
        PeriodStart: period,
        PeriodEnd: period.AddDate(0, 1, 0),
        BaseAmount: baseAmount,
        UserAmount: userAmount,
        TokenOverage: overageTokens,
        TokenOverageAmount: tokenOverageAmount,
        TotalAmount: totalAmount,
        Status: "pending",
        DueAt: time.Now().AddDate(0, 0, 30),
    }
    
    return invoice, store.CreateInvoice(invoice)
}
```

## 五、租户限制

### 5.1 当前限制（v1.x）

| 套餐 | 租户上限 | 实现 |
|------|---------|------|
| Community | 2 | 按 tier 硬编码（`licensing/tenant_limit.go` 待实现） |
| trial | 2 | 同上 |
| standard | 3 | 同上 |
| professional | 10 | 同上 |
| enterprise | 不限 | 不校验 |

> **⚠️ 语义区分**：`License.MaxDevices` 字段控制**设备数**（一个 License 最多绑定几台机器），
> **租户上限**按 `subscription_tier` 硬编码，两者是不同维度。当前代码中无 `MaxTenants` 字段。

### 5.2 限制实现

```go
// licensing/tenant_limit.go（待实现）

func EnforceTenantLimit(ctx context.Context, license *License) error {
    active := tenantStore.CountActive(ctx)
    
    var maxTenants int
    switch license.SubscriptionTier {
    case "community", "trial":
        maxTenants = 2
    case "standard":
        maxTenants = 3
    case "professional":
        maxTenants = 10
    case "enterprise":
        return nil  // 不限
    default:
        return fmt.Errorf("unknown tier: %s", license.SubscriptionTier)
    }
    
    if active >= maxTenants {
        return fmt.Errorf("tenant limit reached (%d / %d). Please upgrade.", active, maxTenants)
    }
    return nil
}
```

```sql

SET 
    subscription_started_at = created_at,
    subscription_renews_at = created_at + INTERVAL '1 year',
    subscription_interval = 'yearly',
    included_tokens_per_month =
```
