```bash

cd llm-gateway-go-v1.13.0

# 2. 校验完整性
sha256sum -c checksums.sha256

# 3. （可选）编辑 deploy.yml
cp deploy.yml.example deploy.yml
vim deploy.yml
# 关键字段：
#   license:
#     key: KXGW-XXXX-XXXX-XXXX  # 留空 = 进入试用流程

#   telemetry:
```

### 3.3 部署场景差异

| 场景 | 入口命令 | 关键差异 |
|------|---------|---------|
| **单机离线**（客户专网） | `./install.sh` | 全部用离线包 |
| **单机在线**（云 VM） | `./install.sh` | 镜像从 registry.kxpms.cn 拉 |
| **K8s/k3s** | `./install.sh --mode k8s` | 生成 K8s manifests，kubectl apply |
| **Docker 直主机** | `./install.sh --mode docker` | docker compose up + systemd 集成 |
| **DB 独立部署** | `./install.sh --mode db-only` | 只起 PG + Redis，应用连远程 DB |

详见 [03-部署架构](./03-部署架构.md)。

```
POST https://llm.kxpms.cn/api/v1/trial

```

```
    "license_key": "KXGW-TRIAL-2026-A1B2",
```

### 4.4 License Key 激活流程

```
POST /api/system/license/activate
{
    "license_key": "KXGW-XXXX-XXXX-XXXX",
    "fingerprint": {...},
    "instance_id": "..."
}
```

```
→ POST https://llm.kxpms.cn/api/v1/activate
→ 验证 key 合法
→ 检查 max_devices
→ 创建/更新 license_devices 记录
→ 签发 signed_license
→ 返回

→ 写入 license.dat
→ 重启网关
→ 跳转到成功页（显示套餐类型、到期、设备数）
```

### 4.5 离线激活流程

完全断网环境（如政府/军工内网）：

**Step 1: 在客户机器生成激活请求**

```
$ /opt/kx-gateway/bin/llm-gw-installer activate \
    --key KXGW-AIRGAP-XXXX-XXXX \
    --mode offline-request \
    --output activation.req

✅ 已生成 activation.req
   文件位置: ./activation.req
   文件大小: 1.2 KB
   
请将此文件通过 U 盘 / 邮件 / 可信通道 传输到联网电脑
访问 https://llm.kxpms.cn/offline-activation 提交文件
```

**Step 2: 在联网电脑提交请求**

```
访问 https://llm.kxpms.cn/offline-activation
  → 上传 activation.req
  → 系统验证 + 签发 license.dat
  → 下载 activation.resp（实际是 license.dat 文件）
```

**Step 3: 在客户机器导入响应**

```
$ /opt/kx-gateway/bin/llm-gw-installer activate \
    --mode offline-import \
    --input activation.resp

✅ License 已导入: /var/lib/kx-gateway/license.dat
✅ 网关已重启激活

试用到期提醒：请联系销售续期
```

### 4.6 试用过期后的降级

试用到期后，不强制停止服务，降级到 Community 免费版：

```
Community 免费版限制：
  - 最多 2 个租户（用户必须删除多余租户）
  - 1 个 gateway 实例
  - 100K tokens / 天
  - 基础功能（路由、限流、审计）
  - 无高级功能（SAML、SSO、白标、远程命令）
  - 启动时显示"未授权商业使用"水印
```

## 六、Phase 5：试用转化 + 续费

### 6.1 试用期触达

| 时机 | 触达方式 | 内容 |
|------|---------|------|
| 试用第 5 天 | 站内 banner | "试用还剩 10 天" |
| 试用第 10 天 | 邮件 + banner | "试用还剩 5 天" + 限时折扣 |
| 试用第 14 天 | 邮件 + banner | "明天到期" + 升级引导 |
| 试用第 15 天 | 邮件 + 强制 banner | "试用已到期" + 选择：购买 / 降级 |

### 6.2 转化场景

**场景 A：用户决定购买**

```
→ 用户访问 https://llm.kxpms.cn/pricing
→ 选择套餐（Standard / Pro / Enterprise）
→ 下单支付
→ 收到 license key（邮件 + 站内信）
→ 在网关中输入 key
→ 自动从试用升级到正式版（无需重新部署）
```

**场景 B：用户决定降级到免费版**

```
→ 试用到期
→ 自动降级到 Community 免费版
→ 显示 2 租户限制水印
→ 用户可随时在设置中输入 License Key 升级到付费版
```

**场景 C：用户暂时搁置**

```
→ 试用到期
→ 自动降级到 Community
→ 数据保留（30 天）
→ 30 天后未激活 → 数据归档（不删除）
```

### 6.3 续费流程

**License 到期前提醒**：

```
30 天前：
  - 站内 banner（醒目标识）
  - 邮件提醒
  - 自动建议续费套餐

7 天前：
  - 每天弹窗提醒（登录时）
  - 邮件提醒
  - 支持一键续费

到期当天：
  - 服务不中断，降级到 Community
  - 用户可随时续费恢复
```
