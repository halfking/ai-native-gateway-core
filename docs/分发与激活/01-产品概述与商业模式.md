# 01. 产品概述与商业模式

## 一、产品定位

**llm-gateway-go** 是企业级 LLM API 统一网关，提供：

- 多 LLM 提供商统一接入（OpenAI / Anthropic / 国产大模型等）
- 请求路由、限流、降级、熔断
- 凭据管理（加密存储 + 自动轮转）
- 实时用量统计与成本控制
- 多租户隔离 + 审计日志

发行目标：**SaaS 化 + 私有化部署 + 离线授权** 三种形态并重。

## 二、商业模式

### 2.1 计费维度（当前 + 未来）

| 维度 | 当前（v1.x） | 未来（v2.x） |
|------|-------------|--------------|
| **许可证费** | 按实例/年（一次性） | 按月 + 用户数（订阅） |
| **功能授权** | 按套餐分级 | 同左 + 高级功能按模块加购 |
| **用量计费** | 不计费 | 按 Token 用量（100M tokens = 0.01 元） |
| **服务支持** | 社区支持 | 标准 / 高级 / 7x24 |
| **OEM/白标** | 不支持 | 支持（合作伙伴分销） |

| 套餐 | 价格 | License 类型 | 限制 |
|------|------|-------------|------|
| **Starter 初始版** | ¥0 | starter | DB 默认值；功能同 Community |

| **试用 Trial** | ¥0 | trial | 15 天 / 2 租户 / 1M tokens/总 |

### 2.3 未来按月+用户计费（架构预留）

```
月费 = 基础月费 + 用户单价 × 用户数 + token 用量费
例：
  基础月费：¥200
  用户单价：¥10/用户/月
  Token 用量：超出 100M 部分按 100M tokens = ¥0.01 阶梯计费
  （换算：1K tokens = ¥0.0000001 = ¥10⁻⁷）

示例：10 个用户，月用量 1B tokens
  = ¥200 + 10 × ¥10 + (1B - 100M)/100M × ¥0.01
  = ¥200 + ¥100 + ¥0.9
  = ¥300.9 / 月
```

**架构预留**（在数据库中保留相关字段，但暂不启用计费）：

```sql
-- 计费预留字段（v1.x 不计费，仅记录）
ALTER TABLE licenses ADD COLUMN IF NOT EXISTS
    -- 订阅相关
    subscription_started_at    TIMESTAMPTZ,
    subscription_renews_at     TIMESTAMPTZ,
    subscription_interval      TEXT DEFAULT 'yearly',  -- monthly/yearly
    billing_cycle_anchor       DATE,
    -- 用量计费
    included_tokens            BIGINT DEFAULT 0,
    overage_price_per_million  NUMERIC(10,4),  -- 元 per 1M tokens
    -- 用户数
    included_users             INT DEFAULT 0,
    overage_price_per_user     NUMERIC(10,4),
    -- 累计用量
    cumulative_tokens_used     BIGINT DEFAULT 0,
    current_period_tokens_used BIGINT DEFAULT 0,
    -- 计费状态
    billing_status             TEXT DEFAULT 'inactive',  -- inactive/active/past_due/canceled
    -- 发票/账单
    last_invoice_id            TEXT,
    last_invoice_amount        NUMERIC(12,2),
    last_invoice_at            TIMESTAMPTZ;
```

**token 用量计量**（v1.x 不计费但需采集）：

```sql
-- 每个请求的 token 用量记录到 telemetry（已存在）
SELECT 
    COUNT(*) AS requests,
    SUM(prompt_tokens + completion_tokens) AS total_tokens
FROM request_logs
WHERE tenant_id = ?
  AND created_at >= NOW() - INTERVAL '1 month';
```

### 2.4 Token 用量计量流程（未来）

```
请求进入
    ↓
chat handler 解析 prompt_tokens + completion_tokens
    ↓
写入 request_logs（已存在）
    ↓
异步更新 license.current_period_tokens_used
    ↓
每月 1 号：重置 current_period_tokens_used
        ↓
        计算 overage（如 100M 之外部分）
        ↓
        生成账单 → 发票 → 支付
```

## 三、产品形态

### 3.1 SaaS 模式（公网托管）

- 客户无需部署，直接调用 `api.llm.kxpms.cn`
- 按调用量计费
- 共享基础设施

### 3.2 私有化部署（客户自有环境）

- 客户在自己服务器/容器/K8s 部署
- 按 License 类型授权
- 数据完全自主

### 3.3 离线授权（军工/政府/金融）

- 完全断网环境
- 通过 U 盘/邮件分发 release 包 + license.dat
- License 由本地 CA 工具签发（合作伙伴持有私钥）

## 五、商业流程

### 5.1 获客漏斗

```
官网访问（llm.kxpms.cn）
    ↓
下载 release 包（无需注册）
    ↓
本地试用 15 天（自动试用 license）
    ↓
试用结束：2 选 1
    ├─→ 购买 → 激活正式版
    └─→ 不购买 → 降级到 Community（2 租户限制）
    ↓
持续使用 + 续费 + 升级套餐
```

### 5.2 客户旅程中的商业触点

| 触点 | 时机 | 内容 |
|------|------|------|
| **试用注册** | 第 1 次访问 | 邮箱 + 同意条款 → 立即开通 15 天 |
| **试用到期提醒** | 到期前 10/5/1 天 | 站内 banner + 邮件 |
| **续费提醒** | License 到期前 30/7/1 天 | 站内 banner + 邮件 |
| **升级推荐** | 用量增长时 | Pro → Enterprise 自动推荐 |
| **离线授权申请** | Air-gapped 客户 | 商务对接，签发离线证书 |
