# 03. 部署架构

> 5 种部署模式，覆盖单机、K8s、Docker、DB 独立等所有主流场景。

## 一、部署模式总览

```
                       ┌───────────────────────────────┐
                       │  部署入口 (install.sh)         │
                       └───────────────┬───────────────┘
                                       │
                ┌──────────────────────┼──────────────────────┐
                ▼                      ▼                      ▼
        ┌──────────────┐      ┌──────────────┐      ┌──────────────┐
        │  M1 单机离线 │      │  M2 单机在线 │      │  M3 K8s/k3s  │
```

## 二、5 种部署模式详解

### 2.1 M1 — 单机离线模式（standalone-offline）

**适用场景**：客户专网 / 隔离网 / 军工 / 政府

**架构**：

```
┌────────────────────────────────────────┐
│         客户机器（无外网）              │
│                                        │
│  ┌──────────────────────────────────┐ │
│  │  ~/llm-gateway/                  │ │
│  │  ├── compose.yml                 │ │
│  │  ├── .env                        │ │
│  │  ├── bin/llm-gw-installer        │ │
│  │  ├── db/                         │ │
│  │  │   ├── data/      (PG bind)   │ │
│  │  │   └── init/      (SQL dump)  │ │
│  │  ├── redis/data/   (Redis bind) │ │
│  │  ├── attachments/ (业务数据)    │ │
│  │  ├── app/logs/     (日志)       │ │
│  │  ├── license.dat   (激活证书)   │ │
│  │  └── reports/                    │ │
│  └──────────────────────────────────┘ │
│                                        │
│  ┌──────────────────────────────────┐ │
│  │  Docker Compose 全栈             │ │
│  │  ┌─────────┐ ┌─────┐ ┌────────┐│ │
│  │  │ kx-citus│ │redis│ │kx-llm- ││ │
│  │  │         │ │     │ │gateway ││ │
│  │  └─────────┘ └─────┘ └────────┘│ │
│  └──────────────────────────────────┘ │
│                                        │
│  端口：8781 (HTTP) / 5432 (PG) / 6379  │
└────────────────────────────────────────┘
```

**特点**：
- 所有镜像来自离线 tar.gz 包
- DB dump 一并打包
- License 通过离线 activation.req / .resp 文件流转
- 无需外网访问

**部署命令**：
```bash
./install.sh  # 自动检测离线包存在 → standalone-offline 模式
```

### 2.2 M2 — 单机在线模式（standalone-online）

**适用场景**：云 VM（阿里云、AWS）/ 个人云主机

**架构**：与 M1 完全相同，但镜像来源不同：

```
镜像拉取顺序（fallback 链）：
  1. ./images/*.tar.gz（离线包，若存在）
  2. registry.kxpms.cn（内部 registry）
  3. registry.cn-hangzhou.aliyuncs.com（阿里云 mirror）
  4. registry-1.docker.io（官方）
```

**特点**：
- 与 M1 完全相同的部署形态
- 镜像从公网拉取（4 层 fallback）
- License 走在线激活

### 2.3 M3 — K8s/k3s 模式（k8s）

**适用场景**：生产集群部署（如 184 环境）

**架构**：

```
┌───────────────────────────────────────────────────────┐
│            K8s/k3s 集群（生产推荐）                    │
│                                                        │
│  Namespace: kx-gateway                                 │
│                                                        │
│  ┌────────────────────────────────────────────────┐  │
│  │  Deployment: llm-gateway-go                    │  │
│  │  replicas: 3                                    │  │
│  │  ┌──────────┐ ┌──────────┐ ┌──────────┐       │  │
│  │  │ Pod-1    │ │ Pod-2    │ │ Pod-3    │       │  │
│  │  │ :8781    │ │ :8781    │ │ :8781    │       │  │
│  │  └──────────┘ └──────────┘ └──────────┘       │  │
│  │  image: kx-llm-gateway-go:v1.13.0             │  │
│  └────────────────────────────────────────────────┘  │
│                                                        │
│  ┌────────────────────────────────────────────────┐  │
│  │  StatefulSet: postgres                          │  │
│  │  ┌──────────┐                                  │  │
│  │  │ citus-0  │ (PG primary)                     │  │
│  │  └──────────┘                                  │  │
│  │  PVC: postgres-data-0 (50Gi)                   │  │
│  └────────────────────────────────────────────────┘  │
│                                                        │
│  ┌────────────────────────────────────────────────┐  │
│  │  Deployment: redis                             │  │
│  │  ┌──────────┐                                  │  │
│  │  │ redis-0  │                                  │  │
│  │  └──────────┘                                  │  │
│  │  PVC: redis-data-0 (5Gi)                       │  │
│  └────────────────────────────────────────────────┘  │
│                                                        │
│  ┌────────────────────────────────────────────────┐  │
│  │  Service: llm-gateway-go (ClusterIP:8781)     │  │
│  │  Ingress: llm-gateway.acme.com                 │  │
│  └────────────────────────────────────────────────┘  │
│                                                        │
│  ┌────────────────────────────────────────────────┐  │
│  │  ConfigMap: deploy.yml 配置                    │  │
│  │  Secret: license.dat (base64) + .env           │  │
│  └────────────────────────────────────────────────┘  │
│                                                        │
│  ┌────────────────────────────────────────────────┐  │
│  │  Job: postgres-init (db schema + seed)        │  │
│  └────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────┘
```

**特点**：
- 蓝绿部署友好（详见 [06-自动升级与蓝绿部署](./06-自动升级与蓝绿部署.md)）
- PVC 持久化
- 高可用（replicas ≥ 2）
- 滚动升级

**部署命令**：
```bash
./install.sh --mode k8s --config deploy.yml
# 内部执行：
#   1. 检测 kubectl / 集群连接
#   2. 渲染 K8s manifests
#   3. apply namespace / secret / configmap / pvc
#   4. apply statefulset (postgres) → 等待 ready
#   5. apply deployment (redis, app) → 等待 ready
#   6. 等待 job (postgres-init) 完成
#   7. 健康检查
```

### 2.4 M4 — Docker 直主机模式（docker）

**适用场景**：154 等直主机部署（无 K8s）

**架构**：与 M1 相同，但额外集成 systemd：

```
┌────────────────────────────────────────────┐
│         Docker Host（直主机）                │
│                                            │
│  ┌──────────────────────────────────────┐ │
│  │  systemd unit: kx-gateway.service   │ │
│  │  - Restart: on-failure              │ │
│  │  - WantedBy: multi-user.target      │ │
│  └──────────────────────────────────────┘ │
│                  │                          │
│                  ▼                          │
│  ┌──────────────────────────────────────┐ │
│  │  Docker Compose 全栈（同 M1）        │ │
│  └──────────────────────────────────────┘ │
│                  │                          │
│                  ▼                          │
│  ┌──────────────────────────────────────┐ │
│  │  bind-mount 持久化目录              │ │
│  │  /var/lib/kx-gateway/data/           │ │
│  └──────────────────────────────────────┘ │
│                                            │
│  /var/log/kx-gateway/  (journal + 文件)    │
└────────────────────────────────────────────┘
```

**特点**：
- systemd 集成（开机自启 + 故障重启）
- 比 K8s 模式轻量
- 适合单实例生产环境

### 2.5 M5 — DB 独立部署模式（db-only）⭐

**适用场景**：大客户需要独立 DB（性能、灾备、合规）

**架构**：

```
┌─────────────────────────────────────────────────────┐
│  业务集群                              DB 节点      │
│  ┌───────────────┐                  ┌────────────┐ │
│  │  llm-gateway  │ ──远程连接──────▶│  Citus     │ │
│  │  (无状态)      │                  │  Cluster   │ │
│  │  replicas: N  │                  │  主+从     │ │
│  └───────────────┘                  └────────────┘ │
│                                              │       │
│                                              ▼       │
│                                       ┌────────────┐ │
│                                       │  Redis     │ │
│                                       └────────────┘ │
└─────────────────────────────────────────────────────┘
```

**特点**：
- 只启动 PG / Redis，不启动应用容器
- 业务集群连接远程 DB
- 支持 PG 流复制（主从灾备）
- 输出"业务端接入指南"

## 三、部署架构组件

### 3.1 核心容器镜像

| 镜像名 | Tag | 大小 | 来源 |
|--------|-----|------|------|
| `kx-llm-gateway-go` | `v1.13.0` | 850 MB | 内部构建 |
| `kx-citus` | `v11.3.0` | 1.2 GB | 基于 `citusdata/citus:11.3.0` 重打 tag |
| `kx-redis` | `v7-alpine` | 50 MB | 基于 `redis:7-alpine` 重打 tag |

### 3.2 持久化目录

| 目录 | 容器内路径 | 内容 |
|------|----------|------|
| `db/data/` | `/var/lib/postgresql/data` | PG 数据 |
| `redis/data/` | `/data` | Redis 数据 |
| `attachments/` | `/opt/llm-gateway-go/data/attachments` | 业务附件 |
| `app/logs/` | `/var/log/llm-gateway` | 应用日志 |
| `license.dat` | `/var/lib/kx-gateway/license.dat` | 激活证书 |
| `config/` | - | MANIFEST.json + env.template |

### 3.3 端口规划

| 端口 | 服务 | 备注 |
|------|------|------|
| 8781 | 网关 HTTP API | 主入口 |
| 5432 | PostgreSQL | 容器内 |
| 6379 | Redis | 容器内 |
| 30080 | NodePort（K8s） | K8s 模式专用 |
| 8782/8783 | 蓝绿 slot | 升级专用 |

## 四、5 种模式的对比

| 维度 | M1 单机离线 | M2 单机在线 | M3 K8s | M4 Docker | M5 DB 独立 |
|------|----------|----------|------|----------|----------|
| 镜像来源 | 离线包 | fallback 4 层 | 内网 registry | 内网 registry | 内网 registry |
| 持久化 | bind-mount | bind-mount | PVC | bind-mount | PVC 或 bind-mount |
| 网络要求 | 无 | 公网 | 内网 | 内网 | 内网 |
| 蓝绿升级 | 通过 nginx 切换 | 通过 nginx 切换 | ✅ 原生支持 | 通过 nginx 切换 | 不适用 |
| 高可用 | 单点 | 单点 | 多副本 | 单点 | DB 主从 |
| 适用规模 | 小型 | 中小型 | 中大型 | 中型 | 大型 |
| 部署复杂度 | 最低 | 低 | 中 | 低 | 中 |

## 五、部署前配置（deploy.yml）

详见 [附录 A - deploy.yml 完整 Schema](./appendices/A-deploy.yml完整Schema.md)。

最小配置示例：

```yaml
# === 必填 ===
deployment_mode: standalone-offline  # 5 种之一
license:
  key: ""                            # 留空 = 进入试用
version:
  image_tag: "v1.13.0"

# === 常用配置 ===
image_source:
  strategy: "auto"
persistence:
  strategy: "bind-mount"
components:
  postgres:
    enabled: true
  redis:
    enabled: true
```

## 六、升级路径与部署模式的关系

| 部署模式 | 升级方式 |
|---------|---------|
| M1/M2 单机 | 直接重启容器（短暂中断） |
| M3 K8s | kubectl set image 滚动升级 / 蓝绿 |
| M4 Docker | docker compose up -d（保留 volumes） |
| M5 DB 独立 | 不升级（DB 独立） |

详细升级方案见 [06-自动升级与蓝绿部署](./06-自动升级与蓝绿部署.md)。
