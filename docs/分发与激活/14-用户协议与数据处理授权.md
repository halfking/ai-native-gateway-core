# KX Gateway 用户协议与数据处理授权

版本：2026-07-14

本协议适用于 KX Gateway 的安装、激活、运行状态服务、版本管理与更新服务。客户管理员在申请 Trial 或启用相关服务前，应完整阅读并明确同意本协议。

## 1. 运行遥测与服务可观测性授权

在客户明确选择启用运行遥测后，客户授权 KX Gateway 以最小必要、目的限定和去内容化处理原则，采集并处理与软件运行、服务质量、容量规划、故障诊断、安全运营和产品改良直接相关的运行状态数据。

运行状态数据包括：软件版本、实例标识、License 状态、资源使用率、服务可用性、聚合请求量、聚合时延、聚合错误分类、升级状态和告警状态。此类数据仅用于服务运营、可靠性改进、安全响应、版本兼容性分析和产品能力优化。

## 2. 版本通知与受控更新授权

客户授权 KX Gateway 向已激活实例发送版本可用性通知、兼容性提示、安全补丁提醒、升级任务编排信息和回滚建议。对于涉及服务重启、版本切换、数据库迁移或功能降级的更新操作，系统应遵循已配置的维护窗口、客户确认、审批策略和发布策略。

本授权不构成对任意远程命令、任意 shell 执行或绕过客户变更管理流程的授权。紧急安全更新、强制更新和远程协助仍须受 License、发布策略、审批记录和客户侧安全策略约束。

## 3. 不采集的数据

KX Gateway 不将下列数据纳入运行遥测或系统改良数据集：

- 原始 AI 会话内容、提示词、模型回复或推理链路内容。
- 用户上传文件、附件、知识库原文或业务文档内容。
- API Key、密码、访问令牌、私钥、模型供应商凭据或其他认证秘密。
- 原始 IP 地址、MAC 地址、完整主机名或可直接识别个人的信息，除非客户在独立业务流程中主动提交且法律允许。
- 错误响应体、请求正文或响应正文；系统仅保留经最小化处理的错误分类和聚合指标。

## 4. 数据最小化、保留与删除

运行状态数据按照字段白名单采集，并在传输和存储过程中采用访问控制、完整性校验和审计记录。客户可在产品设置中撤回运行遥测授权；撤回后，系统应停止新的运行状态采集，并按适用的数据保留和删除流程处理已有数据。

## 5. 客户责任与同意记录

提交 Trial 申请时，客户管理员确认其有权代表所属组织同意本协议。当前 Trial 服务会校验明确同意状态；协议版本、同意时间和申请标识的持久化审计记录属于 `FLOW-ACT-01` 的交付门禁，在该门禁完成前不得将其宣称为已具备的审计证据。

## 6. 协议更新

本协议如发生重大变更，KX Gateway 将通过版本更新通知、管理界面或其他合理方式提示客户管理员。需要重新同意的变更，不会仅凭历史同意状态自动扩大数据处理范围。
