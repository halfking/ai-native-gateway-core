# 08. 防盗版与安全

> 9 类盗版攻击场景及对应防御措施。基于现有 `licensing/` 包的能力 + M3 任务补全。

## 一、防御目标

保护官方 llm-gateway-go 不被：
1. 未授权使用
2. 一码多用
3. 篡改 license.dat
4. 时钟回拨绕过过期
5. 调试器分析
6. 二进制 patch 绕过
7. 虚拟机克隆扩散
8. 离线激活请求重放
9. 内部 license 生成工具泄漏

## 二、攻击场景与防御矩阵

### 2.1 场景 1：未授权使用

**攻击**：下载 release tarball，直接安装使用，不购买。

**防御**：
- ✅ 启动时强制 license 验证（`EnforceAtStartup()`）
- ✅ RSA 签名校验（无 license.dat 或签名错 → 拒绝启动）
- ✅ 重试有限次（连错 3 次 → 锁机重启）

**实现位置**：`cmd/gateway-client/main.go` + `licensing/enforce.go`

### 2.2 场景 2：一码多用

**攻击**：多个机器共用同一 license.dat。

**防御**：
- ✅ 机器指纹绑定（`MatchScore < 0.6` → 拒绝）
- ✅ `license.devices` 表限制 `max_devices`
- ✅ 在线激活时实时同步设备列表

**实现位置**：`licensing/fingerprint.go` + `licensing/validator.go:ValidateDevice()`

### 2.3 场景 3：篡改 license.dat

**攻击**：修改 license 字段（customer、expires_at、max_devices）。

**防御**：
- ✅ RSA-PKCS1v15-SHA256 签名验证（`VerifyLicense`）
- ✅ 修改任何字节 → 签名验证失败 → 拒绝

**实现位置**：`licensing/crypto.go:VerifyLicense()`

### 2.4 场景 4：时钟回拨绕过过期

**攻击**：系统时间改为过去，规避过期检查。

**防御**：
- 🔄 持久化最后启动时间 + 最后 license 验证时间（M1-C10 任务）
- 🔄 检测到时间倒退 > 容忍值 → 拒绝启动
- 🔄 在线激活时上传服务端时间戳，校验本地时间偏差

**实现位置**：`licensing/clock.go`（待实现）

```go
func (g *ClockGuard) ValidateLicense() error {
    now := time.Now()
    
    lastBoot, err := g.storage.LastBootTime()
    if err == nil && now.Before(lastBoot) {
        return errors.New("clock rollback detected")
    }
    
    lastVerify, err := g.storage.LastKnownLicenseVerify()
    if err == nil && now.Before(lastVerify.Add(-g.tolerance)) {
        return errors.New("license verify time rolled back")
    }
    
    return nil
}
```

### 2.5 场景 5：调试器分析

**攻击**：用 gdb/IDA 分析 license 验证逻辑，patch 二进制。

**防御**：
- 🔄 ptrace 检测（启动时检查是否被 trace）
- 🔄 LD_PRELOAD 检测
- 🔄 完整性自校验（启动时计算自身 SHA256 与硬编码常量对比）

**实现位置**：`licensing/antidebug.go`（M3-C12 待实现）

```go
func DetectDebugger() bool {
    // 1. ptrace 检测（仅 Linux）
    if runtime.GOOS == "linux" {
        data, err := os.ReadFile("/proc/self/status")
        if err == nil {
            for _, line := range strings.Split(string(data), "\n") {
                if strings.HasPrefix(line, "TracerPid:") {
                    // TracerPid:\t0 表示无 tracer，非 0 表示被 trace
                    parts := strings.SplitN(line, "\t", 2)
                    if len(parts) == 2 && strings.TrimSpace(parts[1]) != "0" {
                        return true
                    }
                }
            }
        }
    }
    
    // 2. LD_PRELOAD 检测
    if os.Getenv("LD_PRELOAD") != "" {
        return true
    }
    
    return false
}
```

### 2.6 场景 6：二进制 patch 绕过

**攻击**：用编辑器修改二进制指令，跳过 license 校验函数。

**防御**：
- 🔄 启动时自校验：SHA256(可执行文件) = 硬编码常量
- 🔄 关键函数多处冗余校验（10+ 个 check 点）
- 🔄 代码混淆（gobfuscate）

**实现位置**：`licensing/antitamper.go`（M3-C11 待实现）

```go
func VerifyIntegrity() bool {
    exe, err := os.Executable()
    if err != nil {
        return false
    }
    
    data, err := os.ReadFile(exe)
    if err != nil {
        return false
    }
    
    hash := sha256.Sum256(data)
    return hex.EncodeToString(hash[:8]) == "EXPECTED_HASH"
}
```

### 2.7 场景 7：虚拟机克隆

**攻击**：将激活的虚拟机克隆一份部署到其他机器。

**防御**：
- ✅ 机器指纹包含 Disk Serial + BIOS UUID
- ✅ 克隆后这两个字段会变 → 指纹比对失败
- 🔄 云平台 vendor 检测（aws/gcp/azure/alibaba）作为加权维度

**实现位置**：`licensing/enhanced_fingerprint.go`（M1-C11 待实现）

### 2.8 场景 8：离线激活请求重放

**攻击**：截获合法离线激活请求（activation.req），重放到服务端骗取 license。

**防御**：
- 🔄 请求中带 nonce（一次性，60 秒过期）
- 🔄 服务端维护已用 nonce 集合
- 🔄 重放请求 → nonce 已存在 → 拒绝

**实现位置**：`licensing/nonce.go`（M3-C13 待实现）

### 2.9 场景 9：内部 license 生成工具泄漏

**攻击**：内部员工泄漏 license 生成工具（private key），可签发任意 license。

**防御**：
- ✅ 主控端 license 生成工具不打包到客户端（双版本隔离）
- 🔄 私钥存储在 HSM / KMS
- 🔄 私钥使用需多人审批（双人复核）
- 🔄 license.dat 含运维审计编号（可追溯到签发人）

**实现位置**：build 流程 + `packaging/check-customer-binary.sh`

## 三、主控端 vs 客户端 License 强制策略

| 版本 | License 强制 | 实现 |
|------|------------|------|
| **Master** | ❌ 跳过（内置永不过期 master license） | `licensing.SkipEnforcement()` |
| **Customer** | ✅ 强制（启动时 + 24h + 关键操作前） | `licensing.EnforceAtStartup()` |

**保证 master 端永远验证通过**：

```go
// licensing/skip_enforce.go

func SkipEnforcement() {
    // 写入内置的 master license
    masterLic := generateMasterLicense()  // 内置 RSA 公钥签发
    os.WriteFile("/var/lib/kx-gateway/license.dat", masterLic, 0600)
}
```

## 四、安全事件响应

### 4.1 License 验证失败时

```
1. 记录审计日志（含 instance_id、错误类型、堆栈）
2. 通知主控端（如果在线）
3. 进入降级模式：
   - 限制为只读 / 1 租户
   - 显示"License 异常"水印
4. 客户可重新激活（不重新部署）
```

### 4.2 发现盗版/泄漏时

```
1. 远程吊销（CRL）
2. 通知客户机器下次心跳时拒绝
3. 强制下线（多次失败后）
4. 法律行动（针对大规模盗用）
```

## 六、关键决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| License 算法 | RSA-2048（已实现） | 现有稳定；签名验证快 |
| 时间防回拨容差 | 5 分钟 | 平衡 NTP 漂移 |
| 机器指纹匹配阈值 | 0.6 | 已实现，避免硬件微变导致误判 |
| 反调试严格度 | 检测到即拒绝 | 安全优先 |
| 二进制完整性校验 | 启动时校验 | 性能可接受 |
| 重放 nonce 有效期 | 60 秒 | 防重放 + 容错 |
| 盗版证据 | license_key_hash + instance_id | 可追溯到原始客户 |
