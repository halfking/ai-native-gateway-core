# 三项目站点融合部署规划（2026-10-27）

> 适用环境：245（预发布，llmgo.kxpms.cn）为基准环境；154（生产）与 211 按同
> 一约定渐进对齐。状态：**245 已全部落地并实测验证**；154/211 列为后续项。

## 0. 目标与原则

**外界看起来是一个站点（llmgo.kxpms.cn 单域），系统里是三个项目，业务逻辑
不是一个应用：**

| 项目 | 角色 | 进程形态 | 仓 |
|---|---|---|---|
| llm-gateway-go | 网关（SPA + API + 移动面） | 蓝绿 systemd（契约对 8781/8782） | llm-gateway-go |
| ai-native-maintain | 运维中心 / 产品首页 | 单实例 systemd | ai-native-maintain |
| ai-session-manager（ASM） | 会话运营插件与投影服务 | 蓝绿 systemd（对 8790/8791） | ai-session-manager |

原则：同域不同前缀、每项目自有发布/回滚通道、跨项目只经契约（HTTP API /
JWT / 事件），**不共享进程、不共享业务库表**。

## 2. nginx 拓扑（llmgo.kxpms.cn vhost = 唯一公网入口）

```
llmgo.kxpms.cn (252 边缘 nginx → 245 nginx 443)
├─ location = /            产品首页分流（?login→网关SPA；裸 / → /maintain/home；UA 移动 → /m/）
├─ location /              网关 SPA（current/web，try_files → /index.html）
├─ location ^~ /api/ /v1/ /v1beta/ /v2/ /m/ /m-assets/  → 网关（llmgo_local_245，随 run/active-upstream.conf 蓝绿）
├─ location ^~ /maintain/  /maintain/assets/  /maintain-api/ → maintain（静态 alias + 8082 反代）
└─ location ^~ /plugins/ai-session-manager/            → ASM（本轮新增）
   ├─ …/assets/   → alias /opt/asm/bin/current/web/assets/（immutable）
   ├─ …/api/      → proxy_pass http://asm_local_245/api/（upstream 随 /opt/asm/run/active-upstream.conf 蓝绿）
   └─ …/          → alias /opt/asm/bin/current/web/（vite base 同前缀，SPA 兜底 index.html）
```

- 两个蓝绿服务各有一个 `run/active-upstream.conf` 指针文件，部署晋级/回滚时
  由**各自的部署脚本**重写 —— nginx 配置不随发布改（「部署脚本写指针、
  nginx 只 include」是跨项目的统一惯例）。
- vhost 改动照 house 惯例归档：`deploy/nginx/active-20261027/`（改前备份在
  服务器：`llmgo.kxpms.cn.conf.pre-asm-fusion-20261027`）。
- **权限约定**：`/opt/asm` 是 0700（含密钥 env）；nginx worker 只依赖
  `o+x` 遍历位 + web 子树 `a+rX`，ASM 部署脚本已固化这两步
  （漏掉时融合 SPA 全站 500 而 root 探针全绿 —— 2026-10-27 实测）。

## 5. 认证边界（本轮**明确不做**的特性，设计已定）

ASM 强制 `aud=ai-session-manager-api`（代码常量），网关会话 JWT 是
`aud=llm-gateway-api` —— **直接把网关 cookie 当 Bearer 转发会被 ASM 的
audience 校验拒绝**。因此融合页面当前呈 ASM 自身的 honest-unavailable 状态。

**下一步特性（建议下一轮）**：网关新增会话级 token 交换端点
（如 `POST /api/v1/plugin-token/ai-session-manager`，AdminMiddleware 会话
认证 → 用共享 secret 签发 `aud=ai-session-manager-api`、短 TTL、scope 收窄
的 JWT）+ ASM SPA 启动时先换取 token 再调 API。ASM 侧零改动（它已按
issuer=llm-gateway + 该 audience 校验）。
