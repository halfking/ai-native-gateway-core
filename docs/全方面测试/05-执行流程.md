## 三阶段: 一键执行

使用现有脚本 `run-multidim-scenarios.sh` 自动执行 S1-S11:

```bash
# 前置: PostgreSQL + 60 mocks + gateway(:8082) 均已启动

cd /Users/xutaohuang/workspace/llm-gateway-go-3
bash scripts/run-multidim-scenarios.sh
```

该脚本会自动:
1. 检查 Gateway + DB + Mocks 是否就绪
2. 重置所有供应商到健康状态
3. 禁用 F 组 (免费池)
4. 依次执行 S1-S11
5. 每个场景保存结果到 /tmp/multidim-results/

## 四阶段: 生成报告

### 4.1 收集结果

```bash
# 汇总所有场景结果
python3 -c "
import json, os, glob
results = {}
for f in sorted(glob.glob('/tmp/multidim-results/*.json')):
    name = os.path.basename(f).replace('.json', '')
    with open(f) as fh:
        data = json.load(fh)
    results[name] = data

# 生成表格摘要
for name, data in results.items():
    total = data.get('total_requests', 0)
    success = data.get('success_count', 0)
    rate = (success / total * 100) if total else 0
    p95 = data.get('p95_latency_ms', 0)
    p99 = data.get('p99_latency_ms', 0)
    print(f'{name:40s} | {total:6d} req | {rate:5.1f}% | P95={p95:6.0f}ms | P99={p99:6.0f}ms')
"
```

### 4.2 生成完整报告

