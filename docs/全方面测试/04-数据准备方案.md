## 模型定义 (15 个, 不与真实模型重名)

```json
[
  "loadtest-mini-alpha",
  "loadtest-mini-beta",
  "loadtest-mini-gamma",
  "loadtest-standard-alpha",
  "loadtest-standard-beta",
  "loadtest-standard-gamma",
  "loadtest-pro-alpha",
  "loadtest-pro-beta",
  "loadtest-pro-gamma",
  "loadtest-ultra-alpha",
  "loadtest-ultra-beta",
  "loadtest-ultra-gamma",
  "loadtest-vision-alpha",
  "loadtest-vision-beta",
  "loadtest-vision-gamma"
]
```

每个供应商绑定 2-4 个模型, 覆盖 mini/standard/pro/ultra/vision 范围,
通过 credential_model_bindings.available=true 控制可用性。

## Credential 配置

### 加密 Key

```bash
LLM_GATEWAY_CREDENTIAL_ENCRYPTION_KEY="AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA="
```

所有凭证密文使用此 key 通过 AES-GCM 加密, 格式 `v1:legacy:xxx` (Fernet 兼容模式)。

### Credential 模板

```sql
INSERT INTO public.credentials (
    id, provider_id, tenant_id, label, secret_ciphertext,
    status, lifecycle_status, availability_state,
    quota_state, circuit_state, manual_disabled,
    fp_slot_limit, concurrency_limit
) VALUES (
    <provider_id>, <provider_id>, 'default', '<code>-key',
    'v1:legacy:<encrypted>',
    'active', 'active', 'ready',
    'ok', 'closed', false,
    <fp_slot_limit>, <concurrency_limit>
);
```

fp_slot_limit 和 concurrency_limit 严格按画像配置, 测试中不可修改。

### Model Binding 模板

```sql
INSERT INTO public.credential_model_bindings (
    id, credential_id, provider_model_id, available
) VALUES
    (<id>, <credential_id>, <provider_model_id>, true),
    (<id+1>, <credential_id>, <provider_model_id+1>, true);
```

## 初始状态

每次测试开始前, 重置所有供应商到以下状态:

```bash
# 健康状态
for g in A B C D E F G H I J K L; do
  python3 scripts/mock-orchestrator-v2.py reset-group "$g"
done

# 启用所有供应商
psql -d llm_gateway -c "UPDATE providers SET manual_disabled=false WHERE id BETWEEN 9010 AND 9069;"

# 重置配额
python3 scripts/mock-orchestrator-v2.py reset-quota-all

# 重置熔断器状态
psql -d llm_gateway -c "UPDATE credentials SET circuit_state='closed', availability_state='ready' WHERE id BETWEEN 9010 AND 9069;"
```
