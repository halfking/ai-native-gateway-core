## mock_supplier.py 支持的状态

| state | HTTP 表现 | 触发方式 |
|---|---|---|
| `healthy` | 200 OK | 默认 / set-group X healthy |
| `slow` | 200 OK 但延迟 2-4s | set-group X slow |
| `flaky` | 30% 概率 5xx | set-group X flaky |
| `server_error` | 100% 500 | set-group X server_error |
| `auth` | 100% 401 | set-group X auth |
| `quota_429` | 配额耗尽后 429 | set-group-quota X 0 60 |
| `rate_limited` | 100% 429 | set-group X rate_limited |
| `broken_stream` | SSE 写 5 chunk 后断 | set-group X broken_stream |
| `context_too_long` | 100% 413 | set-group X context_too_long |
| `dropped` | 100% 503 dropped | set-group X dropped |

## 客户端视角的故障体验

```
client request
   │
   ▼
gateway (route → resolve candidate)
   │
   ├─ credential 1 → mock_supplier:19080 (A/0)
   │     ├─ state=healthy → 200 OK
   │     ├─ state=slow → 200 OK + 2-4s
   │     ├─ state=flaky → 30% 500/502/503
   │     ├─ state=server_error → 500
   │     ├─ state=auth → 401
   │     ├─ state=quota_429 → 429 (after quota exhausted)
   │     └─ state=broken_stream → 200 SSE + cut after 5 chunks
   │
   └─ gateway 收到 5xx/429/timeout → 候选链下一个
```

## kill-switch 路径（旁路 3 模块）

即使关掉候选链失败降级，还能通过 `KILL_*=1` 完全旁路：

| 旁路模块 | 关键文件 | 重新开启 |
|---|---|---|
| session_cache | `domains/hooks/compression/session_cache.go` GetOrLoad 入口 | 删除 env + 重启 |
| session_compression | `domains/hooks/compression/hook.go` Enabled() | 删除 env + 重启 |
| circuit_degradation | `domains/streaming/executors/executor.go` Allow 检查 | 删除 env + 重启 |

详见 `08-kill-switch.md`。
