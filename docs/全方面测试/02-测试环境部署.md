## 7. 故障级 kill-switch (2026-07-12 incident response)

```bash
# 在 gateway systemd unit 加 Environment= 行 — 重启即生效
# KILL_SESSION_COMPRESSION=1   # 关 compression hook
# KILL_SESSION_CACHE=1         # 关 session_cache
# KILL_CIRCUIT_DEGRADATION=1   # 关 circuit breaker degrade
# KILL_FP_SLOT=1                # 关 fingerprint prefilter
# KILL_RATE_LIMITER=1          # 关 RPM/TPM token bucket

# 例：仅关 fp_slot
ssh root@154 \
  'systemctl edit llm-gateway-go <<EOF
[Service]
Environment="KILL_FP_SLOT=1"
EOF
systemctl restart llm-gateway-go'
```

详见 `08-kill-switch.md`。

## 9. 故障排查速查

| 现象 | 排查 |
|---|---|
| 端口 19080 已占用 | `lsof -i :19080` + `pkill -f mock_supplier.py` |
| DB 连接失败 | 确认 `llm-gateway-pg` 容器在跑：`docker ps` |
| mock_supplier.py 启动失败 | 检查 `/tmp/lab-suppliers/A-0.log` + 检查 `python3 -c "import aiohttp"` |
| gateway 崩溃 | 看 `/tmp/gateway-test.log` + 试 `KILL_*=1` 旁路 |
| 所有 401 from gateway | 检查 api_keys prefix 是否匹配 + `Authorization: Bearer sk-loadtest-01-hash-...` |
| 端口超时 | 确认 nginx → gateway upstream 配的是 `127.0.0.1:8781`（不是 8082 等） |
