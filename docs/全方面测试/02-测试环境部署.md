
**如果已有数据库实例**:
- **容器名**: `llm-gateway-pg`
- **镜像**: kx-citus-pg17-13.3.0 (基于 Citus 13.3-1)
- **端口**: 5432
- **数据目录**: `/Users/xutaohuang/data/docker/llm-gateway-pg17/data` (bind mount)
- **数据库**: `llm_gateway`
- **用户**: `xutaohuang`

**如果数据库不存在, 启动方式**:

```bash
# 检查数据目录是否存在
ls -la /Users/xutaohuang/data/docker/llm-gateway-pg17/data

# 如果容器已存在但停止
docker start llm-gateway-pg

# 如果容器不存在, 从镜像创建 (一次性操作)
docker load -i ~/work/docker-base-images/kx-citus-pg17-13.3.0-arm64.tar.gz
docker run -d \
  --name llm-gateway-pg \
  -p 5432:5432 \
  -v /Users/xutaohuang/data/docker/llm-gateway-pg17/data:/var/lib/postgresql/data \
  -e POSTGRES_USER=xutaohuang \
  -e POSTGRES_PASSWORD=<password> \
  -e POSTGRES_DB=llm_gateway \
  kx-citus-pg17:13.3.0

# 等待数据库启动
sleep 5
docker exec llm-gateway-pg pg_isready -U xutaohuang
```

## 部署步骤

### Step 0: 检查并准备数据库 (必做)

```bash
# 1. 检查数据库容器状态
docker ps -a | grep llm-gateway-pg

# 2. 如果停止, 启动容器
docker start llm-gateway-pg || echo "容器不存在, 需要创建"

# 3. 验证连接
PGPASSWORD=<password> psql -h localhost -p 5432 -U xutaohuang -d llm_gateway -c "SELECT COUNT(*) FROM providers;" 2>/dev/null || echo "数据库不可用"

# 4. 检查现有测试数据 (避免冲突)
PGPASSWORD=<password> psql -h localhost -p 5432 -U xutaohuang -d llm_gateway -c "SELECT COUNT(*) AS existing_test_providers FROM providers WHERE id BETWEEN 9010 AND 9099;"

# 如果有现有测试数据, 决定是否清理 (见 Step 3)
```

### Step 1: 编译 Gateway

```bash
cd /Users/xutaohuang/workspace/llm-gateway-go-3
go build -o gateway ./cmd/gateway/
```

确认编译成功并生成 47M+ 的二进制。

### Step 2: 启动 60 个 Mock 供应商

```bash
./scripts/start-60-mocks.sh
```

这会在端口 19080-19139 启动 60 个 server-v3.py 实例, 分 12 组 (A-L)。

验证:

```bash
# 健康检查
./scripts/mock-state-orchestrator.sh health-all

# 检查每组状态
python3 scripts/mock-orchestrator-v2.py health-matrix

# 检查特定 mock
curl -sS http://localhost:19080/healthz | jq .
```

### Step 3: 初始化数据库配置

**重要**: 先检查现有数据, 避免与生产数据冲突。

```bash
# 检查是否有现有测试数据
PGPASSWORD=<password> psql -h localhost -p 5432 -U xutaohuang -d llm_gateway -c "SELECT id, code, display_name FROM providers WHERE id BETWEEN 9010 AND 9099 LIMIT 5;"

# 如果返回数据, 检查是否为旧的测试数据
# 如果是, 清理旧数据 (谨慎操作, 确认不影响其他测试)
PGPASSWORD=<password> psql -h localhost -p 5432 -U xutaohuang -d llm_gateway <<EOF
-- 仅删除测试用的 mock 供应商数据 (id 9010-9099)
DELETE FROM credential_model_bindings WHERE credential_id BETWEEN 9010 AND 9099;
DELETE FROM provider_models WHERE provider_id BETWEEN 9010 AND 9099;
DELETE FROM credentials WHERE id BETWEEN 9010 AND 9099;
DELETE FROM providers WHERE id BETWEEN 9010 AND 9099;
-- 验证清理结果
SELECT COUNT(*) AS remaining_test_data FROM providers WHERE id BETWEEN 9010 AND 9099;
EOF
```

注入 60 个供应商测试数据:

```bash
# 方式 1: 使用自动注入脚本 (推荐)
./scripts/comprehensive-loadtest.sh inject-creds

# 方式 2: 手动执行 SQL (如果脚本不可用)
PGPASSWORD=<password> psql -h localhost -p 5432 -U xutaohuang -d llm_gateway -f sql/scripts/04-loadtest-mock-credentials.sql 2>&1 | tail -20
```

**验证注入结果**:

```bash
# 检查供应商数量
PGPASSWORD=<password> psql -h localhost -p 5432 -U xutaohuang -d llm_gateway -c "SELECT COUNT(*) AS test_providers FROM providers WHERE id BETWEEN 9010 AND 9099;"

# 检查路由视图
PGPASSWORD=<password> psql -h localhost -p 5432 -U xutaohuang -d llm_gateway -c "SELECT COUNT(*) AS routable FROM v_routable_credential_models WHERE provider_id BETWEEN 9010 AND 9099;"

# 应返回: test_providers=60, routable=120-240
```

### Step 4: 启动 Gateway

```bash
# 构建数据库连接字符串 (根据实际密码替换 <password>)
DATABASE_URL="postgres://xutaohuang:<password>@localhost:5432/llm_gateway?sslmode=disable"

# 启动 Gateway
DATABASE_URL="$DATABASE_URL" \
LLM_GATEWAY_CORS_ORIGINS="*" \
LLM_GATEWAY_LISTEN=":8082" \
LLM_GATEWAY_CREDENTIAL_ENCRYPTION_KEY="AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA=" \
  ./gateway > /tmp/gateway-test.log 2>&1 &

# 记录 PID
echo $! > /tmp/gateway-test.pid

# 等待启动
sleep 5
```

验证:

```bash
# 检查进程
ps aux | grep ./gateway | grep -v grep

# 健康检查
curl -sS http://localhost:8082/healthz | jq .

# 检查日志 (如果启动失败)
tail -50 /tmp/gateway-test.log
```

### Step 5: 验证路由

```bash
# 基础路由验证
curl -s -X POST http://localhost:8082/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-stress-test-01-hash-xxx" \
  -H "X-Gw-Session-Id: test-session-001" \
  -d '{"model":"loadtest-mini-alpha","messages":[{"role":"user","content":"hello"}],"stream":false}' | jq .
```

### Step 6: 运行完整测试

```bash
# 10 个场景一键执行
bash scripts/run-multidim-scenarios.sh

# 或自定义组合
# 先运行基准测试
python3 scripts/loadtest-v2.py \
  --gateway http://localhost:8082 \
  --api-keys "sk-stress-test-01-hash-xxx,sk-stress-test-02-hash-xxx" \
  --clients 100 --rounds 10 \
  --models "loadtest-mini-alpha,loadtest-mini-beta,loadtest-standard-alpha" \
  --prompt-size mixed \
  --output /tmp/test-results/baseline.json
```

### 清理

```bash
# 停止 Gateway
pkill -f './gateway' 2>/dev/null || true

# 停止所有 Mock
pkill -f 'server-v3.py' 2>/dev/null || true

# 清理临时文件
rm -f /tmp/mock-*.pid /tmp/mock-*.log /tmp/mock-state-*.json
rm -f /tmp/gateway-loadtest.pid /tmp/gateway-loadtest.log
```
