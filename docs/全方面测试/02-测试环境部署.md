# 测试环境部署

## 前置条件

### 系统依赖

```bash
# Python 依赖
pip3 install aiohttp

# 系统工具
brew install jq postgresql  # macOS
# 或
apt-get install jq postgresql-client  # Linux

# Go 工具链
go version  # >= 1.24
```

### 数据库

- PostgreSQL 运行中 (本地或 Docker)
- 数据库 `llm_gateway` 已创建
- Schema 已迁移 (sql/migrations/)

## 部署步骤

### Step 1: 编译 Gateway

```bash
cd /Users/xutaohuang/workspace/llm-gateway-go-3
go build -o gateway ./cmd/gateway/
```

确认编译成功并生成 47M+ 的二进制。

### Step 2: 启动 60 个 Mock 供应商

```bash
./scripts/start-60-mocks.sh
```

这会在端口 19080-19139 启动 60 个 server-v3.py 实例, 分 12 组 (A-L)。

验证:

```bash
# 健康检查
./scripts/mock-state-orchestrator.sh health-all

# 检查每组状态
python3 scripts/mock-orchestrator-v2.py health-matrix

# 检查特定 mock
curl -sS http://localhost:19080/healthz | jq .
```

### Step 3: 初始化数据库配置

注入 60 个供应商标识数据:

```bash
# 自动注入 (12 组 × 5 实例, 15 个模型, 60 个凭证)
./scripts/comprehensive-loadtest.sh inject-creds
```

或使用已有 SQL 脚本:

```bash
# 清理旧数据
psql -d llm_gateway -c "DELETE FROM credential_model_bindings WHERE credential_id BETWEEN 9010 AND 9099;"
psql -d llm_gateway -c "DELETE FROM provider_models WHERE provider_id BETWEEN 9010 AND 9099;"
psql -d llm_gateway -c "DELETE FROM credentials WHERE id BETWEEN 9010 AND 9099;"
psql -d llm_gateway -c "DELETE FROM providers WHERE id BETWEEN 9010 AND 9099;"

# 执行注入
# 使用 sql/scripts/ 下的对应 SQL 文件
```

### Step 4: 启动 Gateway

```bash
DATABASE_URL="postgres://xutaohuang@localhost:5432/llm_gateway?sslmode=disable" \
LLM_GATEWAY_CORS_ORIGINS="*" \
LLM_GATEWAY_LISTEN=":8082" \
LLM_GATEWAY_CREDENTIAL_ENCRYPTION_KEY="AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA=" \
  ./gateway > /tmp/gateway-test.log 2>&1 &
```

验证:

```bash
curl -sS http://localhost:8082/healthz | jq .
```

### Step 5: 验证路由

```bash
# 基础路由验证
curl -s -X POST http://localhost:8082/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-stress-test-01-hash-xxx" \
  -H "X-Gw-Session-Id: test-session-001" \
  -d '{"model":"loadtest-mini-alpha","messages":[{"role":"user","content":"hello"}],"stream":false}' | jq .
```

### Step 6: 运行完整测试

```bash
# 10 个场景一键执行
bash scripts/run-multidim-scenarios.sh

# 或自定义组合
# 先运行基准测试
python3 scripts/loadtest-v2.py \
  --gateway http://localhost:8082 \
  --api-keys "sk-stress-test-01-hash-xxx,sk-stress-test-02-hash-xxx" \
  --clients 100 --rounds 10 \
  --models "loadtest-mini-alpha,loadtest-mini-beta,loadtest-standard-alpha" \
  --prompt-size mixed \
  --output /tmp/test-results/baseline.json
```

### 清理

```bash
# 停止 Gateway
pkill -f './gateway' 2>/dev/null || true

# 停止所有 Mock
pkill -f 'server-v3.py' 2>/dev/null || true

# 清理临时文件
rm -f /tmp/mock-*.pid /tmp/mock-*.log /tmp/mock-state-*.json
rm -f /tmp/gateway-loadtest.pid /tmp/gateway-loadtest.log
```

```csv
sk-stress-test-01-hash-0000000000000000000000000000000000000001
sk-stress-test-02-hash-0000000000000000000000000000000000000002
sk-stress-test-03-hash-0000000000000000000000000000000000000003
...
sk-stress-test-20-hash-0000000000000000000000000000000000000020
```
