# 异常场景与数据转换测试 (S40-S55)

本文档定义 S40-S55 异常场景测试，聚焦于：
1. **数据转换问题** - JSON解析、编码、null处理
2. **协议转换边缘情况** - 畸形请求、内容类型错误
3. **错误处理边缘情况** - 超时、部分响应、缓冲区溢出
4. **认证授权边缘情况** - 过期token、错误签名
5. **并发与资源边缘情况** - 竞态条件、死锁、资源耗尽
6. **会话边缘情况** - 会话 fixation、会话劫持尝试

---

## S40: JSON 畸形数据测试

**目标**: 验证网关对畸形JSON数据的处理能力

**场景**:
- S40a: 畸形JSON (缺少引号, 多余逗号, 截断)
- S40b: 超大JSON body (>1MB)
- S40c: 非法UTF-8序列
- S40d: JSON注入尝试

**执行**:
```bash
# S40a: 畸形JSON
curl -X POST http://localhost:8781/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-loadtest-01" \
  -d '{"model":"loadtest-mini-alpha","messages":[{"role":user,"content":"hi}]}'

# S40b: 超大JSON (使用 python 生成)
python3 -c "import json; print(json.dumps({'messages': [{'role': 'user', 'content': 'x' * 2**20}]}))" > /tmp/large.json
curl -X POST http://localhost:8781/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-loadtest-01" \
  -d @/tmp/large.json

# S40c: 非法UTF-8
curl -X POST http://localhost:8781/v1/chat/completions \
  -H "Content-Type: application/json; charset=utf-8" \
  -H "Authorization: Bearer sk-loadtest-01" \
  --data-binary $'\xff\xfe\xfd\xfc'

# S40d: JSON注入尝试
curl -X POST http://localhost:8781/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-loadtest-01" \
  -d '{"model":"loadtest-mini-alpha","messages":[{\"role\":\"user\",\"content\":\"hi\"}],\"__proto__\":{\"admin\":true}}'
```

**验证**:
- 畸形JSON返回400错误，不崩溃
- 超大JSON返回413或合理错误
- 非法UTF-8被正确拒绝
- JSON注入被隔离，不影响其他请求

for round in {1..3}; do
