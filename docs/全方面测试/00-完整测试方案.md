## 🚀 六、CI/CD 集成

### 6.1 GitHub Actions

```yaml
name: Comprehensive Tests

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

jobs:
  # 快速路由测试（每次提交）
  routing-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Install deps
        run: sudo apt-get install -y jq curl
      - name: Start Gateway
        run: ./scripts/start_gateway.sh &
      - name: Run routing tests
        env:
          SKIP_LONG_TESTS: true
          GATEWAY_URL: http://localhost:8080
        run: |
          cd tests/routing
          ./run_all_tests.sh all
      - name: Upload results
        uses: actions/upload-artifact@v3
        with:
          name: routing-test-results
          path: tests/routing/*.log

  # 场景测试（仅 main 分支或手动触发）
  scenario-tests:
    if: github.ref == 'refs/heads/main' || github.event_name == 'workflow_dispatch'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Setup Database
        run: |
          psql -f docs/全方面测试/data/seed.sql
      - name: Start mock suppliers
        run: docs/全方面测试/tools/start_suppliers.sh
      - name: Run scenarios (fast mode)
        run: |
          cd docs/全方面测试/scenarios
          ./run_all.sh --gateway http://localhost:8781 --fast
      - name: Upload results
        uses: actions/upload-artifact@v3
        with:
          name: scenario-test-results
          path: docs/全方面测试/results/
```

## 🔍 八、故障排查

### 8.1 路由测试问题

**Q1: Gateway 未运行**
```bash
curl http://localhost:8080/healthz
# 如果失败，启动 Gateway
```

**Q2: jq 未安装**
```bash
brew install jq  # macOS
sudo apt-get install jq  # Linux
```

**Q3: 测试失败**
```bash
# 查看详细日志
./run_all_tests.sh layer1 2>&1 | tee debug.log
# 检查 Gateway 日志
kubectl logs -l app=llm-gateway --tail=100
```

### 8.2 场景测试问题

**Q1: Mock suppliers 启动失败**
```bash
# 检查端口占用
lsof -i :17000-17059
# 重启
./tools/start_suppliers.sh restart
```

**Q2: 数据库连接失败**
```bash
# 检查数据库
psql -h localhost -p 5432 -U xutaohuang -d llm_gateway -c "\dt"
# 重新初始化
psql -f data/seed.sql
```

**Q3: 场景超时**
```bash
# 使用快速模式
./run_all.sh --fast
# 或运行单个场景
./scenarios/S01_baseline.sh
```
