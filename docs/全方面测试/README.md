# LLM Gateway 全场景高压力测试方案

## 概述

本文档定义了对 llm-gateway-go 进行本地完整、高压力、全场景测试验证的方案。

### 测试目标

- 验证 Gateway 在高并发下的路由、故障转移、熔断恢复能力
- 覆盖 15+ 种故障模式，验证将不稳定上游输出为稳定 LLM 服务
- 验证多维度路由决策：成本、延迟、并发能力、指纹 Slot、健康状态
- 验证 TokenPlan/CodePlan 配额耗尽自动切换
- 验证 Sticky Session 连续性和故障时切换
- 验证流式(SSE)和非流式请求的正确处理
- 验证长时间运行的稳定性
- **验证无可用节点时的错误处理**
- **验证模型不存在时的快速失败**
- **验证跨组故障迁移能力**
- **验证充值后快速恢复 (< 5 秒)**

### 测试规模

| 维度 | 规模 |
|------|------|
| Mock 供应商 | 60 个 (12 组 × 5 实例, 端口 19080-19139) |
| 模型类型 | 15 个 (loadtest-xxx 系列, 不与真实模型重名) |
| 并发客户端 | 100-150 个 |
| API Key | 20+ 个独立 Key |
| 请求总量 | 20,000+ |
| 故障模式 | 15+ 种 |
| 测试场景 | 16 个 (S1-S16) |
