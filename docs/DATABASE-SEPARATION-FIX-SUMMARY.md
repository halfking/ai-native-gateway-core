## 一、背景

### 1.1 问题描述

- **71服务器** (`__HOST_71_IP__`): 生产环境，包含真实用户数据
- **184服务器** (`__INTERNAL_PUBLIC_IP__`): 测试环境，用于开发和测试
- 两个环境之间存在Schema版本差异和数据差异
- 存在误操作风险：脚本可能直接操作生产数据库或从生产同步数据

### 1.2 安全要求

1. **禁止未授权访问71生产环境**
2. **禁止从71同步数据到其他环境**（防止数据泄露）
3. **禁止硬编码IP地址和密码**
4. **所有生产操作需要审批**

## 五、使用指南

### 5.1 开发人员

**日常开发**:
```bash
# 从184测试环境同步数据到本地
./scripts/sync-db-from-184.sh full

# 部署到184测试环境
ssh root@__INTERNAL_PUBLIC_IP__ "cd /path/to/project && ./deploy.sh"
```

**环境变量配置**:
```bash
# 复制环境变量模板
cp .env.example .env

# 从密码管理器或文档中获取真实值，填入.env
# 真实值存储位置: ~/Documents/llm-gateway-env.md
```

### 5.2 运维人员

**部署到71生产环境**:
```bash
# 1. 提交变更申请，获得审批单号 CHG-2026-XXX

# 2. 执行部署（需要审批单号）
APPROVAL_ID="CHG-2026-XXX" ./scripts/deploy-to-prod.sh --env 71

# 3. 查看审计日志
tail -f /var/log/deployment-audit.log
```

**紧急从71同步**:
```bash
# 仅在紧急情况下，经DBA授权
cp scripts/sync-db-from-71.sh.DISABLED scripts/sync-db-from-71.sh.temp
APPROVAL_ID="CHG-2026-XXX" ./scripts/sync-db-from-71.sh.temp schema-only 2>&1 | tee sync-from-71-$(date +%Y%m%d-%H%M%S).log
rm scripts/sync-db-from-71.sh.temp
```

### 5.3 DBA

**Schema迁移审批**:
1. 检查迁移脚本：`migrations/XXX_description.sql`
2. 在184测试环境验证
3. 审批变更单
4. 监控71执行过程
5. 确认备份可用
