**后端提交**: W2.1-W2.3已完成 (2026-11-25)  
**状态**: 后端Schema生成器已完成，前端SchemaForm组件待开发

---

## 1. 功能概述

实现**Schema驱动的插件设置表单**，让插件无需手写Vue组件即可生成配置页面：

- 插件通过Go struct tag定义settings schema
- 后端生成JSON Schema（包含字段类型、验证规则、UI提示）
- 前端SchemaForm组件根据JSON Schema自动渲染表单
- 用户修改后，前端调用PUT /api/admin/plugins/{id}/settings保存

**类似产品**: 
- Grafana的插件配置页
- Backstage的Schema Form
- JSON Schema Form

## 2. 后端Schema结构

### 2.1 插件Manifest（W2.1已实现）
```json
{
  "name": "ai-session-manager",
  "version": "1.2.0",
  "schema_version": 3,
  "settings_schema": {
    "type": "object",
    "properties": {
      "enable_audit": {
        "type": "boolean",
        "title": "启用审计日志",
        "description": "记录所有会话操作",
        "default": true
      },
      "retention_days": {
        "type": "integer",
        "title": "日志保留天数",
        "description": "审计日志保留时长",
        "minimum": 7,
        "maximum": 365,
        "default": 90
      },
      "export_format": {
        "type": "string",
        "title": "导出格式",
        "enum": ["json", "csv", "parquet"],
        "default": "json"
      },
      "notification_webhook": {
        "type": "string",
        "title": "告警Webhook",
        "format": "uri",
        "description": "异常事件推送地址"
      }
    },
    "required": ["enable_audit", "retention_days"]
  }
}
```

### 2.2 Go struct tag示例（后端）
```go
type PluginSettings struct {
    EnableAudit        bool   `json:"enable_audit" schema:"title=启用审计日志;description=记录所有会话操作;default=true"`
    RetentionDays      int    `json:"retention_days" schema:"title=日志保留天数;minimum=7;maximum=365;default=90"`
    ExportFormat       string `json:"export_format" schema:"title=导出格式;enum=json,csv,parquet;default=json"`
    NotificationWebhook string `json:"notification_webhook" schema:"title=告警Webhook;format=uri"`
}
```

**后端自动生成**: 
- `pluginrt/schema_generator.go` 读取struct tag生成JSON Schema
- 插件启动时注册到manifest的`settings_schema`字段


**响应**:
```json
{
```

```json
  "retention_days": 90,
```

### 3.3 更新插件设置
```http
PUT /api/admin/plugins/{name}/settings
Content-Type: application/json
Authorization: Bearer <token>

{
  "enable_audit": false,
  "retention_days": 30,
  "export_format": "csv"
}
```

**响应**:
```json
{
  "success": true,
  "message": "设置已保存，将在下次reconcile生效"
}
```

**验证**:
- 后端根据`settings_schema`验证请求数据
- 违反`minimum`/`maximum`/`required` → 400 Bad Request
- 违反`enum`约束 → 400 Bad Request

```http
Authorization: Bearer <token>
```

**响应**:
```json
{
  "enable_audit": true,
  "retention_days": 90,
  "export_format": "json",
```

## 4. SchemaForm组件设计

### 4.1 组件接口
```vue
<template>
  <SchemaForm
    :schema="pluginSchema"
    :model-value="currentSettings"
    @update:model-value="onSettingsChange"
    @submit="onSubmit"
    :readonly="!canEdit"
  />
</template>

<script setup>
import { ref, onMounted } from 'vue'
import SchemaForm from '@/components/SchemaForm.vue'
import { getPluginManifest, getPluginSettings, updatePluginSettings } from '@/api/plugins'

const props = defineProps(['pluginName'])
const pluginSchema = ref({})
const currentSettings = ref({})
const canEdit = ref(true)

onMounted(async () => {
  const manifest = await getPluginManifest(props.pluginName)
  pluginSchema.value = manifest.settings_schema
  
  currentSettings.value = await getPluginSettings(props.pluginName)
})

const onSettingsChange = (newSettings) => {
  currentSettings.value = newSettings
}

const onSubmit = async () => {
  try {
    await updatePluginSettings(props.pluginName, currentSettings.value)
    ElMessage.success('设置已保存')
  } catch (error) {
    ElMessage.error('保存失败：' + error.message)
  }
}
</script>
```

### 4.2 SchemaForm组件实现（核心）
```vue
<!-- src/components/SchemaForm.vue -->
<template>
  <el-form 
    ref="formRef"
    :model="formData"
    :rules="validationRules"
    label-width="140px"
    :disabled="readonly"
  >
    <el-form-item
      v-for="(propSchema, propKey) in schema.properties"
      :key="propKey"
      :label="propSchema.title || propKey"
      :prop="propKey"
    >
      <!-- 布尔类型 → Switch -->
      <el-switch
        v-if="propSchema.type === 'boolean'"
        v-model="formData[propKey]"
        @change="onChange"
      />

      <!-- 整数类型 → InputNumber -->
      <el-input-number
        v-else-if="propSchema.type === 'integer'"
        v-model="formData[propKey]"
        :min="propSchema.minimum"
        :max="propSchema.maximum"
        :placeholder="propSchema.description"
        @change="onChange"
      />

      <!-- 枚举类型 → Select -->
      <el-select
        v-else-if="propSchema.enum"
        v-model="formData[propKey]"
        :placeholder="propSchema.description"
        @change="onChange"
      >
        <el-option
          v-for="option in propSchema.enum"
          :key="option"
          :label="option"
          :value="option"
        />
      </el-select>

      <!-- URI格式 → Input with prefix -->
      <el-input
        v-else-if="propSchema.format === 'uri'"
        v-model="formData[propKey]"
        :placeholder="propSchema.description"
        prefix-icon="el-icon-link"
        @input="onChange"
      />

      <!-- 字符串类型 → Input -->
      <el-input
        v-else
        v-model="formData[propKey]"
        :placeholder="propSchema.description"
        @input="onChange"
      />

      <!-- 字段说明 -->
      <div v-if="propSchema.description" class="field-description">
        {{ propSchema.description }}
      </div>
    </el-form-item>

    <el-form-item>
      <el-button type="primary" @click="onSubmit">保存设置</el-button>
      <el-button @click="onReset">重置为默认值</el-button>
    </el-form-item>
  </el-form>
</template>

<script setup>
import { ref, reactive, watch, computed } from 'vue'

const props = defineProps({
  schema: {
    type: Object,
    required: true
  },
  modelValue: {
    type: Object,
    default: () => ({})
  },
  readonly: {
    type: Boolean,
    default: false
  }
})

const emit = defineEmits(['update:modelValue', 'submit', 'reset'])

const formRef = ref(null)
const formData = reactive({ ...props.modelValue })

// 监听外部值变化
watch(() => props.modelValue, (newVal) => {
  Object.assign(formData, newVal)
}, { deep: true })

// 生成Element Plus验证规则
const validationRules = computed(() => {
  const rules = {}
  const { properties, required = [] } = props.schema

  Object.entries(properties).forEach(([key, propSchema]) => {
    const fieldRules = []

    // required验证
    if (required.includes(key)) {
      fieldRules.push({
        required: true,
        message: `${propSchema.title || key}不能为空`,
        trigger: 'blur'
      })
    }

    // 数值范围验证
    if (propSchema.type === 'integer') {
      if (propSchema.minimum !== undefined) {
        fieldRules.push({
          type: 'number',
          min: propSchema.minimum,
          message: `最小值为${propSchema.minimum}`,
          trigger: 'blur'
        })
      }
      if (propSchema.maximum !== undefined) {
        fieldRules.push({
          type: 'number',
          max: propSchema.maximum,
          message: `最大值为${propSchema.maximum}`,
          trigger: 'blur'
        })
      }
    }

    // URI格式验证
    if (propSchema.format === 'uri') {
      fieldRules.push({
        type: 'url',
        message: '请输入有效的URL',
        trigger: 'blur'
      })
    }

    if (fieldRules.length > 0) {
      rules[key] = fieldRules
    }
  })

  return rules
})

const onChange = () => {
  emit('update:modelValue', { ...formData })
}

const onSubmit = async () => {
  const valid = await formRef.value.validate().catch(() => false)
  if (valid) {
    emit('submit', { ...formData })
  }
}

const onReset = () => {
  // 重置为schema中的default值
  const defaults = {}
  Object.entries(props.schema.properties).forEach(([key, propSchema]) => {
    if (propSchema.default !== undefined) {
      defaults[key] = propSchema.default
    }
  })
  Object.assign(formData, defaults)
  emit('reset', defaults)
}
</script>

<style scoped>
.field-description {
  font-size: 12px;
  color: #909399;
  margin-top: 4px;
  line-height: 1.4;
}
</style>
```

### 4.3 插件设置页（使用SchemaForm）
```vue
<!-- src/views/plugins/PluginSettings.vue -->
<template>
  <div class="plugin-settings">
    <el-page-header @back="goBack" :content="pluginName + ' 设置'" />

    <el-card v-loading="loading">
      <template #header>
        <div class="card-header">
          <span>插件配置</span>
          <el-tag v-if="hasUnsavedChanges" type="warning">未保存</el-tag>
        </div>
      </template>

      <SchemaForm
        v-if="schema"
        :schema="schema"
        v-model="settings"
        @submit="onSave"
        @reset="onResetToDefaults"
      />

      <el-empty v-else description="该插件无可配置项" />
    </el-card>
  </div>
</template>

<script setup>
import { ref, computed, onMounted } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import SchemaForm from '@/components/SchemaForm.vue'
import { 
  getPluginManifest, 
  getPluginSettings, 
  updatePluginSettings,
  resetPluginSettings
} from '@/api/plugins'

const route = useRoute()
const router = useRouter()
const pluginName = ref(route.params.name)
const schema = ref(null)
const settings = ref({})
const originalSettings = ref({})
const loading = ref(true)

const hasUnsavedChanges = computed(() => {
  return JSON.stringify(settings.value) !== JSON.stringify(originalSettings.value)
})

onMounted(async () => {
  try {
    const manifest = await getPluginManifest(pluginName.value)
    schema.value = manifest.settings_schema

    const currentSettings = await getPluginSettings(pluginName.value)
    settings.value = currentSettings
    originalSettings.value = JSON.parse(JSON.stringify(currentSettings))
  } catch (error) {
    ElMessage.error('加载失败：' + error.message)
  } finally {
    loading.value = false
  }
})

const onSave = async () => {
  try {
    await updatePluginSettings(pluginName.value, settings.value)
    originalSettings.value = JSON.parse(JSON.stringify(settings.value))
    ElMessage.success('设置已保存')
  } catch (error) {
    ElMessage.error('保存失败：' + error.message)
  }
}

const onResetToDefaults = async () => {
  try {
    const defaults = await resetPluginSettings(pluginName.value)
    settings.value = defaults
    ElMessage.success('已重置为默认值')
  } catch (error) {
    ElMessage.error('重置失败：' + error.message)
  }
}

const goBack = () => {
  if (hasUnsavedChanges.value) {
    ElMessageBox.confirm('有未保存的更改，确定离开？', '提示', {
      confirmButtonText: '离开',
      cancelButtonText: '取消',
      type: 'warning'
    }).then(() => {
      router.back()
    }).catch(() => {})
  } else {
    router.back()
  }
}
</script>

<style scoped>
.plugin-settings {
  padding: 20px;
}

.card-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
</style>
```

## 6. API请求封装

```typescript
// src/api/plugins.ts
import request from '@/utils/request'

export function getPluginManifest(pluginName: string) {
  return request({
    url: `/api/admin/plugins/${pluginName}/manifest`,
    method: 'get'
  })
}

export function getPluginSettings(pluginName: string) {
  return request({
    url: `/api/admin/plugins/${pluginName}/settings`,
    method: 'get'
  })
}

export function updatePluginSettings(pluginName: string, settings: Record<string, any>) {
  return request({
    url: `/api/admin/plugins/${pluginName}/settings`,
    method: 'put',
    data: settings
  })
}

export function resetPluginSettings(pluginName: string) {
  return request({
    url: `/api/admin/plugins/${pluginName}/settings/reset`,
    method: 'post'
  })
}
```

```javascript
const visibleProperties = computed(() => {
  const { properties } = props.schema
  return Object.entries(properties).filter(([key, propSchema]) => {
    if (!propSchema.dependsOn) return true
    // 检查依赖字段的值
    return formData[propSchema.dependsOn] === true
  }).reduce((acc, [key, val]) => ({ ...acc, [key]: val }), {})
})
```

## 8. 错误处理

### 8.1 Schema验证失败
```javascript
// 400 Bad Request
{
  "error": "validation_error",
  "message": "retention_days must be >= 7",
  "field": "retention_days"
}
```

**前端处理**:
```javascript
catch (error) {
  if (error.response?.data?.field) {
    // 高亮错误字段
    formRef.value.validateField(error.response.data.field)
    ElMessage.error(error.response.data.message)
  } else {
    ElMessage.error('保存失败：' + error.message)
  }
}
```

---

```json
{
```
