## 1. API端点清单

### 1.1 获取渠道客户列表
```http
GET /api/channels/{id}/customers
Authorization: Bearer <token>  (role=channel 或 super_admin)
```

**响应**:
```json
[
  {
    "id": 123,
    "name": "客户A公司",
    "code": "customer-a",
    "enabled": true,
    "created_at": "2026-11-01T10:00:00Z"
  }
]
```

**权限**: 
- `channel`用户：只能查看归属自己的渠道
- `super_admin`：可查看任意渠道

---

### 1.2 获取渠道整体统计
```http
GET /api/channels/{id}/stats
Authorization: Bearer <token>
```

**响应**:
```json
{
  "total_customers": 15,
  "total_sessions": 1203,
  "monthly_cost_usd": 456.78
}
```

**说明**: 
- `total_sessions`: 近30天所有客户的会话总数（按identity_hash去重）
- `monthly_cost_usd`: 近30天总成本（从request_logs聚合）

---

### 1.3 获取客户统计
```http
GET /api/channels/{id}/customers/{customer_id}/stats
Authorization: Bearer <token>
```

**响应**:
```json
{
  "total_sessions": 234,
  "active_users": 12,
  "monthly_cost_usd": 89.45
}
```

**说明**:
- `total_sessions`: 近30天该客户的会话数（identity_hash去重）
- `active_users`: 近30天活跃用户数（end_user_id去重）
- `monthly_cost_usd`: 近30天该客户产生的总成本

---

### 1.4 获取客户会话列表
```http
GET /api/channels/{id}/customers/{customer_id}/sessions
Authorization: Bearer <token>
```

**响应**:
```json
[
  {
    "identity_hash": "abc123...",
    "last_activity": "2026-11-25T15:30:00Z",
    "request_count": 45,
    "total_cost_usd": 12.34
  }
]
```

**说明**:
- 默认返回近30天数据
- 按`identity_hash`分组（简化版，不含完整session_id）
- 限制50条（v1无分页）

## 2. 权限模型

### 2.1 渠道用户归属检查
```
用户登录 → users表 (role='channel')
       ↓
   channel_users表 (user_id, channel_id)
       ↓
   验证user→channel归属
```

### 2.2 客户归属检查
```
API请求customer_id
       ↓
   customers表 (id, channel_id)
       ↓
   验证customer→channel归属
```

**403场景**:
- 渠道用户A访问渠道B的客户 → Forbidden
- 渠道用户访问不属于自己渠道的customer_id → Forbidden

## 3. 前端Vue组件设计建议

### 3.1 渠道商仪表盘（主页面）
```vue
<template>
  <div class="channel-dashboard">
    <!-- 渠道整体统计卡片 -->
    <MetricsRow>
      <MetricCard title="客户总数" :value="channelStats.total_customers" icon="users" />
      <MetricCard title="会话总数" :value="channelStats.total_sessions" icon="message" />
      <MetricCard title="月度成本" :value="channelStats.monthly_cost_usd" icon="dollar" unit="USD" />
    </MetricsRow>

    <!-- 客户列表 -->
    <CustomerList 
      :customers="customers" 
      @select="onCustomerSelect" 
    />
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import { useRoute } from 'vue-router'
import { getChannelStats, getChannelCustomers } from '@/api/channels'

const route = useRoute()
const channelId = ref(route.params.id)
const channelStats = ref({})
const customers = ref([])

onMounted(async () => {
  channelStats.value = await getChannelStats(channelId.value)
  customers.value = await getChannelCustomers(channelId.value)
})

const onCustomerSelect = (customerId) => {
  router.push(`/channels/${channelId.value}/customers/${customerId}`)
}
</script>
```

### 3.3 API请求封装
```typescript
// src/api/channels.ts
import request from '@/utils/request'

export function getChannelStats(channelId: number) {
  return request({
    url: `/api/channels/${channelId}/stats`,
    method: 'get'
  })
}

export function getChannelCustomers(channelId: number) {
  return request({
    url: `/api/channels/${channelId}/customers`,
    method: 'get'
  })
}

export function getCustomerStats(channelId: number, customerId: number) {
  return request({
    url: `/api/channels/${channelId}/customers/${customerId}/stats`,
    method: 'get'
  })
}

export function getCustomerSessions(channelId: number, customerId: number) {
  return request({
    url: `/api/channels/${channelId}/customers/${customerId}/sessions`,
    method: 'get'
  })
}
```

## 5. 错误处理

### 5.1 403 Forbidden
**原因**: 渠道用户访问非归属资源  
**UI建议**: 显示"无权访问该客户"，重定向到渠道主页

### 5.2 401 Unauthorized
**原因**: Token过期或未登录  
**UI建议**: 重定向到登录页

### 5.3 400 Bad Request
**原因**: channel_id或customer_id格式错误  
**UI建议**: 显示"参数错误"

## 6. 数据源说明

**后端数据来源**:
- `customers` / `channels` 表：客户/渠道基础信息
- `request_logs` 表：会话统计（customer_id字段在迁移407已存在）
- `channel_users` 表：渠道用户归属关系

**数据时效**:
- 统计数据：近30天
- 会话列表：近30天，最多50条（v1）

**未来增强方向**:
- 分页支持（会话列表）
- 时间范围筛选（7天/30天/90天）
- ASM session_projection集成（完整会话详情）
