## 2. P0：8 主题待办落地（非 M3 依赖）

### P0-Z1 会话管理接线到 ursm/v2（老板 08-15 修正）
- **现状**：`main.go:609-630` URSM v2 Manager 已构造，`URSM_V2_MODE` 默认 off（`LoadFromEnv` 缺省 `api.ModeOff`；`main.go:1362` 明确"misconfigured install degrades gracefully to ModeOff"）；生产路径仍是 `ursm/v1` 旧循环。
- **目标**：会话管理（会话生命周期/状态/维度）接入 `ursm/v2` 架构；off → shadow → canary 渐进。
- **切换路径**：
  1. **off → shadow**：`URSM_V2_MODE=shadow`；`URSM_V2_SHADOW_DOUBLE_WRITE=true` 控制 outcome 旁写 v2，不改变 legacy 主写；`URSM_V2_SHADOW_SAMPLE_RATE` 控制异步候选双算；
  2. **shadow → canary**：`URSM_V2_MODE=canary` + `URSM_V2_CANARY_PERCENT` 灰度，并继续采样路由 diff；
  3. **canary → authoritative**：outcome 旁写无失败、availability/order/top1 指标达到门禁并完成运行期验证后切换。
- **验收**：分别核对 outcome 旁写与候选路由 diff，不能用单一 `diff=0` 替代两套证据。
