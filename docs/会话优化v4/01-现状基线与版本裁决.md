## 1. 会话优化v2（08-06 ~ 08-13）

### 1.1 权威三件套
- **31-当前实现基线与修正决策**：ADR-V2-001（**历史错误记录**：原写 schema 为 `gateway.*`，老板 08-15 修正 + migration 513 证实全在 `public.*`）、ADR-GOAL-001（Goal retry 同步内部重试，HTTP 202 未实施）、ADR-TOKEN-001（holder=`{userKey}|{clientType}`，不用 IdentityHash）、ADR-HANDOFF-001（仅请求侧触发已实现）、Phase 前缀规范（V2-/Goal-/Handoff-）。
- **59-业务流程基准（历史来源摘要）**：BP1 请求全链路（`dispatch_v2.enabled` 默认 ON + `KILL_DISPATCH_V2=1` kill-switch；历史曾以 `ChunkCount==0` 表达首字节边界）；BP2 Goal（P0/P1/P2 检测）；BP3 压缩与 V2 增量（DualWriter、SubmitMode P0-P5）；BP4 Token（Limiter 4 层内存 semaphore）；BP5 Dispatch（三层队列）；X-1~X-3 横切；9 个关键 migration。当前切换门禁以第 3 节的 `BytesSent` 与 `AttemptCommitGate` 双轨契约为准。balanced/aggressive 审计门禁以当前 `ModeConfig.UseAudit` 接线为准。
- **60-核实报告**：PASS 49 / note 5 / fail 1（credential_client_quota 未实施）/ N/A 8 / defer 2。NOTE-2：DualWriter 实际检查 `sessions_v2.shadow_write`（非 `sessions_v2.enabled`）。

### 1.2 结论：已上生产
Session V2 影子写、Goal 全套、Handoff 请求侧、Token holder、Dispatch 三层队列（默认 ON）、V2 压缩读路径（`sessions_v2_compression_read` 默认 true）。

### 1.3 遗留待办（v4 接管）
P0：credential_client_quota、HTTP 202 异步重试、V1 下线；Goal↔Handoff 四组件与 dispatch 模型自动变更已实现但仍需按开关/灰度策略推进。
P1：V2-P2.3~2.6 灰度、8 项 N/A runtime 验证、TPM 真实 tokenizer、DEF-004。balanced 审计保持关闭，aggressive 审计由 `ModeConfig.UseAudit` 和 `goal.audit_enabled` 门禁实际接线。
P2：Admin V2 API 三件、`public.sessions` 引用迁移后的清理、client_types 表、账户组共享队列。

## 3. 路由优化v3（URSM，08-12）

### 3.1 设计蓝本（v3.0）
P1-P6 原则、5 层流水线、状态层级 Provider→Credential→Model→Node→Binding、error_origin 三分类（client/gateway/upstream）、成本评分公式、L1/L2/L3 绑定、分级降级（circuit open 30s→half-open）、响应缓存回放（`X-Gw-Replay:true`，TTL 5min）、Hook 25+。

### 3.2 版本裁决（重要）
| 项 | 裁决 |
|---|---|
| 状态模型 | `ursm/v2` 已实现；缺省 `authoritative`，`off` 为回退，`shadow`/`canary` 为兼容与隔离观测；蓝本五维评分+P2C 仍为纸面 |
| 响应缓存 | `X-Gw-Replay:true` 已实现；TTL 5min 智能绑定部分纸面 |
| 智能绑定 | 纸面（待部署证据与后续规划） |
| Hook 插件化 | 纸面 |
| 分级降级 | circuit open 30s / half-open 已实现 |
| 客户端/供应商边界 | 客户端 TCP 物理断开不可恢复；仅可在客户端连接存活且首语义帧未提交前切换供应商，提交后禁止透明从头重放 |

> 详见 04 号文档 §4、[2026-08-17 稳定性审计](../audit/2026-08-17-ursm-v2-client-provider-stability-audit.md)与[URSM v2 cutover runbook](../runbooks/ursm-v2-cutover.md)。
