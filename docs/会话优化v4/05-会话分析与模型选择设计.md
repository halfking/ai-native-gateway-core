## 2. 任务模型选择（主题⑧）

### 2.1 已实现（CURRENT）
- **Goal cost_mode 三档 preset**：minimal（2 retries/40s，monthly 500K）/ balanced（3/50s，2M）/ aggressive（5/120s，10M）。
  - ⚠️ 勘误：minimal 与 balanced preset 均不启用自动审计（`UseAudit=false`）；自动审计及修正为 aggressive 专属（`UseAudit=true`）。v2 26 号曾提出 balanced 开启审计的建议，但未被 v2 18 号原始成本分级设计采纳；当前 `cost_presets.go` 实现无需修改。
- 配置优先级：租户显式配置 > Cost Mode Preset > 平台默认（minimal）> 硬编码 fallback。
- **LoopDetector**：hash 命中切模型（`model_switch_count` 指标）。
- **审计/修复模型选择**：autoroute.Decider（`UseAutorouteAudit`）。
- **客户端类型识别**（41/42）：holder=`{userKey}|{clientType}`；userKey = StickyKey（`{tenant}:{app}:{apiKeyID}:{profile}`）→ X-Request-Id → "anon"；clientType = X-Gw-Client-Type 头 → UA 匹配（11 类）→ "unknown"。不用 IdentityHash。
- **Goal 检测三策略**：P0 Structured Output / P1 Keywords / P2 LLM 信心分。
- 不可重试错误黑名单：KindAuth / KindContentFilter / KindContextLength / KindQuotaPermanent。
