## 3. 核心流程

```
1. parseIntQuery(r, "hours", 24, 1, 168)         // 必须是 1/24/168
2. parseSinceQuery(r, "since", <hours>h)
3. SELECT FROM credentials WHERE id = $1          // 404 if not found
4. SELECT error_kind, COUNT(*), MAX(ts), COUNT(DISTINCT upstream_status_code)
   FROM candidate_failure_logs_with_current_month
   WHERE credential_id = $1 AND ts >= $2
   GROUP BY error_kind
   ORDER BY count DESC
5. SELECT ts, request_id, raw_model_name, attempt_index, error_kind,
         error_message, upstream_status_code, upstream_response_preview, latency_ms
   FROM candidate_failure_logs_with_current_month
   WHERE credential_id = $1 AND ts >= $2
   ORDER BY ts DESC
   LIMIT 10
6. SELECT profile_date, total_score, availability_score, stability_score
   FROM provider_profile_daily
   WHERE credential_id = $1 AND profile_date >= CURRENT_DATE - 7
   ORDER BY profile_date DESC
7. writeJSON(200, payload)
```

## 4. 错误处理

| 场景 | HTTP | 错误码 |
|------|------|--------|
| credential 不存在 | 404 | `credential_not_found` |
| hours 不是 1/24/168 | 400 | `invalid_hours` |
| DB 查询失败 | 500 | 现有分项 code（`credential_query_failed` / `error_summary_query_failed` / `recent_failures_query_failed` / `quality_scores_query_failed`） |
| DB pool 未配置 | 503 | `db_not_configured` |

## 5. 验收标准（AC）
