## 2. URL 路由设计（vue-router）

```ts
{
  path: '/providers/:id',
  component: () => import('@/views/provider-detail/index.vue'),
  children: [
    { path: '', name: 'provider-overview', component: OverviewTab },
    { path: 'models', name: 'provider-models', component: ModelsTab },
    { path: 'credentials', name: 'provider-credentials', component: CredsTab },
    { path: 'logs', name: 'provider-logs', component: LogsTab },
    { path: 'diag', name: 'provider-diag', component: DiagTab },
    { path: 'probes', name: 'provider-probes', component: ProbeHistoryTab },
    { path: 'quality', name: 'provider-quality', component: QualityTab },
    { path: 'error-detail', name: 'provider-error-detail', component: ErrorDetailTab },
  ],
}
```

## 3. 跳转路径

从 `CredsTab.vue` 表格行：
```vue
<el-button size="small" @click="goErrorDetail(cred.id)">
  {{ t('providerDetail.creds.viewErrorDetail') }}
</el-button>

function goErrorDetail(credId: number) {
  router.push({ name: 'provider-error-detail', query: { cred_id: credId } })
}
```

`ErrorDetailTab.vue` 读 `route.query.cred_id` 作为 `props.credentialId`。
