### 端点 1: 活动趋势
```
GET /api/admin/session-analytics/activity
```

**请求参数**:
- date_from (ISO date, 必填)
- date_to (ISO date, 必填)
- granularity (enum: day/week/month, 可选, 默认auto)
- tenant_id (string, super_admin可选)
- model (string[], 可选)
- provider (string[], 可选)

**响应**:
```json
{
  "granularity": "day",
  "series": [
    {
      "date": "2026-07-01",
      "session_count": 42,
      "request_count": 318,
      "success_count": 305,
      "error_count": 13,
      "total_cost_usd": 12.45,
      "total_tokens": 145000,
      "distinct_users": 28
    }
  ],
  "summary": {
    "total_sessions": 280,
    "total_requests": 2100,
    "avg_daily_sessions": 40,
    "peak_date": "2026-07-01",
    "peak_sessions": 42
  }
}
```

**SQL 示例**:
```sql
SELECT 
    date_trunc('day', ts) AS date,
    COUNT(DISTINCT gw_session_id) AS session_count,
    COUNT(*) AS request_count,
    SUM(CASE WHEN success THEN 1 ELSE 0 END) AS success_count,
    SUM(CASE WHEN NOT success THEN 1 ELSE 0 END) AS error_count,
    SUM(COALESCE(cost_usd, 0)) AS total_cost_usd,
    SUM(COALESCE(prompt_tokens, 0) + COALESCE(completion_tokens, 0)) AS total_tokens,
    COUNT(DISTINCT end_user_id) AS distinct_users
FROM request_logs
WHERE ts >= $1 AND ts < $2
  AND ($3 = '' OR tenant_id = $3)
GROUP BY date_trunc('day', ts)
ORDER BY date ASC
```

**缺日补零**：遍历 date_from 到 date_to，无数据日期插入 0 值记录。

firstHalf := series[:len(series)/2]
secondHalf := series[len(series)/2:]
firstAvg := average(firstHalf)
secondAvg := average(secondHalf)
changePct := (secondAvg - firstAvg) / firstAvg * 100

if math.Abs(changePct) < 5 {

### 端点 3: 延迟趋势
```
GET /api/admin/session-analytics/latency-trend
```

**响应**:
```json
{
  "granularity": "day",
  "series": [
    {
      "date": "2026-07-01",
      "p50_latency_ms": 1200,
      "p90_latency_ms": 3500,
      "p99_latency_ms": 8200,
      "max_latency_ms": 12000,
      "avg_latency_ms": 1800,
      "stream_first_chunk_p50_ms": 450
    }
  ]
}
```

**SQL 百分位**:
```sql
SELECT 
    date_trunc('day', ts) AS date,
    percentile_cont(0.5) WITHIN GROUP (ORDER BY latency_ms) AS p50_latency_ms,
    percentile_cont(0.9) WITHIN GROUP (ORDER BY latency_ms) AS p90_latency_ms,
    percentile_cont(0.99) WITHIN GROUP (ORDER BY latency_ms) AS p99_latency_ms,
    MAX(latency_ms) AS max_latency_ms,
    AVG(latency_ms)::int AS avg_latency_ms,
    percentile_cont(0.5) WITHIN GROUP (ORDER BY stream_first_chunk_ms) AS stream_first_chunk_p50_ms
FROM request_logs
WHERE ts >= $1 AND ts < $2
  AND latency_ms IS NOT NULL
GROUP BY date_trunc('day', ts)
ORDER BY date ASC
```

### 端点 4: 健康趋势
```
GET /api/admin/session-analytics/health-trend
```

**响应**:
```json
{
  "granularity": "day",
  "series": [
    {
      "date": "2026-07-01",
      "avg_health_score": 78.5,
      "grade_distribution": {
        "A": 12, "B": 18, "C": 8, "D": 3, "F": 1
      },
      "outcome_distribution": {
        "completed": 35, "error": 5, "abandoned": 2
      }
    }
  ]
}
```

**SQL**:
```sql
SELECT 
    date_trunc('day', first_request_at) AS date,
    AVG(health_score) AS avg_health_score,
    COUNT(*) FILTER (WHERE health_grade = 'A') AS grade_a,
    COUNT(*) FILTER (WHERE health_grade = 'B') AS grade_b,
    -- ...
    COUNT(*) FILTER (WHERE outcome = 'completed') AS outcome_completed
FROM session_summaries
WHERE first_request_at >= $1 AND first_request_at < $2
  AND health_score IS NOT NULL
GROUP BY date_trunc('day', first_request_at)
ORDER BY date ASC
```
