## 技术实现亮点

### 1. 统一过滤器系统
```go
type analyticsFilters struct {
    dateFrom         time.Time  // 默认 7 天
    dateTo           time.Time
    model            string     // 可选
    provider         string     // 可选
    complianceStatus string     // 可选
    userIntent       string     // 可选
}
```

**校验规则**：
- `date_from > date_to` → 400 错误
- 跨度 > 90 天 → 400 错误
- 日期格式：`2006-01-02`

### 2. 租户隔离三重防线
1. **应用层**：`EffectiveTenantIDAll(r)` 显式过滤
2. **查询层**：`WHERE tenant_id = $n`（非 super_admin）
3. **数据库层**：RLS 策略（已有）

### 3. 长尾合并算法
```go
func mergeLongTail(stats []ModelStats, threshold float64) []ModelStats {
    // 1. 计算总请求数
    // 2. 遍历统计项，计算占比
    // 3. 占比 >= threshold → 保留
    // 4. 占比 < threshold → 合并到"其他"
    // 5. 返回新数组（包含"其他"项）
}
```

**阈值**：2%（0.02）
**效果**：减少图表长尾噪音，提升可读性

### 4. 会话形态分桶语义化
不是任意数值分桶，而是赋予业务语义：

| 桶 | 请求数 | 标签 | 业务含义 |
|----|:------:|------|---------|
| quick | 1-5 | 快速问答 | 轻量交互 |
| standard | 6-20 | 标准对话 | 常规多轮 |
| deep | 21-50 | 深度对话 | 复杂任务 |
| marathon | >50 | 马拉松 | 长任务/潜在异常 |

### 5. 健康分布完整性
**四个维度**：
1. 等级分布（A-F）
2. 结果分类（completed/error/abandoned/unknown）
3. 合规状态（compliant/warning/violation）
4. 延迟分桶（<1s / 1-3s / 3-5s / 5-10s / >10s）

**NULL 处理**：
- `health_grade IS NULL` → 映射为 `"unknown"`
- `AVG(health_score)` 仅计算非 NULL 值
- 空结果返回空 map（不是 nil）

### 6. 性能优化
- **超时**：15s 强制取消
- **范围限制**：最大 90 天
- **索引依赖**：`idx_request_logs_tenant_ts`、`idx_session_summaries_health`
- **查询优化**：使用 CTE + 单次聚合

## SQL 查询示例

### 模型分解查询
```sql
WITH model_agg AS (
    SELECT 
        rl.outbound_model AS model,
        COUNT(*) AS request_count,
        COUNT(DISTINCT rl.gw_session_id) AS session_count,
        COALESCE(SUM(rl.cost_usd), 0) AS total_cost_usd,
        COALESCE(SUM(rl.prompt_tokens + rl.completion_tokens), 0) AS total_tokens,
        COALESCE(AVG(rl.latency_ms), 0) AS avg_latency_ms,
        COUNT(*) FILTER (WHERE rl.request_status != 'success') AS error_count
    FROM request_logs_with_current_month rl
    WHERE rl.ts >= $1 AND rl.ts < $2 AND rl.tenant_id = $3
    GROUP BY rl.outbound_model
)
SELECT 
    model, request_count, session_count, total_cost_usd, total_tokens,
    ROUND(avg_latency_ms)::int AS avg_latency_ms,
    ROUND((error_count::numeric / request_count::numeric), 3) AS error_rate
FROM model_agg
ORDER BY total_cost_usd DESC
```

### 会话形态分桶查询
```sql
SELECT 
    CASE 
        WHEN request_count BETWEEN 1 AND 5 THEN '1-5'
        WHEN request_count BETWEEN 6 AND 20 THEN '6-20'
        WHEN request_count BETWEEN 21 AND 50 THEN '21-50'
        WHEN request_count > 50 THEN '>50'
        ELSE 'unknown'
    END AS range,
    CASE 
        WHEN request_count BETWEEN 1 AND 5 THEN 'quick'
        WHEN request_count BETWEEN 6 AND 20 THEN 'standard'
        WHEN request_count BETWEEN 21 AND 50 THEN 'deep'
        WHEN request_count > 50 THEN 'marathon'
        ELSE 'unknown'
    END AS label,
    COUNT(*) AS count
FROM session_summaries ss
WHERE ss.first_request_at >= $1 AND ss.first_request_at < $2
  AND ss.tenant_id = $3
GROUP BY range, label
ORDER BY CASE range
    WHEN '1-5' THEN 1
    WHEN '6-20' THEN 2
    WHEN '21-50' THEN 3
    WHEN '>50' THEN 4
    ELSE 5
END
```
