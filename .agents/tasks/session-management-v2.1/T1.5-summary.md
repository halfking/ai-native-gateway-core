### 2. 核心功能实现

#### ✅ enrichHealthData() - 批量查询健康数据
- 从 `session_summaries` 表批量查询健康数据
- 使用 `ANY($1)` 避免 N+1 问题
- 查询失败不阻塞主流程

#### ✅ filterByHealthGrade() - 健康等级过滤
- 支持逗号分隔多等级（如 "D,F"）
- 未计算健康分的会话默认保留

#### ✅ sortSessionList() - 多维度排序
支持的排序模式：
- `?sort=health`: status 优先 + health_score DESC
- `?sort=cost`: status 优先 + cost DESC
- `?sort=tokens`: status 优先 + tokens DESC
- `?sort=created_at`: status 优先 + created_at DESC
- **默认**: status 优先 + health_score ASC（低分在前）

状态优先级：`error > waiting > active > stopped > recovered`

# 按健康分排序
GET /api/admin/sessions?sort=health

# 组合使用
GET /api/admin/sessions?status=active&health_grade=D,F&sort=cost
