## 优化建议

### 优先级P0（立即优化）

#### 1. 优化latencies数组内存占用
**当前问题**: 无限制增长，10%采样率仍然会消耗大量内存

**优化方案**:
```go
// 使用固定大小的环形缓冲区
type RingBuffer struct {
    buf  []int64
    size int
    pos  int
}

func NewRingBuffer(size int) *RingBuffer {
    return &RingBuffer{
        buf:  make([]int64, size),
        size: size,
    }
}

func (rb *RingBuffer) Add(val int64) {
    rb.buf[rb.pos] = val
    rb.pos = (rb.pos + 1) % rb.size
}
```

**预期效果**: 内存从9.6MB降到约0.08MB（10000个样本）

#### 2. 减少采样率
**当前**: 10%采样率
**优化**: 1%采样率

**预期效果**: 内存降低90%

#### 3. 使用对象池
