## 🎯 使用流程

### 快速开始 (5分钟)

```bash
# 1. 进入目录
cd web-tests

# 2. 安装依赖
npm install
npx playwright install chromium

# 3. 配置环境
export BASE_URL=http://localhost:8090
export TEST_USERNAME=admin
export TEST_PASSWORD=your_password

# 4. 验证环境
./validate-env.sh

# 5. 运行测试
./run-test.sh
```

### 日常使用

```bash
# 运行测试
./run-test.sh                # 无头模式
./run-test.sh headed         # 可视化模式
./run-test.sh debug          # 调试模式
./run-test.sh ui             # UI 模式

# 查看报告
npm run test:report

# 验证环境
./validate-env.sh
```

### ⚠️ 与 Goal 的差异

当前页面 **不包含** 以下功能（需确认是否为新需求）：

1. **档位标签** (free/basic/standard/premium/enterprise)
   - Goal 中提到但当前页面没有
   - 可能需要开发新功能

2. **按档位筛选**
   - 当前只有多模态筛选
   - 需要关联订阅层级数据

3. **总 Credits 计算**
   - 当前只显示单个模型单价
   - 需要汇总逻辑

4. **固定16个模型**
   - 当前显示所有可用模型
   - 需确认是否要限制数量

**建议**: 如果这些是新需求，需要先开发功能再补充测试用例。
