# 测试用例清单

## 测试套件：租户模型定价页面

**目标页面**: `/tenant/models` (TenantModelsView.vue)

---

## 基础功能测试

### TC-001: 页面加载
- **目的**: 验证页面能够成功加载并显示标题
- **步骤**:
  1. 登录系统
  2. 导航到 `/tenant/models`
  3. 等待页面加载完成
- **期望结果**:
  - 页面标题可见
  - 刷新按钮可见

### TC-002: 模型列表显示
- **目的**: 验证模型列表能够正确显示
- **步骤**:
  1. 加载租户模型页面
  2. 检查页面内容
- **期望结果**:
  - 显示模型卡片或表格
  - 至少显示1个模型（如果有数据）
  - 或显示"空状态"提示（如果无数据）

### TC-003: Input/Output Credits 显示
- **目的**: 验证每个模型显示价格信息
- **步骤**:
  1. 加载模型列表
  2. 检查第一个模型的内容
- **期望结果**:
  - 卡片视图：包含 Input/Output 价格标签
  - 表格视图：包含 Input/Output Credits 列

---

## 交互功能测试

### TC-004: 模型搜索
- **目的**: 验证搜索功能正常工作
- **步骤**:
  1. 记录初始模型数量
  2. 在搜索框输入 "gpt"
  3. 观察结果变化
  4. 清除搜索
  5. 验证恢复初始状态
- **期望结果**:
  - 搜索后模型数量变化
  - 清除后恢复原始数量

### TC-005: 多模态筛选
- **目的**: 验证筛选功能正常工作
- **步骤**:
  1. 记录初始模型数量
  2. 切换筛选选项
  3. 观察结果变化
- **期望结果**:
  - 筛选后显示符合条件的模型
  - 结果数量 >= 0

### TC-006: 数据刷新
- **目的**: 验证刷新按钮功能
- **步骤**:
  1. 记录初始内容
  2. 点击刷新按钮
  3. 等待刷新完成
- **期望结果**:
  - 显示加载状态（如果有）
  - 刷新后仍显示数据

---

## 数据验证测试

### TC-007: Credits 数值格式
- **目的**: 验证价格数值格式正确
- **步骤**:
  1. 提取所有价格单元格
  2. 验证每个数值
- **期望结果**:
  - 所有数值为有效数字
  - 数值 >= 0
  - 不包含 NaN

### TC-008: 模型唯一性
- **目的**: 验证每个模型有唯一标识符
- **步骤**:
  1. 提取所有模型标识符
  2. 检查重复项
- **期望结果**:
  - 所有标识符唯一
  - 无重复模型

### TC-009: Credits 数值合理性
- **目的**: 验证价格数值在合理范围内
- **步骤**:
  1. 检查前5个模型的价格
  2. 验证数值合理性
- **期望结果**:
  - 所有数值 >= 0
  - 所有数值不为 NaN
  - Input/Output 价格都存在

## 响应式布局测试

### TC-010: 多视口适配
- **目的**: 验证页面在不同设备上正常显示
- **步骤**:

  2. 验证内容可见

  4. 验证内容可见
  5. 切换到移动视口 (375x667)
  6. 验证内容可见
- **期望结果**:
  - 所有视口下内容都正常显示
  - 布局适配正确

## 已知限制

### 与 Goal 描述的差异

当前页面**不包含**以下功能（可能需要额外开发）：

1. **档位标签** (free/basic/standard/premium/enterprise)
   - 当前没有显示订阅层级信息
   - 需要关联 `/api/admin/tiers` 数据

2. **按档位筛选**
   - 当前只有多模态筛选和搜索
   - 需要新增档位筛选控件

3. **总 Credits 计算**
   - 当前只显示单个模型的单价
   - 需要新增汇总计算逻辑

4. **固定16个模型**
   - 当前显示所有可用模型（数量可变）
   - 需要明确是否要限制显示数量

---

## 测试数据要求

测试依赖以下数据：

1. **数据库配置**
   - 至少1个已配置的模型
   - 模型包含必需字段：
     - `canonical_name`
     - `credits_per_1m_in`
     - `credits_per_1m_out`

2. **权限配置**
   - 测试账号有访问 `/tenant/models` 权限
   - API 端点 `/api/maas/models` 可访问

3. **预期状态**
   - 服务运行在指定端口（默认 8090）
   - 数据库连接正常
   - 租户配置正确
