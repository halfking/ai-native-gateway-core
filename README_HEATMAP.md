## 🎯 功能亮点

### 1. **一眼识别故障模式**
- 色块热力图：绿色=健康，黄色=降级，红色=故障
- 横向扫描：看单个凭据的时间趋势
- 纵向扫描：对比多个凭据的稳定性
- 点击色块：查看详细错误信息和失败请求

### 2. **灵活的时间粒度**
- 1分钟粒度：精准定位故障时刻
- 5分钟粒度：平衡精度和性能
- 1小时/1天粒度：查看长期趋势
- 自动推荐：根据时间范围智能建议粒度

### 3. **强大的筛选能力**
- 排除自检数据：专注真实流量
- 仅显示异常：快速定位问题凭据
- 按模型筛选：关注特定模型的健康状况

### 4. **实时监控**
- 自动刷新：10/30/60秒周期刷新
- 增量更新：仅加载新数据
- 状态保持：刷新时保持滚动位置和展开状态

### 5. **深度分析**
- 错误分布：每种错误类型的次数
- 延迟统计：平均延迟和P95延迟
- 失败采样：最多10个失败请求ID，可点击跳转详情

## 🚀 使用方法

### 快速启动 (推荐)

```bash
# 一键启动向导
./quick-start.sh

# 按照提示完成：
# 1. 数据库迁移
# 2. 后端构建
# 3. 前端依赖安装
# 4. 启动服务
```

### 手动启动

```bash
# 1. 数据库迁移
psql -h localhost -U postgres -d llm_gateway -f migrations/035_add_heatmap_indexes.sql

# 2. 启动后端
make build
./llm-gateway-go

# 3. 启动前端 (新终端)
cd web
pnpm install
pnpm dev

# 4. 测试API
./test-heatmap-api.sh

# 5. 访问页面
open http://localhost:5173/routing-v2/credentials
```

### 访问热力图

1. 打开浏览器：`http://localhost:5173/routing-v2/credentials`
2. 点击 **`热力图`** Tab
3. 选择时间范围（默认：今天）
4. 选择粒度（默认：自动推荐）
5. 点击 **`刷新`** 加载数据
6. 点击 **`▶`** 展开查看模型详情
7. 点击**色块**查看详细统计

## 🔧 技术特点

### 后端

- **高性能查询**: 3个专用索引，P95响应时间<2s
- **灵活聚合**: PostgreSQL `date_trunc` + `FILTER` + `percentile_cont`
- **租户隔离**: tenant_admin自动过滤
- **错误采样**: 失败请求ID采样，便于追踪

### 前端

- **响应式设计**: 适配桌面和移动端
- **状态持久化**: localStorage保存展开状态
- **智能推荐**: 根据时间范围自动推荐粒度
- **用户体验**: 自动刷新不阻塞、滚动位置保持

### 数据库

- **覆盖索引**: INCLUDE子句避免回表
- **部分索引**: WHERE子句减少索引大小
- **并发创建**: CONCURRENTLY不阻塞写入
