## 使用说明

### 查看对象定义

```bash
# 查看某个对象的定义
cat deploy/sql/objects/indexes/<object_name>.sql
```

### 应用对象

```bash
# 应用单个对象
psql "$DATABASE_URL" -f deploy/sql/objects/indexes/<object_name>.sql

# 应用所有对象（按字母顺序）
for f in deploy/sql/objects/indexes/*.sql; do
  psql "$DATABASE_URL" -f "$f"
done
```

## 维护说明

- **不要手动编辑本目录**：所有更改应在 `sql/objects/indexes/` 进行
- **同步方式**：运行 `bash deploy/sql/sync-objects.sh` 重新同步
- **验证方式**：运行 `bash deploy/sql/verify-migration.sh` 验证完整性
