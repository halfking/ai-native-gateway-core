## 优化目标

## 优化方案

### 1. 检测阈值优化 ✅

**问题分析**：
- 当前敏感词检测：每个词 +2 分，需要 ≥5 分才触发 warn
- 单个敏感词只有 2 分，无法触发警告
- Prompt Injection：+5 分，但需要 ≥8 分才触发 need_approval

**优化方案**：
```go
// 调整后的评分策略：
// 1. 敏感词：每个 +3 分（从 +2 提升）
// 2. Prompt Injection：保持 +5 分
// 3. 降低 warn 阈值：从 ≥5 降到 ≥3
// 4. 降低 need_approval 阈值：从 ≥8 降到 ≥6

// 预期效果：
// - 单个敏感词：3分 → 触发 warn ✅
// - 2个敏感词：6分 → 触发 need_approval ✅
// - 单个 Injection：5分 → 触发 warn ✅
// - Injection + 敏感词：8分 → 触发 need_approval ✅
```
