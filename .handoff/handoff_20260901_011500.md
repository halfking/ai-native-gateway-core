## 二、部署期审计发现并修复的 3 个问题（都已推送 main）

1. **tenant_id 是 text 不是 bigint**（`768698db5`）
   252 PG `request_logs_hot.tenant_id → text`。整数占位符 `COALESCE(tenant_id, -1)` 在全新库上类型报错会 brick 启动。并行会话修了 SQL 镜像（7b748269e），本会话补齐 db.go 的 Go ensure 并加防漂移测试。
2. **蓝绿集群全部实例 traffic-only，bg 块被跳过**（`16068c099`）
   systemd 模板硬编码 `LLM_GATEWAY_RUNTIME_ROLE=traffic-only`，且 252 上无 full-role 实例 → `mvRefresher` 原装配在 `!IsTrafficOnly()` 块内从不执行。已移到块外（只需 DB 可用；`pg_try_advisory_lock` 保证多实例安全，蓝绿重叠窗口也安全）。
3. **PG 拒绝表达式唯一索引做 CONCURRENTLY 刷新**（`ee8a5092d`，632 v1.3）
   SQLSTATE 55000：`REFRESH ... CONCURRENTLY` 不接受 COALESCE 表达式索引。已换成普通列 `_ukey` 索引（GROUP BY 保证 NULL 键单行，唯一性成立），ensure 快速路径同时校验视图 + ukey 存在，旧 `_pkey` 幂等 DROP。
